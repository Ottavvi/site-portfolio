Journey

From the first project to a complete system.

  1. Foundation

    Computer Science

    At university, the foundation in logic, algorithms and data structures that supports everything else.

  2. Practice

    First projects

    Barbershop, task manager and time hub: layout, forms, JavaScript modules and apps that work offline.

  3. Real project

    Pousada Lagoa Azul website

    Three languages, a booking simulator with Pix and a site that builds and deploys itself on every change.

  5. Data

    Spreadsheets and Power BI

    Personal and small-business finance dashboards, generated by code from Excel to Power BI.

  6. Now

    Next step

    Looking for opportunities to work in a team, learn from more experienced people and ship real projects.
