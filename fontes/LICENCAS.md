# Fontes

Hospedadas no próprio site (sem depender do Google Fonts), só com os caracteres latinos.

- `inter-latin.woff2`: Inter, de The Inter Project Authors (https://github.com/rsms/inter)
- `space-grotesk-latin.woff2`: Space Grotesk, de The Space Grotesk Project Authors (https://github.com/floriankarsten/space-grotesk)

As duas usam a SIL Open Font License 1.1 (https://openfontlicense.org), que permite usar e redistribuir.
