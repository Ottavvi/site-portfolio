Prática: padronizar com uma tabela de/para

Aula · 30 min

Crie no Excel duas tabelas (Inserir, Tabela) e dê os nomes Clientes e DePara: 

Clientes                         DePara
Nome           Cidade            Errado        Certo
ana  silva     sao paulo         sao paulo     São Paulo
BRUNO COSTA    S. Paulo          s. paulo      São Paulo
carla dias     rio de janeiro    sp            São Paulo
Davi Lima      SP                rio de janeiro  Rio de Janeiro
               bh                bh            Belo Horizonte

Tarefas

  1. Escreva a função fxPadronizar(texto as nullable text, tabela as table) as nullable text que: tira espaços duplicados, compara sem diferenciar maiúsculas e devolve o "Certo" se achar; se não, devolve o texto em Text.Proper.
  2. Aplique a função na coluna Cidade.
  3. Aplique Text.Proper com espaços limpos na coluna Nome.
  4. Remova as linhas sem nome.
Ver a resposta

Consulta fxPadronizar:

(texto as nullable text, tabela as table) as nullable text =>
let
    Limpo = if texto = null then null
            else Text.Combine(List.Select(Text.Split(Text.Trim(texto), " "), each _ <> ""), " "),
    Chave = if Limpo = null then null else Text.Lower(Limpo),
    Achado = if Chave = null then null
             else Table.SelectRows(tabela, each Text.Lower(Text.Trim([Errado])) = Chave),
    Resultado =
        if Limpo = null then null
        else if Table.RowCount(Achado) > 0 then Achado{0}[Certo]
        else Text.Proper(Limpo)
in
    Resultado

Consulta ClientesLimpos:

let
    DePara = Table.Buffer(Excel.CurrentWorkbook(){[Name = "DePara"]}[Content]),
    Fonte = Excel.CurrentWorkbook(){[Name = "Clientes"]}[Content],
    SemVazios = Table.SelectRows(Fonte, each [Nome] <> null and Text.Trim([Nome]) <> ""),
    Nomes = Table.TransformColumns(SemVazios, {{"Nome", each Text.Proper(fxPadronizar(_, #table({"Errado", "Certo"}, {}))), type text}}),
    Cidades = Table.TransformColumns(Nomes, {{"Cidade", each fxPadronizar(_, DePara), type text}})
in
    Cidades

Table.Buffer guarda a tabela de/para na memória: sem ele, ela poderia ser relida a cada linha. Para os nomes, passar uma tabela vazia (#table) reaproveita a limpeza de espaços da mesma função. Dividir pelo espaço e descartar os pedaços vazios é o jeito de remover espaços duplicados no meio do texto, que o Text.Trim não remove.
