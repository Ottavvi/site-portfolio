Dobragem, desempenho e consultas dinâmicas

Aula · 14 min

Dobragem de consulta

Com fontes como SQL Server, PostgreSQL ou OData, o Power Query tenta traduzir as etapas para a linguagem da fonte (query folding): o filtro vira um WHERE e só as linhas necessárias viajam pela rede. Clique com o botão direito numa etapa e veja se Exibir Consulta Nativa está disponível: se estiver, a dobragem chegou até ali.

  • Coloque primeiro as etapas que dobram: filtrar linhas, escolher colunas, agrupar, mesclar com tabelas da mesma fonte.
  • Etapas como adicionar índice, colunas com funções de texto complexas, Table.Buffer e mesclar com uma tabela do Excel quebram a dobragem. Tudo o que vem depois roda na sua máquina.
  • Filtro de data por parâmetro (each [Data] >= DataInicial) dobra; é o que a atualização incremental do Power BI usa. 
// Mandar um SQL próprio, e ainda permitir que as etapas seguintes dobrem sobre ele
Value.NativeQuery(
    Sql.Database("servidor", "pousada"),
    "SELECT quarto_id, entrada, saida FROM reservas WHERE status = @status",
    [status = "confirmada"],
    [EnableFolding = true]
)

Use parâmetros (@status) em vez de montar o SQL juntando textos: é mais seguro e o banco reaproveita o plano.

Desempenho sem banco

  • Table.Buffer e List.Buffer guardam na memória uma tabela ou lista usada muitas vezes (dentro de um List.Contains numa coluna, por exemplo). Não use em tudo: ele lê a fonte inteira.
  • Em vez de Table.SelectRows com List.Contains numa lista grande, prefira mesclar (Table.NestedJoin ou Table.Join).
  • Ao ler uma pasta, filtre os arquivos (extensão, nome) antes de combinar.
  • Desmarque "Habilitar carregamento" das consultas intermediárias.

Consultas que mudam sozinhas

// Pivotar sem saber quais meses existem, e ordenar as colunas por data
let
    Meses = List.Sort(List.Distinct(Vendas[Mes])),
    Pivotada = Table.Pivot(Vendas, List.Transform(Meses, Text.From), "Mes", "Valor", List.Sum)
in
    Pivotada

// Expandir todas as colunas de uma coluna de tabelas, sejam quais forem
Expandida = Table.ExpandTableColumn(Fonte, "Data", Table.ColumnNames(Fonte{0}[Data]))

Expression.Evaluate roda um texto como código M. É poderoso (fórmulas guardadas numa planilha, por exemplo), mas difícil de depurar: use só quando não houver alternativa.
