Funções, each e _

Aula · 13 min

Funções

let
    ComDesconto = (valor as number, optional percentual as nullable number) as number =>
        let
            p = if percentual = null then 10 else percentual
        in
            valor * (1 - p / 100),
    A = ComDesconto(200),        // 180
    B = ComDesconto(200, 25)     // 150
in
    B

Uma função é um valor como outro qualquer: pode ser guardada numa etapa, passada como argumento ou devolvida por outra função. Os tipos (as number) são opcionais, mas ajudam a pegar erros e documentam a função.

each é uma função

each [Diaria] * 1.1
// é exatamente o mesmo que:
(_) => _[Diaria] * 1.1

each cria uma função de um parâmetro chamado _. Dentro dela, [Diaria] é atalho para _[Diaria]. Por isso funciona em Table.AddColumn (o _ é a linha) e em List.Transform (o _ é o item). 

List.Transform({1, 2, 3}, each _ * 10)               // {10, 20, 30}
Table.SelectRows(Quartos, each [Diaria] > 200)      // linhas com diária > 200
List.Transform({"ana", "bruno"}, Text.Proper)        // passa a função direto, sem each

Quando each não basta

Funções dentro de funções com each brigam pelo _. Dê nomes:

// Para cada pedido, somar os itens cuja categoria está na lista do pedido
Table.AddColumn(Pedidos, "Total", (pedido) =>
    List.Sum(
        Table.SelectRows(Itens, (item) => List.Contains(pedido[Categorias], item[Categoria]))[Valor]
    )
)
