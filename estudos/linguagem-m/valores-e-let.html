Iniciante · Módulo 1 · Os fundamentos

Valores, tipos e let

Aula · 10 min

Toda consulta do Power Query é um programa em M (oficialmente, Power Query Formula Language). Os botões só escrevem M por você. Saber a linguagem permite fazer o que nenhum botão faz e entender, e consertar, o que os botões escreveram.

Uma consulta é uma expressão

Crie uma consulta em branco e abra o Editor Avançado:

let
    Diaria = 320,
    Noites = 3,
    Subtotal = Diaria * Noites,
    Desconto = if Noites >= 7 then 0.1 else 0,
    Total = Subtotal * (1 - Desconto)
in
    Total
  • let define nomes (as etapas), separados por vírgula; in diz qual valor a consulta devolve.
  • Não é uma sequência de comandos: é um conjunto de definições. O M calcula só o que o in precisa, na ordem das dependências (é preguiçoso).
  • Nomes com espaço ou acento usam #"...": #"Linhas Filtradas".
  • Maiúsculas importam: Total e total são nomes diferentes, e text.upper não existe (é Text.Upper).

Tipos primitivos

let
    Numero = 19.9,
    Texto = "Pousada",
    Logico = true,
    Nulo = null,
    Data = #date(2026, 12, 24),
    DataHora = #datetime(2026, 12, 24, 14, 0, 0),
    Duracao = #duration(3, 0, 0, 0),           // 3 dias
    Saida = Data + Duracao,                    // 27/12/2026
    Junto = Texto & " " & Text.From(Numero),   // & junta textos (e listas, e registros)
    Comparacao = "a" = "A"                     // false: = compara, não atribui
in
    Saida

O M não converte tipos sozinho: "Total: " & 10 dá erro. Use Text.From, Number.From, Date.From.

Dica

Para testar uma expressão rápido, troque o que vem depois do in pela etapa que quer ver. Cada etapa também aparece no painel "Etapas Aplicadas": clique nela para ver seu valor.

Teste o que aprendeu

  1. O que o in define numa expressão let?

  2. Qual o resultado de "Total: " & 10 em M?

  3. Como se escreve uma etapa chamada Linhas Filtradas?
