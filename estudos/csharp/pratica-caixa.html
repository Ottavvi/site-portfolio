Prática: caixa de uma lojinha

Aula · 20 min

Crie um projeto com dotnet new console -o Caixa e escreva o programa no Program.cs.

Tarefas

  1. Peça o preço de cada item, um por linha, até o usuário digitar uma linha vazia.
  2. Ignore (com aviso) o que não for número.
  3. Mostre a quantidade de itens e o total em reais (formato R$ 12,50).
  4. Se o total passar de R$ 100, aplique 10% de desconto.
  5. Peça o valor pago e mostre o troco, ou quanto falta.
Ver a resposta 
using System.Globalization;

var br = new CultureInfo("pt-BR");
decimal total = 0;
int itens = 0;

while (true)
{
    Console.Write("Preço (Enter para fechar): ");
    string? linha = Console.ReadLine();
    if (string.IsNullOrWhiteSpace(linha)) break;

    if (decimal.TryParse(linha, NumberStyles.Number, br, out decimal preco))
    {
        total += preco;
        itens++;
    }
    else
    {
        Console.WriteLine("Valor inválido, ignorado.");
    }
}

if (total > 100) total *= 0.9m;
Console.WriteLine($"{itens} itens, total {total.ToString("C", br)}");

Console.Write("Valor pago: ");
decimal.TryParse(Console.ReadLine(), NumberStyles.Number, br, out decimal pago);
decimal troco = pago - total;
Console.WriteLine(troco >= 0
    ? $"Troco: {troco.ToString("C", br)}"
    : $"Faltam {(-troco).ToString("C", br)}");

A CultureInfo("pt-BR") faz o programa aceitar vírgula como separador decimal e formatar com "C" (moeda) no padrão brasileiro, independente do idioma do Windows.
