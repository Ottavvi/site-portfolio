Aula · 14 min

async e await

Operações lentas (internet, disco, banco) devolvem uma Task. Com await, o programa espera o resultado sem travar a thread: 

using System.Net.Http.Json;

var http = new HttpClient();
var cep = await http.GetFromJsonAsync<Cep>("https://viacep.com.br/ws/01001000/json/");
Console.WriteLine($"{cep!.Logradouro}, {cep.Localidade}");

record Cep(string Logradouro, string Localidade, string Uf);

Um método que usa await é marcado com async e devolve Task (ou Task<T>). Para rodar várias ao mesmo tempo: await Task.WhenAll(tarefa1, tarefa2).

Dica

Crie um HttpClient e reaproveite. Criar um novo a cada requisição esgota as conexões do sistema em programas que rodam muito tempo.

Uma API em poucas linhas

dotnet new web -o LojaApi
cd LojaApi
dotnet run
// Program.cs
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

var produtos = new List<Produto> { new(1, "Café", 18.5m) };

app.MapGet("/produtos", () => produtos);
app.MapGet("/produtos/{id:int}", (int id) =>
    produtos.FirstOrDefault(p => p.Id == id) is { } p ? Results.Ok(p) : Results.NotFound());
app.MapPost("/produtos", (Produto novo) =>
{
    produtos.Add(novo);
    return Results.Created($"/produtos/{novo.Id}", novo);
});

app.Run();

record Produto(int Id, string Nome, decimal Preco);

São as Minimal APIs do ASP.NET Core: cada Map... liga um método HTTP e um caminho a uma função. O JSON é lido e escrito sozinho a partir dos records.
