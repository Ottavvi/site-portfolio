O primeiro programa

Aula · 9 min

C# (lê-se "C sharp") é a linguagem principal da plataforma .NET, da Microsoft. É muito usada em sistemas de gestão, bancos, APIs, aplicativos para Windows e até jogos (a Unity usa C#). É tipada: cada variável tem um tipo conhecido antes de rodar, e o compilador avisa os erros antes de o programa chegar ao usuário.

Instalar e criar um projeto

Baixe o SDK do .NET (versão LTS) em dot.net e confira no terminal:

dotnet --version
dotnet new console -o Ola     # cria a pasta Ola com um projeto de console
cd Ola
dotnet run                    # compila e roda

O projeto tem um Ola.csproj (configuração) e um Program.cs. Desde o .NET 6, o arquivo pode ter só as instruções, sem a classe em volta (são as instruções de nível superior): 

// Program.cs
Console.WriteLine("Olá, mundo!");

Console.Write("Seu nome: ");
string? nome = Console.ReadLine();
Console.WriteLine($"Prazer, {nome}!");

O $ antes das aspas faz a interpolação: o que está entre chaves é trocado pelo valor. Toda instrução termina com ;.

Dica

No VS Code, instale a extensão C# Dev Kit: ela completa o código, mostra os erros enquanto você digita e roda o projeto com F5.

Compilado, não interpretado

O dotnet run primeiro compila o código para uma linguagem intermediária e só depois executa. Se houver um erro de tipo (somar texto com número de um jeito que não faz sentido, chamar um método que não existe), o programa nem chega a rodar: o erro aparece com o arquivo e a linha.

  1. Qual comando cria um projeto de console novo?

  2. O que faz o $ em $"Olá, {nome}"?

  3. Quando um erro de tipo aparece em C#?
