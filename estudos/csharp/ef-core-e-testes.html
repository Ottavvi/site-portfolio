Entity Framework Core e testes

Aula · 14 min

O Entity Framework Core é o ORM do .NET: você escreve classes e consultas LINQ, e ele gera o SQL. 

dotnet add package Microsoft.EntityFrameworkCore.Sqlite
dotnet add package Microsoft.EntityFrameworkCore.Design
dotnet tool install --global dotnet-ef
using Microsoft.EntityFrameworkCore;

public class Produto
{
    public int Id { get; set; }
    public string Nome { get; set; } = "";
    public decimal Preco { get; set; }
}

public class LojaDb(DbContextOptions<LojaDb> options) : DbContext(options)
{
    public DbSet<Produto> Produtos => Set<Produto>();
}

// Program.cs
builder.Services.AddDbContext<LojaDb>(o => o.UseSqlite("Data Source=loja.db"));

app.MapGet("/produtos", async (LojaDb db) =>
    await db.Produtos.Where(p => p.Preco < 50).OrderBy(p => p.Nome).ToListAsync());

app.MapPost("/produtos", async (Produto p, LojaDb db) =>
{
    db.Produtos.Add(p);
    await db.SaveChangesAsync();
    return Results.Created($"/produtos/{p.Id}", p);
});
dotnet ef migrations add Inicial   # gera o script de criação das tabelas
dotnet ef database update          # aplica no banco

O LojaDb não é criado com new: ele é registrado em builder.Services e o ASP.NET o injeta como parâmetro onde for pedido. É a injeção de dependência, que também facilita trocar o banco nos testes.

Testes com xUnit

dotnet new xunit -o Loja.Testes
dotnet add Loja.Testes reference Loja
dotnet test
public class ContaTestes
{
    [Fact]
    public void Sacar_mais_que_o_saldo_falha()
    {
        var conta = new Conta("Ana");
        conta.Depositar(100);

        Assert.False(conta.Sacar(150));
        Assert.Equal(100, conta.Saldo);
    }

    [Theory]
    [InlineData(0)]
    [InlineData(-10)]
    public void Deposito_invalido_lanca_erro(decimal valor) =>
        Assert.Throws<ArgumentException>(() => new Conta("Ana").Depositar(valor));
}

Teste o que aprendeu

  1. O que o Entity Framework faz com uma consulta LINQ em db.Produtos?

  2. Para que servem as migrations?

  3. Qual a diferença entre [Fact] e [Theory] no xUnit?
