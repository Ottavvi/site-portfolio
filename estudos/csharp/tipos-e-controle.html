Tipos, if, switch e laços

Aula · 12 min

Os tipos do dia a dia

int quantidade = 3;            // inteiro
decimal preco = 19.90m;         // dinheiro: use decimal (o m no fim é obrigatório)
double distancia = 12.5;        // números científicos, medidas
bool pago = false;
string cliente = "Ana";
DateTime hoje = DateTime.Today;

var total = quantidade * preco; // var: o compilador deduz o tipo (aqui, decimal)

Para dinheiro, use sempre decimal: ele guarda os centavos exatos. O double é rápido, mas 0.1 + 0.2 dá 0.30000000000000004.

Converter texto em número

Console.Write("Idade: ");
if (int.TryParse(Console.ReadLine(), out int idade))
    Console.WriteLine($"Ano que vem você terá {idade + 1}");
else
    Console.WriteLine("Isso não é um número.");

int.Parse quebra o programa se o texto não for número; TryParse devolve true ou false e coloca o resultado no out.

Decisões

if (total > 100) Console.WriteLine("Frete grátis");
else if (total > 50) Console.WriteLine("Frete com desconto");
else Console.WriteLine("Frete normal");

// Expressão switch: devolve um valor
string faixa = idade switch
{
    < 12 => "criança",
    < 18 => "adolescente",
    >= 60 => "idoso",
    _ => "adulto"
};

Repetições

for (int i = 1; i <= 10; i++)
    Console.WriteLine($"7 x {i} = {7 * i}");

string[] frutas = { "maçã", "banana", "uva" };
foreach (string fruta in frutas)
    Console.WriteLine(fruta.ToUpper());

int tentativas = 0;
while (tentativas < 3) tentativas++;
