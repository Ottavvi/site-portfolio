Intermediário · Módulo 2 · Flutter

Widgets e layout

Aula · 14 min

Instale o SDK do Flutter (docs.flutter.dev/get-started) e rode flutter doctor: ele lista o que falta (Android Studio, emulador, Xcode no Mac). Dá para começar rodando no navegador ou no Windows, sem emulador. 

flutter create pousada_app
cd pousada_app
flutter run -d chrome     # ou -d windows, ou um emulador/celular conectado

Tudo é widget

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Pousada',
      theme: ThemeData(colorSchemeSeed: Colors.teal, useMaterial3: true),
      home: Scaffold(
        appBar: AppBar(title: const Text('Quartos')),
        body: ListView(
          padding: const EdgeInsets.all(16),
          children: const [
            CartaoQuarto(nome: 'Standard', diaria: 180),
            CartaoQuarto(nome: 'Suíte Mar', diaria: 320),
          ],
        ),
      ),
    );
  }
}

class CartaoQuarto extends StatelessWidget {
  final String nome;
  final double diaria;
  const CartaoQuarto({super.key, required this.nome, required this.diaria});

  @override
  Widget build(BuildContext context) {
    return Card(
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Row(
          children: [
            const Icon(Icons.bed, size: 32),
            const SizedBox(width: 12),
            Expanded(child: Text(nome, style: Theme.of(context).textTheme.titleMedium)),
            Text('R\$ ${diaria.toStringAsFixed(0)}'),
          ],
        ),
      ),
    );
  }
}
  • A tela é uma árvore de widgets: cada widget configura um pedaço e tem filhos (child ou children).
  • Column empilha, Row põe lado a lado, Expanded ocupa o espaço que sobra, SizedBox dá espaço, Padding afasta das bordas.
  • const nos widgets que não mudam evita reconstruí-los: o Flutter fica mais rápido.
  • Salve o arquivo com o app rodando: o hot reload mostra a mudança em menos de um segundo, sem perder o estado.
Dica

Faixa amarela e preta na tela é overflow: o conteúdo não coube. Normalmente se resolve com Expanded num Row, ou trocando um Column por ListView para rolar.

Teste o que aprendeu

  1. Qual widget põe filhos lado a lado?

  2. Para que serve Expanded dentro de um Row?

  3. O que o hot reload faz?
