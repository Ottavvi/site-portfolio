Prática: carrinho de compras em Dart

Aula · 20 min

Tarefas

No DartPad:

  1. Crie class Item com produto, preço unitário e quantidade, e um getter subtotal.
  2. Crie class Carrinho com uma lista de itens e métodos adicionar(produto, preco) (se já existir, aumenta a quantidade) e remover(produto).
  3. Getter total: acima de R$ 200, 10% de desconto.
  4. Método resumo() que devolve um texto com uma linha por item e o total.
Ver a resposta 
class Item {
  final String produto;
  final double preco;
  int quantidade;
  Item(this.produto, this.preco, [this.quantidade = 1]);
  double get subtotal => preco * quantidade;
}

class Carrinho {
  final _itens = <Item>[];

  void adicionar(String produto, double preco) {
    final existente = _itens.where((i) => i.produto == produto).firstOrNull;
    if (existente != null) {
      existente.quantidade++;
    } else {
      _itens.add(Item(produto, preco));
    }
  }

  void remover(String produto) => _itens.removeWhere((i) => i.produto == produto);

  double get bruto => _itens.fold(0, (soma, i) => soma + i.subtotal);
  double get total => bruto > 200 ? bruto * 0.9 : bruto;

  String resumo() => [
        for (final i in _itens) '${i.quantidade}x ${i.produto}: R\$ ${i.subtotal.toStringAsFixed(2)}',
        'Total: R\$ ${total.toStringAsFixed(2)}${bruto > 200 ? ' (10% off)' : ''}',
      ].join('\n');
}

void main() {
  final c = Carrinho()
    ..adicionar('Café', 18.5)
    ..adicionar('Café', 18.5)
    ..adicionar('Azeite', 45)
    ..adicionar('Vinho', 129.9);
  print(c.resumo());
}

O _ no começo do nome (_itens) torna o campo privado ao arquivo. O .. (cascata) chama vários métodos no mesmo objeto. fold acumula um valor percorrendo a lista.
