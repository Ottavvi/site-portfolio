Ferramentas e o laço do agente

Aula · 14 min

Sozinho, o modelo só escreve texto. Com ferramentas, ele pode pedir que o seu programa faça algo: consultar a disponibilidade dos quartos, buscar um pedido no banco, calcular um frete. Ele não roda nada; ele pede, e o seu código decide e executa.

1. Descrever as ferramentas

Cada ferramenta tem nome, uma descrição (é com ela que o modelo decide quando usar) e um JSON Schema dos parâmetros: 

const tools = [
  {
    name: 'consultar_disponibilidade',
    description: 'Diz quais quartos estão livres num período. Use antes de responder qualquer pergunta sobre vagas.',
    input_schema: {
      type: 'object',
      properties: {
        chegada: { type: 'string', description: 'AAAA-MM-DD' },
        saida: { type: 'string', description: 'AAAA-MM-DD' }
      },
      required: ['chegada', 'saida']
    }
  }
];

2. O modelo pede

Quando quer usar uma ferramenta, a resposta vem com stop_reason: "tool_use" e um bloco tool_use com um id, o nome e os argumentos: 

{
  "stop_reason": "tool_use",
  "content": [
    { "type": "text", "text": "Vou verificar as vagas." },
    { "type": "tool_use", "id": "toolu_01A", "name": "consultar_disponibilidade",
      "input": { "chegada": "2026-12-20", "saida": "2026-12-23" } }
  ]
}

3. Você executa e devolve

O seu código roda a função de verdade e manda o resultado de volta: primeiro a resposta do modelo, inteira, como mensagem assistant; depois uma mensagem user com um bloco tool_result para cada tool_use, com o mesmo id: 

messages.push({ role: 'assistant', content: resposta.content });
messages.push({
  role: 'user',
  content: [{ type: 'tool_result', tool_use_id: 'toolu_01A', content: '{"livres": ["casal", "triplo"]}' }]
});

4. Repetir até terminar

Com o resultado, o modelo pode responder ou pedir outra ferramenta. Esse laço é o que se chama de agente: 

while (true) {
  const resposta = await client.messages.create({ model: 'claude-opus-5-5', max_tokens: 4096, tools, messages });
  if (resposta.stop_reason !== 'tool_use') return resposta; // terminou

  messages.push({ role: 'assistant', content: resposta.content });
  const resultados = [];
  for (const bloco of resposta.content) {
    if (bloco.type !== 'tool_use') continue;
    const saida = await executar(bloco.name, bloco.input);
    resultados.push({ type: 'tool_result', tool_use_id: bloco.id, content: JSON.stringify(saida) });
  }
  messages.push({ role: 'user', content: resultados }); // todos os resultados numa mensagem só
}
  • O modelo pode pedir várias ferramentas de uma vez (vários blocos tool_use). Rode todas e devolva todos os tool_result na mesma mensagem.
  • Se a ferramenta falhar, não esconda: devolva o tool_result com is_error: true e a mensagem de erro. O modelo costuma corrigir os argumentos e tentar de novo.
  • Ponha um limite de voltas no laço. Um agente que entra em ciclo gasta dinheiro sem parar.
Dica

Os SDKs oficiais têm um tool runner que faz esse laço para você: você só escreve as funções das ferramentas. Vale escrever o laço à mão uma vez (como no desafio deste nível) para entender o que ele faz.

Teste o que aprendeu

  1. Quem executa a ferramenta?

  2. Como o tool_result se liga ao pedido certo?

  3. A ferramenta deu erro. O que devolver?
