Saída estruturada e extração de dados

Aula · 12 min

Um dos usos mais valiosos de um LLM num sistema é transformar texto livre em dados: ler a mensagem de WhatsApp "oi, queria um quarto pra 2 de 20 a 23 de dezembro, levo meu cachorro" e devolver campos que o sistema de reservas entende.

Pedir JSON não basta

Pedir "responda em JSON" funciona quase sempre, e quase sempre não serve para produção: às vezes vem um texto antes, uma vírgula sobrando, um campo com outro nome. A saída estruturada resolve: você manda um JSON Schema e a API garante que a resposta segue aquele formato. 

const mensagem = await client.messages.create({
  model: 'claude-opus-5-5',
  max_tokens: 1024,
  system: 'Extraia os dados do pedido de reserva. Use null quando a informação não aparecer.',
  messages: [{ role: 'user', content: textoDoWhatsApp }],
  output_config: {
    format: {
      type: 'json_schema',
      schema: {
        type: 'object',
        properties: {
          hospedes: { type: 'integer' },
          chegada: { type: ['string', 'null'], description: 'AAAA-MM-DD' },
          saida: { type: ['string', 'null'], description: 'AAAA-MM-DD' },
          pet: { type: 'boolean' }
        },
        required: ['hospedes', 'chegada', 'saida', 'pet'],
        additionalProperties: false
      }
    }
  }
});

const texto = mensagem.content.find(b => b.type === 'text').text;
const reserva = JSON.parse(texto); // { hospedes: 2, chegada: "2026-12-20", saida: "2026-12-23", pet: true }

O esquema garante o formato, não a verdade

O JSON vem válido, mas o conteúdo ainda pode estar errado: um ano trocado, uma data de saída antes da chegada. Depois de converter, confira as regras do negócio no seu código, como faria com qualquer dado vindo de fora (a trilha de TypeScript tem um desafio inteiro sobre isso).

Onde isso brilha

  • Classificar: a mensagem é reclamação, dúvida ou pedido de reserva? Qual a urgência?
  • Extrair: dados de notas fiscais, currículos, contratos, e-mails.
  • Resumir com campos: avaliações viram "pontos positivos", "pontos negativos" e "nota".
  • Normalizar: endereços escritos de mil jeitos viram rua, número, cidade e CEP.
Dica

Para volumes grandes que não precisam de resposta na hora (classificar 50 mil avaliações antigas), a API de lotes (Message Batches) processa tudo em segundo plano pela metade do preço.

Teste o que aprendeu

  1. Por que usar saída estruturada em vez de só pedir "responda em JSON"?

  2. Com o esquema, o conteúdo está sempre certo?

  3. O que additionalProperties: false faz no esquema?
