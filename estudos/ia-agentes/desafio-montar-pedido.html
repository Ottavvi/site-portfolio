Desafio: montar o pedido e ler a resposta

Desafio · 18 min

O atendente virtual da pousada vai responder perguntas usando as políticas. Escreva duas funções no formato da Messages API do Claude:

  • montarPedido(pergunta, politicas): devolve o corpo do pedido, com model igual a "claude-opus-5-5", max_tokens (um número maior que zero), um system (texto) que mande responder só com base nas políticas (o texto precisa conter a palavra "políticas") e messages com uma única mensagem de role "user", cujo content tem as políticas entre <politicas> e </politicas> e a pergunta entre <pergunta> e </pergunta>.
  • textoDaResposta(resposta): recebe a resposta da API e devolve o texto. A resposta tem um array content de blocos: junte o text dos blocos de type "text" (ignore os de outros tipos, como "thinking"). Se o stop_reason for "refusal", devolva null. Se for "max_tokens" (a resposta foi cortada), acrescente " […]" no fim.

O que o código precisa ter

  • model, max_tokens e system com a palavra "políticas"
  • Uma mensagem de user com as políticas e a pergunta entre tags
  • textoDaResposta junta só os blocos de texto
  • refusal devolve null e max_tokens marca o corte
Ver uma solução possível 
<script>
  const POLITICAS = 'Check-in a partir das 14h e check-out até as 13h. Pets são bem-vindos.';

  function montarPedido(pergunta, politicas) {
    return {
      model: 'claude-opus-5-5',
      max_tokens: 1024,
      system:
        'Você é o atendente virtual da Pousada Maré Mansa. Responda em português, de forma curta e simpática, ' +
        'usando só as políticas enviadas. Se a resposta não estiver nas políticas, diga que vai confirmar com a recepção.',
      messages: [
        {
          role: 'user',
          content: `<politicas>\n${politicas}\n</politicas>\n\n<pergunta>\n${pergunta}\n</pergunta>`
        }
      ]
    };
  }

  function textoDaResposta(resposta) {
    if (resposta.stop_reason === 'refusal') return null;
    const texto = resposta.content
      .filter(bloco => bloco.type === 'text')
      .map(bloco => bloco.text)
      .join('');
    return resposta.stop_reason === 'max_tokens' ? texto + ' […]' : texto;
  }

  console.log(montarPedido('Posso levar meu cachorro?', POLITICAS));
  console.log(textoDaResposta({
    stop_reason: 'end_turn',
    content: [{ type: 'thinking', thinking: '' }, { type: 'text', text: 'Pode sim! Pets são bem-vindos.' }]
  }));
</script>
