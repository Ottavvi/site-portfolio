Prompts que funcionam

Aula · 12 min

Escrever um prompt é parecido com passar uma tarefa para alguém muito capaz que acabou de chegar na empresa e não sabe nada do seu contexto. Quanto mais claro, melhor o resultado.

1. Diga o objetivo e o porquê

"Resuma este e-mail" é vago. "Resuma este e-mail de um hóspede em até 3 linhas para a recepção decidir se precisa ligar para ele hoje" diz o tamanho, o público e o que importa.

2. Dê o contexto, separado das instruções

Documentos, dados e mensagens vão marcados, para o modelo não confundir o que é instrução com o que é material. Tags no estilo XML funcionam muito bem: 

Responda à pergunta do hóspede usando só as políticas abaixo.
Se a resposta não estiver nas políticas, diga que vai confirmar com a recepção.

<politicas>
Check-in a partir das 14h e check-out até as 13h.
Pets são bem-vindos. Não servimos café da manhã.
</politicas>

<pergunta>
Posso chegar às 11h da manhã?
</pergunta>

3. Mostre exemplos

Um ou dois exemplos de entrada e saída ensinam o formato e o tom melhor que um parágrafo de explicação. Use exemplos variados, para o modelo não copiar um detalhe que só aparecia neles.

4. Peça o formato que você vai usar

Se o resultado vai para um programa, peça JSON com campos definidos (e, no nível intermediário, garanta isso com a saída estruturada). Se vai para uma pessoa, diga o tamanho e o estilo.

5. O prompt de sistema

As APIs separam o prompt de sistema (quem o assistente é, as regras que valem sempre) das mensagens (a conversa). O sistema é escrito por você, desenvolvedor; as mensagens podem ter texto de qualquer pessoa. 

Sistema:  Você é o atendente virtual da Pousada Maré Mansa. Responda em português,
          com frases curtas e simpáticas. Use só as informações da seção <politicas>.
          Nunca confirme reservas: encaminhe para o WhatsApp da recepção.

Usuário:  Tem vaga para o feriado?
Dica

Teste o prompt com casos difíceis, não só com o exemplo feliz: a pergunta fora do assunto, a mensagem em inglês, a pessoa irritada, a que tenta fazer o assistente ignorar as regras. Guarde esses casos numa lista e rode de novo a cada mudança no prompt.

Teste o que aprendeu

  1. Para que servem tags como <politicas>...</politicas> no prompt?

  2. O que vai no prompt de sistema?

  3. Qual o melhor jeito de ensinar um formato de resposta?
