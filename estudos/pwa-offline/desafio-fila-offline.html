Desafio: fila de envio offline

Desafio · 22 min

Escreva criarFila(enviar). enviar(acao) devolve uma Promise que rejeita quando não há conexão. A fila devolvida tem:

  • adicionar(acao) (assíncrona): tenta enviar. Se der certo, pronto. Se falhar ou se já houver ações pendentes (para não passar na frente delas), guarda a ação no fim da fila.
  • sincronizar() (assíncrona): envia as pendentes em ordem; para na primeira que falhar, mantendo ela e as seguintes. Devolve quantas enviou.
  • pendentes(): devolve uma cópia da lista de ações pendentes.

O que o código precisa ter

  • Com conexão, adicionar envia na hora e nada fica pendente
  • Sem conexão, as ações ficam pendentes, em ordem
  • Com a conexão de volta, sincronizar envia tudo em ordem e devolve a quantidade
  • sincronizar para no primeiro erro e mantém o resto
Ver uma solução possível

<script>
  function criarFila(enviar) {
    const fila = [];

    return {
      async adicionar(acao) {
        if (fila.length > 0) {
          fila.push(acao);          // há pendentes: entra no fim, para não passar na frente
          return;
        }
        try {
          await enviar(acao);
        } catch {
          fila.push(acao);
        }
      },

      async sincronizar() {
        let enviadas = 0;
        while (fila.length > 0) {
          try {
            await enviar(fila[0]);
          } catch {
            break;                  // para no primeiro erro, mantendo a ordem
          }
          fila.shift();
          enviadas++;
        }
        return enviadas;
      },

      pendentes() {
        return [...fila];
      }
    };
  }
</script>
