Desafio: estratégias de cache

Desafio · 25 min

Para dar para testar fora de um service worker, as funções recebem o cache e a rede como parâmetros. cache tem match(url) (devolve uma Promise com a resposta ou undefined) e put(url, resposta). rede(url) devolve uma Promise que rejeita quando não há internet.

  • cachePrimeiro(url, cache, rede): devolve o que está no cache. Se não houver, busca na rede, guarda no cache (só se resposta.ok) e devolve.
  • redePrimeiro(url, cache, rede): busca na rede, guarda no cache (só se ok) e devolve. Se a rede falhar, devolve o que estiver no cache para essa url; se não houver, devolve o que estiver em '/offline.html'.

As respostas falsas dos testes são objetos simples com ok e texto, então não precisa de clone() aqui.

O que o código precisa ter

  • cachePrimeiro usa o cache sem ir à rede quando já tem
  • cachePrimeiro busca na rede e guarda quando não tem (só respostas ok)
  • redePrimeiro prefere a rede e atualiza o cache
  • Sem rede, redePrimeiro usa o cache e depois a página offline
Ver uma solução possível 
<script>
  async function cachePrimeiro(url, cache, rede) {
    const guardado = await cache.match(url);
    if (guardado) return guardado;
    const resposta = await rede(url);
    if (resposta.ok) await cache.put(url, resposta);
    return resposta;
  }

  async function redePrimeiro(url, cache, rede) {
    try {
      const resposta = await rede(url);
      if (resposta.ok) await cache.put(url, resposta);
      return resposta;
    } catch {
      return (await cache.match(url)) ?? (await cache.match('/offline.html'));
    }
  }
</script>
