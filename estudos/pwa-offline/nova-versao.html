Avisar que há uma versão nova

Aula · 11 min

Na trilha básica, vimos que uma versão nova do service worker fica em espera até todas as abas antigas fecharem. Num app que a pessoa nunca fecha (um PWA instalado, um painel aberto o dia todo), isso pode levar semanas. O padrão é avisar: "Há uma versão nova. Atualizar?".

Na página: perceber a versão em espera

const registro = await navigator.serviceWorker.register('/sw.js');

function oferecerAtualizacao(trabalhador) {
  aviso.hidden = false;                              // "Nova versão disponível. [Atualizar]"
  botaoAtualizar.onclick = () => trabalhador.postMessage({ tipo: 'PULAR_ESPERA' });
}

// Já havia uma esperando (a pessoa abriu a página depois da atualização)
if (registro.waiting) oferecerAtualizacao(registro.waiting);

// Uma nova começou a instalar agora
registro.addEventListener('updatefound', () => {
  const nova = registro.installing;
  nova.addEventListener('statechange', () => {
    if (nova.state === 'installed' && navigator.serviceWorker.controller) oferecerAtualizacao(nova);
  });
});

// Quando a nova assumir, recarrega uma vez para usar os arquivos novos
let recarregou = false;
navigator.serviceWorker.addEventListener('controllerchange', () => {
  if (recarregou) return;
  recarregou = true;
  location.reload();
});

O navigator.serviceWorker.controller no if separa a primeira instalação (quando ainda não há nenhum service worker controlando a página, e não há nada para "atualizar") de uma atualização de verdade.

No service worker: pular a espera quando pedirem

// sw.js
self.addEventListener('message', evento => {
  if (evento.data?.tipo === 'PULAR_ESPERA') self.skipWaiting();
});

Assim a versão nova só assume quando a pessoa aceita, e a página recarrega logo em seguida: nunca há JavaScript antigo conversando com um service worker novo.

Procurar atualizações

O navegador confere o sw.js a cada navegação e, no máximo, a cada 24 horas. Num app que fica aberto, dá para conferir de tempos em tempos com registro.update(), por exemplo a cada hora ou quando a aba volta a ficar visível.

Dica

Não interrompa a pessoa no meio de uma tarefa recarregando sozinho. Um aviso discreto, com o botão "Atualizar", deixa ela escolher a hora. Se houver um formulário sendo preenchido, espere.

Teste o que aprendeu

  1. Onde fica a versão nova do service worker enquanto espera?

  2. Por que recarregar a página no controllerchange?

  3. Qual a melhor forma de aplicar a atualização?
