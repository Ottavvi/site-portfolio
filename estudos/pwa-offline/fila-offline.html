Ações feitas sem internet

Aula · 12 min

Mostrar páginas offline é metade do trabalho. A outra metade é o que a pessoa faz sem internet: marcar uma tarefa, registrar uma entrega, enviar um formulário. Um app offline de verdade guarda essas ações e envia quando a conexão volta.

Saber se há conexão

<p id="status"></p>
<script>
  function mostrar() {
    const el = document.querySelector('#status');
    el.textContent = navigator.onLine ? '● Conectado' : '○ Sem internet: suas ações serão enviadas depois';
    el.style.color = navigator.onLine ? '#0b7a6f' : '#b45309';
  }
  addEventListener('online', mostrar);
  addEventListener('offline', mostrar);
  mostrar();
</script>
<p>Desligue a rede nas ferramentas de desenvolvedor (aba Rede, "Offline") para ver mudar.</p>
Dica

navigator.onLine só sabe se há uma rede, não se a internet funciona (um Wi-Fi de hotel sem login diz "online"). A verdade é a resposta do fetch: trate a falha dele como o sinal definitivo.

A fila de saída

  1. Ao fazer uma ação, atualize a tela na hora (a pessoa não espera a rede) e tente enviar.
  2. Se o envio falhar por falta de conexão, guarde a ação numa fila persistente (IndexedDB ou localStorage), com um id único.
  3. Quando a conexão voltar (evento online, ou ao abrir o app), envie a fila em ordem. Pare no primeiro erro para não embaralhar a sequência.
  4. Mostre quantas ações estão pendentes: "3 alterações aguardando envio".

O id único permite ao servidor ignorar uma ação que chegou duas vezes (a resposta se perdeu, mas o envio tinha funcionado). Isso se chama idempotência.

Background Sync

Em navegadores com Chromium, o service worker pode pedir para ser acordado quando a conexão voltar, mesmo com o app fechado: 

// na página
const registro = await navigator.serviceWorker.ready;
await registro.sync.register('enviar-fila');

// no service worker
self.addEventListener('sync', evento => {
  if (evento.tag === 'enviar-fila') evento.waitUntil(enviarFilaPendente());
});

Como não existe em todos os navegadores, trate como um extra: a fila também é enviada no evento online e ao abrir o app.

Dica

O app do motorista do Rota Municipal, neste portfólio, funciona assim na zona rural: registra as viagens sem sinal e envia quando a conexão volta.

Teste o que aprendeu

  1. navigator.onLine === true garante que a internet funciona?

  2. Por que enviar a fila em ordem e parar no primeiro erro?

  3. Para que serve o id único de cada ação?
