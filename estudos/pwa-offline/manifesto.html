O manifesto

Aula · 10 min

O manifesto é um arquivo JSON (em geral manifest.webmanifest) ligado no <head> de todas as páginas: 

<link rel="manifest" href="/manifest.webmanifest">
<meta name="theme-color" content="#0b7a6f">
<link rel="apple-touch-icon" href="/icones/icone-180.png">

Um manifesto completo

{
  "name": "Tarefas do Dia",
  "short_name": "Tarefas",
  "description": "Listas, prazos e lembretes, mesmo sem internet.",
  "start_url": "/?origem=app",
  "scope": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#0b7a6f",
  "lang": "pt-BR",
  "icons": [
    { "src": "/icones/icone-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icones/icone-512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/icones/maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
  • name aparece na instalação e na tela de abertura; short_name, embaixo do ícone (até uns 12 caracteres, senão é cortado).
  • start_url: a página que abre ao tocar no ícone. Um parâmetro como ?origem=app ajuda a medir quem usa o app instalado.
  • display: standalone abre sem a barra do navegador, como um app. browser abre como site comum.
  • theme_color pinta a barra do sistema; background_color é o fundo da tela de abertura.
  • icons: pelo menos 192×192 e 512×512 em PNG. O ícone maskable tem margem de segurança, para o Android recortar em círculo ou gota sem cortar o desenho.
Dica

No ícone maskable, o desenho importante deve caber num círculo de 80% do tamanho, no centro. O site maskable.app mostra como ele fica em cada formato.

O botão de instalar

Navegadores com Chromium disparam o evento beforeinstallprompt quando o site pode ser instalado. Guardar esse evento permite mostrar um botão "Instalar app" seu, na hora certa: 

let pedidoDeInstalacao;
window.addEventListener('beforeinstallprompt', evento => {
  evento.preventDefault();         // não mostra a sugestão automática
  pedidoDeInstalacao = evento;
  botaoInstalar.hidden = false;
});

botaoInstalar.addEventListener('click', async () => {
  pedidoDeInstalacao.prompt();
  const { outcome } = await pedidoDeInstalacao.userChoice;   // 'accepted' ou 'dismissed'
  botaoInstalar.hidden = true;
});

No iPhone não existe esse evento: a instalação é pelo botão Compartilhar, opção "Adicionar à Tela de Início". Vale explicar isso para quem usa iOS.
