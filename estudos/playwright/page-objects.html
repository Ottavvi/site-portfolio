Page Objects

Aula · 12 min

Com dezenas de testes, o mesmo page.getByLabel('E-mail').fill(...) aparece em todo lugar. Se o rótulo mudar para "Seu e-mail", são dezenas de arquivos para corrigir. O padrão Page Object resolve: uma classe para cada tela, com métodos que descrevem o que a pessoa faz. Os testes chamam os métodos; os localizadores ficam num lugar só. 

<h1>Entrar</h1>
<form id="login">
  <label for="email">E-mail</label> <input id="email">
  <label for="senha">Senha</label> <input id="senha" type="password">
  <button>Entrar</button>
</form>
<p role="alert" id="msg"></p>
<script>
  document.querySelector('#login').addEventListener('submit', e => {
    e.preventDefault();
    const ok = document.querySelector('#email').value === 'ana@cafe.com' && document.querySelector('#senha').value === 'cafe123';
    document.querySelector('#msg').textContent = ok ? 'Bem-vinda, Ana!' : 'E-mail ou senha incorretos';
  });
</script>

// --- login.spec.js ---
import { test, expect } from '@playwright/test';

class PaginaLogin {
  constructor(page) {
    this.page = page;
    this.email = page.getByLabel('E-mail');
    this.senha = page.getByLabel('Senha');
    this.botao = page.getByRole('button', { name: 'Entrar' });
    this.mensagem = page.getByRole('alert');
  }

  async entrar(email, senha) {
    await this.email.fill(email);
    await this.senha.fill(senha);
    await this.botao.click();
  }
}

test('entra com a senha certa', async ({ page }) => {
  const login = new PaginaLogin(page);
  await login.entrar('ana@cafe.com', 'cafe123');
  await expect(login.mensagem).toHaveText('Bem-vinda, Ana!');
});

test('recusa a senha errada', async ({ page }) => {
  const login = new PaginaLogin(page);
  await login.entrar('ana@cafe.com', '123');
  await expect(login.mensagem).toHaveText('E-mail ou senha incorretos');
});
  • Os métodos descrevem ações da pessoa (entrar, adicionarAoCarrinho), não detalhes da tela (clicarNoBotaoAzul).
  • As verificações ficam nos testes, não dentro da classe: cada teste decide o que conferir.
  • Num projeto, cada classe fica no seu arquivo (tests/paginas/login.js) e é importada pelos testes.

Fixtures

O Playwright permite criar fixtures próprias: em vez de cada teste escrever new PaginaLogin(page), ele recebe a página pronta, como recebe o page: 

// tests/fixtures.js
import { test as base } from '@playwright/test';
import { PaginaLogin } from './paginas/login.js';

export const test = base.extend({
  login: async ({ page }, use) => {
    await page.goto('/entrar');
    await use(new PaginaLogin(page));
  }
});

// num teste:
test('entra', async ({ login }) => {
  await login.entrar('ana@cafe.com', 'cafe123');
});
Dica

Comece sem Page Objects. Quando o mesmo trecho aparecer em três testes, extraia para uma classe. Abstrair cedo demais deixa os testes difíceis de ler.
