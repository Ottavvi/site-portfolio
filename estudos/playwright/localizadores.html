Localizadores

Aula · 11 min

Antes de clicar ou conferir, o teste precisa achar o elemento. O Playwright recomenda achar do jeito que uma pessoa acha: pelo papel e pelo nome que aparece na tela.

  • getByRole('button', { name: 'Enviar' }): o mais recomendado. Papéis comuns: button, link, heading, textbox, checkbox, listitem, img.
  • getByLabel('E-mail'): campos de formulário pelo texto do <label>.
  • getByText('Pedido enviado'): elementos sem papel, pelo texto.
  • getByPlaceholder, getByAltText e getByTestId('carrinho') (pelo atributo data-testid), quando nada acima serve. 
<h1>Contato</h1>
<form>
  <label for="email">E-mail</label>
  <input id="email" type="email">
  <label><input type="checkbox"> Quero receber novidades</label>
  <button type="button" onclick="document.querySelector('#ok').hidden = false">Enviar</button>
</form>
<p id="ok" hidden>Mensagem enviada!</p>

// --- contato.spec.js ---
import { test, expect } from '@playwright/test';

test('envia o contato', async ({ page }) => {
  await page.getByLabel('E-mail').fill('ana@exemplo.com');
  await page.getByRole('checkbox', { name: 'novidades' }).check();
  await page.getByRole('button', { name: 'Enviar' }).click();
  await expect(page.getByText('Mensagem enviada!')).toBeVisible();
  await expect(page.getByLabel('E-mail')).toHaveValue('ana@exemplo.com');
});

Por que não usar #id e .classe

Um teste com page.locator('.btn-primary') quebra quando alguém troca uma classe por motivo de estilo, sem nada ter quebrado de verdade. E não percebe quando o botão perde o texto ou o rótulo some, que é o que importa para quem usa. Localizar por papel e nome deixa o teste resistente a mudanças de visual e, de quebra, confere a acessibilidade: se o teste não acha o botão pelo nome, um leitor de tela também não acha.

Um elemento só

Os localizadores são estritos: se uma ação achar dois elementos, o teste falha em vez de clicar no errado. Para escolher, seja mais específico ou filtre: 

page.getByRole('listitem').filter({ hasText: 'Café' })      // o item da lista que tem "Café"
page.getByRole('listitem').filter({ hasText: 'Café' }).getByRole('button', { name: 'Remover' })
page.getByRole('button', { name: 'Comprar' }).first()         // último recurso
page.getByRole('heading', { name: 'Total', exact: true })     // nome exato, não "Subtotal"
Dica

Por padrão, o name compara um pedaço do texto, sem diferenciar maiúsculas: name: "enviar" acha o botão "Enviar mensagem". Use exact: true quando precisar do texto inteiro.
