Testes de ponta a ponta

Aula · 9 min

Testar na mão (abrir o site, preencher o formulário, ver se deu certo) funciona uma vez. Na décima mudança, ninguém mais refaz todos os caminhos, e um bug escapa. Um teste de ponta a ponta (end-to-end, ou e2e) faz isso automaticamente: abre um navegador de verdade, usa o site como uma pessoa e confere o resultado. O Playwright, da Microsoft, é uma das ferramentas mais usadas para isso, com Chrome, Firefox e Safari.

Num projeto de verdade

npm init playwright@latest     # instala e cria a pasta tests/ e o playwright.config.js
npx playwright test            # roda todos os testes
npx playwright test --ui       # modo visual: vê cada passo e o navegador ao lado
npx playwright codegen localhost:3000   # grava seus cliques e gera o código do teste

A estrutura de um teste

// tests/inicio.spec.js
import { test, expect } from '@playwright/test';

test('a página inicial mostra o título', async ({ page }) => {
  await page.goto('http://localhost:3000/');
  await expect(page.getByRole('heading', { name: 'Loja de Café' })).toBeVisible();
});
  • test(nome, função) define um teste. O nome diz o que é esperado, em linguagem de gente.
  • A função recebe page, uma aba do navegador já aberta.
  • Quase tudo é assíncrono: await em cada ação e verificação.
  • expect(...) confere. Se a condição não for verdade, o teste falha e diz o porquê.

Nesta trilha

O editor tem duas partes: em cima, a página que vai ser testada; depois da linha // --- nome.spec.js ---, o arquivo de teste. Um Playwright em miniatura roda os testes na própria página e mostra o resultado no console. Ele tem as partes mais usadas da API real, então o que você escrever aqui funciona lá (o page.goto não faz nada aqui, porque a página já está aberta). 

<h1>Loja de Café</h1>
<button onclick="this.textContent = 'Obrigado!'">Assinar</button>

// --- inicio.spec.js ---
import { test, expect } from '@playwright/test';

test('mostra o título', async ({ page }) => {
  await expect(page.getByRole('heading', { name: 'Loja de Café' })).toBeVisible();
});

test('agradece ao assinar', async ({ page }) => {
  await page.getByRole('button', { name: 'Assinar' }).click();
  await expect(page.getByRole('button')).toHaveText('Obrigado!');
});
Dica

Quebre um teste de propósito (troque "Obrigado!" por outro texto) para ver como é uma falha. Ler bem a mensagem de erro é metade do trabalho com testes.
