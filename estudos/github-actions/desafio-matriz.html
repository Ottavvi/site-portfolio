Desafio: biblioteca em várias versões

Desafio · 22 min

Escreva o workflow Compatibilidade de uma biblioteca:

  • Roda em pull_request e toda segunda-feira às 6h UTC (schedule com cron).
  • concurrency com um group e cancel-in-progress: true.
  • Job testes com matriz: node 20 e 22; os ubuntu-latest e windows-latest; fail-fast: false. O runs-on vem da matriz.
  • Passos: checkout, setup-node com a versão da matriz e cache: npm, npm ci, npm test e, só se algo falhar, actions/upload-artifact@v4.

O que o código precisa ter

  • Roda em pull_request e às segundas, 6h UTC
  • concurrency com group e cancel-in-progress
  • Matriz com node 20 e 22, ubuntu e windows, sem fail-fast
  • setup-node usa a versão da matriz e cache npm
  • npm ci, npm test e upload-artifact só em falha
Ver uma solução possível 
name: Compatibilidade

on:
  pull_request:
  schedule:
    - cron: '0 6 * * 1'

concurrency:
  group: compatibilidade-${{ github.ref }}
  cancel-in-progress: true

jobs:
  testes:
    strategy:
      fail-fast: false
      matrix:
        node: [20, 22]
        os: [ubuntu-latest, windows-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node }}
          cache: npm
      - run: npm ci
      - run: npm test
      - if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: logs-${{ matrix.os }}-${{ matrix.node }}
          path: logs/
