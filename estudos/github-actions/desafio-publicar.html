Desafio: testar e publicar

Desafio · 22 min

Escreva o workflow Publicar de um app React com Vite:

  • Roda em push na main e pelo botão (workflow_dispatch).
  • permissions no topo: contents: read, pages: write e id-token: write.
  • Job build: checkout, setup-node (22), npm ci, npm test, npm run build e actions/upload-pages-artifact@v3 com path: dist.
  • Job deploy: só depois do build (needs), com environment chamado github-pages, e um passo com actions/deploy-pages@v4.

O que o código precisa ter

  • Roda em push na main e por workflow_dispatch
  • permissions: contents read, pages write, id-token write
  • build testa antes de gerar e envia a pasta dist
  • deploy depende do build, usa o environment github-pages e deploy-pages
Ver uma solução possível 
name: Publicar

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
      - run: npm ci
      - run: npm test
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.publicar.outputs.page_url }}
    steps:
      - id: publicar
        uses: actions/deploy-pages@v4
