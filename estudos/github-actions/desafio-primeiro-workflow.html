Desafio: workflow de verificação

Desafio · 15 min

Escreva o workflow Verificar de um projeto Node:

  • Roda em push na branch main e em todo pull_request.
  • Um job chamado verificar, em ubuntu-latest.
  • Passos: actions/checkout@v4; actions/setup-node@v4 com node-version 22; npm ci; npx prettier --check .; e por último npm test.

O que o código precisa ter

  • O YAML é válido e se chama Verificar
  • Roda em push na main e em pull_request
  • O job verificar roda em ubuntu-latest
  • checkout e setup-node (versão 22) vêm primeiro
  • Depois: npm ci, prettier --check e npm test, nessa ordem
Ver uma solução possível 
name: Verificar

on:
  push:
    branches: [main]
  pull_request:

jobs:
  verificar:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm

      - name: Instalar dependências
        run: npm ci

      - name: Conferir a formatação
        run: npx prettier --check .

      - name: Rodar os testes
        run: npm test
