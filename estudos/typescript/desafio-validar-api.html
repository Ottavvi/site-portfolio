Desafio: validar o que veio da API

Desafio · 25 min

A API de reservas manda JSON que às vezes vem quebrado. Escreva, sem any e sem erros de tipo:

  • interface Reserva com id (número), hospede (texto), noites (número) e quarto do tipo 'casal' | 'triplo'.
  • ehReserva(x: unknown): x is Reserva: confere cada propriedade (inclusive se o quarto é um dos dois valores).
  • lerReservas(json: string): Reserva[]: converte o texto e devolve só as reservas válidas. JSON inválido ou que não seja um array devolve [].
  • agruparPor<T, K extends keyof T>(itens: T[], chave: K): devolve um objeto com uma lista de itens para cada valor da chave, como { casal: [...], triplo: [...] }. Tipe o retorno como Record<string, T[]>.

O que o código precisa ter

  • Sem erros de tipo e sem any
  • ehReserva aceita só reservas completas e com quarto válido
  • lerReservas devolve só as válidas, e [] para JSON ruim
  • lerReservas devolve Reserva[] e agruparPor só aceita chaves que existem
  • agruparPor junta os itens pelo valor da chave
Ver uma solução possível 
interface Reserva {
  id: number;
  hospede: string;
  noites: number;
  quarto: 'casal' | 'triplo';
}

function ehReserva(x: unknown): x is Reserva {
  if (typeof x !== 'object' || x === null) return false;
  const r = x as Record<string, unknown>;
  return (
    typeof r.id === 'number' &&
    typeof r.hospede === 'string' &&
    typeof r.noites === 'number' &&
    (r.quarto === 'casal' || r.quarto === 'triplo')
  );
}

function lerReservas(json: string): Reserva[] {
  let dados: unknown;
  try {
    dados = JSON.parse(json);
  } catch {
    return [];
  }
  return Array.isArray(dados) ? dados.filter(ehReserva) : [];
}

function agruparPor<T, K extends keyof T>(itens: T[], chave: K): Record<string, T[]> {
  const grupos: Record<string, T[]> = {};
  for (const item of itens) {
    const valor = String(item[chave]);
    (grupos[valor] ??= []).push(item);
  }
  return grupos;
}

const texto = '[{"id":1,"hospede":"Ana","noites":2,"quarto":"casal"},{"id":"x"}]';
console.log(lerReservas(texto));
