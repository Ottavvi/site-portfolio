Desafio: tipar o carrinho

Desafio · 18 min

O código do carrinho veio de um projeto em JavaScript e está cheio de erros de tipo. Conserte:

  • Crie a interface Item com nome (texto), preco (número), quantidade (número) e cupom opcional (texto).
  • Tipe subtotal(item: Item): number e total(itens: Item[]): number.
  • Crie type Frete = 'normal' | 'expresso' e use em custoDoFrete(tipo: Frete): number (normal custa 10 e expresso 25).
  • O código deve ficar sem nenhum erro de tipo e sem usar any.

O que o código precisa ter

  • O código não tem erros de tipo
  • Não usa any
  • A interface Item tem cupom opcional
  • total recusa itens errados e devolve number
  • custoDoFrete só aceita 'normal' ou 'expresso'
Ver uma solução possível 
interface Item {
  nome: string;
  preco: number;
  quantidade: number;
  cupom?: string;
}

type Frete = 'normal' | 'expresso';

function subtotal(item: Item): number {
  return item.preco * item.quantidade;
}

function total(itens: Item[]): number {
  return itens.reduce((soma, item) => soma + subtotal(item), 0);
}

function custoDoFrete(tipo: Frete): number {
  return tipo === 'expresso' ? 25 : 10;
}

const carrinho: Item[] = [
  { nome: 'Café', preco: 62.9, quantidade: 2 },
  { nome: 'Caneca', preco: 34.5, quantidade: 1, cupom: 'BEMVINDO' }
];
console.log(total(carrinho) + custoDoFrete('expresso'));
