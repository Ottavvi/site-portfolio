Desafio: o estado da tela

Desafio · 22 min

Modele o estado da tela de pedidos:

  • type Estado: uma união discriminada pela propriedade fase: { fase: 'carregando' }, { fase: 'erro'; mensagem: string } e { fase: 'pronto'; pedidos: string[] }.
  • texto(estado: Estado): string: devolve 'Carregando…', 'Erro: ' + a mensagem, ou 'N pedidos' (com N o tamanho da lista). Use um switch com um default que atribui a never.
  • ultimo<T>(lista: T[]): T | undefined: o último item da lista, mantendo o tipo.
  • Sem erros de tipo e sem any.

O que o código precisa ter

  • O código não tem erros de tipo e não usa any
  • Estado aceita só os três formatos
  • texto devolve o texto de cada fase
  • O switch usa never para não esquecer casos
  • ultimo é genérico e mantém o tipo
Ver uma solução possível 
type Estado =
  | { fase: 'carregando' }
  | { fase: 'erro'; mensagem: string }
  | { fase: 'pronto'; pedidos: string[] };

function texto(estado: Estado): string {
  switch (estado.fase) {
    case 'carregando':
      return 'Carregando…';
    case 'erro':
      return 'Erro: ' + estado.mensagem;
    case 'pronto':
      return estado.pedidos.length + ' pedidos';
    default:
      const naoTratado: never = estado;
      return naoTratado;
  }
}

function ultimo<T>(lista: T[]): T | undefined {
  return lista[lista.length - 1];
}

console.log(texto({ fase: 'pronto', pedidos: ['#1', '#2'] }));
