Os comandos do dia a dia

Aula · 13 min

Rodar e acompanhar

docker run -d --name web -p 8080:80 nginx:1.27   # baixa (se preciso) e roda em segundo plano
docker ps                 # contêineres rodando (-a mostra também os parados)
docker logs -f web        # a saída do contêiner, acompanhando (Ctrl+C sai)
docker exec -it web sh    # abre um terminal dentro do contêiner (exit para sair)
docker stop web           # para
docker start web          # liga de novo
docker rm -f web          # apaga (o -f para antes, se estiver rodando)
docker images             # imagens baixadas
  • -d: roda em segundo plano (detached).
  • --name: um nome para usar nos outros comandos (senão, o Docker inventa um).
  • nginx:1.27: a imagem e a tag (versão). Sem tag, vale latest, que muda sem aviso: em projetos, fixe a versão.

Portas

O contêiner tem a sua própria rede. -p 8080:80 liga a porta 8080 do seu computador à porta 80 do contêiner. Com o comando acima, http://localhost:8080 abre a página do nginx.

Variáveis de ambiente

A configuração vai por variáveis, nunca dentro da imagem:

docker run -d --name banco -p 5432:5432 \
  -e POSTGRES_PASSWORD=senha-local -e POSTGRES_DB=loja \
  postgres:17

Volumes: dados que sobrevivem

Tudo que o contêiner grava some quando ele é apagado. Para guardar dados (o banco) ou usar arquivos do seu computador (o site em desenvolvimento), use volumes: 

# Volume nomeado, gerenciado pelo Docker: os dados do banco sobrevivem a um docker rm
docker run -d --name banco -e POSTGRES_PASSWORD=senha-local \
  -v dados-banco:/var/lib/postgresql/data postgres:17

# Pasta do seu computador montada no contêiner (bind mount): muda aqui, muda lá
docker run -d --name site -p 8080:80 -v "$PWD/site:/usr/share/nginx/html:ro" nginx:1.27

O :ro monta só para leitura. No PowerShell, use ${PWD} no lugar de $PWD.

Dica

Para limpar a bagunça de vez em quando: docker system prune apaga contêineres parados, redes sem uso e imagens sem nome. Com --volumes, apaga também volumes sem uso, inclusive dados de bancos: cuidado.
