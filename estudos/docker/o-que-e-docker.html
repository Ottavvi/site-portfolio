O que é um contêiner

Aula · 9 min

"Na minha máquina funciona" é o problema que o Docker resolve. Uma aplicação depende de uma versão do Node ou do Python, de bibliotecas do sistema, de um banco de dados configurado de um jeito. O Docker empacota tudo isso junto, e o pacote roda igual no seu notebook, no do colega e no servidor.

As três palavras

  • Imagem: o pacote pronto, só de leitura: um sistema mínimo, a linguagem, as dependências e o seu código. É como a receita congelada.
  • Contêiner: uma imagem rodando. Dá para ter vários contêineres da mesma imagem ao mesmo tempo, cada um isolado.
  • Registro: onde as imagens ficam guardadas para baixar. O mais conhecido é o Docker Hub; o GitHub tem o próprio (GHCR).

Contêiner não é máquina virtual

Uma máquina virtual simula um computador inteiro, com sistema operacional próprio: pesa gigabytes e leva minutos para ligar. Um contêiner compartilha o núcleo (kernel) do sistema e isola só o necessário: pesa megabytes e liga em segundos. No Windows e no Mac, o Docker Desktop roda os contêineres dentro de uma pequena máquina Linux (no Windows, pelo WSL 2).

Instalar

Instale o Docker Desktop (docker.com). No Windows, ele pede para ativar o WSL 2 na primeira vez. Depois, no terminal: 

docker --version
docker run hello-world   # baixa uma imagem de teste e roda um contêiner que imprime uma mensagem
Dica

Você não precisa instalar Postgres, Redis ou uma versão específica do Node no computador para testar um projeto: com Docker, cada um vira um contêiner que liga e desliga com um comando, sem bagunçar o sistema.
