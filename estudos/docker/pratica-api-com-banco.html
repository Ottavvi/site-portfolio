Prática: a API e o banco com Compose

Aula · 25 min

Crie uma pasta com este servidor.js e um package.json com a dependência pg (npm init -y e npm install pg): 

// servidor.js
const http = require('http');
const { Pool } = require('pg');
const pool = new Pool({ connectionString: process.env.DATABASE_URL });

http.createServer(async (req, res) => {
  const { rows } = await pool.query('SELECT now() AS agora');
  res.setHeader('content-type', 'application/json');
  res.end(JSON.stringify({ ok: true, banco: rows[0].agora }));
}).listen(3000, () => console.log('API na porta 3000'));
  1. Escreva o Dockerfile (Node 22 slim, dependências antes do código, sem as de desenvolvimento) e o .dockerignore.
  2. Escreva o compose.yaml com os serviços api e banco (Postgres 17 com volume e healthcheck). A senha vem de um .env.
  3. Suba tudo e abra http://localhost:3000: deve aparecer a hora vinda do banco.
  4. Mude uma linha do servidor.js e reconstrua só a API.
Ver a resposta 
# Dockerfile
FROM node:22-slim
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci --omit=dev
COPY . .
ENV NODE_ENV=production
EXPOSE 3000
CMD ["node", "servidor.js"]

# .dockerignore
node_modules
.git
.env

# .env  (fora do Git)
DB_SENHA=senha-local

# compose.yaml
services:
  api:
    build: .
    ports: ["3000:3000"]
    environment:
      DATABASE_URL: postgres://postgres:${DB_SENHA}@banco:5432/loja
    depends_on:
      banco:
        condition: service_healthy
  banco:
    image: postgres:17
    environment:
      POSTGRES_PASSWORD: ${DB_SENHA}
      POSTGRES_DB: loja
    volumes: ["dados:/var/lib/postgresql/data"]
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 5s
      retries: 10
volumes:
  dados:
# 3
docker compose up -d --build
curl http://localhost:3000

# 4
docker compose up -d --build api
