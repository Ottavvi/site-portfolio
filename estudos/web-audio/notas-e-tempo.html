Notas e tempo

Aula · 12 min

De nota para frequência

Na afinação usada hoje, o lá central (A4) vibra a 440 Hz, e cada semitom acima multiplica a frequência por 2^(1/12). Doze semitons dobram a frequência: uma oitava. Numerando as teclas do piano como o padrão MIDI faz (A4 é a 69), a fórmula fica: 

frequência = 440 × 2 ^ ((número MIDI − 69) / 12)
<script>
  const midiParaHz = n => 440 * 2 ** ((n - 69) / 12);
  console.log('A4 (69):', midiParaHz(69));
  console.log('A5 (81):', midiParaHz(81));
  console.log('C4 (60):', midiParaHz(60).toFixed(2));
</script>

Agendar em vez de esperar

Tocar uma melodia com setTimeout parece natural, mas o relógio do JavaScript atrasa quando a página está ocupada e o ritmo sai torto. O jeito certo é agendar cada nota no relógio do áudio, que é preciso: 

<button id="tocar">Tocar escala</button>

<script>
  let ctx;
  const midiParaHz = n => 440 * 2 ** ((n - 69) / 12);

  function nota(midi, inicio, duracao) {
    const osc = new OscillatorNode(ctx, { type: 'triangle', frequency: midiParaHz(midi) });
    const vol = new GainNode(ctx, { gain: 0 });
    osc.connect(vol).connect(ctx.destination);
    vol.gain.setValueAtTime(0, inicio);
    vol.gain.linearRampToValueAtTime(0.25, inicio + 0.01);
    vol.gain.linearRampToValueAtTime(0, inicio + duracao);
    osc.start(inicio);
    osc.stop(inicio + duracao);
  }

  document.querySelector('#tocar').addEventListener('click', () => {
    ctx ??= new AudioContext();
    const escala = [60, 62, 64, 65, 67, 69, 71, 72]; // dó maior
    const agora = ctx.currentTime + 0.05;
    escala.forEach((midi, i) => nota(midi, agora + i * 0.25, 0.22));
  });
</script>

As oito notas são agendadas de uma vez, cada uma no seu instante. O navegador cuida do resto, mesmo que o JavaScript fique ocupado.

Dica

Para sequências longas ou infinitas (um metrônomo, por exemplo), agende só um pouco à frente (uns 100 ms) e vá agendando mais com um timer. É o padrão conhecido como "lookahead scheduler".

Mudar a frequência no tempo

A frequência também é um AudioParam. Uma rampa nela faz sirenes e efeitos de "laser":

<button id="laser">Laser</button>
<script>
  let ctx;
  document.querySelector('#laser').addEventListener('click', () => {
    ctx ??= new AudioContext();
    const t = ctx.currentTime;
    const osc = new OscillatorNode(ctx, { type: 'square' });
    const vol = new GainNode(ctx, { gain: 0.15 });
    osc.frequency.setValueAtTime(1500, t);
    osc.frequency.exponentialRampToValueAtTime(100, t + 0.3);
    osc.connect(vol).connect(ctx.destination);
    osc.start(t);
    osc.stop(t + 0.3);
  });
</script>
