Arquivos, filtros e análise

Aula · 14 min

Tocar um arquivo

Para efeitos curtos (cliques, moedas, alertas), carregue o arquivo uma vez, decodifique e toque quantas vezes quiser com um AudioBufferSourceNode: 

const resposta = await fetch('sons/moeda.mp3');
const buffer = await ctx.decodeAudioData(await resposta.arrayBuffer());

function tocarMoeda() {
  const fonte = new AudioBufferSourceNode(ctx, { buffer });
  fonte.connect(ctx.destination);
  fonte.start();
}

Um AudioBuffer também pode ser criado do zero. Este gera um segundo de ruído branco (valores aleatórios entre −1 e 1), a matéria-prima de sons de vento, chuva e percussão: 

<button id="ruido">Ruído</button>
<label><input id="filtro" type="checkbox" checked> Passar por um filtro passa-baixa</label>

<script>
  let ctx;
  document.querySelector('#ruido').addEventListener('click', () => {
    ctx ??= new AudioContext();
    const buffer = ctx.createBuffer(1, ctx.sampleRate, ctx.sampleRate);
    const amostras = buffer.getChannelData(0);
    for (let i = 0; i < amostras.length; i++) amostras[i] = Math.random() * 2 - 1;

    const fonte = new AudioBufferSourceNode(ctx, { buffer });
    const vol = new GainNode(ctx, { gain: 0.15 });
    let saida = fonte;
    if (document.querySelector('#filtro').checked) {
      saida = saida.connect(new BiquadFilterNode(ctx, { type: 'lowpass', frequency: 600 }));
    }
    saida.connect(vol).connect(ctx.destination);
    fonte.start();
  });
</script>

O BiquadFilterNode corta ou realça faixas de frequência: lowpass deixa passar os graves (som abafado, como do outro lado da parede), highpass os agudos e bandpass uma faixa no meio.

Visualizar com o AnalyserNode

O AnalyserNode não muda o som: ele deixa você espiar a onda ou o espectro a cada quadro, para desenhar visualizadores e medidores de volume: 

<button id="ligar">Ligar</button>
<canvas id="tela" width="300" height="100" style="background:#111;display:block;margin-top:8px"></canvas>

<script>
  document.querySelector('#ligar').addEventListener('click', () => {
    const ctx = new AudioContext();
    const osc = new OscillatorNode(ctx, { type: 'sawtooth', frequency: 110 });
    const analisador = new AnalyserNode(ctx, { fftSize: 1024 });
    const vol = new GainNode(ctx, { gain: 0.05 });
    osc.connect(analisador).connect(vol).connect(ctx.destination);
    osc.start();
    osc.stop(ctx.currentTime + 2);

    const tela = document.querySelector('#tela').getContext('2d');
    const dados = new Uint8Array(analisador.fftSize);
    function desenhar() {
      analisador.getByteTimeDomainData(dados);
      tela.clearRect(0, 0, 300, 100);
      tela.strokeStyle = '#5eead4';
      tela.beginPath();
      dados.forEach((v, i) => tela.lineTo((i / dados.length) * 300, (v / 255) * 100));
      tela.stroke();
      if (ctx.currentTime < 2) requestAnimationFrame(desenhar);
    }
    desenhar();
  });
</script>

Renderizar sem tocar

O OfflineAudioContext processa o som o mais rápido possível, sem enviar para as caixas, e devolve um AudioBuffer. Serve para gerar arquivos, aplicar efeitos em lote e, como no próximo desafio, testar se o som saiu como deveria: 

<script>
  const ctx = new OfflineAudioContext(1, 44100, 44100); // 1 canal, 1 segundo
  const osc = new OscillatorNode(ctx, { frequency: 440 });
  osc.connect(ctx.destination);
  osc.start(0.5);

  ctx.startRendering().then(buffer => {
    const dados = buffer.getChannelData(0);
    const pico = (de, ate) => Math.max(...dados.slice(de * 44100, ate * 44100).map(Math.abs));
    console.log('pico antes de 0,5 s:', pico(0, 0.5));
    console.log('pico depois de 0,5 s:', pico(0.5, 1).toFixed(2));
  });
</script>

  1. Que filtro deixa o som abafado, como do outro lado de uma parede?

  2. O AnalyserNode altera o som que passa por ele?

  3. Para que serve o OfflineAudioContext?
