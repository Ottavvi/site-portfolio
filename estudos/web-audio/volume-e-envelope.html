Volume e envelope

Aula · 10 min

Começar e parar um oscilador de uma vez costuma fazer um estalo: a onda é cortada no meio. A solução é controlar o volume com um GainNode e fazer ele subir e descer suavemente. Esse desenho do volume no tempo se chama envelope.

Parâmetros que mudam no tempo

frequency e gain não são números comuns: são AudioParam, que podem ser programados com precisão de amostra usando o relógio do contexto (ctx.currentTime, em segundos): 

<button id="bip">Bip suave</button>
<button id="seco">Bip seco (com estalo)</button>

<script>
  let ctx;
  function tocar(suave) {
    ctx ??= new AudioContext();
    const agora = ctx.currentTime;
    const osc = new OscillatorNode(ctx, { frequency: 660 });
    const volume = new GainNode(ctx, { gain: 0 });
    osc.connect(volume).connect(ctx.destination);

    if (suave) {
      volume.gain.setValueAtTime(0, agora);
      volume.gain.linearRampToValueAtTime(0.3, agora + 0.02);  // ataque
      volume.gain.linearRampToValueAtTime(0, agora + 0.3);     // queda
    } else {
      volume.gain.setValueAtTime(0.3, agora);
      volume.gain.setValueAtTime(0, agora + 0.3);
    }
    osc.start(agora);
    osc.stop(agora + 0.3);
  }
  document.querySelector('#bip').addEventListener('click', () => tocar(true));
  document.querySelector('#seco').addEventListener('click', () => tocar(false));
</script>
  • setValueAtTime(valor, tempo): muda de uma vez naquele instante.
  • linearRampToValueAtTime(valor, tempo): vai mudando em linha reta até chegar ao valor naquele tempo.
  • exponentialRampToValueAtTime: curva mais natural para volume e frequência (não aceita chegar a 0; use 0.0001).

Um volume geral

Ligue todos os sons num GainNode "mestre" antes da saída. Assim, um controle de volume da página muda tudo de uma vez: 

<label>Volume <input id="vol" type="range" min="0" max="1" step="0.01" value="0.3"></label>
<button id="som">Tocar</button>

<script>
  let ctx, mestre;
  document.querySelector('#som').addEventListener('click', () => {
    if (!ctx) {
      ctx = new AudioContext();
      mestre = new GainNode(ctx, { gain: 0.3 });
      mestre.connect(ctx.destination);
    }
    const osc = new OscillatorNode(ctx, { type: 'triangle', frequency: 523.25 });
    osc.connect(mestre);
    osc.start();
    osc.stop(ctx.currentTime + 0.6);
  });
  document.querySelector('#vol').addEventListener('input', e => {
    mestre?.gain.setTargetAtTime(Number(e.target.value), ctx.currentTime, 0.02);
  });
</script>
Dica

Volume 1 já é bem alto para uma onda quadrada. Valores entre 0.1 e 0.3 são mais confortáveis, principalmente com fone de ouvido.
