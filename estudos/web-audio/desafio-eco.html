Desafio: efeito de eco

Desafio · 22 min

Escreva eco(ctx, entrada, atraso, retorno). Ela recebe um nó de entrada e devolve um nó de saída (um GainNode) com:

  • o som original, sem mudança;
  • uma repetição depois de atraso segundos, com volume retorno;
  • outra depois de 2 × atraso, com volume retorno², e assim por diante (realimentação).

Os testes tocam um único "clique" (uma amostra de valor 1) por dentro do seu eco num OfflineAudioContext e medem o que sai: 1 no começo, 0,5 depois do atraso, 0,25 depois de dois atrasos... Curiosidade: num ciclo de realimentação, o navegador acrescenta um bloco de 128 amostras (cerca de 3 ms) a cada volta, então a segunda repetição sai um pouquinho depois de 2 × atraso. Os testes contam com isso.

O que o código precisa ter

  • eco devolve um nó de áudio
  • O som original passa (pico 1 no começo) e há silêncio antes do primeiro eco
  • Repetições com volume 0,5 e 0,25 depois de 1 e 2 atrasos
Ver uma solução possível 
<button id="ouvir">Ouvir</button>

<script>
  function eco(ctx, entrada, atraso, retorno) {
    const saida = new GainNode(ctx);
    const linha = new DelayNode(ctx, { delayTime: atraso, maxDelayTime: 2 });
    const volta = new GainNode(ctx, { gain: retorno });

    entrada.connect(saida);     // som original
    entrada.connect(linha);
    linha.connect(volta);
    volta.connect(saida);       // cada repetição sai...
    volta.connect(linha);       // ...e volta para ser atrasada de novo
    return saida;
  }

  let ctx;
  document.querySelector('#ouvir').addEventListener('click', () => {
    ctx ??= new AudioContext();
    const t = ctx.currentTime;
    const osc = new OscillatorNode(ctx, { frequency: 520 });
    const env = new GainNode(ctx, { gain: 0 });
    env.gain.linearRampToValueAtTime(0.3, t + 0.01);
    env.gain.linearRampToValueAtTime(0, t + 0.1);
    osc.connect(env);
    eco(ctx, env, 0.2, 0.5).connect(ctx.destination);
    osc.start(t);
    osc.stop(t + 0.1);
  });
</script>
