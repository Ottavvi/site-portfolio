Desafio: som de alarme

Desafio · 25 min

Escreva o som do alarme de um app de cronômetro. As funções recebem o contexto (que pode ser um AudioContext ou um OfflineAudioContext) e o momento de início, em segundos:

  • bip(ctx, inicio): um bip de 880 Hz que começa em inicio, sobe até volume 0,3 em 10 ms, desce até 0 e termina em 0,2 s. O oscilador precisa parar no fim.
  • alarme(ctx, inicio, vezes): toca vezes bips, um a cada 0,4 s (começando em inicio).

Os testes "escutam" o resultado renderizando o som com um OfflineAudioContext: conferem silêncio onde não deve haver som, o volume máximo e a frequência.

O que o código precisa ter

  • bip toca entre inicio e inicio + 0,2 s, com silêncio fora
  • O volume máximo fica perto de 0,3
  • A frequência é 880 Hz
  • alarme toca os bips a cada 0,4 s
Ver uma solução possível 
<button id="testar">Ouvir o alarme</button>

<script>
  function bip(ctx, inicio) {
    const fim = inicio + 0.2;
    const osc = new OscillatorNode(ctx, { frequency: 880 });
    const vol = new GainNode(ctx, { gain: 0 });
    osc.connect(vol).connect(ctx.destination);
    vol.gain.setValueAtTime(0, inicio);
    vol.gain.linearRampToValueAtTime(0.3, inicio + 0.01);
    vol.gain.linearRampToValueAtTime(0, fim);
    osc.start(inicio);
    osc.stop(fim);
  }

  function alarme(ctx, inicio, vezes) {
    for (let i = 0; i < vezes; i++) bip(ctx, inicio + i * 0.4);
  }

  let ctx;
  document.querySelector('#testar').addEventListener('click', () => {
    ctx ??= new AudioContext();
    alarme(ctx, ctx.currentTime + 0.05, 3);
  });
</script>
