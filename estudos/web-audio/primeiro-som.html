O primeiro som

Aula · 9 min

A Web Audio API cria e processa som direto no navegador, sem arquivo nenhum. Ela funciona como um estúdio de cabos: você cria nós (um gerador de som, um controle de volume, um filtro) e conecta um no outro até chegar na saída, que é a caixa de som.

Contexto, oscilador e saída

<button id="tocar">Tocar um lá (440 Hz)</button>

<script>
  let ctx;
  document.querySelector('#tocar').addEventListener('click', () => {
    ctx ??= new AudioContext();               // o "estúdio": cria uma vez só
    const osc = ctx.createOscillator();      // gerador de onda
    osc.frequency.value = 440;               // 440 vibrações por segundo
    osc.connect(ctx.destination);            // liga na caixa de som
    osc.start();
    osc.stop(ctx.currentTime + 0.5);         // para meio segundo depois
  });
</script>
  • AudioContext é o ambiente onde tudo acontece. Crie um só e reaproveite.
  • createOscillator() gera uma onda numa frequência. Quanto maior a frequência, mais agudo.
  • connect liga um nó no próximo. ctx.destination é a saída de som.
  • Um oscilador toca uma vez só: depois do stop, crie outro para tocar de novo.
Dica

Navegadores só deixam a página fazer som depois de uma ação da pessoa (um clique ou uma tecla). Por isso o contexto é criado dentro do clique. Se ele foi criado antes, chame ctx.resume() no clique.

Tipos de onda

A forma da onda muda o timbre. sine é suave, square lembra videogame antigo, sawtooth é áspera e triangle fica entre a senoide e a quadrada: 

<button data-tipo="sine">sine</button>
<button data-tipo="square">square</button>
<button data-tipo="sawtooth">sawtooth</button>
<button data-tipo="triangle">triangle</button>

<script>
  let ctx;
  document.querySelectorAll('button').forEach(botao => {
    botao.addEventListener('click', () => {
      ctx ??= new AudioContext();
      const osc = new OscillatorNode(ctx, { type: botao.dataset.tipo, frequency: 330 });
      const volume = new GainNode(ctx, { gain: 0.2 });
      osc.connect(volume).connect(ctx.destination);
      osc.start();
      osc.stop(ctx.currentTime + 0.4);
    });
  });
</script>

Repare na outra forma de criar nós, com new OscillatorNode(ctx, opções), e no connect encadeado: ele devolve o nó de destino, então dá para seguir ligando.
