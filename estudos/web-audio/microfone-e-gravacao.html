Microfone e gravação

Aula · 11 min

O microfone entra no Web Audio como mais um nó. Como envolve privacidade, o navegador sempre pede permissão, e a página precisa estar em HTTPS (ou localhost). Dentro do editor desta trilha (um iframe), o pedido costuma ser bloqueado, então os exemplos são para testar numa página sua.

Medidor de volume

const fluxo = await navigator.mediaDevices.getUserMedia({ audio: true });
const ctx = new AudioContext();
const microfone = ctx.createMediaStreamSource(fluxo);
const analisador = new AnalyserNode(ctx, { fftSize: 2048 });
microfone.connect(analisador);           // não ligue no destination: faria microfonia

const amostras = new Float32Array(analisador.fftSize);
function medir() {
  analisador.getFloatTimeDomainData(amostras);
  const rms = Math.sqrt(amostras.reduce((soma, a) => soma + a * a, 0) / amostras.length);
  const db = 20 * Math.log10(rms || 1e-8);          // decibéis em relação ao máximo (dBFS)
  barra.style.width = Math.max(0, 100 + db * 2) + '%';
  requestAnimationFrame(medir);
}
medir();

O RMS (raiz da média dos quadrados) é a medida de volume mais comum: considera todas as amostras, não só o pico. Convertido em dBFS, 0 é o máximo possível e o silêncio fica em torno de -60 a -90.

Gravar

O MediaRecorder grava um fluxo de áudio (ou vídeo) num arquivo:

const gravador = new MediaRecorder(fluxo);
const pedacos = [];
gravador.addEventListener('dataavailable', e => pedacos.push(e.data));
gravador.addEventListener('stop', () => {
  const audio = new Blob(pedacos, { type: gravador.mimeType });
  player.src = URL.createObjectURL(audio);         // <audio controls id="player">
});

gravador.start();
setTimeout(() => gravador.stop(), 5000);           // 5 segundos
Dica

Quando terminar, desligue o microfone com fluxo.getTracks().forEach(t => t.stop()). Enquanto ele estiver aberto, o navegador mostra o ícone de gravação, e a pessoa tem razão de desconfiar se ele continuar aceso.

Áudio e privacidade

  • Peça o microfone só quando a pessoa clicar em algo como "Gravar", nunca ao abrir a página.
  • Diga o que acontece com o áudio: fica no aparelho ou vai para um servidor?
  • Gravação de voz é dado pessoal, e voz usada para identificar alguém é dado biométrico (sensível), segundo a LGPD.

  2. O que o RMS mede?
