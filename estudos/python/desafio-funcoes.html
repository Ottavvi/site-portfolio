Desafio: funções da cantina

Desafio · 18 min

A cantina da escola precisa de três funções. Os testes chamam cada uma com vários valores, então use return (não print).

  • troco(pago, total): devolve o troco. Se o valor pago não for suficiente, devolve None.
  • desconto(total, aluno): alunos (aluno=True) têm 10% de desconto; compras a partir de 50 têm mais 5% (sobre o total original). Devolve o total com o desconto, arredondado com 2 casas.
  • contar_vogais(texto): quantas vogais (a, e, i, o, u, maiúsculas ou minúsculas) o texto tem.

O que o código precisa ter

  • troco devolve a diferença, ou None se faltar dinheiro
  • desconto aplica 10% para aluno e 5% a partir de 50
  • contar_vogais conta vogais maiúsculas e minúsculas
Ver uma solução possível 
def troco(pago, total):
    if pago < total:
        return None
    return pago - total


def desconto(total, aluno):
    taxa = 0
    if aluno:
        taxa += 0.10
    if total >= 50:
        taxa += 0.05
    return round(total * (1 - taxa), 2)


def contar_vogais(texto):
    quantidade = 0
    for letra in texto.lower():
        if letra in "aeiou":
            quantidade += 1
    return quantidade


print(troco(20, 12.5))
print(desconto(80, True))
print(contar_vogais("Python"))
