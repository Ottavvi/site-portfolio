Decisões e laços

Aula · 11 min

if, elif e else

Os blocos são marcados pelos dois pontos e pela indentação, sem chaves: 

nota = 6.5

if nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")

Os operadores lógicos são palavras: and, or e not. Comparações podem ser encadeadas, como na matemática: 0 <= nota <= 10.

for: repetir para cada item

O for do Python percorre qualquer sequência: uma lista, as letras de um texto, um intervalo de números: 

frutas = ["maçã", "banana", "uva"]
for fruta in frutas:
    print(fruta.upper())

for i in range(1, 4):
    print(f"Volta {i}")

range(1, 4) gera 1, 2 e 3: o fim não entra. Para ter o índice junto com o item, use enumerate: 

for posicao, fruta in enumerate(["maçã", "banana"], start=1):
    print(posicao, fruta)

while: repetir enquanto

saldo = 100
meses = 0
while saldo < 150:
    saldo = saldo * 1.1
    meses += 1
print(f"{meses} meses até passar de 150 (saldo: {saldo:.2f})")

break sai do laço na hora; continue pula para a próxima volta.

Dica

Se o resultado não aparecer nunca, provavelmente o while não termina. A condição precisa ficar falsa em algum momento.
