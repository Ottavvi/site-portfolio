Funções

Aula · 10 min

Uma função dá nome a um pedaço de código para usar várias vezes. Ela é criada com def e devolve um resultado com return: 

def area_retangulo(largura, altura):
    return largura * altura

print(area_retangulo(3, 4))
print(area_retangulo(10, 2.5))

Uma função sem return devolve None. Imprimir não é devolver: o print mostra na tela, o return entrega o valor para quem chamou usar.

Valores padrão e argumentos com nome

def preco_final(preco, desconto=0, frete=15):
    return preco * (1 - desconto) + frete

print(preco_final(100))
print(preco_final(100, desconto=0.1))
print(preco_final(100, frete=0))

Passar o argumento pelo nome (frete=0) deixa a chamada mais clara e permite pular os que vêm antes.

Documentar e anotar

Um texto logo abaixo do def (a docstring) explica o que a função faz. As anotações de tipo são opcionais e não mudam nada na execução, mas ajudam quem lê e o editor: 

def imc(peso: float, altura: float) -> float:
    """Índice de massa corporal, com uma casa decimal."""
    return round(peso / altura ** 2, 1)

print(imc(70, 1.75))
Dica

** é potência em Python: 2 ** 3 é 8. E // é a divisão inteira: 7 // 2 é 3.
