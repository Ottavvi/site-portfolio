Erros e classes

Aula · 14 min

Tratar erros

Quando algo dá errado, o Python levanta uma exceção. Com try e except, o programa decide o que fazer em vez de parar: 

for texto in ["42", "3,5", "abc"]:
    try:
        numero = float(texto.replace(",", "."))
        print(f"{texto!r} vira {numero}")
    except ValueError:
        print(f"{texto!r} não é um número")

Capture só o tipo de erro que você espera (ValueError, KeyError, FileNotFoundError...). Um except: sem tipo esconde bugs de verdade.

Levantar seus próprios erros

def sacar(saldo, valor):
    if valor <= 0:
        raise ValueError("O valor precisa ser positivo")
    if valor > saldo:
        raise ValueError(f"Saldo insuficiente: faltam {valor - saldo:.2f}")
    return saldo - valor

try:
    sacar(100, 150)
except ValueError as erro:
    print("Não deu:", erro)

Classes

Uma classe junta dados e as funções que mexem neles (os métodos). O __init__ monta o objeto, e self é o próprio objeto: 

class Conta:
    def __init__(self, titular, saldo=0):
        self.titular = titular
        self.saldo = saldo

    def depositar(self, valor):
        self.saldo += valor

    def __str__(self):
        return f"{self.titular}: R$ {self.saldo:.2f}"

conta = Conta("Ana")
conta.depositar(250)
print(conta)

dataclass

Para classes que são principalmente dados, o @dataclass escreve o __init__, a comparação e a exibição para você: 

from dataclasses import dataclass

@dataclass
class Produto:
    nome: str
    preco: float
    estoque: int = 0

cafe = Produto("Café", 62.9, 40)
print(cafe)
print(cafe == Produto("Café", 62.9, 40))
