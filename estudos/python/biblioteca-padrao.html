A biblioteca padrão

Aula · 12 min

Python vem com uma biblioteca padrão enorme ("pilhas incluídas"). Antes de escrever algo do zero, vale procurar se já existe.

collections

from collections import Counter, defaultdict

palavras = "o café e o chá e o pão".split()
contagem = Counter(palavras)
print(contagem.most_common(2))

por_inicial = defaultdict(list)
for p in palavras:
    por_inicial[p[0]].append(p)
print(dict(por_inicial))

Counter conta coisas; defaultdict cria o valor padrão sozinho quando a chave ainda não existe, sem precisar de if chave not in d.

datetime

from datetime import date, datetime, timedelta

hoje = date(2026, 10, 28)
vencimento = hoje + timedelta(days=30)
print(vencimento.isoformat())
print(vencimento.strftime("%d/%m/%Y"))

lido = datetime.strptime("05/11/2026 14:30", "%d/%m/%Y %H:%M")
print(lido.year, lido.hour, (lido.date() - hoje).days, "dias")

strftime formata uma data em texto; strptime faz o contrário, lendo o texto com o formato que você informa.

statistics

import statistics as st

vendas = [120, 135, 98, 160, 410, 142, 130]
print("média:", round(st.mean(vendas), 1))
print("mediana:", st.median(vendas))
print("desvio padrão:", round(st.stdev(vendas), 1))
Dica

Repare que a média (170,7) é puxada pelo 410, enquanto a mediana (135) mostra melhor o dia típico. Para dados com valores extremos, a mediana costuma contar uma história mais honesta.
