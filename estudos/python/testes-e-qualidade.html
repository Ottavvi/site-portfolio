Testes e qualidade

Aula · 12 min

assert

O jeito mais simples de conferir algo: se a condição for falsa, o programa para com AssertionError. 

def desconto(preco, taxa):
    return round(preco * (1 - taxa), 2)

assert desconto(100, 0.1) == 90
assert desconto(59.9, 0) == 59.9
print("tudo certo")

unittest

A biblioteca padrão tem um sistema de testes completo. Cada método que começa com test é um teste, e o resultado diz quais passaram e por que os outros falharam: 

import unittest
import sys

def classificar(nota):
    if not 0 <= nota <= 10:
        raise ValueError("nota fora de 0 a 10")
    return "Aprovado" if nota >= 7 else "Recuperação" if nota >= 5 else "Reprovado"

class TestaClassificar(unittest.TestCase):
    def test_aprovado(self):
        self.assertEqual(classificar(7), "Aprovado")

    def test_recuperacao(self):
        self.assertEqual(classificar(5.5), "Recuperação")

    def test_nota_invalida(self):
        with self.assertRaises(ValueError):
            classificar(11)

    def test_quebrado_de_proposito(self):
        self.assertEqual(classificar(4), "Recuperação")

unittest.main(argv=["x"], exit=False, testRunner=unittest.TextTestRunner(stream=sys.stdout, verbosity=2))

O último teste falha de propósito: veja como a mensagem mostra o valor esperado e o recebido.

pytest

No dia a dia, a maioria dos projetos usa o pytest (pip install pytest), que aceita testes com assert simples, em arquivos test_*.py: 

# test_notas.py
import pytest
from notas import classificar

@pytest.mark.parametrize("nota, esperado", [(7, "Aprovado"), (5, "Recuperação"), (2, "Reprovado")])
def test_classificar(nota, esperado):
    assert classificar(nota) == esperado

# no terminal:  pytest -v

Projeto organizado

  • Ambiente virtual por projeto: python -m venv .venv e ative (.venv\Scripts\activate no Windows). Os pacotes ficam isolados.
  • pip freeze > requirements.txt lista as versões, e pip install -r requirements.txt instala igual em outra máquina.
  • Anotações de tipo (def f(x: int) -> str) e o mypy acham erros antes de rodar.
  • O ruff formata e aponta problemas comuns em milissegundos, como o Prettier e o ESLint fazem no JavaScript.
Dica

Escreva o teste do bug antes de corrigir: ele falha, você corrige, ele passa, e o bug nunca mais volta sem alguém perceber.
