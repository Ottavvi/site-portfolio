Listas, dicionários e compreensões

Aula · 13 min

Listas

Uma lista guarda itens em ordem. Os índices começam em 0, e índices negativos contam do fim:

notas = [7.5, 9, 6, 8.5]
notas.append(10)
print(notas[0], notas[-1])
print(len(notas), sum(notas) / len(notas))
print(sorted(notas, reverse=True))
print(notas[1:3])  # fatia: do índice 1 até antes do 3

Dicionários

Um dicionário liga chaves a valores, como um objeto do JavaScript: 

produto = {"nome": "Café", "preco": 62.9, "estoque": 40}
produto["estoque"] -= 2
produto["categoria"] = "Mercearia"

print(produto["nome"], produto["estoque"])
print(produto.get("desconto", 0))  # valor padrão se a chave não existir

for chave, valor in produto.items():
    print(f"{chave}: {valor}")
Dica

produto["x"] dá KeyError se a chave não existe. produto.get("x") devolve None (ou o padrão que você passar).

Compreensões

Uma compreensão de lista cria uma lista nova a partir de outra, numa linha. É o jeito "pythônico" de fazer o que o map e o filter fazem em JavaScript: 

precos = [10, 25, 40, 8]
com_aumento = [round(p * 1.1, 2) for p in precos]
caros = [p for p in precos if p > 20]
print(com_aumento)
print(caros)

# Também existe para dicionários
estoque = {"café": 40, "chá": 0, "filtro": 120}
disponiveis = {nome: qtd for nome, qtd in estoque.items() if qtd > 0}
print(disponiveis)

Tuplas e conjuntos

A tupla (1, 2) é uma lista que não muda, boa para pares como coordenadas. O conjunto {1, 2} não tem ordem nem repetição, e é ótimo para tirar duplicados: set([1, 1, 2]) vira {1, 2}.
