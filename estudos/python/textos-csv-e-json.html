Textos, CSV e JSON

Aula · 13 min

Métodos de texto

linha = "  Café em grãos;Mercearia;62,90  "
limpa = linha.strip()
partes = limpa.split(";")
print(partes)

nome, categoria, preco = partes
preco = float(preco.replace(",", "."))
print(nome.upper(), categoria.lower(), preco)
print("café" in nome.lower(), nome.startswith("Café"))

Os mais usados: strip (tira espaços das pontas), split (quebra numa lista), join (junta uma lista), replace, lower/upper e startswith.

CSV

Para CSV, use o módulo csv da biblioteca padrão: ele cuida de aspas, vírgulas dentro de campos e outros detalhes. Aqui o texto está numa variável; num programa de verdade, viria de open("arquivo.csv", encoding="utf-8"): 

import csv
import io

texto = """data,descricao,valor
2026-10-01,Mercado,-182.40
2026-10-05,Salário,3500.00
2026-10-07,Farmácia,-45.90"""

leitor = csv.DictReader(io.StringIO(texto))
for linha in leitor:
    valor = float(linha["valor"])
    tipo = "entrada" if valor > 0 else "saída"
    print(f'{linha["data"]} {linha["descricao"]:<10} {valor:>9.2f} ({tipo})')
Dica

Arquivos de bancos brasileiros costumam usar ; como separador e vírgula nos decimais. Use csv.DictReader(arquivo, delimiter=";") e troque a vírgula por ponto antes do float().

JSON

O módulo json converte texto JSON em dicionários e listas (loads) e o contrário (dumps): 

import json

resposta = '{"cidade": "Recife", "temperaturas": [29, 31, 30]}'
dados = json.loads(resposta)
print(dados["cidade"], max(dados["temperaturas"]))

relatorio = {"media": sum(dados["temperaturas"]) / 3, "acima_de_30": True}
print(json.dumps(relatorio, ensure_ascii=False, indent=2))
