Primeiros passos em Python

Aula · 9 min

Python é uma linguagem conhecida por ser fácil de ler. Ela é usada para automatizar tarefas chatas, analisar dados, criar sites e treinar modelos de inteligência artificial. Nesta trilha, o Python roda dentro da página (com o Pyodide): clique em Experimente e o resultado aparece como num terminal. Na primeira vez, ele leva alguns segundos para carregar. 

print("Olá, Python!")
print(2 + 3)
print("Isso", "tem", "várias", "partes")

Variáveis

Em Python, basta dar um nome e usar =. Não há let, const nem ponto e vírgula. Os nomes costumam ser em snake_case (palavras separadas por _): 

nome = "Ana"
idade = 28
altura = 1.65
estuda = True

print(nome, idade, altura, estuda)
print(type(idade), type(altura))

Os tipos básicos são str (texto), int (inteiro), float (decimal), bool (True ou False, com maiúscula) e None (nenhum valor).

f-strings

Com um f antes das aspas, o que estiver entre chaves é calculado e colocado no texto. Depois de :, dá para formatar: 

produto = "café"
preco = 18.5
quantidade = 3

print(f"{quantidade} pacotes de {produto}: R$ {preco * quantidade:.2f}")

Conversões

Texto e número não se misturam sozinhos. int(), float() e str() convertem: 

print("2" + "3")
print(int("2") + int("3"))
print("Total: " + str(10))
Dica

Em Python, a indentação (os espaços no começo da linha) faz parte da linguagem. Ela é que diz o que está dentro de um if ou de uma função. Use sempre 4 espaços.
