Intermediário · Módulo 2 · Ramos e GitHub

Prática: ramo, conflito e merge

Aula · 18 min

Use o repositório teste-git da prática anterior (ou crie um novo com um index.html e um commit).

  1. Crie o ramo titulo-novo e, nele, troque a primeira linha do index.html por <h1>Bem-vindo</h1>. Faça o commit.
  2. Volte para a main e troque a mesma linha por <h1>Olá, visitante</h1>. Faça o commit.
  3. Junte o ramo titulo-novo na main. O que o Git diz?
  4. Resolva deixando <h1>Bem-vindo, visitante</h1> e conclua o merge.
  5. Mostre o histórico com os ramos desenhados e apague o ramo.
Ver a resposta 
# 1
git switch -c titulo-novo
# edite a 1ª linha: <h1>Bem-vindo</h1>
git commit -am "Muda o título para Bem-vindo"

# 2
git switch main
# edite a 1ª linha: <h1>Olá, visitante</h1>
git commit -am "Muda o título para Olá, visitante"

# 3
git merge titulo-novo
# CONFLICT (content): Merge conflict in index.html

# 4
# edite o index.html: apague as marcas e deixe <h1>Bem-vindo, visitante</h1>
git add index.html
git commit -m "Junta os dois títulos"

# 5
git log --oneline --graph
git branch -d titulo-novo

O -a do git commit -am prepara sozinho os arquivos já acompanhados que mudaram. Arquivos novos ainda precisam de git add.
