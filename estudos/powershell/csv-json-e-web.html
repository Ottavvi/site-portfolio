CSV, JSON e APIs

Aula · 12 min

CSV

Import-Csv transforma cada linha num objeto, com uma propriedade por coluna. Tudo o que você viu de pipeline funciona em cima: 

# CSV brasileiro: separador ; e acentos
$vendas = Import-Csv .\vendas.csv -Delimiter ';' -Encoding UTF8

$vendas | Where-Object Vendedor -eq 'Ana' | Select-Object Data, Produto, Valor

# Somar: os valores chegam como texto, e "62,90" precisa virar número
$total = ($vendas | ForEach-Object { [decimal]($_.Valor -replace '\.', '' -replace ',', '.') } |
    Measure-Object -Sum).Sum

# Gravar um resultado
$vendas | Group-Object Vendedor | Select-Object Name, Count |
    Export-Csv .\por-vendedor.csv -Delimiter ';' -NoTypeInformation -Encoding UTF8
Dica

Use -Delimiter ";" e -Encoding UTF8 para o arquivo abrir certo no Excel em português. No 5.1, o -NoTypeInformation evita uma linha estranha "#TYPE" no começo (no 7 ela já não aparece).

JSON

$config = Get-Content .\config.json -Raw -Encoding UTF8 | ConvertFrom-Json
$config.pasta
$config.extensoes += '.webp'
$config | ConvertTo-Json -Depth 5 | Set-Content .\config.json -Encoding UTF8

O -Depth importa: por padrão o ConvertTo-Json só desce 2 níveis e o resto vira texto.

APIs

Invoke-RestMethod chama uma API e já converte o JSON da resposta em objetos:

$cep = Invoke-RestMethod 'https://viacep.com.br/ws/01001000/json/'
"$($cep.logradouro), $($cep.localidade) - $($cep.uf)"

$cotacao = Invoke-RestMethod 'https://economia.awesomeapi.com.br/json/last/USD-BRL'
"Dólar: R$ $($cotacao.USDBRL.bid)"

$( ) dentro de aspas duplas calcula uma expressão: necessário para acessar propriedades ("$cep.uf" sozinho não funciona).
