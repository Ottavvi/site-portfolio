Scripts, parâmetros e erros

Aula · 13 min

O primeiro script

Um script é um arquivo .ps1 com os comandos. Por segurança, o Windows vem bloqueando scripts. Libere os seus (uma vez só, sem precisar de administrador): 

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Com RemoteSigned, scripts criados no seu computador rodam; os baixados da internet precisam ser assinados (ou desbloqueados com Unblock-File, se você confiar neles). 

# relatorio.ps1
param(
    [Parameter(Mandatory)] [string] $Pasta,
    [int] $Dias = 30
)

$limite = (Get-Date).AddDays(-$Dias)
$recentes = Get-ChildItem $Pasta -File | Where-Object LastWriteTime -ge $limite

if ($recentes.Count -eq 0) {
    Write-Host "Nada modificado nos últimos $Dias dias."
} else {
    foreach ($arquivo in $recentes) {
        Write-Host ("{0,-40} {1:dd/MM/yyyy}" -f $arquivo.Name, $arquivo.LastWriteTime)
    }
}
.\relatorio.ps1 -Pasta $HOME\Documents -Dias 7
  • param() no topo declara os parâmetros, com tipo e valor padrão. Mandatory pergunta se faltar.
  • Variáveis começam com $. Dentro de aspas duplas, elas são substituídas: "Olá, $nome". Em aspas simples, não.
  • -f formata: "{0:N2}" -f 1234.5 dá "1.234,50" num Windows em português.
  • Funções: function Converter-Tamanho { param($Bytes) ... }.

Erros

try {
    $dados = Get-Content 'C:\nao-existe.txt' -ErrorAction Stop
} catch {
    Write-Warning "Não deu para ler: $($_.Exception.Message)"
}

Muitos erros do PowerShell não interrompem o script ("não terminais"): o catch só pega os que param a execução. -ErrorAction Stop transforma o erro daquele comando num erro que para, e o catch funciona. Para valer no script inteiro: $ErrorActionPreference = 'Stop' no começo.

Dica

No Windows PowerShell 5.1, salve os scripts como UTF-8 com BOM (no VS Code: clique em "UTF-8" na barra de baixo, Salvar com codificação). Sem o BOM, o 5.1 lê o arquivo na codificação antiga do Windows e "Relatório" vira "RelatÃ³rio". O PowerShell 7 não tem esse problema.
