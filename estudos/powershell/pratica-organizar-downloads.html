Prática: organizar arquivos por tipo

Aula · 25 min

Para não arriscar seus arquivos de verdade, crie uma pasta de teste com arquivos falsos:

$teste = "$HOME\Desktop\TesteOrganizar"
New-Item -ItemType Directory $teste -Force | Out-Null
'nota.txt', 'foto1.jpg', 'foto2.PNG', 'boleto.pdf', 'planilha.xlsx', 'video.mp4', 'sem-extensao' |
    ForEach-Object { New-Item -Path $teste -Name $_ -ItemType File -Force | Out-Null }

Tarefas

Escreva o script organizar.ps1:

  1. Recebe -Pasta (obrigatório) e um parâmetro -Simular (switch).
  2. Usa um mapa de categorias: Imagens (.jpg, .jpeg, .png, .webp), Documentos (.pdf, .txt, .docx), Planilhas (.xlsx, .csv) e Vídeos (.mp4).
  3. Move cada arquivo para a subpasta da categoria (criando se não existir). Arquivos de outros tipos ficam onde estão.
  4. Com -Simular, só mostra o que faria.
  5. No fim, mostra quantos arquivos foram para cada pasta.
Ver a resposta 
# organizar.ps1  (salve como UTF-8 com BOM se usar o PowerShell 5.1)
param(
    [Parameter(Mandatory)] [string] $Pasta,
    [switch] $Simular
)

$categorias = @{
    Imagens    = '.jpg', '.jpeg', '.png', '.webp'
    Documentos = '.pdf', '.txt', '.docx'
    Planilhas  = '.xlsx', '.csv'
    Videos     = '.mp4'
}

$movidos = @{}
foreach ($arquivo in Get-ChildItem $Pasta -File) {
    $categoria = $categorias.Keys | Where-Object { $categorias[$_] -contains $arquivo.Extension.ToLower() }
    if (-not $categoria) { continue }

    $destino = Join-Path $Pasta $categoria
    if ($Simular) {
        Write-Host "Moveria $($arquivo.Name) para $categoria"
    } else {
        New-Item -ItemType Directory $destino -Force | Out-Null
        Move-Item $arquivo.FullName $destino
    }
    $movidos[$categoria] = 1 + $movidos[$categoria]
}

$movidos.GetEnumerator() | Sort-Object Name | ForEach-Object { "{0}: {1}" -f $_.Name, $_.Value }
.\organizar.ps1 -Pasta $HOME\Desktop\TesteOrganizar -Simular
.\organizar.ps1 -Pasta $HOME\Desktop\TesteOrganizar

Resultado: Documentos 2, Imagens 2, Planilhas 1, Videos 1, e sem-extensao fica na raiz. O .ToLower() faz o "foto2.PNG" entrar em Imagens (o -contains não diferencia maiúsculas, mas é bom deixar explícito). [switch] vira verdadeiro só por estar presente na chamada.
