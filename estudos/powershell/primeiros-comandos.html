Cmdlets e ajuda

Aula · 9 min

O PowerShell é o terminal e a linguagem de automação do Windows (e também roda no Linux e no Mac). Com ele, o que você faz clicando (renomear 300 fotos, organizar downloads, gerar um relatório toda segunda) vira um script que roda em segundos. Abra pelo menu Iniciar ("PowerShell") ou no terminal do VS Code.

Verbo-Substantivo

Os comandos se chamam cmdlets e seguem o padrão Verbo-Substantivo, o que ajuda a adivinhar: Get- lê, Set- altera, New- cria, Remove- apaga. 

Get-Location                       # onde estou (atalho: pwd)
Set-Location C:\Users\ana\Desktop  # entrar numa pasta (atalho: cd)
Get-ChildItem                      # listar o conteúdo (atalhos: ls, dir)
New-Item -ItemType Directory Testes
New-Item Testes\nota.txt
Copy-Item Testes\nota.txt Testes\copia.txt
Rename-Item Testes\copia.txt backup.txt
Remove-Item Testes\backup.txt

Os parâmetros começam com hífen (-ItemType). A tecla Tab completa nomes de comandos, parâmetros e caminhos: use sempre.

Descobrir sozinho

Get-Command *-Item*          # todos os comandos com "Item" no nome
Get-Help Copy-Item -Examples  # exemplos de uso
Get-Help Copy-Item -Online    # a documentação no navegador
Update-Help                   # baixa a ajuda completa (rode uma vez, como administrador)
Dica

O PowerShell não pergunta "tem certeza?" na maioria dos comandos. Antes de um Remove-Item ou Move-Item com curinga (*), rode o mesmo comando com -WhatIf: ele mostra o que faria, sem fazer.

5.1 e 7

O Windows já vem com o Windows PowerShell 5.1 (powershell.exe). O PowerShell 7 (pwsh) é a versão nova, que se instala à parte, roda em qualquer sistema e tem recursos como &&, ?? e o operador ternário. Os comandos desta trilha funcionam nos dois, e as diferenças importantes aparecem nas dicas.
