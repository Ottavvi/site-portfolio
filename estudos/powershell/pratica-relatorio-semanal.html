Avançado · Módulo 3 · Automação

Prática: relatório semanal automático

Aula · 30 min

Junte tudo: um script que toda segunda gera um resumo da pasta Documentos.

Tarefas

  1. Escreva resumo-semanal.ps1, que lista os arquivos de Documents (com subpastas) modificados nos últimos 7 dias.
  2. Gere um CSV em Documents\Relatorios com nome que inclua a data (resumo-2026-10-28.csv), com Nome, Pasta, Tamanho em KB e Data de modificação, separado por ; e em UTF-8.
  3. Grave um log com Start-Transcript e trate erros com try/catch.
  4. Agende para toda segunda às 9h e rode uma vez na mão para testar.
Ver a resposta 
# resumo-semanal.ps1
$ErrorActionPreference = 'Stop'
$docs = [Environment]::GetFolderPath('MyDocuments')
$saida = Join-Path $docs 'Relatorios'
New-Item -ItemType Directory $saida -Force | Out-Null
Start-Transcript -Path (Join-Path $saida 'log.txt') -Append

try {
    $limite = (Get-Date).AddDays(-7)
    $arquivos = Get-ChildItem $docs -File -Recurse -ErrorAction SilentlyContinue |
        Where-Object { $_.LastWriteTime -ge $limite -and $_.DirectoryName -ne $saida }

    $arquivo = Join-Path $saida ("resumo-{0:yyyy-MM-dd}.csv" -f (Get-Date))
    $arquivos |
        Select-Object @{ Name = 'Nome'; Expression = { $_.Name } },
                      @{ Name = 'Pasta'; Expression = { $_.DirectoryName } },
                      @{ Name = 'KB'; Expression = { [math]::Round($_.Length / 1KB, 1) } },
                      @{ Name = 'Modificado'; Expression = { $_.LastWriteTime.ToString('dd/MM/yyyy HH:mm') } } |
        Export-Csv $arquivo -Delimiter ';' -NoTypeInformation -Encoding UTF8

    Write-Output "$($arquivos.Count) arquivo(s) no resumo: $arquivo"
} catch {
    Write-Error "Falhou: $($_.Exception.Message)"
} finally {
    Stop-Transcript
}
$acao = New-ScheduledTaskAction -Execute 'powershell.exe' -Argument "-NoProfile -ExecutionPolicy Bypass -File `"$HOME\Scripts\resumo-semanal.ps1`""
$quando = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Monday -At 9am
Register-ScheduledTask -TaskName 'Resumo semanal' -Action $acao -Trigger $quando
Start-ScheduledTask -TaskName 'Resumo semanal'

[Environment]::GetFolderPath('MyDocuments') acha a pasta Documentos mesmo quando ela está no OneDrive. O -ErrorAction SilentlyContinue no Get-ChildItem ignora pastas sem permissão, e o filtro tira os próprios relatórios da lista. A crase (`") escapa as aspas dentro de aspas duplas.
