Aula · 12 min

Seus próprios objetos

Scripts ficam muito mais úteis quando devolvem objetos em vez de texto: aí o resultado pode ser filtrado, ordenado e exportado como qualquer outro. 

$relatorio = foreach ($disco in Get-CimInstance Win32_LogicalDisk -Filter "DriveType = 3") {
    [PSCustomObject]@{
        Disco   = $disco.DeviceID
        LivreGB = [math]::Round($disco.FreeSpace / 1GB, 1)
        Alerta  = ($disco.FreeSpace / $disco.Size) -lt 0.15
    }
}
$relatorio | Where-Object Alerta | Export-Csv alertas.csv -NoTypeInformation -Encoding UTF8

Hashtables e splatting

Comandos com muitos parâmetros ficam ilegíveis numa linha. O splatting passa os parâmetros a partir de uma hashtable, com @ no lugar do $: 

$email = @{
    To         = 'equipe@empresa.com'
    Subject    = 'Relatório semanal'
    Body       = $texto
    Attachments = 'relatorio.csv'
}
Send-MailMessage @email -SmtpServer 'smtp.empresa.com'   # (comando legado, só como exemplo de splatting)

$config = @{ Pasta = "$HOME\Downloads"; Dias = 30 }
$config.Pasta
$config['Dias'] += 7

Em segundo plano

$tarefa = Start-Job { Get-ChildItem C:\ -Recurse -File -ErrorAction SilentlyContinue | Measure-Object Length -Sum }
# ... o terminal continua livre ...
Receive-Job $tarefa -Wait -AutoRemoveJob

Em paralelo (PowerShell 7)

Para muitas operações lentas e independentes (conferir 50 sites, processar 200 arquivos), ForEach-Object -Parallel roda várias ao mesmo tempo: 

$sites = 'https://github.com', 'https://ottavvi.github.io', 'https://www.gov.br'
$sites | ForEach-Object -Parallel {
    $inicio = Get-Date
    try {
        $r = Invoke-WebRequest $_ -Method Head -TimeoutSec 10
        [PSCustomObject]@{ Site = $_; Status = $r.StatusCode; Ms = ((Get-Date) - $inicio).TotalMilliseconds }
    } catch {
        [PSCustomObject]@{ Site = $_; Status = 'ERRO'; Ms = $null }
    }
} -ThrottleLimit 5

Dentro do bloco paralelo, variáveis de fora só entram com $using: ($using:limite), porque cada execução roda isolada.

Dica

Para administrar outros computadores da rede, o PowerShell tem o remoting: Invoke-Command -ComputerName PC01, PC02 -ScriptBlock { Get-Service Spooler } roda o bloco nos dois ao mesmo tempo (exige o WinRM habilitado e permissão de administrador lá).
