O pipeline de objetos

Aula · 11 min

Em outros terminais, o | passa texto de um comando para o outro. No PowerShell, passa objetos, com propriedades. Um arquivo não é uma linha de texto: é um objeto com Name, Length (tamanho em bytes), LastWriteTime, Extension... 

# Ver as propriedades de um objeto
Get-ChildItem | Get-Member -MemberType Property

# Os 5 maiores arquivos da pasta Downloads
Get-ChildItem $HOME\Downloads -File |
    Sort-Object Length -Descending |
    Select-Object -First 5 Name, @{ Name = 'MB'; Expression = { [math]::Round($_.Length / 1MB, 1) } }

O @{ Name = ...; Expression = { ... } } é uma propriedade calculada: uma coluna nova feita na hora. As chaves Name e Expression são sempre em inglês.

  • Where-Object filtra: Where-Object Extension -eq '.pdf' ou Where-Object { $_.Length -gt 10MB }.
  • Sort-Object ordena; Select-Object escolhe propriedades e quantidade (-First, -Last).
  • Measure-Object conta e soma: | Measure-Object Length -Sum.
  • Group-Object agrupa: | Group-Object Extension.
  • Dentro de { }, $_ é o objeto atual do pipeline.

Comparações

Os operadores são palavras: -eq (igual), -ne (diferente), -gt, -lt, -ge, -le, -like (com curinga: -like '*.jpg') e -match (expressão regular). Comparações de texto não diferenciam maiúsculas por padrão; -ceq diferencia. 

# Quantos arquivos de cada tipo há em Documentos, do tipo mais comum para o menos
Get-ChildItem $HOME\Documents -File -Recurse |
    Group-Object Extension |
    Sort-Object Count -Descending |
    Select-Object Count, Name -First 10
Dica

1MB, 1GB e 1KB são números de verdade no PowerShell: $_.Length -gt 50MB funciona como você espera.
