Iniciante · Módulo 1 · Primeiros comandos

Prática: raio-x de uma pasta

Aula · 15 min

Só leitura: nada nesta prática apaga ou move arquivos.

Tarefas

  1. Quantos arquivos há na sua pasta Downloads (sem contar subpastas)?
  2. Quanto eles ocupam ao todo, em MB?
  3. Liste os 10 maiores, com nome e tamanho em MB.
  4. Mostre quantos arquivos há de cada extensão, da mais comum para a menos comum.
  5. Liste os arquivos que não são modificados há mais de 180 dias.
Ver a resposta 
$pasta = "$HOME\Downloads"
$arquivos = Get-ChildItem $pasta -File

# 1
$arquivos.Count

# 2
[math]::Round(($arquivos | Measure-Object Length -Sum).Sum / 1MB, 1)

# 3
$arquivos | Sort-Object Length -Descending | Select-Object -First 10 Name,
    @{ Name = 'MB'; Expression = { [math]::Round($_.Length / 1MB, 1) } }

# 4
$arquivos | Group-Object Extension | Sort-Object Count -Descending | Select-Object Count, Name

# 5
$limite = (Get-Date).AddDays(-180)
$arquivos | Where-Object LastWriteTime -lt $limite | Select-Object Name, LastWriteTime

Guardar a lista numa variável ($arquivos) evita ler o disco de novo a cada pergunta. $arquivos.Count funciona porque o resultado é uma lista de objetos.
