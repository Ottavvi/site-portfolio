Criar tabelas e alterar dados

Aula · 13 min

CREATE TABLE

Criar uma tabela é dizer o nome e o tipo de cada coluna, e as restrições que protegem os dados: 

CREATE TABLE fornecedores (
  id       INTEGER PRIMARY KEY,
  nome     TEXT NOT NULL,
  email    TEXT UNIQUE,
  avaliacao INTEGER CHECK (avaliacao BETWEEN 1 AND 5),
  ativo    INTEGER NOT NULL DEFAULT 1
);

INSERT INTO fornecedores (nome, email, avaliacao) VALUES
  ('Torrefação Serra', 'contato@serra.com', 5),
  ('Cerâmicas Sul', 'vendas@ceramicassul.com', 4);

SELECT * FROM fornecedores;
  • PRIMARY KEY: identifica a linha. Um INTEGER PRIMARY KEY é preenchido sozinho com o próximo número.
  • NOT NULL: a coluna é obrigatória. UNIQUE: não pode repetir.
  • CHECK: uma regra que todo valor precisa cumprir. DEFAULT: o valor quando nada é informado.

Os tipos do SQLite são poucos: INTEGER, REAL, TEXT e BLOB. Datas costumam ir como TEXT ('2026-10-28') e verdadeiro/falso como 0 e 1.

UPDATE e DELETE

UPDATE produtos SET preco = preco * 1.10 WHERE categoria = 'Mercearia';
DELETE FROM produtos WHERE estoque = 0;
SELECT nome, preco, estoque FROM produtos;
Dica

Um UPDATE ou DELETE sem WHERE muda a tabela inteira. Antes de rodar, troque por um SELECT com o mesmo WHERE e veja quais linhas seriam afetadas.

Restrições em ação

Tente quebrar as regras: o banco recusa, e o erro diz qual restrição barrou.

CREATE TABLE fornecedores (id INTEGER PRIMARY KEY, nome TEXT NOT NULL,
  avaliacao INTEGER CHECK (avaliacao BETWEEN 1 AND 5));
INSERT INTO fornecedores (nome, avaliacao) VALUES ('Sem nota boa', 9);

Transações

Algumas mudanças só fazem sentido juntas: tirar do estoque e registrar o item do pedido. Uma transação garante que ou tudo acontece, ou nada: 

BEGIN;
UPDATE produtos SET estoque = estoque - 2 WHERE id = 1;
INSERT INTO itens (pedido_id, produto_id, quantidade, preco) VALUES (9, 1, 2, 62.9);
COMMIT;   -- ou ROLLBACK; para desfazer tudo desde o BEGIN

Teste o que aprendeu

  1. O que faz UPDATE produtos SET preco = 0; (sem WHERE)?

  2. Qual restrição impede dois fornecedores com o mesmo e-mail?

  3. Para que serve uma transação?
