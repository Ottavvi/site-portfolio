Filtrar e ordenar

Aula · 11 min

Quase nunca queremos a tabela inteira. WHERE deixa só as linhas que atendem a uma condição: 

SELECT nome, preco FROM produtos
WHERE preco < 50;

Comparações

Os operadores são =, <> (diferente), <, >, <= e >=. Texto vai entre aspas simples: 

SELECT nome, cidade FROM clientes
WHERE estado = 'PR';

Juntando condições

AND exige as duas, OR aceita qualquer uma. Use parênteses quando misturar os dois: 

SELECT nome, categoria, preco FROM produtos
WHERE categoria = 'Utensílios' AND (preco < 100 OR estoque > 5);

Atalhos úteis

  • IN ('SP', 'PR'): o valor está numa lista.
  • BETWEEN 20 AND 70: entre dois valores, incluindo os dois.
  • LIKE 'Ca%': texto que começa com "Ca". O % vale qualquer sequência; o _, um caractere.
  • IS NULL: a coluna está vazia. = NULL nunca funciona.
SELECT nome FROM produtos WHERE nome LIKE '%café%';
SELECT nome, estado FROM clientes WHERE estado IN ('SP', 'PE');
Dica

No SQLite, LIKE ignora maiúsculas e minúsculas, mas só nas letras sem acento.

Ordenar e limitar

ORDER BY ordena (ASC crescente, o padrão, ou DESC decrescente). LIMIT corta o resultado. Juntos, respondem perguntas como "os 3 mais caros": 

SELECT nome, preco FROM produtos
ORDER BY preco DESC
LIMIT 3;

A ordem das partes é sempre a mesma: SELECT, FROM, WHERE, ORDER BY, LIMIT.

Dica

Sem ORDER BY, o banco não promete ordem nenhuma. Se a ordem importa, peça.
