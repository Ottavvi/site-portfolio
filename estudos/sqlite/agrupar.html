Contar, somar e agrupar

Aula · 12 min

As funções de agregação transformam várias linhas num número só:

  • COUNT(*): quantas linhas.
  • SUM(coluna) e AVG(coluna): soma e média.
  • MIN(coluna) e MAX(coluna): menor e maior.
SELECT COUNT(*) AS produtos,
       ROUND(AVG(preco), 2) AS preco_medio,
       MAX(preco) AS mais_caro
FROM produtos;

GROUP BY: uma linha por grupo

Com GROUP BY, a agregação é feita para cada grupo. "Quantos produtos e qual o preço médio de cada categoria?": 

SELECT categoria, COUNT(*) AS quantidade, ROUND(AVG(preco), 2) AS preco_medio
FROM produtos
GROUP BY categoria
ORDER BY quantidade DESC;

A regra: toda coluna no SELECT ou está no GROUP BY, ou está dentro de uma função de agregação. (O SQLite até aceita fugir disso, mas devolve um valor qualquer do grupo. Outros bancos dão erro.)

HAVING: filtrar grupos

WHERE filtra as linhas antes de agrupar. HAVING filtra os grupos depois, e por isso pode usar as agregações: 

-- Estados com mais de um cliente
SELECT estado, COUNT(*) AS clientes
FROM clientes
GROUP BY estado
HAVING COUNT(*) > 1;

Agrupar por parte de uma data

Datas no SQLite costumam ser texto no formato AAAA-MM-DD. A função strftime extrai pedaços, como o mês: 

SELECT strftime('%Y-%m', data) AS mes, COUNT(*) AS pedidos
FROM pedidos
WHERE status <> 'cancelado'
GROUP BY mes
ORDER BY mes;
Dica

Guardar datas como AAAA-MM-DD é o que faz a ordenação e as comparações funcionarem: nesse formato, a ordem alfabética é a mesma da ordem no tempo.
