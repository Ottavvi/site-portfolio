Juntar tabelas com JOIN

Aula · 13 min

Os dados ficam em tabelas separadas para não repetir informação: o pedido guarda só o cliente_id, não o nome e a cidade do cliente. Essa coluna que aponta para o id de outra tabela se chama chave estrangeira. Para ver tudo junto, usamos JOIN.

INNER JOIN

SELECT pedidos.id, pedidos.data, clientes.nome
FROM pedidos
JOIN clientes ON clientes.id = pedidos.cliente_id
ORDER BY pedidos.data;

O ON diz como as linhas se ligam. JOIN sozinho é o mesmo que INNER JOIN: só aparecem as combinações que existem dos dois lados.

Apelidos

Dar um apelido curto a cada tabela deixa a consulta legível, principalmente quando são várias:

SELECT p.id AS pedido, c.nome AS cliente, pr.nome AS produto, i.quantidade, i.preco
FROM itens i
JOIN pedidos p   ON p.id = i.pedido_id
JOIN clientes c  ON c.id = p.cliente_id
JOIN produtos pr ON pr.id = i.produto_id
ORDER BY p.id;

LEFT JOIN: incluir quem não tem par

Quais clientes nunca compraram? Com INNER JOIN, eles somem do resultado. O LEFT JOIN mantém todas as linhas da tabela da esquerda e preenche com NULL quando não há par: 

SELECT c.nome, p.id AS pedido
FROM clientes c
LEFT JOIN pedidos p ON p.cliente_id = c.id
WHERE p.id IS NULL;

JOIN com GROUP BY

Juntar e depois agrupar responde as perguntas mais comuns de relatório, como o total gasto por cliente: 

SELECT c.nome, ROUND(SUM(i.quantidade * i.preco), 2) AS total
FROM clientes c
JOIN pedidos p ON p.cliente_id = c.id
JOIN itens i   ON i.pedido_id = p.id
WHERE p.status <> 'cancelado'
GROUP BY c.id, c.nome
ORDER BY total DESC;
Dica

Esquecer o ON (ou errar a coluna) combina cada linha de uma tabela com todas da outra. Se o resultado ficou enorme de repente, confira os ON.

Teste o que aprendeu

  1. O que é uma chave estrangeira?

  2. Qual JOIN mostra também os clientes sem nenhum pedido?

  3. Num LEFT JOIN, o que aparece nas colunas da direita quando não há par?
