Bancos, tabelas e SELECT

Aula · 9 min

Um banco de dados relacional guarda informações em tabelas, parecidas com planilhas: cada coluna tem um nome e um tipo, e cada linha é um registro. SQL é a linguagem para conversar com ele: perguntar, inserir, alterar e apagar dados.

O SQLite é um banco que cabe num único arquivo, sem servidor. Ele está no seu celular, no navegador e em milhões de apps. Nesta trilha, ele roda dentro da página: cada exemplo tem o botão Experimente e o resultado aparece como tabela.

O banco de exemplo

Todas as aulas usam o banco de uma pequena loja de café:

  • clientes: id, nome, cidade, estado, desde (data do cadastro)
  • produtos: id, nome, categoria, preco, estoque
  • pedidos: id, cliente_id, data, status
  • itens: pedido_id, produto_id, quantidade, preco (o preço pago naquele pedido)

SELECT: pedir dados

A forma mais simples é SELECT colunas FROM tabela. O asterisco pede todas as colunas:

SELECT * FROM produtos;

Pedir só as colunas que interessam deixa o resultado mais claro e a consulta mais rápida:

SELECT nome, preco FROM produtos;

Calcular e renomear

Dá para fazer contas nas colunas e dar um nome ao resultado com AS:

SELECT nome, preco, estoque, preco * estoque AS valor_em_estoque
FROM produtos;
Dica

SQL não diferencia maiúsculas nas palavras-chave: select e SELECT funcionam igual. Escrever as palavras-chave em maiúsculas é só um costume para facilitar a leitura. O ponto e vírgula separa um comando do outro.

Valores sem repetição

DISTINCT tira as linhas repetidas do resultado:

SELECT DISTINCT estado FROM clientes;

Teste o que aprendeu

  1. Numa tabela, o que é cada linha?

  2. O que SELECT nome FROM clientes devolve?

  3. Para que serve DISTINCT?
