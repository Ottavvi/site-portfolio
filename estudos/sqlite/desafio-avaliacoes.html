Desafio: avaliações de produtos

Desafio · 25 min

A loja vai aceitar avaliações. Escreva, nesta ordem:

  1. Um CREATE TABLE avaliacoes com: id (chave primária), produto_id (inteiro, obrigatório, chave estrangeira para produtos), nota (inteiro, obrigatório, só de 1 a 5) e comentario (texto, opcional).
  2. Os INSERT destas avaliações: produto 1 com notas 5 e 4; produto 3 com nota 5; produto 2 com notas 3, 2 e 4.
  3. Uma consulta com nome do produto, media das notas (2 casas) e avaliacoes (quantidade), da maior média para a menor. Só produtos com avaliação.

Um teste tenta inserir uma nota 7: a tabela precisa recusar.

O que o código precisa ter

  • A tabela avaliacoes existe com produto_id, nota e comentario
  • nota e produto_id são obrigatórios (NOT NULL)
  • Uma nota fora de 1 a 5 é recusada
  • As 6 avaliações foram inseridas
  • O ranking mostra nome, media e avaliacoes, da maior média para a menor
Ver uma solução possível 
CREATE TABLE avaliacoes (
  id INTEGER PRIMARY KEY,
  produto_id INTEGER NOT NULL REFERENCES produtos(id),
  nota INTEGER NOT NULL CHECK (nota BETWEEN 1 AND 5),
  comentario TEXT
);

INSERT INTO avaliacoes (produto_id, nota) VALUES
  (1, 5), (1, 4), (3, 5), (2, 3), (2, 2), (2, 4);

SELECT p.nome, ROUND(AVG(a.nota), 2) AS media, COUNT(*) AS avaliacoes
FROM avaliacoes a
JOIN produtos p ON p.id = a.produto_id
GROUP BY p.id, p.nome
ORDER BY media DESC;
