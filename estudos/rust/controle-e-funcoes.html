Expressões, controle e funções

Aula · 12 min

Quase tudo é expressão

let idade = 20;
let faixa = if idade >= 18 { "adulto" } else { "menor" };

fn dobro(x: i32) -> i32 {
    x * 2          // sem ponto e vírgula: é o valor devolvido
}

A última expressão de um bloco, sem ponto e vírgula, é o valor dele. Com ;, vira uma instrução e o bloco devolve () (nada). Esquecer ou sobrar um ; é um erro comum no começo.

Laços

for i in 1..=10 {                  // 1 até 10, inclusive (1..10 iria até 9)
    println!("7 x {i} = {}", 7 * i);
}

let frutas = ["maçã", "banana", "uva"];
for (i, f) in frutas.iter().enumerate() {
    println!("{i}: {f}");
}

let mut tentativas = 0;
let resultado = loop {               // loop infinito que devolve valor no break
    tentativas += 1;
    if tentativas == 3 { break tentativas * 10; }
};

match

let nota = 8;
let conceito = match nota {
    9..=10 => "A",
    7..=8 => "B",
    5 | 6 => "C",
    _ => "D",
};

O match precisa cobrir todos os casos possíveis; o _ pega o resto. Se faltar um caso, o código não compila.

Teste o que aprendeu

  1. O que uma função devolve quando a última linha é x * 2 sem ponto e vírgula?

  2. Quais números 1..5 percorre?

  3. O que acontece se um match não cobrir todos os casos?
