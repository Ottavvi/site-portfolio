Cargo e o primeiro programa

Aula · 10 min

Rust gera programas tão rápidos quanto C e C++, mas o compilador impede, antes de rodar, erros de memória que causam travamentos e falhas de segurança nessas linguagens. É usada em navegadores, sistemas operacionais, ferramentas de linha de comando e no back-end de empresas que precisam de desempenho. A curva de aprendizado é mais íngreme: o compilador é exigente, mas as mensagens de erro ensinam muito.

Instalar

Instale pelo rustup (rustup.rs). Para testar sem instalar, use o Rust Playground. No VS Code, instale a extensão rust-analyzer. 

cargo new ola      # cria o projeto (Cargo.toml + src/main.rs)
cd ola
cargo run          # compila e roda
cargo build --release   # versão otimizada em target/release/
fn main() {
    let nome = "Ana";               // imutável por padrão
    let mut visitas = 1;            // mut: pode mudar
    visitas += 1;

    let preco: f64 = 19.9;
    let quantidade: u32 = 3;        // inteiro sem sinal de 32 bits
    let total = preco * quantidade as f64;   // conversão explícita com "as"

    println!("Olá, {nome}! Visita {visitas}");
    println!("Total: {:.2}", total);
}
  • Variáveis são imutáveis por padrão. Para alterar, declare com mut.
  • Inteiros têm tamanho no nome: i32, i64, u8, u32, usize (índices). Decimais: f64.
  • Rust não converte tipos sozinho: somar f64 com u32 é erro. Converta com as.
  • O ! em println! indica uma macro. {nome} imprime a variável; {:.2}, com 2 casas.
Dica

Leia as mensagens de erro do compilador até o fim: quase sempre elas dizem exatamente o que mudar ("help: consider adding mut").

Teste o que aprendeu

  1. Como declarar uma variável que pode mudar?

  2. O que acontece ao somar um f64 com um u32 sem conversão?

  3. O que o ! em println! indica?
