Prática: resumir um CSV na linha de comando

Aula · 35 min

Arquivo vendas.csv de exemplo:

vendedor,valor
Ana,120.50
Bruno,80
Ana,45.5
Carla,300
Bruno,abc

Tarefas

  1. Com o clap, aceite resumo vendas.csv --top 2 (top é opcional, padrão 3).
  2. Leia o arquivo, pule o cabeçalho e some os valores por vendedor.
  3. Linhas inválidas não param o programa: conte e avise no fim, com o número da linha.
  4. Imprima o ranking dos N maiores.
  5. Escreva um teste para a função que interpreta uma linha.
Ver a resposta 
use clap::Parser;
use std::collections::HashMap;
use std::fs;

#[derive(Parser)]
struct Args {
    /// Arquivo CSV com vendedor,valor
    arquivo: String,
    /// Quantos mostrar no ranking
    #[arg(long, default_value_t = 3)]
    top: usize,
}

fn interpretar(linha: &str) -> Option<(&str, f64)> {
    let (vendedor, valor) = linha.split_once(',')?;
    let valor = valor.trim().parse().ok()?;
    Some((vendedor.trim(), valor))
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let args = Args::parse();
    let conteudo = fs::read_to_string(&args.arquivo)?;

    let mut totais: HashMap<&str, f64> = HashMap::new();
    let mut invalidas = Vec::new();
    for (i, linha) in conteudo.lines().enumerate().skip(1) {
        match interpretar(linha) {
            Some((v, x)) => *totais.entry(v).or_default() += x,
            None => invalidas.push(i + 1),
        }
    }

    let mut ranking: Vec<_> = totais.into_iter().collect();
    ranking.sort_by(|a, b| b.1.total_cmp(&a.1));
    for (pos, (v, x)) in ranking.iter().take(args.top).enumerate() {
        println!("{}. {v:<10} {x:>10.2}", pos + 1);
    }
    if !invalidas.is_empty() {
        eprintln!("{} linha(s) ignorada(s): {:?}", invalidas.len(), invalidas);
    }
    Ok(())
}

#[cfg(test)]
mod testes {
    use super::*;

    #[test]
    fn linha_valida() {
        assert_eq!(interpretar("Ana, 12.5"), Some(("Ana", 12.5)));
    }

    #[test]
    fn linha_invalida() {
        assert_eq!(interpretar("Bruno,abc"), None);
        assert_eq!(interpretar("sem virgula"), None);
    }
}

Os comentários com /// viram o texto de ajuda do --help, gerado pelo clap. Dentro de uma função que devolve Option, o ? também funciona: em None, devolve None. {v:<10} alinha à esquerda em 10 colunas; {x:>10.2}, à direita com 2 casas.
