Ownership e empréstimos

Aula · 15 min

Rust não tem coletor de lixo nem obriga a liberar memória à mão. Ele usa três regras de posse (ownership), conferidas na compilação:

  1. Cada valor tem um dono (uma variável).
  2. Só pode haver um dono por vez.
  3. Quando o dono sai de escopo, o valor é liberado.
let a = String::from("olá");
let b = a;                 // a posse MOVE para b
// println!("{a}");        // erro: a não é mais dona de nada
let c = b.clone();         // cópia de verdade (custa memória)
println!("{b} {c}");

let x = 5;
let y = x;                 // números são Copy: copiam sozinhos
println!("{x} {y}");

Emprestar em vez de mover

fn tamanho(s: &String) -> usize {   // & : pega emprestado só para ler
    s.len()
}

fn exclamar(s: &mut String) {        // &mut : empréstimo que pode alterar
    s.push('!');
}

let mut nome = String::from("Ana");
let n = tamanho(&nome);              // nome continua sendo de quem era
exclamar(&mut nome);
println!("{nome} {n}");              // Ana! 3

A regra dos empréstimos: num mesmo momento, ou vários & (leitura), ou um único &mut. Isso elimina, em tempo de compilação, uma classe inteira de bugs em que um pedaço do código altera dados que outro está lendo.

String e &str

  • String: texto com dono, que pode crescer (String::from, .to_string(), format!).
  • &str: uma "fatia" emprestada de um texto. Literais ("olá") são &str.
  • Em parâmetros que só leem texto, prefira &str: aceita os dois.

Teste o que aprendeu

  1. Depois de let b = a; com a sendo uma String, o que acontece com a?

  2. Quantos empréstimos &mut do mesmo valor podem existir ao mesmo tempo?

  3. Qual tipo de parâmetro aceita tanto String quanto literais de texto?
