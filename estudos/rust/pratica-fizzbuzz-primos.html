Prática: números com regras

Aula · 20 min

Tarefas

  1. Escreva fn eh_primo(n: u32) -> bool.
  2. Imprima os primos até 50.
  3. Escreva fn fizzbuzz(n: u32) -> String: "FizzBuzz" para múltiplos de 15, "Fizz" para 3, "Buzz" para 5 e o número nos outros casos. Use match com uma tupla.
  4. Escreva fn collatz(n: u64) -> u32: quantos passos até chegar a 1 (par: divide por 2; ímpar: 3n + 1).
  5. Descubra qual número abaixo de 10.000 tem a sequência de Collatz mais longa.
Ver a resposta 
fn eh_primo(n: u32) -> bool {
    if n < 2 {
        return false;
    }
    let mut d = 2;
    while d * d <= n {
        if n % d == 0 {
            return false;
        }
        d += 1;
    }
    true
}

fn fizzbuzz(n: u32) -> String {
    match (n % 3, n % 5) {
        (0, 0) => "FizzBuzz".to_string(),
        (0, _) => "Fizz".to_string(),
        (_, 0) => "Buzz".to_string(),
        _ => n.to_string(),
    }
}

fn collatz(mut n: u64) -> u32 {
    let mut passos = 0;
    while n != 1 {
        n = if n % 2 == 0 { n / 2 } else { 3 * n + 1 };
        passos += 1;
    }
    passos
}

fn main() {
    let primos: Vec<u32> = (1..=50).filter(|&n| eh_primo(n)).collect();
    println!("{:?}", primos);

    for n in 1..=15 {
        println!("{}", fizzbuzz(n));
    }

    let maior = (1..10_000).max_by_key(|&n| collatz(n)).unwrap();
    println!("{maior} leva {} passos", collatz(maior));   // 6171 leva 261 passos
}

Só é preciso testar divisores até a raiz de n (d * d <= n). {:?} imprime estruturas no formato de depuração. |&n| ... é uma closure (função anônima).
