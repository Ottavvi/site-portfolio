Desafio: o cliente da API de tarefas

Desafio · 20 min

Escreva as funções que o app usa para falar com a API de tarefas em https://api.exemplo.com/tarefas. Os testes trocam o fetch por um servidor de mentira, então nada vai para a internet.

  • listarTarefas(): faz um GET em https://api.exemplo.com/tarefas e devolve o array que veio em JSON. Se a resposta não for ok, lança um Error cuja mensagem contém o status (por exemplo, "Erro 500").
  • criarTarefa(titulo): faz um POST no mesmo endereço, com o cabeçalho Content-Type: application/json e o corpo {"titulo": ..., "feita": false}. Devolve a tarefa criada (o JSON da resposta). Se a resposta não for ok, lança um Error com o status.

As duas são async.

O que o código precisa ter

  • listarTarefas faz GET no endereço certo e devolve o array
  • listarTarefas lança um Error com o status quando a resposta não é ok
  • criarTarefa faz POST com Content-Type JSON e o corpo certo
  • criarTarefa devolve a tarefa criada
  • criarTarefa lança um Error com o status quando a API recusa
Ver uma solução possível 
<script>
  const API = 'https://api.exemplo.com/tarefas';

  async function listarTarefas() {
    const resposta = await fetch(API);
    if (!resposta.ok) throw new Error(`Erro ${resposta.status}`);
    return resposta.json();
  }

  async function criarTarefa(titulo) {
    const resposta = await fetch(API, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ titulo, feita: false })
    });
    if (!resposta.ok) throw new Error(`Erro ${resposta.status}`);
    return resposta.json();
  }
</script>
