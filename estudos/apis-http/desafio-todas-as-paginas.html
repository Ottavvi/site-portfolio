Desafio: retentativas e paginação

Desafio · 25 min

Escreva duas funções async. Os testes simulam a API, então nada vai para a internet.

  • comRetentativas(funcao, tentativas): chama funcao() (que devolve uma Promise) até dar certo, no máximo tentativas vezes, e devolve o resultado. Se todas falharem, lança o último erro. Não tente de novo quando o erro tiver a propriedade status entre 400 e 499 exceto 429: lance na hora. (Não precisa esperar entre as tentativas.)
  • buscarTodas(url): a API devolve páginas no formato { "dados": [...], "proximo": "url da próxima" }, e proximo é null na última. Busque a primeira página em url, siga o proximo até acabar e devolva um array com os dados de todas as páginas, na ordem.

O que o código precisa ter

  • comRetentativas devolve o resultado quando dá certo depois de falhar
  • comRetentativas desiste depois de N tentativas e lança o último erro
  • comRetentativas não repete erros 4xx, mas repete o 429
  • buscarTodas segue o proximo e junta os dados de todas as páginas
  • buscarTodas funciona com uma página só
Ver uma solução possível 
<script>
  async function comRetentativas(funcao, tentativas) {
    for (let i = 1; ; i++) {
      try {
        return await funcao();
      } catch (erro) {
        const definitivo = erro.status >= 400 && erro.status < 500 && erro.status !== 429;
        if (definitivo || i >= tentativas) throw erro;
      }
    }
  }

  async function buscarTodas(url) {
    const todos = [];
    let proxima = url;
    while (proxima) {
      const resposta = await fetch(proxima);
      if (!resposta.ok) throw new Error(`Erro ${resposta.status}`);
      const pagina = await resposta.json();
      todos.push(...pagina.dados);
      proxima = pagina.proximo;
    }
    return todos;
  }
</script>
