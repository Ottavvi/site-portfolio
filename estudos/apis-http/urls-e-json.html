URLs, parâmetros e JSON

Aula · 10 min

As partes de uma URL

https://api.loja.com:443/v1/produtos?categoria=cafe&pagina=2#topo
\___/   \__________/ \_/ \__________/ \____________________/ \__/
protocolo   host     porta  caminho        parâmetros (query)   fragmento

Os parâmetros vêm depois do ?, no formato nome=valor, separados por &. Servem para filtrar, ordenar e paginar.

Não monte URL somando textos

Espaços, acentos e símbolos como & precisam ser codificados (o espaço vira %20 ou +). Somar textos à mão quebra na primeira busca por "pão & café". O objeto URL cuida disso: 

<script>
  const url = new URL('https://api.loja.com/v1/produtos');
  url.searchParams.set('busca', 'pão & café');
  url.searchParams.set('pagina', 2);
  console.log(url.toString());

  // E o caminho de volta: ler os parâmetros de uma URL
  const lida = new URL('https://site.com/busca?q=caneca&ordem=preco');
  console.log(lida.searchParams.get('q'), lida.searchParams.get('ordem'));
  console.log(lida.searchParams.get('naoTem')); // null
</script>

Para um formulário ou um objeto inteiro, new URLSearchParams({ busca: 'x', pagina: 1 }) gera o texto busca=x&pagina=1.

JSON

JSON é o formato de texto que as APIs usam. Parece um objeto do JavaScript, com regras mais rígidas: chaves sempre entre aspas duplas, sem vírgula sobrando, sem funções, sem undefined e sem datas (que viajam como texto). 

<script>
  const pedido = { cliente: 'Ana', itens: [{ id: 3, qtd: 2 }], data: new Date('2026-10-28') };
  const texto = JSON.stringify(pedido);
  console.log(texto);                     // a data virou texto ISO

  const devolta = JSON.parse(texto);
  console.log(devolta.itens[0].qtd);      // 2
  console.log(typeof devolta.data);       // string: precisa de new Date() para virar data

  try {
    JSON.parse("{ cliente: 'Ana' }");     // inválido: chave sem aspas e aspas simples
  } catch (erro) {
    console.log('JSON inválido:', erro.message);
  }
</script>
Dica

JSON.stringify(objeto, null, 2) gera o texto indentado com 2 espaços, muito mais fácil de ler no console.
