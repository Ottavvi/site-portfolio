Desafio: o resumo de um conjunto de números

Desafio · 18 min

Escreva duas funções usando o módulo statistics:

  • resumo(valores): devolve um dicionário com n (quantidade), media, mediana, desvio (desvio padrão de amostra), minimo e maximo. Arredonde média, mediana e desvio com 2 casas. Com menos de 2 valores, o desvio é 0.
  • fora_da_curva(valores): devolve a lista dos valores abaixo de Q1 − 1,5 × IQR ou acima de Q3 + 1,5 × IQR, na ordem em que aparecem. Use quantiles(valores, n=4) para os quartis. Com menos de 4 valores, devolva [].

O que o código precisa ter

  • resumo devolve n, média, mediana, mínimo e máximo
  • resumo calcula o desvio padrão de amostra com 2 casas
  • fora_da_curva acha os valores extremos, na ordem
  • fora_da_curva devolve [] quando não há extremos ou há poucos valores
Ver uma solução possível 
from statistics import mean, median, stdev, quantiles


def resumo(valores):
    return {
        "n": len(valores),
        "media": round(mean(valores), 2),
        "mediana": round(median(valores), 2),
        "desvio": round(stdev(valores), 2) if len(valores) >= 2 else 0,
        "minimo": min(valores),
        "maximo": max(valores),
    }


def fora_da_curva(valores):
    if len(valores) < 4:
        return []
    q1, _, q3 = quantiles(valores, n=4)
    iqr = q3 - q1
    baixo, alto = q1 - 1.5 * iqr, q3 + 1.5 * iqr
    return [v for v in valores if v < baixo or v > alto]


tempos = [1.2, 0.8, 1.1, 0.9, 1.0, 1.3, 0.7, 1.1, 9.5, 1.0, 0.9, 1.2]
print(resumo(tempos))
print(fora_da_curva(tempos))
