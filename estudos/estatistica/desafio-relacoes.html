Desafio: dias incomuns e previsão

Desafio · 22 min

A pousada registrou, para cada semana, o investimento em anúncios e o número de reservas. Escreva:

  • escores_z(valores): a lista do escore z de cada valor (em relação à média e ao desvio padrão de amostra da própria lista), com 2 casas.
  • incomuns(valores, limite=2): os índices dos valores com escore z, em módulo, maior ou igual ao limite.
  • prever(x, y, novo_x): usando a regressão linear de y em função de x, devolve um dicionário com previsao (o y previsto para novo_x, arredondado para inteiro) e r2 (a correlação ao quadrado, com 3 casas).

O que o código precisa ter

  • escores_z calcula (valor − média) / desvio, com 2 casas
  • incomuns devolve os índices dos valores extremos
  • prever usa a regressão linear e arredonda
  • prever devolve o R² com 3 casas
Ver uma solução possível 
from statistics import mean, stdev, correlation, linear_regression

anuncios = [200, 350, 150, 400, 300, 500, 250, 450]   # R$ investidos na semana
reservas = [12, 18, 10, 22, 16, 27, 14, 24]            # reservas na semana


def escores_z(valores):
    m, s = mean(valores), stdev(valores)
    return [round((v - m) / s, 2) for v in valores]


def incomuns(valores, limite=2):
    return [i for i, z in enumerate(escores_z(valores)) if abs(z) >= limite]


def prever(x, y, novo_x):
    inclinacao, intercepto = linear_regression(x, y)
    return {
        "previsao": round(inclinacao * novo_x + intercepto),
        "r2": round(correlation(x, y) ** 2, 3),
    }


print(prever(anuncios, reservas, 600))
