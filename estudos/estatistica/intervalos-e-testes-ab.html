Margem de erro e testes A/B

Aula · 14 min

Margem de erro

De 400 visitantes, 32 reservaram: taxa de 8%. Mas, com outros 400, poderia dar 6% ou 10%. O intervalo de confiança diz a faixa provável da taxa verdadeira. Para uma proporção p com n observações, o erro padrão é √(p × (1 − p) / n), e o intervalo de 95% vai de p − 1,96 × erro a p + 1,96 × erro: 

from math import sqrt
from statistics import NormalDist

def intervalo(sucessos, n, confianca=0.95):
    p = sucessos / n
    z = NormalDist().inv_cdf(0.5 + confianca / 2)   # 1,96 para 95%
    erro = sqrt(p * (1 - p) / n)
    return p, p - z * erro, p + z * erro

for sucessos, n in [(32, 400), (320, 4000)]:
    p, baixo, alto = intervalo(sucessos, n)
    print(f"{sucessos}/{n}: {p:.1%} (entre {baixo:.1%} e {alto:.1%})")

A mesma taxa de 8%, com 10 vezes mais dados, tem um intervalo bem mais estreito.

Teste A/B

Para saber se o botão novo de "Reservar" funciona melhor, metade dos visitantes (escolhidos ao acaso) vê o antigo (A) e metade vê o novo (B). Como a única diferença entre os grupos é o botão, uma diferença nas taxas pode ser atribuída a ele. A pergunta é: a diferença é grande demais para ser só sorte? 

from math import sqrt
from statistics import NormalDist

def teste_ab(conv_a, n_a, conv_b, n_b):
    pa, pb = conv_a / n_a, conv_b / n_b
    p = (conv_a + conv_b) / (n_a + n_b)              # a taxa juntando os dois grupos
    erro = sqrt(p * (1 - p) * (1 / n_a + 1 / n_b))
    z = (pb - pa) / erro
    valor_p = 2 * (1 - NormalDist().cdf(abs(z)))       # bicaudal
    return pa, pb, z, valor_p

pa, pb, z, valor_p = teste_ab(80, 2000, 112, 2000)
print(f"A: {pa:.1%} | B: {pb:.1%} | z = {z:.2f} | valor-p = {valor_p:.4f}")
print("Diferença significativa a 5%?", valor_p < 0.05)

O valor-p é a chance de ver uma diferença tão grande quanto a observada se os dois botões fossem iguais. Abaixo de 0,05 (5%), costuma-se dizer que a diferença é estatisticamente significativa.

As regras do jogo

  • Decida o tamanho antes e não pare o teste "quando der significativo": espiar todo dia e parar no primeiro p < 0,05 encontra diferenças que não existem.
  • Significativo não é importante: com milhões de visitas, uma diferença de 0,01% passa no teste e não vale o trabalho. Olhe o tamanho do efeito e o intervalo.
  • Rode semanas inteiras: o comportamento de segunda é diferente do de sábado.
