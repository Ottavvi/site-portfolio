Desafio: o teste A/B da página de reservas

Desafio · 25 min

Use NormalDist e sqrt. Escreva:

  • intervalo(sucessos, n, confianca=0.95): devolve a tupla (p, baixo, alto) da proporção e do intervalo de confiança (com o z de NormalDist().inv_cdf(0.5 + confianca / 2)), cada um arredondado com 4 casas. O baixo nunca é menor que 0 e o alto nunca é maior que 1.
  • teste_ab(conv_a, n_a, conv_b, n_b, alfa=0.05): devolve um dicionário com taxa_a e taxa_b (4 casas), z (2 casas), valor_p (bicaudal, 4 casas, calculado com o z sem arredondar) e significativo (True se o valor-p for menor que alfa). Use o erro padrão com a taxa combinada dos dois grupos, como na aula.
  • taxa_total(meses): recebe uma lista de tuplas (sucessos, tentativas) e devolve a taxa do período inteiro (não a média das taxas), com 4 casas.

O que o código precisa ter

  • intervalo calcula p e a faixa de 95%
  • intervalo respeita os limites 0 e 1 e aceita outra confiança
  • teste_ab calcula taxas, z e valor-p
  • teste_ab decide a significância pelo alfa
  • taxa_total soma antes de dividir
Ver uma solução possível 
from math import sqrt
from statistics import NormalDist


def intervalo(sucessos, n, confianca=0.95):
    p = sucessos / n
    z = NormalDist().inv_cdf(0.5 + confianca / 2)
    erro = sqrt(p * (1 - p) / n)
    return round(p, 4), round(max(0, p - z * erro), 4), round(min(1, p + z * erro), 4)


def teste_ab(conv_a, n_a, conv_b, n_b, alfa=0.05):
    pa, pb = conv_a / n_a, conv_b / n_b
    p = (conv_a + conv_b) / (n_a + n_b)
    erro = sqrt(p * (1 - p) * (1 / n_a + 1 / n_b))
    z = (pb - pa) / erro
    valor_p = 2 * (1 - NormalDist().cdf(abs(z)))
    return {
        "taxa_a": round(pa, 4),
        "taxa_b": round(pb, 4),
        "z": round(z, 2),
        "valor_p": round(valor_p, 4),
        "significativo": valor_p < alfa,
    }


def taxa_total(meses):
    sucessos = sum(s for s, _ in meses)
    tentativas = sum(t for _, t in meses)
    return round(sucessos / tentativas, 4)


print(intervalo(32, 400))
print(teste_ab(80, 2000, 112, 2000))
print(taxa_total([(10, 100), (90, 300)]))
