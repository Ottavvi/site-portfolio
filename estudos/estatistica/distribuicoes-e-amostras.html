Distribuições, escore z e amostras

Aula · 13 min

A curva normal

Muitas medidas (altura, erro de medição, a média de muitas compras) se distribuem em forma de sino: a maioria perto da média, cada vez menos valores à medida que se afasta. É a distribuição normal, descrita só pela média e pelo desvio padrão. O Python a traz pronta: 

from statistics import NormalDist

# Tempo de entrega: média de 3 dias, desvio de 0,8 dia
entrega = NormalDist(mu=3, sigma=0.8)
print("Chance de chegar em até 4 dias:", round(entrega.cdf(4) * 100, 1), "%")
print("Chance de passar de 5 dias:    ", round((1 - entrega.cdf(5)) * 100, 2), "%")
print("Prazo que cobre 95% das entregas:", round(entrega.inv_cdf(0.95), 1), "dias")

Escore z: quão incomum é este valor?

O escore z diz a quantos desvios padrão um valor está da média: z = (valor − média) / desvio. Ele põe medidas diferentes na mesma régua. Um z de 2 ou mais (ou −2 ou menos) é incomum; acima de 3, raríssimo. 

from statistics import mean, stdev

vendas_dia = [980, 1010, 1000, 995, 1020, 1005, 990, 1450]
m, s = mean(vendas_dia[:-1]), stdev(vendas_dia[:-1])   # o padrão dos dias normais
z = (vendas_dia[-1] - m) / s
print("Média", round(m), "| desvio", round(s, 1), "| z do último dia:", round(z, 1))

Amostra e população

Quase nunca dá para medir todo mundo. Pesquisa-se uma amostra e estima-se o todo. Duas regras:

  • A amostra precisa ser representativa: perguntar a satisfação só a quem respondeu o e-mail de avaliação ouve os mais engajados (e os mais irritados).
  • Quanto maior a amostra, menor o erro, mas o ganho diminui: o erro cai com a raiz quadrada do tamanho. Para cortar o erro pela metade, é preciso uma amostra quatro vezes maior. 
import random
from statistics import mean, stdev

random.seed(42)
# Uma "população" de 100 mil valores de pedidos; a média real é conhecida
populacao = [random.lognormvariate(4, 0.5) for _ in range(100_000)]
print("Média real:", round(mean(populacao), 2))

for n in [10, 100, 1000, 10000]:
    medias = [mean(random.sample(populacao, n)) for _ in range(200)]
    print(f"Amostras de {n:>5}: as médias variam com desvio de {stdev(medias):.2f}")
