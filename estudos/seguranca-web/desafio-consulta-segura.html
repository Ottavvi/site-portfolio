Desafio: a busca de produtos segura

Desafio · 22 min

O back-end da loja monta a busca de produtos somando textos, o que permite injeção de SQL. Reescreva montarBusca(filtros) para devolver { sql, parametros }, que o servidor passa ao banco separados:

  • A base é SELECT nome, preco FROM produtos.
  • Se houver filtros.busca, acrescente a condição nome LIKE ? com o parâmetro '%' + busca + '%'.
  • Se houver filtros.precoMaximo, acrescente preco <= ? com o número como parâmetro. As condições se juntam com WHERE e AND.
  • filtros.ordem só pode ser nome, preco ou estoque; qualquer outro valor (ou nenhum) vira nome. Termine com ORDER BY e a coluna.
  • Nenhum valor digitado pode aparecer dentro do sql.

O que o código precisa ter

  • Sem filtros: só a base, ordenada por nome
  • A busca vira nome LIKE ? com o parâmetro %busca%
  • Busca e preço máximo juntos, com AND e dois parâmetros na ordem
  • Texto malicioso nunca entra no SQL
  • Ordem fora da lista vira nome
Ver uma solução possível 
<script>
  const COLUNAS_DE_ORDEM = ['nome', 'preco', 'estoque'];

  function montarBusca(filtros) {
    const condicoes = [];
    const parametros = [];
    if (filtros.busca) {
      condicoes.push('nome LIKE ?');
      parametros.push('%' + filtros.busca + '%');
    }
    if (filtros.precoMaximo !== undefined) {
      condicoes.push('preco <= ?');
      parametros.push(filtros.precoMaximo);
    }
    const ordem = COLUNAS_DE_ORDEM.includes(filtros.ordem) ? filtros.ordem : 'nome';
    let sql = 'SELECT nome, preco FROM produtos';
    if (condicoes.length) sql += ' WHERE ' + condicoes.join(' AND ');
    sql += ' ORDER BY ' + ordem;
    return { sql, parametros };
  }

  console.log(montarBusca({ busca: "x' OR '1'='1", ordem: 'preco; DROP TABLE produtos' }));
</script>
