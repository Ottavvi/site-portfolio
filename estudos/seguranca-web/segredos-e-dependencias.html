Segredos, dependências e registros

Aula · 11 min

Segredos

Senhas de banco, chaves de API e tokens nunca vão para o código. Eles ficam em variáveis de ambiente: no computador, num arquivo .env listado no .gitignore; em produção, nas configurações da hospedagem; no GitHub Actions, em Settings → Secrets. 

# .env (nunca vai para o Git)
DATABASE_URL=postgres://app:senha-forte@localhost/loja
API_KEY=sk-...

// No código (Node 20+: node --env-file=.env servidor.js)
const chave = process.env.API_KEY;

Vazou uma chave num commit? Apagar o arquivo não basta: ela continua no histórico, e robôs varrem o GitHub atrás disso em minutos. Revogue a chave e gere outra imediatamente. O GitHub tem o secret scanning, que avisa quando reconhece uma chave num push.

Dependências

Um projeto com React tem centenas de pacotes. Qualquer um deles pode ter uma falha descoberta amanhã. 

npm audit            # lista falhas conhecidas nas dependências
npm audit fix        # atualiza o que dá sem quebrar
npm outdated         # o que está desatualizado
  • Ligue o Dependabot no GitHub: ele abre pull requests sozinho atualizando pacotes com falhas.
  • Antes de instalar um pacote, olhe quem mantém, quantos downloads tem e quando foi atualizado. Nomes parecidos com os de pacotes famosos (reactt) são um golpe comum.
  • Grave o package-lock.json no repositório e use npm ci no servidor e no CI: instala exatamente as versões conferidas.

Registros (logs)

Registre o que importa para investigar um incidente: logins (com sucesso e falha), mudanças de permissão, erros do servidor. Mas não registre senhas, tokens, números de cartão e dados pessoais além do necessário: logs vazam também, e a LGPD vale para eles. 

// Ruim
console.log('Login', { email, senha });
// Bom
console.log('Login falhou', { usuarioId, ip, quando: new Date().toISOString() });

Erros que não contam segredos

Para o usuário, uma mensagem genérica ("Algo deu errado. Tente de novo."). O detalhe técnico (a pilha do erro, a consulta SQL, o caminho dos arquivos) vai só para o log. Uma página de erro que mostra a consulta ao banco é um mapa para o atacante.

Dica

A trilha de LGPD aprofunda o lado legal: o que fazer num incidente com dados pessoais e o prazo para avisar a ANPD.
