Injeção de SQL e consultas parametrizadas

Aula · 12 min

Na injeção de SQL, o texto digitado pelo usuário vira parte do comando SQL. Imagine o login montado assim no servidor: 

const sql = "SELECT * FROM usuarios WHERE email = '" + email + "' AND senha_hash = '" + hash + "'";

Se alguém digitar no e-mail ' OR 1=1 --, o comando vira:

SELECT * FROM usuarios WHERE email = '' OR 1=1 --' AND senha_hash = '...'

O OR 1=1 é sempre verdadeiro e o -- transforma o resto em comentário. A pessoa entra sem senha, como o primeiro usuário da tabela (muitas vezes, o administrador). Com variações, dá para ler outras tabelas ou apagar dados.

Experimente o ataque

O SQLite abaixo é o da trilha de SQL. A "busca de clientes" foi montada somando o texto digitado:

-- O que o sistema pretendia: buscar um nome digitado
-- SELECT nome, cidade FROM clientes WHERE nome = '<o que a pessoa digitou>';

-- O que acontece quando a pessoa digita:  x' OR '1'='1
SELECT nome, cidade FROM clientes WHERE nome = 'x' OR '1'='1';

A correção: parâmetros

Em vez de montar o texto, mande o SQL com marcadores (? ou $1) e os valores separados. O banco trata os valores sempre como dados, nunca como comando, não importa o que tenham dentro: 

// Node com better-sqlite3
const usuario = db.prepare('SELECT * FROM usuarios WHERE email = ?').get(email);

// Node com pg (PostgreSQL)
const r = await pool.query('SELECT * FROM pedidos WHERE cliente_id = $1 AND status = $2', [id, 'pago']);

// Python com sqlite3
cursor.execute("SELECT * FROM clientes WHERE estado = ?", (estado,))

Parâmetros servem para valores. Nomes de colunas e tabelas (num ORDER BY escolhido pela pessoa, por exemplo) não podem ser parâmetro: para eles, use uma lista do que é permitido e recuse o resto. 

const COLUNAS = ['nome', 'preco', 'estoque'];
const ordem = COLUNAS.includes(pedido.ordem) ? pedido.ordem : 'nome';
db.prepare(`SELECT * FROM produtos ORDER BY ${ordem}`).all();
Dica

A mesma ideia vale para outras injeções: ao rodar comandos do sistema, passe os argumentos numa lista (execFile("convert", [arquivo, saida])), nunca montando o texto do comando.
