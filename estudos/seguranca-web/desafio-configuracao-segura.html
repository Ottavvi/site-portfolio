Desafio: configuração segura do servidor

Desafio · 22 min

Escreva duas funções que o servidor da pousada vai usar:

  • cabecalhosDeSeguranca(): devolve um objeto com estes cabeçalhos:
    • Strict-Transport-Security com max-age de pelo menos 31536000 e includeSubDomains;
    • Content-Security-Policy com default-src 'self', frame-ancestors 'none', object-src 'none' e um script-src que permita 'self' e https://cdn.jsdelivr.net, sem 'unsafe-inline' nem 'unsafe-eval';
    • X-Content-Type-Options: nosniff e Referrer-Policy: strict-origin-when-cross-origin.
  • destinoSeguro(volta): recebe o valor de ?volta= do login e devolve para onde redirecionar. Só aceite caminhos internos: começam com /, mas não com // nem /\. Qualquer outra coisa (inclusive vazio) vira '/'.

O que o código precisa ter

  • HSTS de pelo menos um ano, com includeSubDomains
  • CSP com default-src 'self', frame-ancestors e object-src 'none'
  • script-src com 'self' e o jsDelivr, sem unsafe
  • nosniff e Referrer-Policy
  • destinoSeguro aceita só caminhos internos
Ver uma solução possível 
<script>
  function cabecalhosDeSeguranca() {
    const csp = [
      "default-src 'self'",
      "script-src 'self' https://cdn.jsdelivr.net",
      "img-src 'self' data: https:",
      "frame-ancestors 'none'",
      "object-src 'none'",
      "base-uri 'self'"
    ].join('; ');
    return {
      'Strict-Transport-Security': 'max-age=31536000; includeSubDomains',
      'Content-Security-Policy': csp,
      'X-Content-Type-Options': 'nosniff',
      'Referrer-Policy': 'strict-origin-when-cross-origin'
    };
  }

  function destinoSeguro(volta) {
    if (typeof volta !== 'string') return '/';
    const interno = volta.startsWith('/') && !volta.startsWith('//') && !volta.startsWith('/\\');
    return interno ? volta : '/';
  }

  console.log(cabecalhosDeSeguranca());
  console.log(destinoSeguro('https://site-falso.com'));
</script>
