Prática: resumo de vendas

Aula · 20 min

Crie os dados direto no R:

library(tidyverse)
vendas <- tribble(
  ~data,        ~vendedor, ~produto,   ~qtd, ~preco,
  "2026-10-01", "Ana",     "Café",      3,   18.5,
  "2026-10-01", "Bruno",   "Arroz",     2,   27.9,
  "2026-10-02", "Ana",     "Arroz",     1,   27.9,
  "2026-10-03", "Carla",   "Feijão",    4,   9.8,
  "2026-10-03", "Ana",     "Café",      2,   18.5,
  "2026-10-04", "Bruno",   "Café",      5,   18.5,
  "2026-10-04", "Carla",   "Arroz",     NA,  27.9
) |> mutate(data = as.Date(data))

Tarefas

  1. Crie a coluna valor = qtd * preco.
  2. Quantas linhas têm quantidade ausente? Remova essas linhas.
  3. Faturamento total por vendedor, do maior para o menor.
  4. Produto com mais unidades vendidas.
  5. Faturamento por dia, com o acumulado (cumsum).
Ver a resposta 
vendas <- vendas |> mutate(valor = qtd * preco)

sum(is.na(vendas$qtd))                 # 1
limpas <- vendas |> filter(!is.na(qtd))

limpas |>
  group_by(vendedor) |>
  summarise(faturamento = sum(valor)) |>
  arrange(desc(faturamento))

limpas |>
  group_by(produto) |>
  summarise(unidades = sum(qtd)) |>
  slice_max(unidades, n = 1)

limpas |>
  group_by(data) |>
  summarise(dia = sum(valor)) |>
  mutate(acumulado = cumsum(dia))

vendas$qtd pega uma coluna como vetor. Somar um vetor de TRUE/FALSE conta os TRUE. slice_max fica com as linhas de maior valor; em empate, devolve todas.
