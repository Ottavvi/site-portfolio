Data frames e o dplyr

Aula · 13 min

Um data frame (ou tibble, no tidyverse) é uma tabela: cada coluna é um vetor do mesmo tamanho. 

library(tidyverse)

vendas <- read_csv2("vendas.csv")   # csv2: separador ; e decimal com vírgula (padrão brasileiro)
glimpse(vendas)                      # colunas, tipos e primeiros valores
summary(vendas)

Os verbos do dplyr

vendas |>
  filter(valor > 100, vendedor != "Teste") |>     # linhas
  select(data, vendedor, produto, valor) |>       # colunas
  mutate(com_imposto = valor * 1.12,              # colunas novas
         mes = format(data, "%Y-%m")) |>
  arrange(desc(valor))                            # ordenar

O |> é o pipe: passa o resultado da esquerda como primeiro argumento da função da direita. Leia como "e então". (Em código antigo, você vai ver %>%, que faz o mesmo.)

Agrupar e resumir

vendas |>
  group_by(vendedor) |>
  summarise(
    vendas = n(),
    total = sum(valor),
    ticket_medio = mean(valor),
    .groups = "drop"
  ) |>
  arrange(desc(total))

vendas |> count(produto, sort = TRUE)   # atalho para contar
Dica

Valores ausentes aparecem como NA. Qualquer conta com NA dá NA: use sum(valor, na.rm = TRUE) para ignorá-los, e is.na(valor) para encontrá-los.

Teste o que aprendeu

  1. Qual verbo do dplyr escolhe linhas?

  2. O que o pipe |> faz?

  3. Quanto dá sum(c(10, NA, 5))?
