Gráficos com ggplot2

Aula · 14 min

O ggplot2 monta gráficos em camadas: dados, estética (que coluna vai em x, y, cor) e geometria (ponto, barra, linha). 

ggplot(limpas, aes(x = vendedor, y = valor)) +
  geom_col()                      # barras somando os valores

ggplot(limpas, aes(x = data, y = valor, color = vendedor)) +
  geom_point(size = 3) +
  geom_line()

ggplot(mpg, aes(x = displ, y = hwy)) +   # mpg vem com o ggplot2
  geom_point(alpha = 0.5) +
  geom_smooth(method = "lm")              # linha de tendência

Deixar pronto para apresentar

limpas |>
  group_by(vendedor) |>
  summarise(total = sum(valor)) |>
  ggplot(aes(x = reorder(vendedor, total), y = total)) +
  geom_col(fill = "#2f6f5e") +
  geom_text(aes(label = scales::label_dollar(prefix = "R$ ", big.mark = ".", decimal.mark = ",")(total)),
            hjust = -0.1) +
  coord_flip() +
  scale_y_continuous(expand = expansion(mult = c(0, 0.2))) +
  labs(title = "Faturamento por vendedor", subtitle = "Outubro de 2026", x = NULL, y = NULL) +
  theme_minimal(base_size = 13)

ggsave("faturamento.png", width = 8, height = 5, dpi = 150)
  • reorder ordena as barras pelo valor, em vez da ordem alfabética.
  • coord_flip deita as barras: nomes longos ficam legíveis.
  • facet_wrap(~ produto) faz um gráfico pequeno para cada produto.
  • theme_minimal() tira o fundo cinza; labs põe títulos.
Dica

Cor fixa (fill = "#2f6f5e") vai fora do aes(). Dentro do aes(), ela vira uma variável, e o ggplot cria uma legenda com o texto "#2f6f5e".

  2. Como ordenar barras pelo valor?

  3. Para que serve facet_wrap?
