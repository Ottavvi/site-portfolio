R, RStudio e vetores

Aula · 10 min

R é uma linguagem feita para análise de dados e estatística. É muito usada em pesquisa, saúde, finanças e por analistas que precisam de gráficos e modelos de qualidade. Instale o R (cran.r-project.org) e depois o RStudio (posit.co), o ambiente onde você escreve e roda o código.

O console

No RStudio, escreva num script (Arquivo, Novo, R Script) e rode a linha com Ctrl+Enter. 

2 + 3 * 4
idade <- 32                # atribuição (o = também funciona, mas <- é o costume)
nome <- "Ana"
paste("Olá,", nome)        # junta textos com espaço
round(10 / 3, 2)           # 3.33

Vetores: tudo é coleção

Em R, até um número sozinho é um vetor de tamanho 1. As operações valem para todos os elementos de uma vez, sem laço: 

vendas <- c(120, 340, 90, 410, 275)       # c() combina valores
vendas * 1.1                               # reajuste em todos
sum(vendas); mean(vendas); max(vendas)
length(vendas)
vendas[2]                                  # o segundo (R começa em 1!)
vendas[vendas > 200]                       # só os maiores que 200
meses <- c("jan", "fev", "mar", "abr", "mai")
meses[which.max(vendas)]                   # o mês da maior venda
Dica

Em R, os índices começam em 1, não em 0 como em Python e JavaScript.

Ajuda e pacotes

?mean                         # ajuda de uma função
install.packages("tidyverse") # uma vez por computador
library(tidyverse)            # em cada sessão/script

O tidyverse é um conjunto de pacotes (dplyr, ggplot2, readr, tidyr...) que deixa a análise de dados mais legível. Esta trilha usa ele do começo ao fim.
