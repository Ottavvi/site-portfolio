Prática: relatório de um teste A/B

Aula · 35 min

set.seed(42)
teste <- tibble(
  versao = rep(c("A", "B"), each = 2000),
  comprou = c(rbinom(2000, 1, 0.050), rbinom(2000, 1, 0.062)),
  valor = if_else(comprou == 1, round(rnorm(4000, 180, 40), 2), 0)
)

Tarefas

  1. Taxa de conversão e ticket médio (só de quem comprou) por versão.
  2. Teste se a diferença de conversão é significativa com prop.test.
  3. Gráfico de barras da conversão por versão, com a taxa escrita em cima.
  4. Monte um .qmd com o resultado e uma frase de recomendação que use os números calculados.
Ver a resposta 
resumo <- teste |>
  group_by(versao) |>
  summarise(
    visitantes = n(),
    compras = sum(comprou),
    conversao = mean(comprou),
    ticket = mean(valor[comprou == 1])
  )

resultado <- prop.test(resumo$compras, resumo$visitantes)
resultado$p.value
resultado$conf.int        # intervalo para a diferença A - B

ggplot(resumo, aes(versao, conversao)) +
  geom_col(fill = c("grey60", "#2f6f5e"), width = 0.6) +
  geom_text(aes(label = scales::percent(conversao, accuracy = 0.1, decimal.mark = ",")), vjust = -0.5) +
  scale_y_continuous(labels = scales::label_percent(), expand = expansion(mult = c(0, 0.15))) +
  labs(title = "Conversão por versão", x = NULL, y = NULL) +
  theme_minimal()

No .qmd, escreva a recomendação com código embutido, por exemplo: a versão B converteu `r scales::percent(resumo$conversao[2], 0.1)` contra `r scales::percent(resumo$conversao[1], 0.1)` (p = `r round(resultado$p.value, 3)`). Se o p-valor ficar acima de 0,05 com os seus dados, a conclusão honesta é "ainda não dá para afirmar": aumente a amostra antes de decidir.
