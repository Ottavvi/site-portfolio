Testes, regressão e Quarto

Aula · 14 min

Teste de hipótese

# A página nova converte mais? (valor: 1 = comprou, 0 = não)
t.test(valor ~ versao, data = teste_ab)
prop.test(x = c(48, 71), n = c(1000, 1000))   # comparar duas proporções

Olhe o p-valor e o intervalo de confiança. p < 0,05 diz que a diferença dificilmente é só acaso; o intervalo diz o tamanho provável dela, que é o que importa para decidir.

Regressão linear

modelo <- lm(vendas ~ investimento_anuncio + feriado, data = semanas)
summary(modelo)

library(broom)
tidy(modelo, conf.int = TRUE)    # coeficientes numa tabela
glance(modelo)                   # R², AIC...
predict(modelo, newdata = tibble(investimento_anuncio = 2000, feriado = FALSE))

Um coeficiente de 3.2 para investimento_anuncio quer dizer: mantendo o resto igual, cada real a mais em anúncio está associado a R$ 3,20 a mais em vendas. Associado, não causado: correlação em dados observados não prova causa.

Relatórios com Quarto

Um arquivo .qmd mistura texto e código. Ao renderizar, o código roda e os resultados (tabelas, gráficos) entram no documento. Mudou o dado, renderiza de novo.

title: "Vendas de outubro"
format: html
---

O faturamento do mês foi de `r reais(sum(vendas$valor))`.

```{r}

ggplot(vendas, aes(vendedor, valor)) + geom_col()
```

No RStudio, o botão Render gera o HTML. Troque format: html por pdf ou docx para outros formatos.

Dica

Use projetos do RStudio (Arquivo, Novo Projeto) e caminhos relativos. Nada de setwd("C:/Users/..."): o script quebra no computador de qualquer outra pessoa.
