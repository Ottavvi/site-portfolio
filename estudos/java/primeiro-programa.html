O primeiro programa

Aula · 9 min

Java é uma das linguagens mais usadas em empresas: bancos, seguradoras, governo, comércio eletrônico e o Android foram construídos sobre ela. O código compila para bytecode, que roda na JVM (máquina virtual Java) de qualquer sistema: "escreva uma vez, rode em qualquer lugar".

Instalar

Instale um JDK LTS (21 ou mais novo), por exemplo o Temurin, em adoptium.net. Para escrever, o IntelliJ IDEA Community é o editor mais usado; o VS Code com o "Extension Pack for Java" também funciona. 

java -version
javac -version

Olá, mundo

// Ola.java (o nome do arquivo precisa ser igual ao da classe pública)
public class Ola {
    public static void main(String[] args) {
        System.out.println("Olá, mundo!");
        String nome = args.length > 0 ? args[0] : "visitante";
        System.out.printf("Bem-vindo, %s!%n", nome);
    }
}
javac Ola.java      # compila: gera Ola.class
java Ola Ana        # roda
java Ola.java Ana   # desde o Java 11: compila e roda num passo só
  • Todo código Java vive dentro de uma classe.
  • O programa começa no método public static void main(String[] args).
  • Instruções terminam com ; e blocos ficam entre { }.
  • printf formata: %s texto, %d inteiro, %.2f decimal com 2 casas, %n quebra de linha.
