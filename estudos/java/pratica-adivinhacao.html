Prática: jogo de adivinhação

Aula · 20 min

Tarefas

  1. Sorteie um número de 1 a 100.
  2. Peça palpites até o usuário acertar, dizendo "maior" ou "menor".
  3. Se o usuário digitar algo que não é número, avise e peça de novo (sem quebrar o programa).
  4. Ao acertar, mostre quantas tentativas foram.
  5. Pergunte se quer jogar de novo e mostre o melhor resultado da sessão.
Ver a resposta 
import java.util.Random;
import java.util.Scanner;

public class Adivinhacao {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        Random sorteio = new Random();
        int recorde = Integer.MAX_VALUE;

        do {
            int segredo = sorteio.nextInt(1, 101);
            int tentativas = 0;
            while (true) {
                System.out.print("Palpite: ");
                String linha = entrada.nextLine().trim();
                int palpite;
                try {
                    palpite = Integer.parseInt(linha);
                } catch (NumberFormatException e) {
                    System.out.println("Digite um número.");
                    continue;
                }
                tentativas++;
                if (palpite < segredo) System.out.println("Maior!");
                else if (palpite > segredo) System.out.println("Menor!");
                else break;
            }
            System.out.printf("Acertou em %d tentativas.%n", tentativas);
            recorde = Math.min(recorde, tentativas);
            System.out.print("Jogar de novo? (s/n) ");
        } while (entrada.nextLine().trim().equalsIgnoreCase("s"));

        System.out.println("Melhor resultado: " + recorde);
    }
}

Ler sempre com nextLine e converter com Integer.parseInt evita o problema clássico de misturar nextInt e nextLine (a quebra de linha que sobra no buffer). nextInt(1, 101) sorteia de 1 até 100: o limite superior não entra.
