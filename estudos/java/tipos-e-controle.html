Dica

Strings se comparam com .equals, não com ==: nome.equals("Ana"). O == compara se são o mesmo objeto na memória, e pode dar false para textos iguais.

Métodos

public class Calculos {
    static double comDesconto(double valor, double percentual) {
        return valor * (1 - percentual / 100);
    }

    public static void main(String[] args) {
        System.out.printf("%.2f%n", comDesconto(200, 15));   // 170,00 ou 170.00, conforme o idioma do sistema
    }
}

O static diz que o método pertence à classe, sem precisar criar um objeto. O tipo antes do nome (double) é o tipo do retorno; void quando não devolve nada.
