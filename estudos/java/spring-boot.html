API com Spring Boot e JPA

Aula · 15 min

O Spring Boot é o framework mais usado para back-end em Java. Gere um projeto em start.spring.io com as dependências Spring Web, Spring Data JPA, Validation e H2 (um banco em memória, ótimo para estudar). 

@Entity
public class Produto {
    @Id @GeneratedValue
    private Long id;
    @NotBlank private String nome;
    @Positive private BigDecimal preco;
    // getters e setters
}

public interface ProdutoRepository extends JpaRepository<Produto, Long> {
    List<Produto> findByPrecoLessThanOrderByNome(BigDecimal limite);   // o Spring cria a consulta pelo nome
}

@RestController
@RequestMapping("/produtos")
public class ProdutoController {
    private final ProdutoRepository repo;

    public ProdutoController(ProdutoRepository repo) {   // injetado pelo Spring
        this.repo = repo;
    }

    @GetMapping
    public List<Produto> listar() { return repo.findAll(); }

    @GetMapping("/{id}")
    public ResponseEntity<Produto> buscar(@PathVariable Long id) {
        return repo.findById(id).map(ResponseEntity::ok).orElse(ResponseEntity.notFound().build());
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public Produto criar(@Valid @RequestBody Produto p) { return repo.save(p); }
}
./mvnw spring-boot:run
curl localhost:8080/produtos
  • @Entity liga a classe a uma tabela; o JPA/Hibernate gera o SQL.
  • JpaRepository traz save, findById, findAll, delete prontos. Métodos com nomes como findByPrecoLessThan viram consultas sozinhos.
  • O Spring cria os objetos e os entrega pelo construtor: é a injeção de dependência. Nada de new ProdutoRepository().
  • @Valid confere as anotações (@NotBlank, @Positive) e devolve 400 se falhar.
Dica

Em projetos maiores, não exponha a entidade direto na API: use records de entrada e saída (DTOs). Assim, um campo novo no banco não aparece sem querer no JSON.

Teste o que aprendeu

  1. O que faz um método findByPrecoLessThan num JpaRepository?

  2. Como o controller recebe o repositório?

  3. O que @Valid faz no parâmetro?
