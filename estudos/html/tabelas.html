Tabelas

Aula · 7 min

Tabelas servem para dados tabulares: informações que fazem sentido em linhas e colunas, como horários, preços ou notas. Elas não devem ser usadas para montar o layout da página, como se fazia nos anos 2000.

A estrutura

<table>
  <caption>Notas do bimestre</caption>
  <thead>
    <tr>
      <th scope="col">Aluno</th>
      <th scope="col">Nota</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Ana</th>
      <td>9,5</td>
    </tr>
    <tr>
      <th scope="row">Bruno</th>
      <td>8,0</td>
    </tr>
  </tbody>
</table>
  • <table> envolve tudo.
  • <caption> é o título da tabela.
  • <thead> agrupa a linha de cabeçalho, e <tbody>, as linhas de dados.
  • <tr> é uma linha (table row).
  • <th> é uma célula de cabeçalho, e <td>, uma célula de dado.

O atributo scope

scope="col" diz que o cabeçalho vale para a coluna, e scope="row", para a linha. Com isso, o leitor de tela consegue anunciar "Ana, Nota: 9,5" em vez de ler números soltos.

Juntando células

colspan faz uma célula ocupar várias colunas, e rowspan, várias linhas.

<table>
  <tr>
    <th colspan="2">Horário de funcionamento</th>
  </tr>
  <tr>
    <td>Segunda a sexta</td>
    <td>9h às 18h</td>
  </tr>
  <tr>
    <td>Sábado</td>
    <td>9h às 13h</td>
  </tr>
</table>
Dica

Sem CSS, a tabela aparece sem bordas. É normal: a aparência fica para o CSS.

Teste o que aprendeu

  1. Qual é a diferença entre <th> e <td>?

  2. Tabela é uma boa forma de montar o layout da página em colunas?

  3. Para que serve scope="col" num <th>?
