dialog, details e popover

Aula · 11 min

Por muito tempo, abrir um modal ou uma sanfona exigia uma biblioteca de JavaScript. Hoje o HTML tem elementos prontos para isso, que já vêm acessíveis pelo teclado e por leitores de tela.

details e summary

Uma área que abre e fecha. O <summary> é o título clicável; o resto aparece quando aberto: 

<details>
  <summary>Qual o prazo de entrega?</summary>
  <p>De 2 a 5 dias úteis para as capitais.</p>
</details>

<details open>
  <summary>Posso trocar o produto?</summary>
  <p>Sim, em até 30 dias, com a etiqueta.</p>
</details>

Com o mesmo atributo name em vários <details>, eles viram uma sanfona exclusiva: abrir um fecha os outros, sem nenhuma linha de JavaScript. 

<details name="faq"><summary>Entrega</summary><p>De 2 a 5 dias úteis.</p></details>
<details name="faq"><summary>Trocas</summary><p>Em até 30 dias.</p></details>
<details name="faq"><summary>Pagamento</summary><p>Pix, cartão ou boleto.</p></details>

dialog

O <dialog> é uma janela sobre a página. Aberto com showModal(), ele vira um modal de verdade: escurece o fundo (o ::backdrop), prende o foco do teclado dentro dele e fecha com Esc. Um formulário com method="dialog" fecha o diálogo ao ser enviado: 

<style>
  dialog::backdrop { background: rgb(0 0 0 / 0.5); }
  dialog { border: 0; border-radius: 12px; padding: 20px; }
</style>

<button onclick="document.querySelector('#confirmar').showModal()">Excluir conta</button>

<dialog id="confirmar">
  <h2>Excluir a conta?</h2>
  <p>Esta ação não pode ser desfeita.</p>
  <form method="dialog">
    <button value="cancelar">Cancelar</button>
    <button value="excluir">Excluir</button>
  </form>
</dialog>

<p id="resultado"></p>
<script>
  const dialogo = document.querySelector('#confirmar');
  dialogo.addEventListener('close', () => {
    document.querySelector('#resultado').textContent = 'Você escolheu: ' + dialogo.returnValue;
  });
</script>

O value do botão usado para fechar fica em dialogo.returnValue. Prefira o <dialog> a uma <div> com position: fixed: manter o foco preso e devolver o foco ao botão que abriu, à mão, é trabalhoso e fácil de errar.

popover

O atributo popover transforma qualquer elemento numa camada que aparece por cima de tudo, ligada a um botão com popovertarget. Fecha ao clicar fora ou com Esc. Ideal para menus e dicas: 

<button popovertarget="menu">Menu ▾</button>
<div id="menu" popover>
  <a href="#">Meu perfil</a><br>
  <a href="#">Pedidos</a><br>
  <a href="#">Sair</a>
</div>
Dica

Diferença rápida: o popover não bloqueia o resto da página (a pessoa continua clicando em outras coisas); o dialog com showModal bloqueia até ser fechado. Use modal só quando a pessoa realmente precisa decidir antes de continuar.

  2. Qual a vantagem de dialog.showModal() sobre uma div fixa na tela?

  3. O que um <form method="dialog"> faz dentro de um dialog?
