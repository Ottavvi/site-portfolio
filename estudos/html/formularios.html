Formulários e campos

Aula · 9 min

Formulários são a forma de a pessoa mandar informação para o site: um cadastro, uma busca, uma mensagem de contato.

O formulário e os campos

<form action="/enviar" method="post">
  <label for="nome">Nome</label>
  <input id="nome" name="nome" type="text">

  <label for="email">E-mail</label>
  <input id="email" name="email" type="email">

  <button type="submit">Enviar</button>
</form>
  • <form> agrupa os campos. action diz para onde os dados vão, e method, como (post para enviar dados, get para buscas).
  • <input> é o campo. O name é o nome com que o valor é enviado: sem ele, o campo não vai junto.
  • <button type="submit"> envia o formulário.

Sempre com label

O <label> é o nome visível do campo. O for do label precisa ser igual ao id do campo. Com essa ligação, clicar no texto coloca o cursor no campo, e o leitor de tela anuncia o nome certo.

Dica

O placeholder (aquele texto cinza dentro do campo) não substitui o label: ele some quando a pessoa começa a digitar e costuma ter pouco contraste.

Tipos de campo

O atributo type muda o campo, e no celular muda até o teclado que aparece:

<label for="f-email">E-mail</label>
<input id="f-email" type="email">

<label for="f-tel">Telefone</label>
<input id="f-tel" type="tel">

<label for="f-data">Data</label>
<input id="f-data" type="date">

<label for="f-qtd">Quantidade</label>
<input id="f-qtd" type="number" min="1" max="10">

<label><input type="checkbox" name="novidades"> Quero receber novidades</label>

Escolhas e textos longos

<label for="assunto">Assunto</label>
<select id="assunto" name="assunto">
  <option value="orcamento">Orçamento</option>
  <option value="duvida">Dúvida</option>
</select>

<fieldset>
  <legend>Como prefere o contato?</legend>
  <label><input type="radio" name="contato" value="email"> E-mail</label>
  <label><input type="radio" name="contato" value="whatsapp"> WhatsApp</label>
</fieldset>

<label for="mensagem">Mensagem</label>
<textarea id="mensagem" name="mensagem" rows="4"></textarea>

Botões de rádio com o mesmo name formam um grupo: só um pode ficar marcado. O <fieldset> com <legend> dá um título ao grupo.

Teste o que aprendeu

  1. O que liga um <label> ao seu campo?

  2. Um campo sem o atributo name...

  3. Qual a vantagem de usar type="email" em vez de type="text"?
