O que é HTML

Aula · 8 min

HTML (HyperText Markup Language) é a linguagem que descreve o conteúdo e a estrutura de uma página: o que é título, o que é parágrafo, onde há um link ou uma imagem. Ele não cuida da aparência (isso é com o CSS) nem do comportamento (isso é com o JavaScript).

Tags e elementos

O HTML marca cada pedaço do conteúdo com tags. A maioria vem em par: uma de abertura e uma de fechamento, com uma barra. Tudo junto (abertura, conteúdo e fechamento) forma um elemento. 

<p>Este é um parágrafo.</p>

Alguns elementos não têm conteúdo e, por isso, não têm tag de fechamento. São os chamados elementos vazios, como a quebra de linha <br> e a imagem <img>.

Atributos

Atributos ficam dentro da tag de abertura e dão informações extras ao elemento, sempre no formato nome="valor". 

<a href="https://developer.mozilla.org">Documentação da MDN</a>

Aqui, href diz para onde o link leva. Cada elemento tem seus atributos próprios, e alguns, como id, class e lang, valem para qualquer um.

O esqueleto da página

Todo documento HTML segue a mesma estrutura básica:

<!doctype html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Minha primeira página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
    <p>Esta é a minha primeira página.</p>
  </body>
</html>
  • <!doctype html> avisa o navegador que a página usa o HTML atual.
  • <html lang="pt-BR"> envolve tudo e informa o idioma, o que ajuda leitores de tela e o Google.
  • <head> guarda informações sobre a página que não aparecem nela: a codificação de caracteres, o título da aba e a configuração para celular.
  • <body> guarda tudo o que aparece na tela.
Dica

A linha meta name="viewport" é o que faz a página se ajustar à largura do celular. Sem ela, o celular mostra a página como se fosse uma tela de computador, bem pequena.

Aninhamento

Elementos ficam uns dentro dos outros, e o que abre por último fecha primeiro. Indentar o código (recuar as linhas de dentro) deixa essa hierarquia fácil de enxergar. 

<p>Isto é <strong>muito importante</strong>.</p>
