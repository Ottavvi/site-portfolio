Módulo 1 · Primeiros passos

Links e imagens

Aula · 8 min

Links

O elemento <a> (de anchor, âncora) cria um link. O destino vai no atributo href, e o texto entre as tags é o que a pessoa clica. 

<a href="https://www.wikipedia.org">Wikipédia</a>
<a href="sobre.html">Sobre mim</a>
<a href="#contato">Ir para o contato</a>
<a href="mailto:voce@exemplo.com">Mande um e-mail</a>
  • Endereço completo (com https://): leva a outro site.
  • Caminho relativo (sobre.html, ../index.html): leva a uma página do mesmo site, a partir da pasta atual. .. quer dizer "a pasta de cima".
  • #id: leva a um elemento da própria página que tenha aquele id.
  • mailto: abre o programa de e-mail.

Para abrir em outra aba, use target="_blank" junto com rel="noreferrer", que impede o site aberto de controlar a sua aba. 

<a href="https://github.com" target="_blank" rel="noreferrer">GitHub</a>
Dica

Escreva o texto do link dizendo para onde ele leva. "Clique aqui" não ajuda quem usa leitor de tela, que costuma ouvir a lista de links da página fora de contexto.

Imagens

A imagem é um elemento vazio: <img> não tem fechamento. Dois atributos são essenciais:

  • src: o endereço da imagem.
  • alt: um texto que descreve a imagem. Ele é lido por leitores de tela, aparece se a imagem não carregar e ajuda o Google a entender a página. 
<img src="https://picsum.photos/id/1025/400/260" alt="Cachorro da raça pug enrolado num cobertor" width="400" height="260">

Informar width e height reserva o espaço da imagem antes de ela carregar, e assim o texto não "pula" na tela. Se a imagem for só decoração, use alt="" (vazio), para o leitor de tela pular.

Imagem com link

Dá para colocar uma imagem dentro de um link. Nesse caso, o alt deve dizer para onde o link leva. 

<a href="index.html">
  <img src="https://picsum.photos/id/1062/120/80" alt="Página inicial" width="120" height="80">
</a>

Teste o que aprendeu

  1. Para que serve o atributo alt de uma imagem?

  2. Você está em blog/post.html e quer um link para index.html, que fica na pasta de cima. Qual href?

  3. O que fazer com o alt de uma imagem puramente decorativa?
