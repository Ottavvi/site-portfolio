Desafio: estrutura de um blog

Desafio · 15 min

Monte a estrutura de uma página de blog com um post. Não se preocupe com a aparência: o objetivo é usar os elementos que dizem o que cada parte é.

O que o código precisa ter

  • Ter um <header>
  • Ter um <nav> com pelo menos 2 links
  • Ter exatamente um <main>
  • Ter um <article> dentro do <main>, com um título
  • Ter um <footer>
  • Não pular níveis de título (h1 → h2 → h3...)
Ver uma solução possível 
<header>
  <strong>Meu Blog</strong>
  <nav>
    <a href="#">Início</a>
    <a href="#">Sobre</a>
  </nav>
</header>

<main>
  <article>
    <h1>Título do post</h1>
    <p>Texto do post...</p>
    <h2>Uma seção do post</h2>
    <p>Mais texto.</p>
  </article>
</main>

<footer>
  <p>Feito por mim, 2026.</p>
</footer>
