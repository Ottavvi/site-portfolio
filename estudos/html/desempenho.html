Desempenho no HTML

Aula · 10 min

Uma página lenta perde visitas: muita gente desiste se ela demora mais de alguns segundos para aparecer, principalmente no celular. Boa parte da velocidade se decide no HTML, na ordem e no jeito de carregar cada coisa.

Scripts: defer, async e module

Um <script src> comum para tudo: o navegador interrompe a leitura da página, baixa o arquivo, executa e só então continua. Os atributos mudam isso: 

<!-- Baixa junto com a página e executa no fim, na ordem: o mais usado -->
<script src="app.js" defer></script>

<!-- Baixa junto e executa assim que chegar, fora de ordem: bom para contadores e anúncios -->
<script src="contador.js" async></script>

<!-- Módulos já se comportam como defer -->
<script type="module" src="main.js"></script>
Dica

Com defer, o script pode ficar no <head> sem atrasar nada, e ainda roda só quando o HTML inteiro já foi lido.

CSS no head

O CSS também bloqueia: o navegador não desenha a página antes de ter os estilos, para não mostrar a página "pelada" e depois mudar tudo. Por isso ele fica no <head>, e quanto menor e mais perto (no mesmo servidor), melhor.

Pedir antes: preload e preconnect

<!-- Começa a baixar já, um arquivo que só seria descoberto depois (como uma fonte usada no CSS) -->
<link rel="preload" href="fontes/inter.woff2" as="font" type="font/woff2" crossorigin>

<!-- Adianta a conexão com outro servidor que a página vai usar -->
<link rel="preconnect" href="https://cdn.exemplo.com">

Imagens que não fazem a página pular

Se a imagem não informa o tamanho, o navegador não sabe quanto espaço reservar: o texto aparece, a imagem chega e empurra tudo para baixo. Esse pulo tem nome, layout shift, e irrita quem estava lendo. A solução é simples: width e height em toda imagem. 

<!-- A imagem principal: carrega com prioridade -->
<img src="capa.jpg" alt="..." width="1200" height="600" fetchpriority="high">

<!-- As outras: só quando chegarem perto da tela -->
<img src="foto.jpg" alt="..." width="600" height="400" loading="lazy">

Medir antes de otimizar

O Chrome traz o Lighthouse (F12 → aba Lighthouse), que dá uma nota de 0 a 100 e aponta o que está pesando. As métricas principais são:

  • LCP: quanto tempo o maior elemento do topo leva para aparecer.
  • CLS: quanto a página pula enquanto carrega.
  • INP: quanto a página demora para responder a um clique.

Teste o que aprendeu

  1. O que o atributo defer faz num script?

  2. Por que informar width e height nas imagens?

  3. Qual imagem deve ter fetchpriority="high"?
