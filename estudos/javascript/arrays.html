Arrays

Aula · 10 min

Um array guarda vários valores em ordem, numa variável só. Ele é escrito entre colchetes, com os itens separados por vírgula. 

<script>
  const frutas = ['maçã', 'banana', 'uva'];

  console.log(frutas[0]);      // o primeiro item tem índice 0
  console.log(frutas[2]);
  console.log(frutas.length);  // quantos itens
  console.log(frutas[frutas.length - 1]); // o último
</script>

Mudando a lista

  • push(item) acrescenta no fim; pop() tira o último.
  • unshift(item) acrescenta no começo; shift() tira o primeiro.
  • includes(item) diz se o item está na lista.
  • indexOf(item) diz em que posição ele está (ou -1, se não estiver).
  • splice(posição, quantos) remove itens do meio.
<script>
  const tarefas = ['estudar', 'lavar louça'];
  tarefas.push('ir à feira');
  console.log(tarefas);
  console.log(tarefas.includes('estudar'));

  const posicao = tarefas.indexOf('lavar louça');
  tarefas.splice(posicao, 1);
  console.log(tarefas);
</script>
Dica

Um array criado com const ainda pode ganhar e perder itens. O const impede só de trocar a lista inteira por outra.

Percorrendo a lista

O for...of passa por cada item, do primeiro ao último:

<script>
  const precos = [12.5, 8, 30];
  let total = 0;

  for (const preco of precos) {
    total = total + preco;
  }
  console.log(`Total: ${total}`);
</script>

Quando você precisa do índice, existe o for clássico, que repete enquanto a condição for verdadeira: 

<script>
  const nomes = ['Ana', 'Bruno', 'Carla'];
  for (let i = 0; i < nomes.length; i++) {
    console.log(`${i + 1}º lugar: ${nomes[i]}`);
  }
</script>
