Map, Set e agrupamentos

Aula · 11 min

Set: valores sem repetição

Um Set guarda cada valor uma vez só. É o jeito mais curto de tirar duplicados e de perguntar "já vi isto?" rapidamente: 

<script>
  const tags = ['js', 'css', 'js', 'html', 'css'];
  const unicas = new Set(tags);
  console.log(unicas.size, [...unicas]);

  unicas.add('react');
  console.log(unicas.has('css'), unicas.has('python'));

  // Interseção: tags que aparecem nas duas listas
  const minhas = new Set(['js', 'react', 'node']);
  console.log([...unicas].filter(t => minhas.has(t)));
</script>

has num Set é instantâneo mesmo com milhares de itens, enquanto includes num array percorre a lista inteira. Para conferir muitos valores, transforme a lista num Set antes.

Map: chave e valor de qualquer tipo

Um Map é parecido com um objeto, mas a chave pode ser qualquer coisa (até um elemento do DOM), a ordem de inserção é mantida e ele tem size: 

<script>
  const estoque = new Map();
  estoque.set('café', 40).set('chá', 0).set('filtro', 120);

  estoque.set('café', estoque.get('café') - 2);
  console.log(estoque.get('café'), estoque.size, estoque.has('caneca'));

  for (const [produto, quantidade] of estoque) {
    console.log(produto, quantidade);
  }

  const semEstoque = [...estoque].filter(([, q]) => q === 0).map(([p]) => p);
  console.log('Sem estoque:', semEstoque);
</script>
Dica

Use objeto para dados com formato fixo (um produto com nome e preço) e Map para coleções que crescem, com chaves vindas dos dados (contagem por categoria, cache por id).

Agrupar

Agrupar uma lista por uma propriedade é tão comum que ganhou função própria, Object.groupBy (e Map.groupBy, que devolve um Map): 

<script>
  const vendas = [
    { vendedor: 'Ana', valor: 188.7 },
    { vendedor: 'Bruno', valor: 149 },
    { vendedor: 'Ana', valor: 99 },
    { vendedor: 'Carla', valor: 138 }
  ];

  const porVendedor = Object.groupBy(vendas, v => v.vendedor);
  console.log(Object.keys(porVendedor));

  const totais = Object.fromEntries(
    Object.entries(porVendedor).map(([nome, lista]) => [nome, lista.reduce((s, v) => s + v.valor, 0)])
  );
  console.log(totais);
</script>

  2. Qual a vantagem de Map sobre objeto para uma coleção que cresce?

  3. O que Object.groupBy(lista, fn) devolve?
