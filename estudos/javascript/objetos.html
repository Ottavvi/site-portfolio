Objetos

Aula · 10 min

Um array guarda itens em ordem. Um objeto guarda dados com nome: cada valor tem uma chave que diz o que ele é. É a forma natural de representar uma coisa do mundo real, como um produto ou uma pessoa. 

<script>
  const produto = {
    nome: 'Café especial',
    preco: 32.9,
    emEstoque: true,
    tags: ['grãos', 'torra média']
  };

  console.log(produto.nome);
  console.log(produto['preco']);
  console.log(produto.tags[0]);
</script>

Use o ponto (produto.nome) na maior parte do tempo. Os colchetes servem quando o nome da chave está numa variável: produto[campo].

Mudando e acrescentando

<script>
  const pessoa = { nome: 'Bia', idade: 29 };
  pessoa.idade = 30;           // muda
  pessoa.cidade = 'Recife';    // acrescenta
  delete pessoa.idade;         // remove
  console.log(pessoa);

  console.log(Object.keys(pessoa));   // as chaves
  console.log('cidade' in pessoa);    // a chave existe?
</script>

Métodos

Uma função guardada num objeto se chama método. Dentro dele, this é o próprio objeto: 

const conta = {
  saldo: 100,
  depositar(valor) {
    this.saldo += valor;
  }
};
conta.depositar(50); // conta.saldo agora é 150

Listas de objetos

A combinação mais comum na vida real: um array em que cada item é um objeto. É assim que chegam os dados de quase toda API. 

<script>
  const pedidos = [
    { cliente: 'Ana', valor: 120 },
    { cliente: 'Bruno', valor: 45.5 },
    { cliente: 'Carla', valor: 89 }
  ];

  for (const pedido of pedidos) {
    console.log(`${pedido.cliente}: R$ ${pedido.valor.toFixed(2)}`);
  }
</script>

toFixed(2) formata o número com duas casas decimais, o que é bom para dinheiro.
