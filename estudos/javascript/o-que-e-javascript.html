O que é JavaScript

Aula · 8 min

JavaScript é a linguagem de programação da web. O HTML diz o que cada parte da página é, o CSS diz como ela parece, e o JavaScript faz a página reagir: abrir um menu, validar um formulário, buscar dados novos sem recarregar.

Ele também roda fora do navegador (no Node.js, por exemplo), mas nesta trilha vamos usá-lo onde nasceu: na página.

A tag <script>

O código JavaScript vai dentro de uma tag <script>, ou num arquivo separado ligado com <script src="app.js" defer></script>. O navegador executa as instruções de cima para baixo, uma por vez. 

<h1>Olá!</h1>

<script>
  console.log('Primeira linha');
  console.log('Segunda linha');
  console.log(2 + 3);
</script>
Dica

Clique em Experimente: o editor desta trilha tem um Console embaixo do resultado. Tudo o que você passar para console.log() aparece lá, assim como os erros.

O console

console.log() mostra valores no console. É a ferramenta mais usada para entender o que o código está fazendo, de quem começa a quem programa há décadas. No navegador, o console fica nas ferramentas de desenvolvedor (tecla F12).

Instruções e comentários

Cada instrução costuma terminar com ponto e vírgula. Ele é opcional na maioria dos casos, mas usar sempre evita surpresas. Comentários explicam o código e são ignorados pelo navegador: 

// Comentário de uma linha

/* Comentário
   de várias linhas */

Quando algo dá errado

Se o navegador não entende uma linha, ele mostra um erro no console e para de executar aquele script naquele ponto. Ler a mensagem de erro é uma habilidade: ela diz o tipo do problema e, quase sempre, a linha. 

<script>
  console.log('Isto aparece');
  console.lg('Erro de digitação');
  console.log('Isto não aparece, o script parou acima');
</script>

  3. O que acontece quando uma linha do script tem um erro?
