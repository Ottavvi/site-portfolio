Classes

Aula · 12 min

Quando você precisa de vários objetos com a mesma forma e o mesmo comportamento (vários produtos, vários usuários, várias contas), uma classe funciona como um molde. Cada objeto criado a partir dela é uma instância. 

<script>
  class Conta {
    constructor(titular, saldoInicial = 0) {
      this.titular = titular;
      this.saldo = saldoInicial;
    }

    depositar(valor) {
      this.saldo += valor;
    }

    sacar(valor) {
      if (valor > this.saldo) throw new Error('Saldo insuficiente.');
      this.saldo -= valor;
    }
  }

  const conta = new Conta('Ana', 100);
  conta.depositar(50);
  conta.sacar(30);
  console.log(conta.titular, conta.saldo);
</script>
  • constructor roda ao criar a instância com new e prepara os dados.
  • this é a instância que está sendo usada.
  • Os métodos são compartilhados por todas as instâncias.

Campos privados e getters

No exemplo acima, qualquer um pode escrever conta.saldo = 1000000. Um campo com # na frente só pode ser usado dentro da classe. E um get é um método que se lê como propriedade: 

<script>
  class Conta {
    #saldo = 0;
    #extrato = [];

    depositar(valor) {
      if (valor <= 0) throw new Error('Valor inválido.');
      this.#saldo += valor;
      this.#extrato.push({ tipo: 'depósito', valor });
    }

    get saldo() {
      return this.#saldo;
    }

    get extrato() {
      return [...this.#extrato]; // uma cópia: quem recebe não altera o original
    }
  }

  const conta = new Conta();
  conta.depositar(80);
  console.log(conta.saldo);   // 80, sem parênteses
  conta.saldo = 1000000;      // ignorado: só existe o get
  console.log(conta.saldo);
</script>

Herança

extends cria uma classe a partir de outra, e super chama o que existe na classe de cima: 

class ContaPoupanca extends Conta {
  renderJuros(taxa) {
    this.depositar(this.saldo * taxa);
  }
}
Dica

Herança parece elegante, mas cadeias longas ficam difíceis de entender. Na maior parte do tempo, funções e objetos simples resolvem; use classes quando houver estado com regras para protegê-lo.

Teste o que aprendeu

  1. Quando o constructor de uma classe é executado?

  2. O que o # na frente de um campo faz?

  3. Por que o getter extrato devolve [...this.#extrato] em vez de this.#extrato?
