Métodos de array

Aula · 12 min

Os arrays têm métodos que recebem uma função e fazem o trabalho do laço por você. O código fica mais curto e diz o que está sendo feito, não como.

map: transformar cada item

Devolve um array novo, do mesmo tamanho, com o resultado da função para cada item.

<script>
  const precos = [10, 25, 40];
  const comImposto = precos.map(preco => preco * 1.1);
  console.log(comImposto);

  const produtos = [{ nome: 'Café' }, { nome: 'Chá' }];
  console.log(produtos.map(p => p.nome));
</script>

filter: ficar só com alguns

Devolve um array novo só com os itens para os quais a função devolveu verdadeiro.

<script>
  const notas = [9, 4.5, 7, 3, 8];
  const aprovadas = notas.filter(nota => nota >= 7);
  console.log(aprovadas);
</script>

find, some e every

  • find devolve o primeiro item que combina (ou undefined).
  • some diz se algum combina; every, se todos combinam. 
<script>
  const usuarios = [
    { nome: 'Ana', admin: false },
    { nome: 'Rui', admin: true }
  ];
  console.log(usuarios.find(u => u.nome === 'Rui'));
  console.log(usuarios.some(u => u.admin));
  console.log(usuarios.every(u => u.admin));
</script>

reduce: juntar tudo num valor

reduce percorre a lista carregando um acumulador. O segundo argumento é o valor inicial dele. É o jeito clássico de somar: 

<script>
  const carrinho = [
    { nome: 'Caneca', preco: 35, quantidade: 2 },
    { nome: 'Camiseta', preco: 59.9, quantidade: 1 }
  ];
  const total = carrinho.reduce((soma, item) => soma + item.preco * item.quantidade, 0);
  console.log(total.toFixed(2));
</script>

sort: ordenar

Cuidado: sem argumentos, sort ordena como texto, e [10, 9, 1].sort() dá [1, 10, 9]. Para números, passe uma função de comparação. E saiba que sort muda o array original; para não mexer nele, use toSorted. 

<script>
  const idades = [32, 5, 18, 100];
  console.log(idades.toSorted((a, b) => a - b)); // crescente
  console.log(idades.toSorted((a, b) => b - a)); // decrescente
  console.log(['Rui', 'ana', 'Bia'].toSorted((a, b) => a.localeCompare(b, 'pt-BR')));
</script>
Dica

Os métodos se encadeiam: pedidos.filter(p => p.pago).map(p => p.valor) lê como uma frase: "dos pedidos pagos, pegue o valor".

  2. O que [3, 1, 2].map(n => n * 10) devolve?
