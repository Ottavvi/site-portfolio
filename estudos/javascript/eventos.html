Eventos

Aula · 11 min

Um evento é algo que acontece na página: um clique, uma tecla, o texto de um campo mudando, a página terminando de carregar. Com addEventListener, você diz "quando isto acontecer, rode esta função". 

<button id="curtir">♡ Curtir</button>
<p id="contagem">0 curtidas</p>

<script>
  const botao = document.querySelector('#curtir');
  const contagem = document.querySelector('#contagem');
  let curtidas = 0;

  botao.addEventListener('click', () => {
    curtidas++;
    contagem.textContent = `${curtidas} ${curtidas === 1 ? 'curtida' : 'curtidas'}`;
  });
</script>
Dica

Você vai ver onclick="..." direto no HTML em tutoriais antigos. Prefira addEventListener: mantém o JavaScript fora do HTML e permite vários ouvintes no mesmo elemento.

Eventos mais usados

  • click: clique ou toque (e também Enter ou espaço num botão, pelo teclado).
  • input: o valor de um campo mudou, a cada tecla.
  • change: o valor mudou e a pessoa saiu do campo (ou marcou um checkbox).
  • submit: um formulário foi enviado.
  • keydown: uma tecla foi apertada.

O objeto do evento

A função recebe um objeto com detalhes do que aconteceu. event.target é o elemento que recebeu a ação; event.key é a tecla: 

<label>Seu nome <input id="nome"></label>
<p id="ola">Olá!</p>

<script>
  const campo = document.querySelector('#nome');
  campo.addEventListener('input', event => {
    const nome = event.target.value.trim();
    document.querySelector('#ola').textContent = nome ? `Olá, ${nome}!` : 'Olá!';
  });
  campo.addEventListener('keydown', event => {
    if (event.key === 'Escape') campo.value = '';
  });
</script>

Delegação de eventos

Eventos "sobem" pela árvore: um clique num li também é um clique na ul. Em vez de pôr um ouvinte em cada item, ponha um só no pai e veja quem foi clicado. Assim, itens criados depois também funcionam: 

<ul id="cores">
  <li>Vermelho</li>
  <li>Azul</li>
</ul>
<button id="mais">Adicionar Verde</button>

<script>
  const cores = document.querySelector('#cores');
  cores.addEventListener('click', event => {
    const item = event.target.closest('li');
    if (item) console.log('Clicou em', item.textContent);
  });
  document.querySelector('#mais').addEventListener('click', () => {
    const li = document.createElement('li');
    li.textContent = 'Verde';
    cores.append(li);
  });
</script>

closest('li') sobe a partir do elemento clicado até achar um li, o que funciona mesmo se o item tiver outras tags dentro.
