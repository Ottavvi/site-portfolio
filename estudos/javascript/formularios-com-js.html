Formulários com JavaScript

Aula · 11 min

Formulários são a principal forma de a pessoa mandar informações para o site. O JavaScript entra para validar com mais detalhe, mostrar o resultado sem recarregar a página e enviar os dados para uma API.

Escute o submit, não o clique

Ouça o evento submit do <form>, não o click do botão. Ele dispara tanto no clique quanto ao apertar Enter num campo, e só depois que a validação do HTML (como required) passou. event.preventDefault() impede o navegador de recarregar a página. 

<form id="cadastro">
  <label>E-mail <input name="email" type="email" required></label>
  <label>Senha <input name="senha" type="password" required minlength="8"></label>
  <button>Criar conta</button>
</form>
<p id="mensagem" role="status"></p>

<script>
  const form = document.querySelector('#cadastro');
  form.addEventListener('submit', event => {
    event.preventDefault();
    const dados = new FormData(form);
    const email = dados.get('email');
    document.querySelector('#mensagem').textContent = `Conta criada para ${email}.`;
    form.reset();
  });
</script>
  • new FormData(form) lê todos os campos pelo atributo name. Object.fromEntries(new FormData(form)) transforma tudo num objeto.
  • Um campo também pode ser lido direto: form.elements.email.value ou input.value.
  • form.reset() limpa o formulário.

Validações que o HTML não faz

Para regras próprias, como "as senhas precisam ser iguais", você pode usar setCustomValidity: o navegador mostra a sua mensagem no lugar das dele e bloqueia o envio. 

<form id="senhas">
  <label>Senha <input id="s1" type="password" required></label>
  <label>Repita a senha <input id="s2" type="password" required></label>
  <button>Salvar</button>
</form>

<script>
  const s1 = document.querySelector('#s1');
  const s2 = document.querySelector('#s2');
  const conferir = () => s2.setCustomValidity(s1.value === s2.value ? '' : 'As senhas não são iguais.');
  s1.addEventListener('input', conferir);
  s2.addEventListener('input', conferir);
</script>

Texto vazio em setCustomValidity('') significa "está válido".

Limpe o que veio digitado

Use .trim() para tirar espaços do começo e do fim: um nome com três espaços não é um nome. E lembre que todo valor de campo é texto; converta com Number() antes de fazer contas.

Dica

A validação no navegador é para ajudar a pessoa. Quem recebe os dados (o servidor) precisa validar de novo, porque qualquer um pode desligar o JavaScript ou enviar dados direto.

  1. Por que ouvir o submit do formulário em vez do click do botão?

  2. O que event.preventDefault() faz num submit?

  3. A validação feita no JavaScript do navegador é suficiente?
