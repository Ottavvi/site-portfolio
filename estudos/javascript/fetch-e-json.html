fetch e JSON

Aula · 12 min

Uma API é um endereço que devolve dados em vez de páginas. É assim que um site mostra a previsão do tempo, o endereço de um CEP ou os produtos de uma loja sem recarregar.

JSON

Os dados quase sempre chegam em JSON, um texto com o mesmo formato dos objetos e arrays do JavaScript (com as chaves sempre entre aspas duplas). Dois métodos convertem nos dois sentidos: 

<script>
  const texto = '{"nome":"Ana","linguagens":["JS","Python"]}';
  const objeto = JSON.parse(texto);  // texto → objeto
  console.log(objeto.linguagens[0]);

  const deVolta = JSON.stringify({ ok: true, total: 3 }); // objeto → texto
  console.log(deVolta);
</script>

fetch

fetch(endereço) faz a requisição e devolve uma Promise com a resposta. resposta.json() lê o corpo e converte o JSON (também é uma Promise). Este exemplo consulta um CEP na API pública ViaCEP: 

<form id="busca">
  <label>CEP <input name="cep" value="01001000" inputmode="numeric"></label>
  <button>Buscar</button>
</form>
<p id="resultado" role="status"></p>

<script>
  const saida = document.querySelector('#resultado');

  async function buscarCep(cep) {
    saida.textContent = 'Buscando...';
    try {
      const resposta = await fetch(`https://viacep.com.br/ws/${cep}/json/`);
      if (!resposta.ok) throw new Error(`Erro ${resposta.status}`);
      const dados = await resposta.json();
      if (dados.erro) throw new Error('CEP não encontrado.');
      saida.textContent = `${dados.logradouro}, ${dados.bairro} - ${dados.localidade}/${dados.uf}`;
    } catch (erro) {
      saida.textContent = `Não deu: ${erro.message}`;
    }
  }

  document.querySelector('#busca').addEventListener('submit', event => {
    event.preventDefault();
    const cep = new FormData(event.target).get('cep').replace(/[^0-9]/g, '');
    buscarCep(cep);
  });
</script>

Os três cuidados de toda requisição

  1. Mostre que está carregando. A rede pode levar segundos, e um botão que não reage parece quebrado.
  2. Confira resposta.ok. O fetch só rejeita a Promise quando a rede falha. Um erro 404 ou 500 chega como resposta "normal", e é você quem precisa checar.
  3. Trate o erro para a pessoa. Uma mensagem clara na tela, não só no console.

Enviando dados

await fetch('/api/pedidos', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ produto: 12, quantidade: 2 })
});
Dica

Nem toda API aceita ser chamada de qualquer site. Quando o navegador mostra um erro de CORS, é o servidor da API que não autorizou o seu domínio, e isso não se resolve no JavaScript da página.

Teste o que aprendeu

  1. O que JSON.parse faz?

  2. O fetch rejeita a Promise quando o servidor responde 404?

  3. Por que mostrar um "Buscando..." durante a requisição?
