O DOM

Aula · 11 min

Quando o navegador lê o HTML, ele monta uma árvore de objetos na memória: o DOM (Document Object Model). Cada tag vira um objeto que o JavaScript pode ler e mudar, e a tela se atualiza na hora.

Encontrar elementos

  • document.querySelector('seletor') devolve o primeiro elemento que combina com um seletor CSS (ou null).
  • document.querySelectorAll('seletor') devolve todos, numa lista que dá para percorrer com for...of.
Dica

São os mesmos seletores da trilha de CSS: #id, .classe, nav a. Quem sabe CSS já sabe encontrar elementos.

Ler e mudar

<h1 id="titulo">Bem-vindo</h1>
<p class="aviso">Carregando...</p>
<a id="link" href="#">Saiba mais</a>

<script>
  const titulo = document.querySelector('#titulo');
  titulo.textContent = 'Olá de novo!';

  const aviso = document.querySelector('.aviso');
  aviso.classList.add('pronto');
  aviso.textContent = 'Tudo carregado.';
  aviso.style.color = 'green';

  document.querySelector('#link').setAttribute('href', 'https://developer.mozilla.org');
</script>
  • textContent: o texto do elemento.
  • classList.add, remove, toggle e contains: mexem nas classes. É o jeito preferido de mudar a aparência: o visual fica no CSS e o JavaScript só troca a classe.
  • setAttribute e getAttribute: atributos. Muitos têm atalho: link.href, img.src, input.value.

Criar e remover

<ul id="lista"></ul>

<script>
  const lista = document.querySelector('#lista');
  const frutas = ['Manga', 'Caju', 'Acerola'];

  for (const fruta of frutas) {
    const item = document.createElement('li');
    item.textContent = fruta;
    lista.append(item);
  }

  lista.firstElementChild.remove();
</script>

Cuidado com innerHTML

innerHTML troca o conteúdo por um HTML inteiro. É prático, mas perigoso com texto que veio de uma pessoa: se alguém digitar <img src=x onerror="...">, o navegador executa. Para texto, use sempre textContent, que mostra os caracteres como são.

Onde colocar o script

O script só encontra elementos que já foram lidos. Por isso ele vai no fim do <body> ou, melhor, no <head> com defer, que espera o HTML inteiro.
