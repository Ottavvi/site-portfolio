Código assíncrono

Aula · 12 min

Algumas coisas demoram: buscar dados na internet, esperar um tempo, ler um arquivo. Se o JavaScript ficasse parado esperando, a página inteira congelaria. Em vez disso, ele agenda o que fazer depois e segue em frente.

setTimeout

<script>
  console.log('1. Antes');
  setTimeout(() => console.log('3. Um segundo depois'), 1000);
  console.log('2. Depois do setTimeout');
</script>

Repare na ordem: o "2" aparece antes do "3", porque o setTimeout só agenda a função. setInterval repete de tempos em tempos, até ser parado com clearInterval.

Promises

Uma Promise é um objeto que representa um resultado que ainda vai chegar. Ela pode ser cumprida (deu certo, com um valor) ou rejeitada (deu errado, com um erro). Quase toda API moderna devolve Promises, como o fetch, que veremos na próxima aula. 

<script>
  function esperar(ms) {
    return new Promise(resolve => setTimeout(resolve, ms));
  }

  esperar(500)
    .then(() => console.log('Meio segundo depois'))
    .catch(erro => console.log('Deu errado:', erro));
</script>

async e await

Encadear .then() fica confuso quando há muitas etapas. Dentro de uma função marcada com async, o await "espera" a Promise e o código fica com cara de código normal, de cima para baixo. Os erros são tratados com o try...catch de sempre: 

<script>
  const esperar = ms => new Promise(resolve => setTimeout(resolve, ms));

  async function preparar() {
    console.log('Fervendo a água...');
    await esperar(800);
    console.log('Passando o café...');
    await esperar(800);
    console.log('Café pronto ☕');
  }

  preparar();
  console.log('Enquanto isso, a página continua respondendo.');
</script>
Dica

Uma função async sempre devolve uma Promise. Para usar o resultado dela em outra função, essa outra também precisa usar await (ou .then).

Várias coisas ao mesmo tempo

Dois await seguidos esperam um depois do outro. Se as tarefas não dependem uma da outra, Promise.all roda todas juntas e espera a última: 

const [usuario, pedidos] = await Promise.all([
  buscarUsuario(id),
  buscarPedidos(id)
]);
