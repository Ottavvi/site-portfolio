Desafio: funções da loja

Desafio · 20 min

Uma loja precisa de algumas funções para o site. Os nomes e os parâmetros já estão no código: falta escrever o que cada uma faz. Os testes chamam suas funções com vários valores diferentes, então elas precisam devolver o resultado com return.

  • saudacao(nome) devolve "Olá, NOME!".
  • ehPar(numero) devolve true ou false.
  • frete(valor) devolve 0 para compras a partir de 200 e 25 para as menores.
  • classificarNota(nota) devolve "Aprovado" (7 ou mais), "Recuperação" (5 até menos de 7) ou "Reprovado".

O que o código precisa ter

  • saudacao("Ana") devolve "Olá, Ana!"
  • ehPar devolve true para pares e false para ímpares
  • frete é 25 abaixo de 200 e 0 a partir de 200
  • classificarNota devolve Aprovado, Recuperação ou Reprovado
Ver uma solução possível 
<script>
  function saudacao(nome) {
    return `Olá, ${nome}!`;
  }

  function ehPar(numero) {
    return numero % 2 === 0;
  }

  function frete(valor) {
    return valor >= 200 ? 0 : 25;
  }

  function classificarNota(nota) {
    if (nota >= 7) return 'Aprovado';
    if (nota >= 5) return 'Recuperação';
    return 'Reprovado';
  }

  console.log(saudacao('Ana'));
</script>
