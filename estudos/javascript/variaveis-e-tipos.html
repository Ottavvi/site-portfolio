Variáveis e tipos

Aula · 10 min

Uma variável é um nome que guarda um valor para usar depois. Em JavaScript moderno, há duas formas de criar uma:

  • const: o valor não pode ser trocado depois. Use por padrão.
  • let: o valor pode mudar. Use quando precisar reatribuir, como num contador.
<script>
  const nome = 'Ana';
  let pontos = 10;
  pontos = pontos + 5;

  console.log(nome);
  console.log(pontos);
</script>
Dica

Você vai encontrar var em códigos antigos. Ele funciona, mas tem regras de escopo que causam bugs. Em código novo, use const e let.

Os tipos básicos

  • string (texto): entre aspas simples, duplas ou crases. 'Olá'
  • number: inteiros e decimais, com ponto. 42, 3.14
  • boolean: true ou false.
  • undefined: a variável existe, mas ainda não tem valor.
  • null: "nenhum valor", colocado de propósito.

typeof diz o tipo de um valor: typeof 42 é 'number'.

Template strings

Com crases, dá para colocar valores no meio do texto usando ${ }. É bem mais legível que juntar pedaços com +: 

<script>
  const produto = 'café';
  const preco = 18.5;
  const quantidade = 2;

  console.log('Comprei ' + quantidade + ' pacotes de ' + produto);
  console.log(`Comprei ${quantidade} pacotes de ${produto} por R$ ${preco * quantidade}`);
</script>

Cuidado: texto que parece número

O que vem de um campo de formulário é sempre texto. Somar dois textos junta os dois, em vez de somar: 

<script>
  console.log('2' + '3');                 // "23"
  console.log(Number('2') + Number('3')); // 5
  console.log(Number('abc'));             // NaN: "não é um número"
</script>

Teste o que aprendeu

  1. Quando usar let em vez de const?

  2. Qual o resultado de '5' + '5'?

  3. Qual linha mostra "Olá, Ana" com template string, sendo nome = "Ana"?
