Medidas e colunas calculadas

Aula · 11 min

DAX (Data Analysis Expressions) é a linguagem de fórmulas do Power BI, do Power Pivot no Excel e do Analysis Services. As funções lembram as do Excel, mas a lógica é outra: em vez de células, o DAX trabalha com tabelas e colunas, e o resultado depende dos filtros de cada ponto do relatório.

Coluna calculada

É calculada uma vez por linha, quando os dados são atualizados, e fica guardada no modelo, como uma coluna qualquer: 

Lucro = fVendas[Valor] - fVendas[Custo]
Faixa = IF(fVendas[Valor] >= 200, "Grande", "Normal")

Use quando precisar do valor por linha para filtrar, agrupar ou relacionar: faixas, classificações, chaves.

Medida

É calculada na hora, para cada célula de cada visual, respeitando os filtros daquele ponto. Não ocupa espaço no modelo: 

Faturamento = SUM(fVendas[Valor])
Vendas = COUNTROWS(fVendas)
Ticket médio = DIVIDE([Faturamento], [Vendas])
Margem % = DIVIDE([Faturamento] - SUM(fVendas[Custo]), [Faturamento])

Use para tudo o que é um número de resultado: totais, médias, percentuais, comparações. Regra prática: na dúvida, é medida.

Dica

Para ler fácil: referencie colunas sempre com a tabela (fVendas[Valor]) e medidas sempre sem ([Faturamento]). Assim, só de olhar, você sabe o que é cada coisa.

Funções básicas

  • SUM, AVERAGE, MIN, MAX de uma coluna.
  • COUNTROWS(tabela) conta linhas; DISTINCTCOUNT(coluna) conta valores diferentes (clientes únicos).
  • DIVIDE(a, b, [alternativo]) divide sem erro quando b é zero ou vazio.
  • IF, SWITCH, AND (ou &&), OR (ou ||), BLANK().
  • FORMAT(valor, "0.0%") transforma em texto formatado (só para títulos e rótulos: o resultado deixa de ser número).
Dica

O Power BI usa vírgula para separar argumentos e ponto nos decimais, mesmo em português: DIVIDE([A], 2.5). Em Opções, Configurações regionais, dá para trocar para ponto e vírgula, mas os exemplos da internet quase todos usam vírgula.
