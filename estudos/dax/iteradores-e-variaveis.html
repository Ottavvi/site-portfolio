Iteradores, variáveis e ranking

Aula · 13 min

Iteradores: as funções com X

SUM(coluna) soma uma coluna que já existe. Quando o valor a somar precisa ser calculado linha a linha, use o iterador SUMX(tabela, expressão): ele percorre cada linha da tabela, calcula a expressão e soma os resultados. Sem criar coluna nenhuma: 

Faturamento calculado = SUMX(fItens, fItens[Quantidade] * fItens[Preço unitário])
Faturamento com preço de tabela = SUMX(fItens, fItens[Quantidade] * RELATED(dProduto[Preço]))

RELATED busca o valor na tabela do lado "1" do relacionamento, para a linha atual: é o PROCX do DAX. A família inclui AVERAGEX, MINX, MAXX, COUNTX e CONCATENATEX.

Iterar sobre uma dimensão

Iterar sobre os valores de uma dimensão responde perguntas "por grupo":

Média mensal = AVERAGEX(VALUES(dCalendario[Ano-Mês]), [Faturamento])
Melhor mês = MAXX(VALUES(dCalendario[Ano-Mês]), [Faturamento])
Produtos vendidos = CONCATENATEX(VALUES(dProduto[Produto]), dProduto[Produto], ", ")

Meses sem venda dão [Faturamento] vazio, e o AVERAGEX ignora os vazios: a média é dos meses que tiveram vendas.

Variáveis

VAR guarda um valor e RETURN diz o resultado. A medida fica legível, cada parte é calculada uma vez só, e dá para depurar devolvendo uma variável no lugar do resultado: 

Crescimento anual % =
VAR Atual = [Faturamento]
VAR Anterior = CALCULATE([Faturamento], SAMEPERIODLASTYEAR(dCalendario[Date]))
RETURN
    IF(NOT ISBLANK(Anterior), DIVIDE(Atual - Anterior, Anterior))
Dica

Uma variável é calculada no contexto onde foi declarada e não muda depois. Um CALCULATE em volta de uma variável não altera o valor dela, o que surpreende muita gente.

Ranking

Posição do vendedor =
RANKX(ALL(fVendas[Vendedor]), [Faturamento], , DESC, DENSE)

O ALL é essencial: sem ele, a lista de vendedores para comparar seria só o da linha atual, e todos ficariam em 1º. DENSE não pula posições em empates (1, 2, 2, 3).
