Curva ABC e segmentação dinâmica

Aula · 13 min

Curva ABC (Pareto)

Em muitos negócios, poucos itens fazem a maior parte do resultado. A curva ABC ordena os itens do maior para o menor e soma os percentuais: os que formam os primeiros 80% são A (cuidar de perto, nunca faltar estoque), até 95% são B e o resto é C. 

% acumulado =
VAR Atual = [Faturamento]
VAR Total = CALCULATE([Faturamento], ALL(dProduto))
VAR Acumulado =
    SUMX(
        FILTER(ALL(dProduto[Produto]), [Faturamento] >= Atual),
        [Faturamento]
    )
RETURN DIVIDE(Acumulado, Total)

Classe ABC =
VAR P = [% acumulado]
RETURN
    IF(
        ISBLANK([Faturamento]),
        BLANK(),
        SWITCH(TRUE(), P <= 0.8, "A", P <= 0.95, "B", "C")
    )

O truque está no Acumulado: para o produto da linha, soma o faturamento de todos os produtos que faturaram tanto ou mais que ele. Para o primeiro colocado, é só ele; para o último, são todos (100%).

Segmentação dinâmica

Agrupar vendedores (ou clientes) em faixas ("até R$ 100", "R$ 100 a 300", "acima de 300") pelo faturamento no período filtrado não dá para fazer com coluna calculada, que é fixa. A saída: uma tabela de faixas sem relacionamento, e uma medida que conta quem cai em cada uma: 

Faixas = DATATABLE("Faixa", STRING, "Min", CURRENCY, "Max", CURRENCY, "Ordem", INTEGER, {
    {"Até R$ 100", 0, 100, 1},
    {"R$ 100 a 300", 100, 300, 2},
    {"Acima de R$ 300", 300, 999999999, 3}
})

Vendedores na faixa =
VAR Min = SELECTEDVALUE(Faixas[Min])
VAR Max = SELECTEDVALUE(Faixas[Max])
RETURN COUNTROWS(FILTER(VALUES(fVendas[Vendedor]), [Faturamento] > Min && [Faturamento] <= Max))

Numa tabela com Faixas[Faixa] nas linhas e a medida nos valores, a contagem muda conforme o período escolhido na segmentação de datas.

Dica

Use a classificação ABC junto com outros números: um produto C com margem altíssima pode valer mais que um A com margem negativa.
