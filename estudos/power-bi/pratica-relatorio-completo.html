Prática: relatório para a diretoria

Aula · 40 min

Use o modelo estrela da prática anterior (ou baixe um dos painéis financeiros deste portfólio como base). Monte um relatório que você mostraria numa entrevista.

Tarefas

  1. Página Resumo: cartões com Faturamento, Margem % e Ticket médio; linha com o faturamento por mês; barras por categoria; segmentação por período.
  2. Página Vendedor, configurada como página de drill through pelo campo Vendedor, com os números e uma tabela das vendas dele.
  3. Um menu com botões para ir de uma página à outra.
  4. Uma função de RLS que deixa cada vendedor ver só as próprias vendas, testada com "Exibir como".
  5. Salve como PBIP e faça um commit num repositório Git.
Ver a resposta
  1. Ticket médio precisa de uma contagem de vendas: Vendas = COUNTROWS(fVendas) e Ticket médio = DIVIDE([Faturamento], [Vendas]). A segmentação de período usa dCalendario[Date], no estilo "Entre".
  2. Na página Vendedor, no painel Visualizações, arraste Vendedor para "Detalhamento" (drill through). O Power BI cria o botão Voltar sozinho. Na página Resumo, botão direito numa barra de vendedor, Detalhar.
  3. Inserir, Botões, Navegador de páginas: cria um menu com todas as páginas, que se atualiza sozinho.
  4. Crie a dimensão dVendedor (Vendedor, E-mail), relacione 1:* com fVendas, e em Gerenciar funções: tabela dVendedor, filtro [E-mail] = USERPRINCIPALNAME(). Em "Exibir como", marque a função e informe outro usuário: o e-mail da Ana mostra só as vendas da Ana.
  5. Arquivo, Salvar como, tipo Projeto do Power BI (.pbip). Na pasta: git init, git add ., git commit -m "Relatório de vendas". O .gitignore criado pelo Power BI já deixa de fora o cache com os dados.
