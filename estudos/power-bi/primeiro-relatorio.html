Visuais, filtros e formatação

Aula · 12 min

Os visuais mais usados

  • Cartão: um número em destaque (faturamento do mês). O novo visual de cartão permite vários números lado a lado.
  • Barras ou colunas clusterizadas: comparar categorias.
  • Linhas: evolução no tempo. Arraste a data para o eixo X.
  • Matriz: a tabela dinâmica do Power BI, com subtotais e expansão por níveis.
  • Segmentação de dados (slicer): filtros em forma de botões, lista ou intervalo de datas.
  • Mapa, rosca, dispersão e cascata (de onde vem e para onde vai o resultado, ótima para DRE).

Para criar, clique num visual em Visualizações e arraste os campos do painel Dados para os campos do visual (Eixo X, Eixo Y, Legenda...). O Power BI soma números sozinho, mas o certo é usar medidas (próximo nível).

Filtros em três níveis

No painel Filtros: neste visual, nesta página e em todas as páginas. Filtros fixos (só o ano atual, sem os pedidos cancelados) ficam ali; os que a pessoa vai mexer viram segmentações na página.

Um layout que se lê

  • A leitura vai da esquerda para a direita, de cima para baixo: os números principais (cartões) no topo, os detalhes embaixo.
  • Poucos visuais por página (4 a 6). Mais que isso vira poluição; crie outra página.
  • Alinhe tudo numa grade (Exibir, Linhas de grade, Ajustar à grade) e use o mesmo espaçamento.
  • Títulos que dizem algo. Cores com significado: uma para o destaque, cinza para o resto, vermelho e verde só para ruim e bom.
  • Use um tema (Exibir, Temas) para padronizar cores e fontes em todas as páginas.
Dica

Faça um rascunho do painel no papel antes de abrir o Power BI: quais 3 perguntas ele responde, e qual visual responde cada uma. Isso evita o "painel de tudo", que não responde nada.

Teste o que aprendeu

  1. Qual visual equivale à tabela dinâmica do Excel?

  2. Onde fica um filtro fixo que vale para o relatório inteiro?

  3. Quantos visuais por página costumam funcionar bem?
