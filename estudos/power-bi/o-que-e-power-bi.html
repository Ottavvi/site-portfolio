O que é o Power BI

Aula · 9 min

O Power BI é a ferramenta da Microsoft para transformar dados em relatórios interativos: a pessoa clica numa barra do gráfico e todo o relatório filtra para aquela categoria. Ele junta, num lugar só, o que no Excel fica espalhado: buscar e limpar dados (Power Query), relacionar tabelas (o modelo), calcular indicadores (DAX) e desenhar o painel.

As duas partes

  • Power BI Desktop: o programa (gratuito, para Windows) onde o relatório é construído. Baixe pela Microsoft Store.
  • Serviço do Power BI (app.powerbi.com): onde o relatório é publicado, atualizado automaticamente e compartilhado. Compartilhar com outras pessoas exige licença Pro (ou capacidade Premium/Fabric) para quem publica e para quem vê.

O caminho dos dados

  1. Obter dados: Excel, CSV, pastas, bancos de dados, SharePoint, APIs.
  2. Transformar no Power Query (a mesma ferramenta do Excel, com a trilha própria aqui).
  3. Modelar: relacionar as tabelas e criar as medidas em DAX.
  4. Visualizar: arrastar campos para gráficos, cartões e tabelas.
  5. Publicar e agendar a atualização.

As três telas do Desktop

Na barra da esquerda: Relatório (o painel), Tabela (ver os dados carregados) e Modelo (as tabelas e os relacionamentos, como um diagrama). À direita ficam os painéis de Visualizações, Dados (as tabelas e campos) e Filtros.

Dica

Um relatório do Power BI é interativo por padrão: clicar num elemento de um visual filtra (ou destaca) os outros. Planeje o painel pensando nos cliques, não só na aparência.

Quando usar Power BI e quando usar Excel

  • Excel: controle pessoal, cálculos pontuais, quem recebe precisa editar os números.
  • Power BI: várias tabelas relacionadas, muitos dados, o mesmo relatório atualizado todo mês para várias pessoas, filtros interativos e controle de quem vê o quê.
