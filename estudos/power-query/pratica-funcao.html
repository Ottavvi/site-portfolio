Prática: uma função de limpeza

Aula · 20 min

Um cadastro de clientes chegou assim. Crie uma Tabela tbClientes com estes dados e leve ao Power Query:

Cliente Cidade
Ana curitiba - pr
Bruno SAO PAULO/SP
Carla Curitiba-PR
Diego recife - PE
Elisa São Paulo - sp

Tarefas

  1. Crie uma consulta em branco chamada PadronizarCidade com uma função que recebe o texto e devolve um registro com Cidade (em "Título Próprio", sem espaços sobrando) e UF (duas letras maiúsculas). Considere que a UF são sempre os dois últimos caracteres.
  2. Corrija "Sao Paulo" para "São Paulo" dentro da função.
  3. Use a função em tbClientes para criar as colunas Cidade e UF.
  4. Agrupe por Cidade e UF contando os clientes: devem sair 3 grupos (Curitiba 2, São Paulo 2, Recife 1).
Ver a resposta 
// Consulta PadronizarCidade (Página Inicial, Nova Fonte, Consulta Nula, e cole no Editor Avançado)
(texto as text) as record =>
    let
        Limpo = Text.Trim(texto),
        UF = Text.Upper(Text.End(Limpo, 2)),
        Resto = Text.Start(Limpo, Text.Length(Limpo) - 2),
        SemSeparador = Text.Trim(Text.TrimEnd(Text.Trim(Resto), {"-", "/"})),
        Nome = Text.Proper(SemSeparador),
        Corrigido = if Nome = "Sao Paulo" then "São Paulo" else Nome
    in
        [Cidade = Corrigido, UF = UF]

// Em tbClientes:
ComRegistro = Table.AddColumn(Fonte, "Local", each PadronizarCidade([Cidade])),
SemOriginal = Table.RemoveColumns(ComRegistro, {"Cidade"}),
Expandido = Table.ExpandRecordColumn(SemOriginal, "Local", {"Cidade", "UF"}),
Grupos = Table.Group(Expandido, {"Cidade", "UF"}, {{"Clientes", each Table.RowCount(_), Int64.Type}})

O truque é tirar a UF primeiro (os dois últimos caracteres) e depois limpar o que sobrou: espaços, hífen ou barra no fim, e maiúsculas. Uma função que devolve um registro permite criar duas colunas de uma vez com Table.ExpandRecordColumn.
