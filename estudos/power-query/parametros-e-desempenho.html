Parâmetros, funções e desempenho

Aula · 12 min

Parâmetros

Um caminho como C:\Users\ana\Desktop\vendas.xlsx escrito na consulta quebra no computador de outra pessoa. Crie um parâmetro (Página Inicial, Gerenciar Parâmetros) com o caminho e use-o na fonte. Para mudar, edita-se um lugar só. Os painéis de exemplo deste portfólio fazem exatamente isso com o parâmetro CaminhoPlanilha. 

Fonte = Excel.Workbook(File.Contents(CaminhoPlanilha), null, true)

Funções próprias

Uma consulta pode virar uma função que outras chamam. É o que o "Combinar arquivos" de uma pasta faz por baixo dos panos: 

// Consulta chamada LimparTelefone
(texto as nullable text) as nullable text =>
    let
        Digitos = Text.Select(texto ?? "", {"0".."9"}),
        Formatado = if Text.Length(Digitos) = 11
            then "(" & Text.Start(Digitos, 2) & ") " & Text.Middle(Digitos, 2, 5) & "-" & Text.End(Digitos, 4)
            else null
    in
        Formatado

// Em outra consulta:
= Table.TransformColumns(Clientes, {{"Telefone", LimparTelefone, type text}})

Desempenho

  • Dobragem de consulta (query folding): com bancos de dados, o Power Query traduz as etapas em SQL e o banco faz o trabalho. Clique com o botão direito numa etapa: se "Exibir Consulta Nativa" estiver disponível, ela está dobrando. Filtre e remova colunas cedo, enquanto ainda dobra.
  • Em arquivos, também vale filtrar e remover colunas no começo: menos dados passando por todas as outras etapas.
  • Referência (botão direito, Referência) cria uma consulta nova a partir do resultado de outra; Duplicar copia todas as etapas. Prefira referência quando várias consultas partem da mesma limpeza: a limpeza fica num lugar só.
  • Consultas auxiliares que não precisam aparecer: botão direito, desmarque Habilitar Carregamento.

Erros

Células com Error aparecem quando uma conversão falha. Antes de "Remover Erros", entenda a causa: clique na célula e leia a mensagem. Remover erros às cegas é jogar dados fora em silêncio. Uma etapa de verificação (uma consulta que lista as linhas com erro e é revisada a cada atualização) evita surpresas.

Dica

Para conferir o resultado, compare um total do Power Query com o total do sistema de origem. Uma diferença de centavos costuma ser arredondamento; de milhares, uma linha perdida no caminho.
