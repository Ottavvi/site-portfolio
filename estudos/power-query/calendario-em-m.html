Um calendário feito em M

Aula · 12 min

Toda análise no tempo precisa de uma tabela calendário (a trilha de Power BI explica por quê). Ela pode ser feita em DAX, mas fazer em M tem vantagens: dá para juntar com uma tabela de feriados, reaproveitar no Excel e controlar tudo num lugar. 

let
    Inicio = #date(2026, 1, 1),
    Fim = #date(2026, 12, 31),
    Dias = List.Dates(Inicio, Duration.Days(Fim - Inicio) + 1, #duration(1, 0, 0, 0)),
    Tabela = Table.FromList(Dias, Splitter.SplitByNothing(), {"Data"}, null, ExtraValues.Error),
    Tipo = Table.TransformColumnTypes(Tabela, {{"Data", type date}}),
    Ano = Table.AddColumn(Tipo, "Ano", each Date.Year([Data]), Int64.Type),
    Mes = Table.AddColumn(Ano, "Mês", each Date.Month([Data]), Int64.Type),
    NomeMes = Table.AddColumn(Mes, "Nome do mês", each Text.Proper(Date.MonthName([Data], "pt-BR")), type text),
    AnoMes = Table.AddColumn(NomeMes, "Ano-Mês", each Date.ToText([Data], "yyyy-MM"), type text),
    DiaSemana = Table.AddColumn(AnoMes, "Dia da semana", each Date.DayOfWeek([Data], Day.Monday) + 1, Int64.Type),
    FimDeSemana = Table.AddColumn(DiaSemana, "Fim de semana", each [Dia da semana] >= 6, type logical)
in
    FimDeSemana
  • List.Dates gera a lista de datas: início, quantidade e o passo (um dia).
  • Date.DayOfWeek([Data], Day.Monday) devolve 0 para segunda; somando 1, segunda é 1 e domingo é 7, como no Brasil.
  • O "pt-BR" no Date.MonthName garante os nomes em português em qualquer computador.

Feriados e dias úteis

Com uma consulta Feriados (de uma planilha ou de uma API), uma mesclagem marca os feriados, e o dia útil vira uma coluna: 

ComFeriado = Table.AddColumn(FimDeSemana, "Feriado", each List.Contains(Feriados[Data], [Data]), type logical),
DiaUtil = Table.AddColumn(ComFeriado, "Dia útil", each not [Fim de semana] and not [Feriado], type logical)

No Power BI, uma medida simples conta os dias úteis de qualquer período filtrado: Dias úteis = CALCULATE(COUNTROWS(dCalendario), dCalendario[Dia útil] = TRUE()).

Dica

Gere o calendário a partir das datas dos seus dados (List.Min e List.Max da coluna de data da fato, indo do início do primeiro ano ao fim do último). Assim ele nunca fica curto quando entram dados novos.
