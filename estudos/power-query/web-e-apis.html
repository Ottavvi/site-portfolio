Dados da web e de APIs

Aula · 12 min

Além de arquivos, o Power Query lê páginas da web (tabelas HTML) e APIs que devolvem JSON. Em Obter Dados, Da Web, cole o endereço.

Uma API em JSON

let
    Resposta = Json.Document(Web.Contents("https://viacep.com.br/ws/80010000/json/")),
    Tabela = Table.FromRecords({Resposta}),
    Colunas = Table.SelectColumns(Tabela, {"cep", "logradouro", "localidade", "uf"})
in
    Colunas
  • Web.Contents baixa a resposta; Json.Document transforma o JSON em registros e listas do M.
  • Um objeto JSON vira um registro; uma lista de objetos vira uma lista de registros, que Table.FromRecords transforma em tabela.
  • Campos aninhados aparecem como colunas de registro ou de lista: expanda com o botão do cabeçalho.

Parâmetros, cabeçalhos e chaves

Separe o endereço fixo das partes que mudam, usando RelativePath e Query. Além de mais legível, isso permite que o Serviço do Power BI atualize a consulta (endereços montados com texto, às vezes, não são aceitos na atualização agendada): 

Web.Contents("https://api.exemplo.com", [
    RelativePath = "v1/vendas",
    Query = [mes = "2026-10", pagina = "1"],
    Headers = [Accept = "application/json"],
    ApiKeyName = "api_key"           // a chave fica nas credenciais da fonte, não no código
])
Dica

Nunca escreva uma chave de API no código M: quem abre o arquivo vê tudo. Use as credenciais da fonte de dados (o Power Query pergunta na primeira vez) ou um parâmetro que não vai junto quando o arquivo é compartilhado.

Paginação

APIs costumam devolver os dados em páginas (100 itens por vez). List.Generate busca página por página até vir uma vazia: 

let
    Pagina = (n as number) => Json.Document(Web.Contents("https://api.exemplo.com",
        [RelativePath = "v1/vendas", Query = [pagina = Text.From(n)]])),
    Paginas = List.Generate(
        () => [n = 1, dados = Pagina(1)],
        each List.Count([dados]) > 0,
        each [n = [n] + 1, dados = Pagina([n] + 1)],
        each [dados]
    ),
    Tudo = Table.FromRecords(List.Combine(Paginas))
in
    Tudo

Tabelas de páginas

Para uma tabela HTML (cotações, rankings, a lista de feriados de um site oficial), Obter Dados, Da Web, mostra as tabelas encontradas na página. É frágil: se o site mudar o layout, a consulta quebra. Prefira uma API ou um arquivo para download quando houver.
