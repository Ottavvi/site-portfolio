O que é o Power Query

Aula · 9 min

Todo mês chega o mesmo relatório bagunçado: colunas a mais, datas como texto, espaços sobrando, o total misturado com os dados. Arrumar à mão leva uma hora, e no mês seguinte começa tudo de novo. O Power Query grava cada passo da limpeza e repete tudo sozinho quando o arquivo novo chega. Ele está no Excel (guia Dados, grupo Obter e Transformar) e no Power BI (Transformar dados), com a mesma interface.

O fluxo

  1. Obter dados: de um arquivo Excel ou CSV, de uma pasta, de um banco, de uma página da web ou de uma API.
  2. Transformar no editor: cada clique (remover coluna, mudar tipo, filtrar) vira uma etapa aplicada, listada à direita.
  3. Fechar e Carregar: o resultado vai para uma Tabela do Excel ou para o modelo do Power BI.
  4. No mês seguinte, troque o arquivo e clique em Atualizar. Todas as etapas rodam de novo.
Dica

O arquivo original nunca é alterado. O Power Query lê, transforma na memória e carrega o resultado. Se errar uma etapa, apague-a da lista ou clique numa etapa anterior para ver os dados naquele ponto.

Tipos de dados

O ícone no cabeçalho de cada coluna mostra o tipo: ABC (texto), 123 (número inteiro), 1.2 (decimal), um calendário (data). Acertar os tipos é a etapa mais importante: um valor que ficou como texto não soma, e uma data como texto não ordena direito.

Datas e números brasileiros (28/10/2026, 1.234,56) exigem atenção: use o botão direito no cabeçalho, Alterar Tipo, Usando Localidade, e escolha Português (Brasil). Sem isso, num computador configurado em inglês, 05/10 vira 10 de maio.

A barra de fórmulas

Cada etapa é uma linha da linguagem M, que aparece na barra de fórmulas (ative em Exibir, Barra de Fórmulas). Você não precisa escrever M para usar o Power Query, mas ler ajuda a entender o que cada clique fez: 

= Table.TransformColumnTypes(#"Cabeçalhos Promovidos", {{"Valor", type number}, {"Data", type date}}, "pt-BR")
