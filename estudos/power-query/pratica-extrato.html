Prática: limpar um extrato bancário

Aula · 20 min

Salve este conteúdo num arquivo extrato.csv (no Bloco de Notas, com codificação UTF-8). É assim que muitos bancos exportam: com título, separador ; e números brasileiros. 

EXTRATO DE CONTA CORRENTE
Período: 01/10/2026 a 31/10/2026
Data;Histórico;Valor
01/10/2026;  PIX RECEBIDO - CLIENTE ACME  ;3.500,00
03/10/2026;SUPERMERCADO BOM PRECO;-182,40
05/10/2026;PIX ENVIADO - ALUGUEL;-1.500,00
05/10/2026;PIX ENVIADO - ALUGUEL;-1.500,00
07/10/2026;FARMACIA VIDA;-45,90
12/10/2026;TARIFA PACOTE;-29,90
SALDO;;241,80

Tarefas

No Excel: Dados, Obter Dados, De Arquivo, De Texto/CSV, e depois Transformar Dados.

  1. Remova as duas linhas de título e use a primeira linha como cabeçalho.
  2. Tire a linha de SALDO.
  3. Apare o Histórico e remova a linha duplicada do aluguel.
  4. Converta Data para data e Valor para número decimal, usando a localidade Português (Brasil).
  5. Crie a coluna Tipo (Entrada ou Saída) e a coluna Mês (o nome do mês da data).
  6. Carregue numa Tabela e confira: o total das saídas deve ser -1.758,20.
Ver a resposta
  1. Página Inicial, Remover Linhas, Remover Linhas Superiores, 2. Depois Usar a Primeira Linha como Cabeçalho.
  2. Filtro no cabeçalho de Data: desmarque SALDO. (Melhor ainda: filtre depois de converter para data e remova os erros, assim qualquer linha que não for data sai.)
  3. Selecione Histórico, Transformar, Formatar, Aparar. Selecione as três colunas e Remover Linhas, Remover Duplicatas.
  4. Botão direito em Data, Alterar Tipo, Usando Localidade: Data, Português (Brasil). Em Valor: Número Decimal, Português (Brasil). Assim "3.500,00" vira 3500.
  5. Adicionar Coluna, Coluna Condicional: se Valor for menor que 0, Saída, senão Entrada. Para o mês, selecione Data, Adicionar Coluna, Data, Mês, Nome do Mês.
  6. Saídas: -182,40 - 1.500,00 - 45,90 - 29,90 = -1.758,20. Se der -3.258,20, a duplicata do aluguel ainda está lá. 
let
    Fonte = Csv.Document(File.Contents("C:\Dados\extrato.csv"), [Delimiter=";", Encoding=65001]),
    SemTitulo = Table.Skip(Fonte, 2),
    Cabecalhos = Table.PromoteHeaders(SemTitulo, [PromoteAllScalars=true]),
    SemSaldo = Table.SelectRows(Cabecalhos, each [Data] <> "SALDO"),
    Aparado = Table.TransformColumns(SemSaldo, {{"Histórico", Text.Trim, type text}}),
    SemDuplicatas = Table.Distinct(Aparado),
    Tipos = Table.TransformColumnTypes(SemDuplicatas, {{"Data", type date}, {"Valor", type number}}, "pt-BR"),
    ComTipo = Table.AddColumn(Tipos, "Tipo", each if [Valor] < 0 then "Saída" else "Entrada", type text),
    ComMes = Table.AddColumn(ComTipo, "Mês", each Date.MonthName([Data], "pt-BR"), type text)
in
    ComMes
