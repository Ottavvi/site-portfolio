Agrupar e despivotar

Aula · 12 min

Agrupar Por

Resume a tabela, como uma tabela dinâmica que vira tabela de dados: total por categoria, quantidade de pedidos por cliente, primeira e última compra. Em Página Inicial, Agrupar Por, modo Avançado para várias colunas e várias agregações. 

= Table.Group(Vendas, {"Cliente"}, {
    {"Pedidos", each Table.RowCount(_), Int64.Type},
    {"Total", each List.Sum([Valor]), type number},
    {"Última compra", each List.Max([Data]), type date}
})

Despivotar: o formato que as ferramentas entendem

Planilhas feitas para leitura costumam ter um mês por coluna. Para analisar (somar por período, fazer gráfico de evolução, ligar com um calendário), o formato certo é longo: uma coluna para o mês e outra para o valor.

Produto jan fev mar
Café 120 135 150
Chá 40 38 52

Selecione a coluna Produto e use Transformar, Despivotar Outras Colunas:

Produto Atributo Valor
Café jan 120
Café fev 135
Café mar 150
Chá jan 40
Chá fev 38
Chá mar 52

"Despivotar outras colunas" é melhor que selecionar os meses: quando abril aparecer, ele entra sozinho. Renomeie Atributo para Mês e o resultado está pronto para qualquer análise.

Pivotar faz o caminho inverso, útil no fim, para montar uma tabela de apresentação.

Dica

Regra prática: se você está prestes a escrever a mesma fórmula para jan, fev, mar... os dados estão no formato largo. Despivote primeiro.

Teste o que aprendeu

  1. Uma planilha tem uma coluna para cada mês. Qual operação deixa ela pronta para análise?

  2. Por que "Despivotar outras colunas" em vez de selecionar os meses?

  3. O que Table.RowCount(_) calcula dentro do Agrupar Por?
