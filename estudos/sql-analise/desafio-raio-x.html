Iniciante · Módulo 1 · Perguntas de negócio

Desafio: raio-x da loja

Desafio · 18 min

Escreva três consultas, nesta ordem. Os testes comparam colunas e linhas com o resultado esperado.

  1. Situação dos pedidos: colunas status, pedidos (quantidade) e pct (percentual do total de pedidos, 1 casa decimal), do status com mais pedidos para o com menos; empates pelo nome do status.
  2. Estoque por faixa: colunas faixa e produtos. As faixas são 'esgotado' (estoque 0), 'baixo' (1 a 9) e 'ok' (10 ou mais), em ordem alfabética.
  3. Clientes por estado: colunas estado, clientes (quantos) e compraram (quantos têm pelo menos um pedido não cancelado), por estado.

O que o código precisa ter

  • 1ª consulta: status, pedidos e pct (1 casa), do maior para o menor
  • 2ª consulta: faixa e produtos (esgotado, baixo e ok)
  • 3ª consulta: estado, clientes e quantos compraram (sem cancelados)
Ver uma solução possível 
-- 1. Situação dos pedidos
SELECT status,
  COUNT(*) AS pedidos,
  ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER (), 1) AS pct
FROM pedidos
GROUP BY status
ORDER BY pedidos DESC, status;

-- 2. Estoque por faixa
SELECT
  CASE
    WHEN estoque = 0 THEN 'esgotado'
    WHEN estoque < 10 THEN 'baixo'
    ELSE 'ok'
  END AS faixa,
  COUNT(*) AS produtos
FROM produtos
GROUP BY faixa
ORDER BY faixa;

-- 3. Clientes por estado
SELECT c.estado,
  COUNT(*) AS clientes,
  SUM(EXISTS (
    SELECT 1 FROM pedidos p
    WHERE p.cliente_id = c.id AND p.status <> 'cancelado'
  )) AS compraram
FROM clientes c
GROUP BY c.estado
ORDER BY c.estado;
