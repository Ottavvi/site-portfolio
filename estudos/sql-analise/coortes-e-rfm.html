Coortes e segmentação RFM

Aula · 14 min

Coortes

Uma coorte é um grupo de clientes que começou no mesmo período. Comparar coortes responde "os clientes que chegaram em agosto voltam mais do que os de julho?", o que um total geral esconde. 

WITH validos AS (
  SELECT * FROM pedidos WHERE status <> 'cancelado'
),
primeira AS (
  SELECT cliente_id, strftime('%Y-%m', MIN(data)) AS coorte
  FROM validos
  GROUP BY cliente_id
)
SELECT pr.coorte,
  COUNT(DISTINCT pr.cliente_id) AS clientes,
  COUNT(v.id) AS pedidos,
  ROUND(1.0 * COUNT(v.id) / COUNT(DISTINCT pr.cliente_id), 2) AS pedidos_por_cliente
FROM primeira pr
JOIN validos v ON v.cliente_id = pr.cliente_id
GROUP BY pr.coorte
ORDER BY pr.coorte;

A mesma estrutura, com uma coluna para "meses desde a primeira compra", vira a tabela de retenção que aparece em todo painel de assinatura.

RFM

RFM classifica clientes por três números: Recência (há quantos dias foi a última compra), Frequência (quantos pedidos) e Monetário (quanto gastou). Com eles, dá para separar quem está ativo, quem gasta muito e quem está sumindo. 

WITH base AS (
  SELECT c.nome,
    CAST(julianday('2026-10-31') - julianday(MAX(p.data)) AS INTEGER) AS recencia,
    COUNT(DISTINCT p.id) AS frequencia,
    ROUND(SUM(i.quantidade * i.preco), 2) AS monetario
  FROM clientes c
  JOIN pedidos p ON p.cliente_id = c.id AND p.status <> 'cancelado'
  JOIN itens i   ON i.pedido_id = p.id
  GROUP BY c.id
)
SELECT *,
  CASE
    WHEN recencia <= 30 AND frequencia >= 2 THEN 'fiel'
    WHEN recencia <= 30 THEN 'recente'
    WHEN monetario >= 200 THEN 'valioso, sumindo'
    ELSE 'a reativar'
  END AS segmento
FROM base
ORDER BY monetario DESC;
Dica

Repare no p.status <> 'cancelado' dentro do ON. Ele filtra os pedidos antes de juntar. Num LEFT JOIN, essa diferença importa: no ON, o cliente sem pedido válido continua na lista (com NULL); no WHERE, ele some.
