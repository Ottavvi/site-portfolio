Da pergunta à consulta

Aula · 11 min

Esta trilha continua a de SQLite, com o mesmo banco da loja de café (clientes, produtos, pedidos e itens). Lá você aprendeu os comandos; aqui, a pensar como analista: pegar uma pergunta vaga ("como estão as vendas?") e transformá-la numa consulta que responde exatamente o que foi perguntado.

Primeiro: uma linha é o quê?

Antes de escrever, decida a granularidade do resultado: uma linha por cliente? por mês? por produto e mês? Isso define o GROUP BY. E confira a granularidade das tabelas: em itens, uma linha é um produto dentro de um pedido. Contar linhas de itens não é contar pedidos. 

-- Linhas de itens x pedidos de verdade
SELECT COUNT(*) AS linhas_de_itens,
       COUNT(DISTINCT pedido_id) AS pedidos
FROM itens;

Faixas com CASE

Quem lê o relatório quer grupos com nome, não 30 preços diferentes. O CASE cria a faixa e o GROUP BY agrupa por ela: 

SELECT
  CASE
    WHEN preco < 30  THEN '1. até R$ 30'
    WHEN preco < 100 THEN '2. de R$ 30 a R$ 100'
    ELSE '3. acima de R$ 100'
  END AS faixa,
  COUNT(*) AS produtos
FROM produtos
GROUP BY faixa
ORDER BY faixa;
Dica

O número no começo do nome da faixa ("1.", "2.") é um truque simples para o ORDER BY seguir a ordem lógica, e não a alfabética.

Contar com condição

Muitas perguntas pedem várias contagens lado a lado: "quantos pedidos no total e quantos cancelados?". Uma soma de CASE conta só as linhas que cumprem a condição. O SQLite também aceita o atalho FILTER: 

SELECT
  COUNT(*) AS pedidos,
  SUM(CASE WHEN status = 'cancelado' THEN 1 ELSE 0 END) AS cancelados,
  COUNT(*) FILTER (WHERE status IN ('pago', 'enviado')) AS em_andamento
FROM pedidos;

Linhas que viram colunas

A mesma ideia monta uma tabela cruzada (o "pivô" das planilhas): uma linha por estado e uma coluna por situação. 

SELECT c.estado,
  SUM(p.status = 'entregue')  AS entregues,
  SUM(p.status <> 'entregue') AS outros
FROM pedidos p
JOIN clientes c ON c.id = p.cliente_id
GROUP BY c.estado
ORDER BY c.estado;

No SQLite, uma comparação vale 1 (verdadeiro) ou 0 (falso), então SUM(status = 'entregue') já conta. Em outros bancos, use o CASE.
