Desafio: segmentar os clientes

Desafio · 25 min

Considere hoje = 2026-10-31 e só pedidos não cancelados. Escreva duas consultas, nesta ordem:

  1. Segmentos: para todos os clientes (inclusive quem nunca comprou), as colunas nome, pedidos (0 para quem não comprou), gasto (soma de quantidade × preço, 2 casas, 0 para quem não comprou) e segmento:
    • 'novo' se não tem pedidos;
    • 'vip' se gastou 300 ou mais;
    • 'ativo' se o último pedido foi há 30 dias ou menos;
    • 'inativo' nos outros casos.
    As regras valem nessa ordem (a primeira que bater). Ordene por gasto do maior para o menor e, nos empates, por nome.
  2. Resumo: colunas segmento e clientes, com quantos clientes há em cada segmento, em ordem alfabética de segmento.

O que o código precisa ter

  • 1ª consulta: nome, pedidos, gasto e segmento de todos os clientes
  • 2ª consulta: segmento e quantidade de clientes
Ver uma solução possível 
-- 1. Segmento de cada cliente
WITH valor_do_pedido AS (
  SELECT p.id, p.cliente_id, p.data, SUM(i.quantidade * i.preco) AS valor
  FROM pedidos p
  JOIN itens i ON i.pedido_id = p.id
  WHERE p.status <> 'cancelado'
  GROUP BY p.id
),
base AS (
  SELECT c.nome,
    COUNT(v.id) AS pedidos,
    ROUND(COALESCE(SUM(v.valor), 0), 2) AS gasto,
    julianday('2026-10-31') - julianday(MAX(v.data)) AS dias
  FROM clientes c
  LEFT JOIN valor_do_pedido v ON v.cliente_id = c.id
  GROUP BY c.id
)
SELECT nome, pedidos, gasto,
  CASE
    WHEN pedidos = 0 THEN 'novo'
    WHEN gasto >= 300 THEN 'vip'
    WHEN dias <= 30 THEN 'ativo'
    ELSE 'inativo'
  END AS segmento
FROM base
ORDER BY gasto DESC, nome;

-- 2. Quantos clientes por segmento
WITH valor_do_pedido AS (
  SELECT p.id, p.cliente_id, p.data, SUM(i.quantidade * i.preco) AS valor
  FROM pedidos p
  JOIN itens i ON i.pedido_id = p.id
  WHERE p.status <> 'cancelado'
  GROUP BY p.id
),
base AS (
  SELECT COUNT(v.id) AS pedidos,
    ROUND(COALESCE(SUM(v.valor), 0), 2) AS gasto,
    julianday('2026-10-31') - julianday(MAX(v.data)) AS dias
  FROM clientes c
  LEFT JOIN valor_do_pedido v ON v.cliente_id = c.id
  GROUP BY c.id
)
SELECT
  CASE
    WHEN pedidos = 0 THEN 'novo'
    WHEN gasto >= 300 THEN 'vip'
    WHEN dias <= 30 THEN 'ativo'
    ELSE 'inativo'
  END AS segmento,
  COUNT(*) AS clientes
FROM base
GROUP BY segmento
ORDER BY segmento;
