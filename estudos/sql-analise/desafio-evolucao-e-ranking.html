Desafio: relatório mensal

Desafio · 22 min

Pedidos cancelados não contam. Escreva duas consultas, nesta ordem:

  1. Pedidos por mês: colunas mes (AAAA-MM), pedidos (quantos pedidos no mês), anterior (os pedidos do mês anterior) e diferenca (pedidos menos anterior), em ordem de mês.
  2. O melhor cliente de cada mês: colunas mes, nome e total (soma de quantidade × preço daquele cliente no mês, 2 casas). Uma linha por mês, com o cliente que mais gastou nele; em caso de empate, o de menor nome. Ordem de mês.

O que o código precisa ter

  • 1ª consulta: mes, pedidos, anterior e diferenca
  • 2ª consulta: mes, nome e total do cliente que mais gastou em cada mês
Ver uma solução possível 
-- 1. Pedidos por mês, com o mês anterior
WITH mensal AS (
  SELECT strftime('%Y-%m', data) AS mes, COUNT(*) AS pedidos
  FROM pedidos
  WHERE status <> 'cancelado'
  GROUP BY mes
)
SELECT mes, pedidos,
  LAG(pedidos) OVER (ORDER BY mes) AS anterior,
  pedidos - LAG(pedidos) OVER (ORDER BY mes) AS diferenca
FROM mensal
ORDER BY mes;

-- 2. O melhor cliente de cada mês
WITH gastos AS (
  SELECT strftime('%Y-%m', p.data) AS mes, c.nome,
         ROUND(SUM(i.quantidade * i.preco), 2) AS total
  FROM pedidos p
  JOIN clientes c ON c.id = p.cliente_id
  JOIN itens i    ON i.pedido_id = p.id
  WHERE p.status <> 'cancelado'
  GROUP BY mes, c.id
),
ranking AS (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY mes ORDER BY total DESC, nome) AS n
  FROM gastos
)
SELECT mes, nome, total
FROM ranking
WHERE n = 1
ORDER BY mes;
