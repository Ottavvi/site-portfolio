Intermediário · Módulo 2 · Tempo e ranking

Ranking, top N e o último de cada um

Aula · 12 min

Três jeitos de numerar

Todos numeram as linhas na ordem do OVER. A diferença está nos empates:

  • ROW_NUMBER(): 1, 2, 3, 4. Nunca repete (desempata de forma arbitrária).
  • RANK(): 1, 2, 2, 4. Empatados dividem a posição e a seguinte é pulada.
  • DENSE_RANK(): 1, 2, 2, 3. Empatados dividem e nada é pulado.

Top N por grupo

"O produto mais vendido de cada categoria" é um clássico: numere dentro de cada categoria e fique com o 1º. Como uma janela não pode ir no WHERE da mesma consulta, o filtro fica numa consulta de fora: 

WITH vendas AS (
  SELECT pr.categoria, pr.nome, SUM(i.quantidade) AS unidades,
         ROW_NUMBER() OVER (PARTITION BY pr.categoria ORDER BY SUM(i.quantidade) DESC, pr.nome) AS posicao
  FROM itens i
  JOIN produtos pr ON pr.id = i.produto_id
  GROUP BY pr.id
)
SELECT categoria, nome, unidades
FROM vendas
WHERE posicao = 1
ORDER BY categoria;

O último registro de cada um

A mesma técnica responde "qual foi o último pedido de cada cliente?" e serve para remover duplicados: numere as cópias e fique só com a número 1. 

WITH ordenados AS (
  SELECT p.*, ROW_NUMBER() OVER (PARTITION BY cliente_id ORDER BY data DESC) AS n
  FROM pedidos p
)
SELECT cliente_id, id AS ultimo_pedido, data, status
FROM ordenados
WHERE n = 1
ORDER BY cliente_id;

Dividir em grupos iguais

NTILE(4) separa as linhas em 4 grupos do mesmo tamanho (quartis), útil para classificar clientes em "os 25% que mais compram", "os seguintes" e assim por diante. 

SELECT nome, preco, NTILE(4) OVER (ORDER BY preco DESC) AS quartil
FROM produtos;
Dica

Sempre desempate o ORDER BY de um ROW_NUMBER com uma coluna única (o id ou o nome). Sem isso, a mesma consulta pode escolher linhas diferentes a cada execução quando há empate.
