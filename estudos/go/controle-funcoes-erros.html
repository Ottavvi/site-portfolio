Controle, funções e erros

Aula · 12 min

Um só laço: for

for i := 1; i <= 5; i++ {
    fmt.Println(i)
}

n := 0
for n < 3 {        // o "while" do Go
    n++
}

frutas := []string{"maçã", "banana"}
for i, f := range frutas {
    fmt.Println(i, f)
}

if e switch

if idade >= 18 {
    fmt.Println("adulto")
} else {
    fmt.Println("menor")
}

switch dia {
case "sab", "dom":
    fmt.Println("fim de semana")
default:
    fmt.Println("dia útil")
}   // sem break: cada case termina sozinho

Funções com vários retornos

func dividir(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("divisão por zero")
    }
    return a / b, nil
}

resultado, err := dividir(10, 0)
if err != nil {
    fmt.Println("Erro:", err)
    return
}
fmt.Println(resultado)

Go não tem exceções para erros comuns: a função devolve o erro como último valor, e quem chama confere com if err != nil. É repetitivo, mas deixa claro em cada linha onde algo pode falhar. 

idade, err := strconv.Atoi("32")      // texto para int
if err != nil { /* não era número */ }

if err != nil {
    return fmt.Errorf("lendo configuração: %w", err)   // acrescenta contexto ao erro
}
Dica

Nunca ignore um erro com _ (valor, _ := ...) a não ser que você tenha certeza de que ele não pode acontecer. Erros ignorados viram bugs silenciosos.
