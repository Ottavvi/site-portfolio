Goroutines e channels

Aula · 14 min

Concorrência é o ponto forte do Go. Uma goroutine é uma função rodando ao mesmo tempo que as outras, e custa tão pouco que dá para ter milhares. 

func checar(url string, wg *sync.WaitGroup) {
    defer wg.Done()                           // avisa que terminou, aconteça o que acontecer
    resp, err := http.Get(url)
    if err != nil {
        fmt.Println(url, "FORA:", err)
        return
    }
    resp.Body.Close()
    fmt.Println(url, resp.StatusCode)
}

func main() {
    sites := []string{"https://go.dev", "https://github.com", "https://exemplo.invalido"}
    var wg sync.WaitGroup
    for _, s := range sites {
        wg.Add(1)
        go checar(s, &wg)                    // "go" na frente: roda em paralelo
    }
    wg.Wait()                                 // espera todas
}

defer agenda uma chamada para o fim da função: ótimo para fechar arquivos e liberar recursos.

Channels

"Não se comunique compartilhando memória; compartilhe memória se comunicando." Um channel é um cano por onde as goroutines trocam valores: 

resultados := make(chan string)

for _, s := range sites {
    go func(url string) {
        resultados <- url + " ok"            // envia
    }(s)
}

for range sites {
    fmt.Println(<-resultados)               // recebe (espera até chegar)
}

select {                                     // espera o que vier primeiro
case r := <-resultados:
    fmt.Println(r)
case <-time.After(2 * time.Second):
    fmt.Println("demorou demais")
}

Mutex

var (
    mu    sync.Mutex
    total int
)
mu.Lock()
total++          // só uma goroutine por vez aqui dentro
mu.Unlock()
Dica

Rode os testes com go test -race: o detector de corridas acusa quando duas goroutines mexem na mesma variável sem proteção.
