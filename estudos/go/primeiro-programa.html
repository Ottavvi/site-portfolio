O primeiro programa

Aula · 9 min

Go (ou Golang) foi criada no Google para ser simples de ler e rápida de compilar e rodar. Docker, Kubernetes e muitas ferramentas de infraestrutura são escritos em Go, e ela é muito usada em APIs que precisam aguentar muito acesso. Para testar sem instalar, use o Go Playground (go.dev/play); para instalar, go.dev/dl. 

mkdir ola && cd ola
go mod init ola       # cria o go.mod (o módulo)
go run .              # compila e roda
go build              # gera um executável único, sem dependências
// main.go
package main

import "fmt"

func main() {
    nome := "Ana"                // declara e atribui, deduzindo o tipo
    var idade int = 32           // forma longa
    const pi = 3.14159

    fmt.Println("Olá,", nome)
    fmt.Printf("%s tem %d anos\n", nome, idade)
    total := fmt.Sprintf("R$ %.2f", 19.9*3)
    fmt.Println(total, pi)
}
  • Todo programa executável tem package main e uma func main().
  • := declara uma variável nova (só dentro de funções). Variáveis sem valor começam com o valor zero: 0, "", false, nil.
  • Variável declarada e não usada é erro de compilação, assim como import não usado. Parece chato, mas mantém o código limpo.
  • gofmt formata o código num estilo único (o editor faz ao salvar): ninguém discute onde vai a chave.

Teste o que aprendeu

  1. O que := faz?

  2. O que acontece com uma variável declarada e nunca usada?

  3. Qual o valor de var n int antes de qualquer atribuição?
