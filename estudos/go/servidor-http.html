Servidor HTTP e context

Aula · 14 min

A biblioteca padrão do Go já tem um servidor HTTP pronto para produção. Desde o Go 1.22, as rotas aceitam método e parâmetros: 

func main() {
    mux := http.NewServeMux()
    mux.HandleFunc("GET /produtos", listar)
    mux.HandleFunc("GET /produtos/{id}", buscar)
    mux.HandleFunc("POST /produtos", criar)

    log.Println("Ouvindo em :8080")
    log.Fatal(http.ListenAndServe(":8080", registrar(mux)))
}

func buscar(w http.ResponseWriter, r *http.Request) {
    id, err := strconv.Atoi(r.PathValue("id"))
    if err != nil {
        http.Error(w, "id inválido", http.StatusBadRequest)
        return
    }
    p, ok := produtos[id]
    if !ok {
        http.NotFound(w, r)
        return
    }
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(p)
}

func criar(w http.ResponseWriter, r *http.Request) {
    var p Produto
    if err := json.NewDecoder(r.Body).Decode(&p); err != nil || p.Nome == "" {
        http.Error(w, "JSON inválido", http.StatusBadRequest)
        return
    }
    // ... guardar
    w.WriteHeader(http.StatusCreated)
    json.NewEncoder(w).Encode(p)
}

Cada requisição roda na sua própria goroutine: se dois handlers mexem no mesmo map, proteja com um sync.Mutex.

Middleware

func registrar(proximo http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        inicio := time.Now()
        proximo.ServeHTTP(w, r)
        log.Printf("%s %s %v", r.Method, r.URL.Path, time.Since(inicio))
    })
}

context: cancelar e limitar tempo

ctx, cancel := context.WithTimeout(r.Context(), 3*time.Second)
defer cancel()
req, _ := http.NewRequestWithContext(ctx, "GET", "https://api.lenta.com", nil)
resp, err := http.DefaultClient.Do(req)   // desiste em 3 s, ou se o cliente desconectar

O context leva prazos e cancelamentos por toda a cadeia de chamadas. Funções que fazem rede ou banco recebem um ctx como primeiro parâmetro, por convenção.
