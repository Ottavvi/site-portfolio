Dicionários de texto

Aula · 11 min

O primeiro passo é tirar os textos do código. Cada texto ganha uma chave, e cada idioma tem um dicionário com as mesmas chaves: 

<h1 data-i18n="titulo"></h1>
<p data-i18n="boasVindas"></p>
<button data-i18n="botao"></button>
<p>
  <button data-idioma="pt">Português</button>
  <button data-idioma="en">English</button>
</p>

<script>
  const textos = {
    pt: { titulo: 'Loja de café', boasVindas: 'Bem-vindo! Escolha o seu café.', botao: 'Comprar' },
    en: { titulo: 'Coffee shop', boasVindas: 'Welcome! Pick your coffee.', botao: 'Buy' }
  };

  function aplicar(idioma) {
    document.documentElement.lang = idioma;
    document.querySelectorAll('[data-i18n]').forEach(el => {
      el.textContent = textos[idioma][el.dataset.i18n];
    });
  }

  document.querySelectorAll('[data-idioma]').forEach(b =>
    b.addEventListener('click', () => aplicar(b.dataset.idioma))
  );
  aplicar('pt');
</script>

Variáveis no meio do texto

Nunca monte frases juntando pedaços: a ordem das palavras muda entre idiomas. Coloque marcadores no texto e troque na hora de usar: 

<script>
  const textos = {
    pt: { pedido: 'Olá, {nome}! Seu pedido nº {numero} saiu para entrega.' },
    en: { pedido: 'Hi {nome}! Your order #{numero} is on its way.' }
  };

  function t(idioma, chave, vars = {}) {
    const modelo = textos[idioma]?.[chave] ?? textos.pt[chave] ?? chave;
    return modelo.replace(/\{(\w+)\}/g, (_, nome) => vars[nome] ?? `{${nome}}`);
  }

  console.log(t('pt', 'pedido', { nome: 'Ana', numero: 42 }));
  console.log(t('en', 'pedido', { nome: 'Ana', numero: 42 }));
</script>

Idioma de reserva

Sempre vai faltar alguma tradução. A função acima cai para o português (o idioma "base") e, em último caso, mostra a própria chave, o que torna o esquecimento fácil de achar na tela. Em projetos grandes, um script que compara as chaves dos dicionários aponta o que falta antes de publicar.

Dica

Bibliotecas como i18next (JavaScript) e react-intl (React) fazem tudo isso e mais. Entender a versão caseira ajuda a usar qualquer uma delas.

  1. Por que não montar 'Olá, ' + nome + '!' em código?

  2. O que a função deve fazer quando falta uma tradução?

  3. O que document.documentElement.lang = "en" muda?
