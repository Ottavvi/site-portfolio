Mensagens no formato ICU

Aula · 11 min

Na trilha básica, os plurais ficavam num objeto separado ({ one: ..., other: ... }). As bibliotecas profissionais (FormatJS, i18next com o plugin ICU, e a maioria das ferramentas de tradução) usam o formato de mensagem ICU, que coloca as variações dentro do próprio texto: 

{n, plural, =0 {Carrinho vazio} one {# item no carrinho} other {# itens no carrinho}}

{genero, select, feminino {Ela comentou} masculino {Ele comentou} other {Comentaram}} na sua foto.

Olá, {nome}! Você tem {n, plural, one {# mensagem nova} other {# mensagens novas}}.
  • plural escolhe pela categoria do número no idioma (one, other...), e =0 pega um valor exato. O # é trocado pelo número.
  • select escolhe por um texto, como o gênero, e other é o caso padrão (obrigatório).
  • A frase inteira fica com o tradutor, que pode mudar a ordem e as variações conforme o idioma pede.

Um select em miniatura

Bibliotecas fazem a análise completa, mas o princípio cabe em poucas linhas:

<script>
  // Entende só: {variavel, select, opcao {texto} ... other {texto}}
  function formatarSelect(mensagem, vars) {
    return mensagem.replace(/\{(\w+), select, ((?:\w+ \{[^}]*\} ?)+)\}/g, (_, nome, opcoes) => {
      const mapa = Object.fromEntries([...opcoes.matchAll(/(\w+) \{([^}]*)\}/g)].map(m => [m[1], m[2]]));
      return mapa[vars[nome]] ?? mapa.other;
    });
  }

  const msg = '{genero, select, feminino {Ela comentou} masculino {Ele comentou} other {Comentaram}} na sua foto.';
  console.log(formatarSelect(msg, { genero: 'feminino' }));
  console.log(formatarSelect(msg, { genero: 'masculino' }));
  console.log(formatarSelect(msg, {}));
</script>

Contexto para quem traduz

"Abrir" é um verbo num botão ("Abrir arquivo") e pode ser um estado numa etiqueta ("Aberto"). Sem contexto, o tradutor erra. Boas práticas:

  • Chaves que dizem onde o texto aparece: carrinho.botaoFinalizar, não texto37.
  • Uma descrição junto de cada texto ambíguo ("botão; até 20 caracteres").
  • Prints das telas para o tradutor, quando possível.
  • Nunca reaproveitar a mesma chave em dois lugares só porque, em português, o texto é igual.
Dica

Ferramentas como Crowdin, Lokalise e Weblate guardam os textos, mostram o contexto para os tradutores e geram os arquivos de cada idioma, integrando com o Git.
