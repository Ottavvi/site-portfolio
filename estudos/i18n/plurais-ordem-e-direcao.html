Plurais, ordem e direção

Aula · 13 min

Plurais

quantidade === 1 ? 'item' : 'itens' funciona em português e inglês, mas não em muitas línguas. O Intl.PluralRules diz qual categoria de plural um número usa naquele idioma (zero, one, two, few, many ou other), e o dicionário tem um texto por categoria: 

<script>
  const formas = {
    pt: { one: '{n} item no carrinho', other: '{n} itens no carrinho' },
    en: { one: '{n} item in your cart', other: '{n} items in your cart' }
  };

  function itens(n, idioma) {
    const categoria = new Intl.PluralRules(idioma).select(n);
    return (formas[idioma][categoria] ?? formas[idioma].other).replace('{n}', n);
  }

  for (const n of [0, 1, 2, 5]) console.log(itens(n, 'pt'), '|', itens(n, 'en'));

  // Algumas línguas têm mais categorias:
  const pl = new Intl.PluralRules('pl');
  console.log('polonês:', [1, 2, 5, 22].map(n => n + '→' + pl.select(n)).join(' '));
</script>

Repare no zero: em inglês ele é "other" ("0 items"), mas no português do Brasil (e no francês) cai em "one" e vira "0 item". No português de Portugal, volta a ser "other". É exatamente o tipo de regra que ninguém lembra de cabeça.

Ordenar com acentos

O sort() padrão compara códigos de caractere: maiúsculas vêm antes das minúsculas, e "Ávila" vai parar depois de "Zé". O Intl.Collator ordena como um dicionário daquela língua: 

<script>
  const nomes = ['Zé', 'ana', 'Ávila', 'Bruno', 'Álvaro', 'arthur'];
  console.log([...nomes].sort().join(', '));
  console.log([...nomes].sort(new Intl.Collator('pt-BR').compare).join(', '));

  // Busca que ignora acento e maiúsculas
  const igual = new Intl.Collator('pt-BR', { sensitivity: 'base' }).compare;
  console.log(igual('avila', 'Ávila') === 0);
</script>

Direita para a esquerda

Em árabe, hebraico e persa, <html dir="rtl"> inverte a direção do texto e do layout. Para o CSS acompanhar, use propriedades lógicas: margin-inline-start em vez de margin-left, padding-inline, inset-inline-end, text-align: start. Elas se adaptam sozinhas à direção: 

<style>
  .cartao { border-inline-start: 4px solid teal; padding-inline-start: 12px; margin-block: 8px; }
</style>
<div class="cartao" dir="ltr" lang="en">Order shipped</div>
<div class="cartao" dir="rtl" lang="ar">تم شحن الطلب</div>
Dica

Teste o layout com textos longos e com dir="rtl" mesmo que ainda não tenha tradução para árabe: os problemas aparecem na hora.
