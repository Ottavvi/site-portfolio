Conferir traduções e testar o layout

Aula · 11 min

Com vários idiomas, os erros mais comuns são previsíveis e dá para pegar com código antes de publicar:

  • Chave faltando num idioma: o texto cai no idioma de reserva ou aparece a chave na tela.
  • Chave sobrando: um texto que não existe mais no idioma base.
  • Variável diferente: o tradutor escreveu {nme} em vez de {nome}, ou esqueceu uma variável.
  • Texto que não cabe: a tradução é mais longa e quebra o botão.

Um script que compara os dicionários pode rodar no GitHub Actions a cada push e barrar o que estiver incompleto. É o próximo desafio.

Pseudo-localização

Antes de ter qualquer tradução, dá para testar se o site aguenta: troque cada texto por uma versão "falsa", mais longa e cheia de acentos, mas ainda legível. Textos que continuam em português na tela são os que alguém esqueceu de tirar do código, e botões que quebram mostram onde o layout é frágil: 

<style>
  .barra { display: flex; gap: 8px; max-width: 360px; }
  button { white-space: nowrap; padding: 8px 12px; }
</style>
<div class="barra" id="barra">
  <button data-i18n="salvar">Salvar</button>
  <button data-i18n="cancelar">Cancelar</button>
  <button data-i18n="excluir">Excluir conta</button>
</div>
<p><label><input type="checkbox" id="pseudo"> Pseudo-localização</label></p>

<script>
  const acentos = { a: 'á', e: 'ë', i: 'ï', o: 'ö', u: 'ü', c: 'ç', n: 'ñ', A: 'Å', E: 'É', S: 'Š', C: 'Ç' };
  const pseudo = texto => '[' + [...texto].map(l => acentos[l] ?? l).join('') + ' ' + '·'.repeat(Math.ceil(texto.length * 0.4)) + ']';

  const originais = [...document.querySelectorAll('[data-i18n]')].map(b => b.textContent);
  document.querySelector('#pseudo').addEventListener('change', e => {
    document.querySelectorAll('[data-i18n]').forEach((b, i) => {
      b.textContent = e.target.checked ? pseudo(originais[i]) : originais[i];
    });
  });
</script>

Os colchetes mostram se o texto foi cortado no começo ou no fim, e os pontos simulam o crescimento de 30% a 40% comum em traduções. Com a caixa marcada, os botões passam da largura da barra: é o sinal para permitir quebra de linha ou repensar o layout.

Dica

No Chrome, as ferramentas de desenvolvedor permitem simular outro idioma (Sensores, Localização, e o idioma em Configurações de idioma). Combine com dir="rtl" para testar árabe e hebraico.
