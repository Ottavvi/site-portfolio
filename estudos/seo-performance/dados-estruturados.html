Dados estruturados com schema.org

Aula · 12 min

O texto da página diz "Diária a partir de R$ 180, check-in às 14h". Uma pessoa entende; um robô precisa adivinhar. Os dados estruturados dizem a mesma coisa num formato que máquinas leem sem adivinhar, usando o vocabulário do schema.org. Em troca, o Google pode mostrar o resultado com estrelas, preços, perguntas expansíveis ou o quadro do negócio.

JSON-LD

O formato recomendado é um <script type="application/ld+json"> com um objeto JSON, em qualquer lugar da página. Ele não aparece para o visitante: 

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "LodgingBusiness",
  "name": "Pousada Maré Mansa",
  "url": "https://pousadamaremansa.com.br/",
  "telephone": "+55-81-99999-0000",
  "priceRange": "R$ 100 a R$ 280",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Rua da Praia, 123",
    "addressLocality": "Ipojuca",
    "addressRegion": "PE",
    "postalCode": "55590-000",
    "addressCountry": "BR"
  },
  "checkinTime": "14:00",
  "checkoutTime": "13:00",
  "petsAllowed": true
}
</script>
<script>
  // Confere se o JSON é válido e mostra o tipo
  const dados = JSON.parse(document.querySelector('script[type="application/ld+json"]').textContent);
  console.log(dados['@type'], '·', dados.address.addressLocality);
</script>

@type diz o que é a coisa (LodgingBusiness é uma hospedagem; há Restaurant, Dentist, Product, Course, Article...). Cada tipo tem propriedades próprias, listadas no schema.org.

Perguntas frequentes

{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Aceita animais de estimação?",
      "acceptedAnswer": { "@type": "Answer", "text": "Sim, pets são bem-vindos." }
    }
  ]
}

As regras

  • Os dados precisam corresponder ao que está visível na página. Marcar uma nota 5 estrelas que não aparece em lugar nenhum é motivo de punição.
  • Teste no Teste de pesquisa aprimorada do Google (search.google.com/test/rich-results): ele mostra os erros e quais destaques a página pode ganhar.
  • Dados estruturados não garantem os destaques: o Google decide quando mostrar.
Dica

O site da Pousada Lagoa Azul, no portfólio, tem um bloco JSON-LD do tipo LodgingBusiness gerado a partir dos mesmos dados do painel de edição. Assim, o que o robô lê nunca fica diferente do que o hóspede vê.

Teste o que aprendeu

  1. Qual o formato recomendado de dados estruturados?

  2. Para que serve o @type?

  3. Posso marcar avaliações que não aparecem na página?
