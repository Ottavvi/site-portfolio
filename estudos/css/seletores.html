Seletores

Aula · 9 min

O seletor é a parte da regra que diz quais elementos recebem o estilo. Saber escolher o seletor certo é metade do CSS.

Os seletores básicos

  • Tag: p pega todos os parágrafos.
  • Classe: .destaque pega todo elemento com class="destaque". Um elemento pode ter várias classes, separadas por espaço.
  • Id: #topo pega o elemento com id="topo", que deve ser único na página.
  • Universal: * pega todos os elementos.
<style>
  p { color: #555; }
  .destaque { background: #fff3b0; }
  .aviso { font-weight: bold; }
  #rodape { color: #999; }
</style>

<p>Um parágrafo comum.</p>
<p class="destaque">Este tem fundo amarelo.</p>
<p class="destaque aviso">Este tem fundo amarelo e negrito.</p>
<p id="rodape">Este é o rodapé.</p>
Dica

Prefira classes para estilizar. Elas podem ser reaproveitadas e têm uma força (especificidade) equilibrada. Deixe o id para links internos e JavaScript.

Combinando seletores

  • Descendente (com espaço): nav a pega links que estão em qualquer lugar dentro de um nav.
  • Filho direto: ul > li pega só os li que estão logo abaixo da ul.
  • Tag com classe (sem espaço): p.destaque pega parágrafos que têm a classe destaque.
  • Grupo (com vírgula): h1, h2, h3 aplica a mesma regra aos três.
<style>
  h1, h2 { font-family: Georgia, serif; }
  nav a { color: white; text-decoration: none; }
  nav { background: #1d4e89; padding: 8px; }
</style>

<nav><a href="#">Início</a> · <a href="#">Contato</a></nav>
<h1>Título</h1>
<h2>Subtítulo</h2>
<p>Este <a href="#">link</a> fora do nav continua azul e sublinhado.</p>

Pseudo-classes

Pseudo-classes, escritas com dois-pontos, selecionam elementos num estado: a:hover (mouse em cima), input:focus (campo ativo), li:first-child (o primeiro item). Veremos mais delas no nível avançado. 

a:hover { color: crimson; }
li:first-child { font-weight: bold; }
