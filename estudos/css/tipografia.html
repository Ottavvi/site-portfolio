Tipografia

Aula · 9 min

A maior parte de um site é texto. Cuidar da tipografia é o que mais muda a cara de uma página com o menor esforço.

A família da fonte

font-family recebe uma lista de fontes, da preferida para a reserva. O navegador usa a primeira que encontrar. A lista sempre termina numa família genérica: serif (com serifa), sans-serif (sem serifa) ou monospace (largura fixa, para código). 

body { font-family: system-ui, "Segoe UI", Roboto, sans-serif; }
h1 { font-family: Georgia, "Times New Roman", serif; }
code { font-family: ui-monospace, Consolas, monospace; }

Nomes com espaço vão entre aspas. system-ui usa a fonte do sistema da pessoa, que carrega na hora porque já está instalada. Para fontes de fora, como as do Google Fonts, é preciso carregar o arquivo antes.

Tamanho, peso e estilo

  • font-size: o tamanho, de preferência em rem.
  • font-weight: a espessura, de 100 a 900. 400 é o normal e 700, o negrito.
  • font-style: italic: itálico.
  • text-transform: uppercase: tudo em maiúsculas, sem mudar o texto no HTML.
  • letter-spacing: espaço entre as letras. Textos em maiúsculas ficam melhores com um pouco a mais.

Altura de linha e largura

line-height é o espaço entre as linhas. Para textos corridos, algo entre 1.5 e 1.7 (sem unidade, multiplica o tamanho da letra) deixa a leitura confortável. Títulos grandes ficam melhores com menos, perto de 1.2.

Linhas longas demais cansam: o olho se perde ao voltar para o começo da próxima. Limite a largura do texto a uns 60 a 75 caracteres com max-width: 65ch (ch é a largura do caractere "0"). 

<style>
  body { font-family: system-ui, sans-serif; }
  h1 { font-family: Georgia, serif; font-size: 2.25rem; line-height: 1.2; }
  .chapeu { text-transform: uppercase; letter-spacing: 0.1em; font-size: 0.8rem; font-weight: 700; color: #b5482b; }
  .texto { line-height: 1.7; max-width: 65ch; }
  .centro { text-align: center; font-style: italic; }
</style>

<p class="chapeu">Tipografia</p>
<h1>Um bom texto começa pelo espaço entre as linhas</h1>
<p class="texto">Repare como este parágrafo é confortável de ler: as linhas têm espaço para respirar e não passam de uma largura razoável, então o olho encontra fácil o começo da linha seguinte, mesmo numa tela grande.</p>
<p class="centro">Texto centralizado funciona para frases curtas, não para parágrafos.</p>
Dica

Duas famílias de fonte por site costumam bastar: uma para títulos e outra para o texto. Mais do que isso tende a parecer bagunçado.

Teste o que aprendeu

  1. Por que a lista do font-family termina em algo como sans-serif?

  2. Qual line-height é mais confortável para um parágrafo longo?

  3. Para que serve max-width: 65ch num parágrafo?
