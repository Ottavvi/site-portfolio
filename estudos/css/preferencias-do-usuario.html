Respeitar as preferências da pessoa

Aula · 11 min

O sistema operacional guarda preferências que o CSS consegue ler. Respeitar essas preferências é acessibilidade e também boa educação com quem visita.

prefers-reduced-motion

Para pessoas com distúrbios vestibulares, animações grandes (parallax, zoom, elementos deslizando) causam enjoo e tontura de verdade. Quem ativa "reduzir movimento" no sistema deve receber uma página calma: 

.cartao { transition: transform 0.4s; }
.cartao:hover { transform: translateY(-6px) scale(1.02); }

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

A regra acima é um "freio geral" usado em muitos sites. Reduzir movimento não precisa tirar todo efeito: uma mudança de cor ou de opacidade costuma continuar confortável.

prefers-color-scheme

<style>
  :root { --fundo: #ffffff; --texto: #1f2933; color-scheme: light dark; }
  @media (prefers-color-scheme: dark) {
    :root { --fundo: #0f1720; --texto: #e6edf3; }
  }
  body { background: var(--fundo); color: var(--texto); }
</style>
<p>Mude o tema do seu sistema e veja esta página acompanhar.</p>
<input placeholder="Até os campos acompanham">

color-scheme: light dark avisa ao navegador que a página suporta os dois temas, e ele ajusta sozinho barras de rolagem e campos de formulário.

Foco visível

Quem navega pelo teclado precisa ver onde está. Nunca remova o contorno de foco sem colocar outro no lugar. :focus-visible mostra o anel só quando a navegação é pelo teclado, e não a cada clique do mouse: 

<style>
  button { padding: 8px 14px; border: 0; border-radius: 8px; background: #0b7a6f; color: #fff; }
  button:focus { outline: none; }
  button:focus-visible { outline: 3px solid #f5a524; outline-offset: 3px; }
</style>
<button>Primeiro</button> <button>Segundo</button>
<p>Clique e depois use Tab: o anel aparece só com o teclado.</p>

Contraste e cores forçadas

  • Texto comum precisa de contraste de pelo menos 4,5:1 com o fundo (WCAG AA); texto grande, 3:1. As ferramentas de desenvolvedor mostram o contraste ao inspecionar uma cor.
  • @media (prefers-contrast: more) permite reforçar bordas e cores para quem pediu mais contraste.
  • No modo de alto contraste do Windows (forced-colors: active), o sistema troca as cores. Sombras somem: use bordas transparentes onde a borda importa, porque elas ganham cor nesse modo.
Dica

Teste rápido de acessibilidade: navegue pela página só com Tab, Enter e Esc. Se alguma coisa não dá para usar ou o foco some, há trabalho a fazer.

Teste o que aprendeu

  1. Por que respeitar prefers-reduced-motion?

  2. Qual a diferença entre :focus e :focus-visible?

  3. Qual o contraste mínimo para texto comum no nível AA?
