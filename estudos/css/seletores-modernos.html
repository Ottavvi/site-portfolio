Seletores modernos

Aula · 11 min

O CSS ganhou nos últimos anos seletores que antes exigiam JavaScript ou muita repetição. Todos funcionam nos navegadores atuais.

:focus-visible

Quem navega pelo teclado depende do contorno de foco para saber onde está. :focus mostra o contorno até num clique de mouse, e muita gente apaga o contorno por isso, o que é um erro grave de acessibilidade. :focus-visible só aparece quando o navegador acha que o foco precisa ser visto, como na navegação com Tab: 

<style>
  .botao { padding: 10px 16px; border: 0; border-radius: 8px; background: #1d4e89; color: white; }
  .botao:focus-visible { outline: 3px solid #f5a623; outline-offset: 3px; }
</style>

<button class="botao">Clique em mim</button>
<button class="botao">Depois aperte Tab</button>
Dica

Nunca use outline: none sem colocar outro indicador de foco no lugar.

:is() e :where(): menos repetição

:is() agrupa seletores dentro de um seletor maior. Em vez de escrever três seletores longos: 

/* Antes */
article h1, article h2, article h3 { line-height: 1.2; }

/* Com :is() */
article :is(h1, h2, h3) { line-height: 1.2; }

:where() faz o mesmo, mas com especificidade zero. É ótimo para estilos padrão que devem ser fáceis de sobrescrever.

:has(): o seletor de pai

Por anos, o CSS só conseguia olhar para dentro: estilizar um filho com base no pai. :has() inverte: estiliza um elemento com base no que ele contém. 

<style>
  .campo { padding: 12px; border: 2px solid #ccc; border-radius: 10px; margin-bottom: 8px; }
  .campo:has(input:checked) { border-color: #0b7a6f; background: #e6f6f3; }
  .cartao:has(img) { display: grid; grid-template-columns: 80px 1fr; gap: 12px; }
</style>

<label class="campo"><input type="checkbox"> Quero receber novidades</label>
<label class="campo"><input type="checkbox"> Aceito os termos</label>

Sem nenhuma linha de JavaScript, o cartão muda quando a caixa é marcada.

CSS aninhado

Agora dá para escrever regras dentro de regras, como nos pré-processadores. O & representa o seletor de fora: 

<style>
  .cartao {
    padding: 16px;
    border-radius: 12px;
    background: #f4f1ea;

    h2 { margin-top: 0; color: #1d4e89; }

    &:hover { background: #ece6d9; }

    @media (min-width: 600px) {
      padding: 32px;
    }
  }
</style>

<div class="cartao">
  <h2>Aninhamento</h2>
  <p>Tudo o que é do cartão fica junto, num bloco só.</p>
</div>
Dica

Aninhe pouco: dois ou três níveis no máximo. Aninhamento fundo gera seletores longos e com especificidade alta, justamente o que a aula de cascata ensinou a evitar.
