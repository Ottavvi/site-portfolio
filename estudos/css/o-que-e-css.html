O que é CSS

Aula · 8 min

CSS (Cascading Style Sheets) é a linguagem que define a aparência da página: cores, fontes, espaços, tamanhos e a posição de cada coisa. O HTML diz o que cada parte é, e o CSS diz como ela deve parecer.

A anatomia de uma regra

Todo CSS é feito de regras. Cada regra tem um seletor (em quem aplicar) e um bloco de declarações entre chaves. Cada declaração é um par propriedade: valor;. 

h1 {
  color: navy;
  font-size: 32px;
}

Lendo em voz alta: "todo h1 fica com a cor azul-marinho e letra de 32 pixels". O ponto e vírgula separa uma declaração da outra; esquecer um é o erro mais comum de quem começa, e faz o navegador ignorar a linha seguinte.

Onde escrever o CSS

Há três jeitos de ligar o CSS a uma página:

  • Arquivo separado, com <link rel="stylesheet" href="estilo.css"> no <head>. É o jeito certo para sites de verdade: um arquivo serve todas as páginas e o navegador guarda em cache.
  • Tag <style> dentro da página. Prático para exemplos e páginas únicas. É o que vamos usar nos exercícios.
  • Atributo style direto no elemento. Funciona, mas espalha o visual pelo HTML e fica difícil de manter. Evite. 
<style>
  body { background: #f4f1ea; }
  h1 { color: #1d4e89; }
  p { color: #444; }
</style>

<h1>Meu primeiro CSS</h1>
<p>Este parágrafo ficou cinza, e o título, azul.</p>
Dica

Clique em Experimente e mude os valores: troque #1d4e89 por crimson e veja o título mudar na hora.

Comentários

Comentários em CSS ficam entre /* e */. O navegador ignora tudo o que estiver ali dentro, então eles servem para explicar o porquê de uma regra ou desligar uma linha temporariamente. 

/* Cor da marca, usada nos títulos */
h1 { color: #1d4e89; }

  2. Qual é a melhor forma de ligar o CSS num site com várias páginas?

  3. O que acontece se faltar o ponto e vírgula entre duas declarações?
