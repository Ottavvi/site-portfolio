Cores e unidades

Aula · 9 min

Cores

As propriedades mais usadas para cor são color (cor do texto) e background-color (cor do fundo; o atalho background também serve). Existem várias formas de escrever a mesma cor:

  • Nome: tomato, navy, white. Há cerca de 140 nomes prontos.
  • Hexadecimal: #ff6347. Dois dígitos para vermelho, verde e azul, de 00 a ff. É o formato que você vai encontrar em quase todo design.
  • rgb(): rgb(255 99 71). As mesmas três quantidades, de 0 a 255.
  • hsl(): hsl(9 100% 64%). Matiz (0 a 360 no círculo das cores), saturação e luminosidade. Fácil de ajustar à mão: para uma versão mais escura, baixe só a luminosidade.

Para transparência, acrescente uma barra e a opacidade: rgb(0 0 0 / 50%) é preto pela metade. 

<style>
  .a { background: tomato; }
  .b { background: #1d4e89; color: white; }
  .c { background: hsl(150 60% 40%); color: white; }
  .d { background: hsl(150 60% 25%); color: white; }
  .e { background: rgb(0 0 0 / 15%); }
  p { padding: 8px; }
</style>

<p class="a">Nome: tomato</p>
<p class="b">Hexadecimal: #1d4e89</p>
<p class="c">hsl(150 60% 40%)</p>
<p class="d">O mesmo verde, só com luminosidade 25%</p>
<p class="e">Preto com 15% de opacidade</p>
Dica

Texto precisa de contraste com o fundo para ser lido por todo mundo. Cinza claro sobre branco fica bonito no monitor de quem desenhou e ilegível no celular ao sol.

Unidades de medida

  • px: pixels. Bom para bordas e detalhes finos.
  • rem: múltiplos do tamanho de letra da raiz da página (normalmente 16px). 1.5rem = 24px. Respeita quem aumentou a fonte nas configurações do navegador, por isso é a melhor escolha para textos e espaçamentos.
  • em: múltiplos do tamanho de letra do próprio elemento. Útil para espaços que acompanham o texto, como o recuo de um botão.
  • %: porcentagem do elemento pai. width: 50% ocupa metade da largura de quem o contém. 
<style>
  h1 { font-size: 2rem; }
  p { font-size: 1rem; }
  .pequeno { font-size: 0.875rem; color: #666; }
  .metade { width: 50%; background: #e0ecf8; }
</style>

<h1>2rem = 32px</h1>
<p>1rem = 16px, o tamanho padrão.</p>
<p class="pequeno">0.875rem = 14px</p>
<p class="metade">Eu ocupo metade da largura.</p>

Teste o que aprendeu

  1. Qual propriedade muda a cor do texto?

  2. Por que usar rem em vez de px para o tamanho dos textos?

  3. Em hsl(210 70% 50%), o que mudar para deixar a cor mais escura sem mudar o tom?
