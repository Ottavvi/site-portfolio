Modelo de caixa

Aula · 10 min

Para o CSS, todo elemento é uma caixa retangular. Entender as camadas dessa caixa resolve a maior parte dos "por que isso está desalinhado?".

As quatro camadas

  1. Conteúdo: o texto ou a imagem, com width e height.
  2. Padding: o espaço interno, entre o conteúdo e a borda. Fica com a cor de fundo do elemento.
  3. Borda (border): a linha em volta.
  4. Margem (margin): o espaço externo, que afasta a caixa das vizinhas. É sempre transparente. 
<style>
  .caixa {
    background: #e0ecf8;
    padding: 20px;
    border: 4px solid #1d4e89;
    margin: 24px;
    border-radius: 12px;
  }
</style>

<div class="caixa">Fundo azul-claro = conteúdo + padding. A borda escura vem depois, e a margem de 24px é o espaço vazio em volta.</div>
<div class="caixa">Outra caixa, afastada da primeira pela margem.</div>
Dica

Clique com o botão direito no resultado e escolha Inspecionar. O painel de estilos do navegador desenha o modelo de caixa de cada elemento, com as medidas.

Atalhos de lado

padding, margin e border aceitam valores por lado. A ordem é a dos ponteiros do relógio, começando em cima: 

padding: 10px;                /* os quatro lados */
padding: 10px 20px;           /* cima e baixo | esquerda e direita */
padding: 10px 20px 30px 40px; /* cima | direita | baixo | esquerda */
padding-top: 10px;            /* um lado só */
margin: 0 auto;               /* centraliza na horizontal uma caixa com largura definida */

A borda segue o padrão espessura estilo cor, como 1px solid #ccc. Sem o estilo (solid, dashed, dotted), ela não aparece. border-radius arredonda os cantos.

box-sizing: o ajuste que todo site faz

Por padrão, width mede só o conteúdo: uma caixa com width: 300px, padding de 20px e borda de 2px ocupa na verdade 344px. Isso confunde. Com box-sizing: border-box, a largura passa a incluir padding e borda, e 300px é 300px. 

*, *::before, *::after {
  box-sizing: border-box;
}

Essa regra aparece no topo de praticamente todo CSS moderno.

Block e inline

Elementos como div, p e h1 são block: ocupam a linha inteira e aceitam largura, altura e margens. Já span, a e strong são inline: ficam no meio do texto e ignoram largura, altura e margens de cima e de baixo. Na próxima etapa você vai aprender a trocar isso com display.

Teste o que aprendeu

  1. Qual camada fica entre o conteúdo e a borda?

  2. Com box-sizing: border-box, uma caixa com width: 200px e padding: 20px ocupa quanto de largura?

  3. O que faz margin: 0 auto numa caixa com max-width?
