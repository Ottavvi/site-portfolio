Cascata e especificidade

Aula · 10 min

É comum duas regras tentarem mudar a mesma propriedade do mesmo elemento. O "C" de CSS, a cascata, é o conjunto de critérios que decide quem vence.

1. Especificidade: o seletor mais específico vence

Cada seletor tem um peso. Pense numa pontuação com três casas:

  • id (#menu) vale 1-0-0;
  • classe, pseudo-classe e atributo (.ativo, :hover, [type]) valem 0-1-0;
  • tag (p, li) vale 0-0-1.

As casas se somam e são comparadas da esquerda para a direita. nav .link (0-1-1) vence a (0-0-1), e um único id vence qualquer quantidade de classes. 

<style>
  #aviso { color: purple; }   /* 1-0-0: vence */
  .texto { color: green; }    /* 0-1-0 */
  p { color: red; }           /* 0-0-1 */
</style>

<p id="aviso" class="texto">De que cor eu fico?</p>
<p class="texto">E eu?</p>
<p>E eu?</p>

2. Ordem: com o mesmo peso, a última vence

Se dois seletores têm a mesma especificidade, vale o que aparece por último no código. Por isso a ordem das regras e dos arquivos CSS importa. 

<style>
  .botao { background: gray; }
  .botao { background: teal; } /* mesma força, vem depois: vence */
  .botao { color: white; padding: 8px 16px; border: 0; }
</style>

<button class="botao">Botão</button>

3. Herança

Algumas propriedades, principalmente as de texto (color, font-family, line-height), passam de pai para filho. Por isso definir a fonte no body muda a página inteira. Propriedades de caixa, como padding, border e background, não são herdadas. Qualquer regra que mire o elemento diretamente vence o valor herdado.

E o !important?

Colocar !important depois de um valor passa por cima da especificidade. Parece uma solução, mas cria uma guerra: para vencer um !important, só outro !important. Se você precisa dele, quase sempre o problema é um seletor forte demais em outro lugar. Use em último caso.

Dica

Para manter o CSS fácil de mudar, mantenha a especificidade baixa e parecida: uma classe por seletor resolve quase tudo.

Teste o que aprendeu

  1. Quem vence: ".menu a" ou "#topo"?

  2. Duas regras .card mudam o background. Qual vence?

  3. Qual destas propriedades é herdada pelos filhos?
