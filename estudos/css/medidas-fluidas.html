Medidas fluidas

Aula · 9 min

Media queries mudam o layout em pontos fixos. Medidas fluidas fazem as coisas crescerem e encolherem de forma contínua, e muitas vezes dispensam a media query.

max-width em vez de width

width: 900px estoura a tela de um celular de 360px. max-width: 900px diz "no máximo 900px", e a caixa encolhe quando não houver espaço. Essa troca simples resolve muitos layouts quebrados. 

<style>
  .conteudo {
    max-width: 40rem;
    margin: 0 auto;
    padding: 0 16px;
  }
</style>

<div class="conteudo">
  <h1>Uma coluna de leitura</h1>
  <p>Numa tela grande, este texto fica centralizado com no máximo 40rem. Num celular, ocupa a largura toda, com 16px de folga nas laterais.</p>
</div>

Imagens que não estouram

img, video {
  max-width: 100%;
  height: auto;
}

Com isso, a imagem nunca passa da largura de quem a contém, e a altura acompanha para manter a proporção.

Unidades da tela

vw e vh são 1% da largura e da altura da tela. 100vh parece "a tela inteira", mas no celular a barra de endereço muda de tamanho; prefira 100dvh (altura dinâmica), que acompanha essa barra.

clamp(): mínimo, ideal e máximo

clamp(mínimo, ideal, máximo) escolhe o valor ideal, mas nunca sai dos limites. É perfeito para títulos que crescem com a tela sem ficar minúsculos no celular nem gigantes no monitor: 

<style>
  h1 { font-size: clamp(1.75rem, 1rem + 4vw, 3.5rem); line-height: 1.1; }
  .secao { padding: clamp(16px, 5vw, 64px); background: #f4f1ea; }
</style>

<div class="secao">
  <h1>Título fluido</h1>
  <p>Estreite e alargue a janela: o título e o espaço em volta acompanham, dentro dos limites.</p>
</div>

Também existem min() e max(). width: min(100%, 600px) é outra forma de dizer "toda a largura, mas no máximo 600px".

Dica

Combine as duas ideias: medidas fluidas para tamanhos e espaços, e media queries só quando o layout precisa mudar de forma, como passar de uma coluna para duas.

  2. Em clamp(1rem, 4vw, 3rem), qual é o tamanho numa tela muito pequena?

  3. Qual regra impede uma imagem de passar da largura da tela?
