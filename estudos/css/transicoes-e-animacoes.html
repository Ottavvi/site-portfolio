Transições e animações

Aula · 11 min

Movimento bem usado explica o que está acontecendo: um botão que responde ao toque, um menu que desliza de onde veio. Mal usado, distrai e pode até causar enjoo em algumas pessoas.

transition: do estado A ao B

Uma transição suaviza a mudança de uma propriedade. Você diz qual propriedade, quanto tempo e a curva de velocidade: 

<style>
  .botao {
    background: #1d4e89;
    color: white;
    border: 0;
    padding: 12px 20px;
    border-radius: 10px;
    transition: background-color 0.2s ease, transform 0.2s ease;
  }
  .botao:hover { background: #2f6fb8; transform: translateY(-2px); }
  .botao:active { transform: translateY(0); }
</style>

<button class="botao">Passe o mouse</button>

transform: mexer sem bagunçar o layout

transform move (translate), gira (rotate) e muda o tamanho (scale) de um elemento depois que o layout foi calculado, sem empurrar os vizinhos. Animar transform e opacity é bem mais leve para o navegador do que animar width, top ou margin.

@keyframes: animações com etapas

Quando o movimento precisa de várias etapas ou se repetir, use @keyframes para descrevê-lo e animation para aplicá-lo: 

<style>
  @keyframes pulsar {
    0%, 100% { transform: scale(1); opacity: 1; }
    50% { transform: scale(1.15); opacity: 0.7; }
  }
  .ponto {
    width: 16px;
    height: 16px;
    border-radius: 50%;
    background: crimson;
    animation: pulsar 1.2s ease-in-out infinite;
  }
  @keyframes entrar {
    from { opacity: 0; transform: translateY(12px); }
    to { opacity: 1; transform: none; }
  }
  .aviso { animation: entrar 0.5s ease both; }
</style>

<p class="aviso">Gravando <span class="ponto" style="display:inline-block"></span></p>

Menos movimento para quem pediu

Algumas pessoas sentem tontura ou náusea com animações (é comum em quem tem labirintite ou enxaqueca) e ativam a opção "reduzir movimento" no sistema. Respeite essa escolha: 

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

Este é um dos raros casos em que o !important faz sentido: a preferência da pessoa deve vencer qualquer animação do site.

Dica

Transições de interface ficam boas entre 150 e 300 milissegundos. Mais que isso, o site parece lento.

Teste o que aprendeu

  1. Quais propriedades são mais leves para animar?

  2. Quando usar @keyframes em vez de transition?

  3. Para que serve @media (prefers-reduced-motion: reduce)?
