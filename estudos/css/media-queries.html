Media queries

Aula · 10 min

Mais da metade do acesso à internet no Brasil vem do celular. Um site responsivo se adapta a qualquer largura de tela, do celular ao monitor grande.

A media query

Uma media query aplica regras só quando uma condição é verdadeira. A mais comum compara a largura da tela: 

/* Só quando a tela tiver 700px de largura ou mais */
@media (min-width: 700px) {
  .colunas { grid-template-columns: 1fr 1fr; }
}

Começar pelo celular (mobile first)

A abordagem recomendada é escrever primeiro o CSS para a tela pequena, sem media query, e usar min-width para acrescentar coisas quando sobrar espaço. Fica mais simples, porque o layout de celular costuma ser uma coluna só, que é o comportamento natural do HTML. 

<style>
  .colunas { display: grid; gap: 12px; }
  .colunas div { background: #e0ecf8; padding: 16px; border-radius: 8px; }

  @media (min-width: 500px) {
    .colunas { grid-template-columns: 1fr 1fr; }
  }
  @media (min-width: 800px) {
    .colunas { grid-template-columns: repeat(4, 1fr); }
  }
</style>

<div class="colunas">
  <div>A</div><div>B</div><div>C</div><div>D</div>
</div>
<p>Abra esta página no celular ou estreite a janela para ver as colunas mudarem.</p>
Dica

Escolha os pontos de quebra pelo conteúdo, não por modelos de aparelho. Estreite a janela até o layout ficar ruim: ali é o lugar da media query.

Não esqueça a meta viewport

Sem <meta name="viewport" content="width=device-width, initial-scale=1"> no <head>, o celular finge ter uma tela de computador e as media queries nunca disparam como esperado.

Outras condições úteis

  • (prefers-color-scheme: dark): a pessoa usa o sistema no modo escuro.
  • (prefers-reduced-motion: reduce): a pessoa pediu menos animação. Veremos no nível avançado.
  • (hover: hover): o aparelho tem um mouse de verdade, então dá para depender de efeitos ao passar o mouse.
  • print: estilos para quando a página é impressa.
