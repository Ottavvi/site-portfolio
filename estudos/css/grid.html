Grid

Aula · 12 min

O flexbox pensa numa direção de cada vez. O grid pensa em duas: linhas e colunas ao mesmo tempo. Use flexbox para alinhar itens numa fila e grid para montar uma grade.

Definindo colunas

Com display: grid no pai, grid-template-columns diz quantas colunas existem e qual a largura de cada uma. A unidade fr (fração) divide o espaço disponível. 

<style>
  .grade {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 12px;
  }
  .grade div { background: #e0ecf8; padding: 20px; border-radius: 8px; text-align: center; }
</style>

<div class="grade">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
</div>
  • 1fr 1fr 1fr: três colunas iguais. O mesmo que repeat(3, 1fr).
  • 250px 1fr: uma barra lateral fixa e o resto para o conteúdo.
  • 2fr 1fr: a primeira coluna tem o dobro da segunda.

A grade que se ajusta sozinha

Esta é uma das linhas mais úteis do CSS. Ela cria quantas colunas couberem, cada uma com no mínimo 180px, e divide o que sobrar: 

<style>
  .galeria {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
    gap: 12px;
  }
  .galeria div { background: hsl(200 60% 85%); height: 100px; border-radius: 8px; }
</style>

<div class="galeria">
  <div></div><div></div><div></div><div></div><div></div><div></div>
</div>

Sem nenhuma media query, a galeria tem uma coluna no celular e quatro ou cinco numa tela larga.

Itens que ocupam mais espaço

Um item pode atravessar várias colunas ou linhas com grid-column e grid-row. span 2 significa "ocupe duas". 

<style>
  .painel { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; }
  .painel div { background: #f4f1ea; padding: 16px; border-radius: 8px; }
  .painel .grande { grid-column: span 2; background: #fde2c8; }
</style>

<div class="painel">
  <div class="grande">Destaque (2 colunas)</div>
  <div>B</div>
  <div>C</div>
  <div>D</div>
  <div>E</div>
</div>

Áreas com nome

Para o esqueleto de uma página, dá para desenhar o layout com nomes, como um mapa:

<style>
  .pagina {
    display: grid;
    grid-template-columns: 160px 1fr;
    grid-template-areas:
      "topo   topo"
      "lateral conteudo"
      "rodape rodape";
    gap: 8px;
  }
  .pagina > * { padding: 12px; background: #e0ecf8; border-radius: 6px; }
  header { grid-area: topo; }
  aside  { grid-area: lateral; }
  main   { grid-area: conteudo; }
  footer { grid-area: rodape; }
</style>

<div class="pagina">
  <header>Topo</header>
  <aside>Lateral</aside>
  <main>Conteúdo</main>
  <footer>Rodapé</footer>
</div>
