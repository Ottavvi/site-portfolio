Flexbox

Aula · 12 min

O flexbox organiza os filhos de uma caixa numa direção: em linha ou em coluna. Ele resolve de forma simples coisas que antes eram difíceis, como centralizar algo na vertical ou distribuir itens de um menu.

O contêiner e os itens

Basta display: flex no pai: os filhos diretos viram itens flex e ficam lado a lado. 

<style>
  .linha { display: flex; gap: 12px; }
  .linha div { background: #e0ecf8; padding: 16px; border-radius: 8px; }
</style>

<div class="linha">
  <div>Um</div>
  <div>Dois</div>
  <div>Três</div>
</div>

Os dois eixos

O flexbox pensa em dois eixos. O principal segue a direção (flex-direction: row, o padrão, é horizontal; column é vertical). O transversal é o outro.

  • justify-content distribui os itens no eixo principal: flex-start, center, space-between (pontas encostadas, espaço igual entre eles), space-around.
  • align-items alinha no eixo transversal: stretch (o padrão, estica), center, flex-start, flex-end.
  • gap define o espaço entre os itens, sem precisar de margens.
<style>
  header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 12px 20px;
    background: #1d4e89;
    color: white;
  }
  nav { display: flex; gap: 16px; }
  nav a { color: white; }
  .logo { font-size: 1.5rem; font-weight: 700; }
</style>

<header>
  <span class="logo">Loja</span>
  <nav>
    <a href="#">Produtos</a>
    <a href="#">Sobre</a>
    <a href="#">Contato</a>
  </nav>
</header>

Centralizar de verdade

A pergunta mais antiga do CSS, "como centralizo isso na vertical?", tem resposta curta com flexbox:

<style>
  .palco {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 200px;
    background: #f4f1ea;
  }
</style>

<div class="palco"><p>Bem no meio</p></div>

Crescer, encolher e quebrar a linha

  • flex: 1 num item faz ele ocupar todo o espaço que sobrar. Útil num campo de busca ao lado de um botão.
  • flex-wrap: wrap no contêiner deixa os itens descerem para a próxima linha quando não couberem. 
<style>
  .busca { display: flex; gap: 8px; }
  .busca input { flex: 1; padding: 8px; }
  .tags { display: flex; flex-wrap: wrap; gap: 6px; margin-top: 16px; }
  .tags span { background: #eee; padding: 4px 10px; border-radius: 999px; }
</style>

<form class="busca">
  <input type="search" placeholder="Buscar..." aria-label="Buscar">
  <button>Buscar</button>
</form>
