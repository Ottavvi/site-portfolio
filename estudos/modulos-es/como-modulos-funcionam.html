Como os módulos funcionam

Aula · 11 min

Módulos não são só scripts com import. Eles têm algumas regras diferentes que vale conhecer:

  • Modo estrito sempre: atribuir a uma variável não declarada dá erro, em vez de criar uma global sem querer.
  • Escopo próprio: const e function no topo do módulo não viram propriedades de window.
  • Rodam uma vez só: se dez arquivos importarem o mesmo módulo, ele é executado uma vez e todos recebem a mesma instância.
  • São adiados: type="module" já se comporta como defer. O HTML inteiro é lido antes, então dá para buscar elementos sem esperar o DOMContentLoaded.

Um módulo é executado uma vez

Isso permite guardar estado compartilhado num módulo, como uma configuração ou um "store" simples:

<p id="saida"></p>
<script type="module" src="./main.js"></script>

// --- config.js ---
console.log('config.js executou');
export const config = { tema: 'claro' };

// --- tema.js ---
import { config } from './config.js';
export function escurecer() { config.tema = 'escuro'; }

// --- main.js ---
import { config } from './config.js';
import { escurecer } from './tema.js';

escurecer();
document.querySelector('#saida').textContent = 'Tema: ' + config.tema;

Repare no console: "config.js executou" aparece uma vez só, e a mudança feita por tema.js é vista em main.js.

Importações são ligações vivas

O que você importa não é uma cópia: é uma ligação com a variável do outro módulo. Se ela mudar lá, muda aqui. Mas só quem exporta pode reatribuir: tentar contador = 5 no arquivo que importou dá erro.

await no topo

Dentro de módulos, dá para usar await fora de funções. O módulo que importa espera esse terminar: 

<p id="saida">Carregando…</p>
<script type="module" src="./main.js"></script>

// --- dados.js ---
const espera = ms => new Promise(r => setTimeout(r, ms));
await espera(500);
export const produtos = ['Café', 'Chá', 'Filtro'];

// --- main.js ---
import { produtos } from './dados.js';
document.querySelector('#saida').textContent = produtos.join(', ');
Dica

Await no topo é ótimo para carregar uma configuração, mas segura todos os módulos que dependem daquele. Para coisas lentas, prefira carregar depois, com import() (próximo nível).
