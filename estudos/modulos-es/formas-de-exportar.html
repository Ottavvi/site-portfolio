Formas de exportar e importar

Aula · 10 min

Exportação com nome e exportação padrão

Um módulo pode ter várias exportações com nome e no máximo uma exportação padrão (export default). A padrão é importada sem chaves, com o nome que você quiser: 

<ul id="lista"></ul>
<script type="module" src="./main.js"></script>

// --- tarefa.js ---
export default class Tarefa {
  constructor(titulo) {
    this.titulo = titulo;
    this.feita = false;
  }
}

export function criarVarias(titulos) {
  return titulos.map(t => new Tarefa(t));
}

// --- main.js ---
import Tarefa, { criarVarias } from './tarefa.js';

const tarefas = [new Tarefa('Estudar'), ...criarVarias(['Treinar', 'Ler'])];
for (const t of tarefas) {
  const li = document.createElement('li');
  li.textContent = t.titulo;
  document.querySelector('#lista').append(li);
}
Dica

Muitos times preferem só exportações com nome: o nome fica igual em todo o projeto, a busca acha todos os usos e o editor completa o import sozinho.

Renomear e importar tudo

// Renomear na importação (útil quando dois módulos exportam o mesmo nome)
import { formatar as formatarData } from './datas.js';
import { formatar as formatarMoeda } from './dinheiro.js';

// Renomear na exportação
function calcularTotal() { /* ... */ }
export { calcularTotal as total };

// Importar tudo num objeto
import * as datas from './datas.js';
datas.formatar(new Date());

Reexportar: um arquivo de entrada

Quando uma pasta tem vários módulos, é comum criar um arquivo que reexporta tudo. Quem usa importa de um lugar só: 

<p id="saida"></p>
<script type="module" src="./main.js"></script>

// --- texto.js ---
export const maiusculas = t => t.toUpperCase();

// --- numeros.js ---
export const dobro = n => n * 2;

// --- utils.js ---
export { maiusculas } from './texto.js';
export * from './numeros.js';

// --- main.js ---
import { maiusculas, dobro } from './utils.js';
document.querySelector('#saida').textContent = maiusculas('ok ') + dobro(21);
