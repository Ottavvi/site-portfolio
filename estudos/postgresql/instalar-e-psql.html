Instalar e usar o psql

Aula · 9 min

O PostgreSQL (ou Postgres) é um banco de dados relacional gratuito, robusto e cheio de recursos. Diferente do SQLite, que é um arquivo usado por um programa só, o Postgres é um servidor: muitos usuários e aplicações acessam ao mesmo tempo, com permissões, conexões pela rede e backups. Supabase, Neon e a maioria das hospedagens oferecem Postgres pronto.

Subir um servidor

# Com Docker (o jeito mais limpo de estudar)
docker run --name pg -e POSTGRES_PASSWORD=segredo -p 5432:5432 -d postgres:17
docker exec -it pg psql -U postgres

Sem Docker, use o instalador de postgresql.org (no Windows, ele traz o pgAdmin, uma interface gráfica).

O psql

CREATE DATABASE pousada;
\c pousada            -- conecta no banco
\l                    -- lista os bancos
\dt                   -- lista as tabelas
\d reservas           -- estrutura de uma tabela
\x                    -- alterna a exibição vertical (bom para linhas largas)
\timing               -- mostra quanto cada consulta levou
\q                    -- sai

Comandos que começam com \ são do psql; o resto é SQL e termina com ;. Esquecer o ponto e vírgula deixa o psql esperando a continuação (o prompt muda de =# para -#).

Bancos e esquemas

Um servidor tem vários bancos; cada banco tem esquemas (pastas de tabelas). O padrão é public. Dá para separar, por exemplo, app.reservas e relatorios.ocupacao_mensal.

Teste o que aprendeu

  1. Qual a principal diferença entre SQLite e PostgreSQL?

  2. O que faz \d reservas no psql?

  3. O psql ficou esperando depois do comando. O que faltou provavelmente?
