O que é uma expressão regular

Aula · 10 min

Uma expressão regular (regex) é um padrão que descreve um formato de texto: "cinco números, um hífen e mais três números" é um CEP. Com ela, dá para conferir se um texto segue o formato, achar todos os pedaços que seguem e trocá-los por outra coisa. Ela existe em quase toda linguagem e ferramenta: JavaScript, Python, SQL, PowerShell, Power Query, a busca do VS Code.

Em JavaScript

Uma regex fica entre barras: /padrão/flags. Os métodos mais usados:

<script>
  const texto = 'Pedido 1234 enviado para o CEP 01310-100';

  console.log(/CEP/.test(texto));            // true: o padrão aparece?
  console.log(texto.match(/\d+/));            // o primeiro trecho de dígitos
  console.log(texto.match(/\d+/g));           // com g: todos os trechos
  console.log(texto.replace(/\d/g, '#'));     // troca cada dígito por #
</script>

Caracteres e classes

Padrão Casa com
abc o texto "abc", literalmente
. qualquer caractere (menos quebra de linha)
\d um dígito (0 a 9)
\w letra sem acento, dígito ou _
\s espaço, tab ou quebra de linha
\D \W \S o contrário de cada um
[aeiou] um dos caracteres da lista
[a-z0-9] um caractere nos intervalos
[^0-9] qualquer um que NÃO esteja na lista
\. um ponto de verdade (a barra tira o poder especial)

Os caracteres especiais . * + ? ^ $ ( ) [ ] { } | \ / precisam de barra invertida antes para valerem como eles mesmos.

Flags

  • g: todas as ocorrências, não só a primeira.
  • i: ignora maiúsculas e minúsculas.
  • m: ^ e $ valem para cada linha.
  • u: modo Unicode (acentos e emojis direito; mais no nível avançado).
Dica

Use um testador visual, como o regex101.com (escolha "ECMAScript/JavaScript"). Ele colore o que casou e explica cada pedaço do padrão em inglês.

Teste o que aprendeu

  1. O que \d casa?

  2. Como casar um ponto de verdade, e não "qualquer caractere"?

  3. Para que serve a flag g em texto.replace(/a/g, "b")?
