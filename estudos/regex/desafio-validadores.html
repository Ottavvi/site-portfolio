Desafio: validadores de formulário

Desafio · 16 min

Escreva três funções que devolvem true ou false, cada uma com uma expressão regular:

  • cepValido(texto): 5 dígitos, hífen opcional e 3 dígitos. Nada antes nem depois.
  • placaValida(texto): placa no padrão Mercosul, como ABC1D23 (3 letras, 1 dígito, 1 letra, 2 dígitos) ou no padrão antigo, como ABC-1234 (3 letras, hífen, 4 dígitos). Aceite letras minúsculas também.
  • horarioValido(texto): horário de 00:00 a 23:59, sempre com dois dígitos de cada lado. 24:00 e 12:60 são inválidos.

O que o código precisa ter

  • cepValido aceita 01310-100 e 01310100
  • cepValido recusa formatos errados e lixo em volta
  • placaValida aceita o padrão Mercosul e o antigo
  • placaValida recusa placas fora do padrão
  • horarioValido aceita de 00:00 a 23:59 e recusa o resto
Ver uma solução possível 
<script>
  function cepValido(texto) {
    return /^\d{5}-?\d{3}$/.test(texto);
  }

  function placaValida(texto) {
    return /^[a-z]{3}(\d[a-z]\d{2}|-\d{4})$/i.test(texto);
  }

  function horarioValido(texto) {
    return /^([01]\d|2[0-3]):[0-5]\d$/.test(texto);
  }

  console.log(cepValido('01310-100'), placaValida('ABC1D23'), horarioValido('14:30'));
</script>
