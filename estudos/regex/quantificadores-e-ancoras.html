Quantificadores, âncoras e alternativas

Aula · 11 min

Quantificadores

Dizem quantas vezes o item anterior se repete:

Padrão Quantas vezes
a? zero ou uma (opcional)
a* zero ou mais
a+ uma ou mais
a{3} exatamente 3
a{2,4} de 2 a 4
a{2,} 2 ou mais 
<script>
  const cep = /\d{5}-?\d{3}/;      // 5 dígitos, hífen opcional, 3 dígitos
  console.log(cep.test('01310-100'), cep.test('01310100'), cep.test('0131-100'));
</script>

Âncoras: validar o texto inteiro

Sem âncoras, a regex procura o padrão em qualquer lugar. Para validar um campo, isso é um problema: /\d{5}-\d{3}/ aceita "abc01310-100xyz". As âncoras prendem o padrão ao começo (^) e ao fim ($) do texto: 

<script>
  const solto = /\d{5}-\d{3}/;
  const preso = /^\d{5}-\d{3}$/;
  console.log(solto.test('abc01310-100xyz'));  // true: achou no meio
  console.log(preso.test('abc01310-100xyz'));  // false
  console.log(preso.test('01310-100'));        // true
</script>

Outra âncora útil é \b, a borda de palavra: /\bcafé\b/ casa "café", mas não "cafeteira".

Alternativas

A barra vertical é "ou". Os parênteses delimitam até onde vai a alternativa:

<script>
  const quarto = /^(casal|triplo|quádruplo)$/i;
  console.log(quarto.test('Casal'), quarto.test('suíte'));

  // Telefone: (DDD) opcional, 4 ou 5 dígitos, hífen opcional, 4 dígitos
  const telefone = /^(\(\d{2}\)\s?)?\d{4,5}-?\d{4}$/;
  for (const t of ['(81) 99999-0000', '3333-4444', '999990000', '(81)99999-000']) {
    console.log(t, telefone.test(t));
  }
</script>
Dica

Uma regex de validação diz se o formato está certo, não se o dado existe: 00000-000 passa no padrão de CEP. Para CPF, além do formato, há os dígitos verificadores, que precisam de uma conta.

Teste o que aprendeu

  1. O que \d{2,4} casa?

  2. Por que usar ^ e $ numa validação?

  3. O que /^(sim|não)$/ aceita?
