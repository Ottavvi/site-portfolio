Regex fora do JavaScript

Aula · 10 min

O que você aprendeu vale em quase todo lugar, com pequenas diferenças de sintaxe.

VS Code: buscar e trocar no projeto inteiro

Na busca (Ctrl+Shift+F), ligue o botão .*. Na troca, os grupos são $1, $2. Exemplo: trocar todos os console.log(...) por nada antes de publicar, ou converter var nome = require('x') em import nome from 'x': 

Buscar:  var (\w+) = require\('([^']+)'\);
Trocar:  import $1 from '$2';

Python

import re

texto = "Pedidos: #12 (R$ 50,00), #15 (R$ 120,90)"
print(re.findall(r"#(\d+)", texto))                 # ['12', '15']
print(re.sub(r"(\d{2})/(\d{2})/(\d{4})", r"\3-\2-\1", "28/10/2026"))
m = re.search(r"(?P<valor>[\d.]+,\d{2})", texto)
print(m.group("valor"))

O r"..." (texto cru) evita dobrar as barras. Os grupos nomeados usam ?P<nome> e, na troca, \1.

PowerShell

'Pedido 1234' -match '\d+'      # True; o trecho fica em $Matches[0]
'28/10/2026' -replace '(\d{2})/(\d{2})/(\d{4})', '$3-$2-$1'
Select-String -Path *.log -Pattern 'ERRO|FALHA'   # o "grep" do Windows

Os operadores do PowerShell ignoram maiúsculas por padrão; para diferenciar, use -cmatch e -creplace.

SQL e Power Query

  • No SQL, o LIKE só tem % e _. Bancos como PostgreSQL têm regex de verdade (~, regexp_replace); no SQLite, o REGEXP depende de uma extensão.
  • No Power Query, não há regex nativa: as funções Text.Select, Text.Remove e Splitter.SplitTextByCharacterTransition resolvem os casos comuns (manter só dígitos, separar letras de números).
Dica

Em Python e no VS Code, a sintaxe de lookbehind e de grupos nomeados é quase igual à do JavaScript. A maior diferença costuma ser como escrever as barras e como referenciar os grupos na troca.

  2. No VS Code, como usar o primeiro grupo no campo de troca?
