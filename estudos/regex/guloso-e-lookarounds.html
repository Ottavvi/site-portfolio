Guloso, preguiçoso e lookarounds

Aula · 12 min

Guloso x preguiçoso

Os quantificadores são gulosos: pegam o máximo possível. Isso surpreende:

<script>
  const html = '<b>café</b> e <b>chá</b>';
  console.log(html.match(/<b>.*<\/b>/)[0]);   // pega do primeiro <b> até o ÚLTIMO </b>
  console.log(html.match(/<b>.*?<\/b>/)[0]);  // com ?, para no primeiro </b>
  console.log(html.match(/<b>.*?<\/b>/g));    // e com g, cada um separado
</script>

Colocar ? depois de *, + ou {} torna o quantificador preguiçoso: o mínimo possível. Muitas vezes, uma classe negada é ainda melhor e mais rápida: <b>[^<]*<\/b> ("tudo que não for <").

Lookarounds: conferir sem pegar

Às vezes você quer casar algo só se vier antes ou depois de outra coisa, sem incluir essa outra coisa no resultado:

Padrão Significa
X(?=Y) X, se seguido de Y
X(?!Y) X, se NÃO seguido de Y
(?<=Y)X X, se precedido de Y
(?<!Y)X X, se NÃO precedido de Y 
<script>
  const texto = 'Café R$ 62,90 · 2 unidades · Frete R$ 10,00';
  console.log(texto.match(/(?<=R\$ )[\d,]+/g));   // só os valores depois de "R$ "

  // Separador de milhar: põe um ponto antes de cada grupo de 3 dígitos até o fim
  console.log('1234567'.replace(/\B(?=(\d{3})+$)/g, '.'));
</script>

Senha forte com lookaheads

Lookaheads no começo do padrão funcionam como uma lista de exigências, cada uma conferida a partir do início: 

<script>
  // pelo menos 8 caracteres, uma minúscula, uma maiúscula e um dígito
  const forte = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/;
  for (const s of ['abc', 'abcdefgh', 'Abcdefg1', 'ABCDEFG1']) console.log(s, forte.test(s));
</script>
Dica

Numa tela de cadastro, mostre cada exigência separada ("✓ 8 caracteres", "✗ um número"), cada uma com a sua regex simples. Ajuda muito mais do que um único "senha inválida".

Teste o que aprendeu

  1. Em "<b>a</b><b>c</b>", o que /<b>.*<\/b>/ pega?

  2. O que (?<=R\$ )\d+ devolve em "R$ 50"?

  3. Para que servem os (?=...) no começo da regex de senha?
