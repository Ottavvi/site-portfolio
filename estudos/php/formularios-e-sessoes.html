Formulários, validação e sessões

Aula · 13 min

<?php
// contato.php
$erros = [];
$nome = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nome = trim($_POST['nome'] ?? '');
    $email = trim($_POST['email'] ?? '');

    if ($nome === '') $erros[] = 'Informe o nome.';
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) $erros[] = 'E-mail inválido.';

    if (!$erros) {
        // ... salvar ou enviar
        header('Location: obrigado.php');   // Post/Redirect/Get
        exit;
    }
}
?>
<form method="post">
  <?php foreach ($erros as $e): ?><p class="erro"><?= $e ?></p><?php endforeach; ?>
  <input name="nome" value="<?= htmlspecialchars($nome) ?>">
  <input name="email" type="email">
  <button>Enviar</button>
</form>
  • $_GET traz os parâmetros da URL (?pagina=2); $_POST, os campos de um formulário enviado com method="post".
  • ?? devolve o valor da direita se a chave não existir, evitando avisos.
  • Depois de processar um POST, redirecione. Assim, apertar F5 não reenvia o formulário.
  • Nunca confie só na validação do navegador (required, type="email"): quem quiser manda o que quiser direto para o servidor.

Sessões

<?php
session_start();                          // antes de qualquer HTML
$_SESSION['usuario'] = 'ana@exemplo.com'; // depois do login

// em outra página
session_start();
if (!isset($_SESSION['usuario'])) {
    header('Location: login.php');
    exit;
}

A sessão guarda dados no servidor, ligados a um cookie no navegador. Para senhas, use sempre password_hash($senha, PASSWORD_DEFAULT) ao cadastrar e password_verify ao entrar: nunca guarde a senha em texto.
