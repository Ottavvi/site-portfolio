Prática: tabela de preços de uma pousada

Aula · 20 min

Tarefas

  1. Crie index.php com um array de quartos (nome, diária, capacidade).
  2. Mostre uma tabela HTML com todos os quartos, diária em formato brasileiro (R$ 1.250,00).
  3. Escreva totalEstadia($diaria, $noites): a partir de 7 noites, 10% de desconto.
  4. Acrescente uma coluna com o valor de 3 noites e outra com o de 7.
  5. Destaque (com uma classe CSS) o quarto mais barato.
Ver a resposta 
<?php
declare(strict_types=1);

$quartos = [
    ['nome' => 'Standard', 'diaria' => 180.0, 'capacidade' => 2],
    ['nome' => 'Família', 'diaria' => 290.0, 'capacidade' => 4],
    ['nome' => 'Suíte Mar', 'diaria' => 320.0, 'capacidade' => 2],
];

function reais(float $v): string
{
    return 'R$ ' . number_format($v, 2, ',', '.');
}

function totalEstadia(float $diaria, int $noites): float
{
    $total = $diaria * $noites;
    return $noites >= 7 ? $total * 0.9 : $total;
}

$menor = min(array_column($quartos, 'diaria'));
?>
<style>.destaque { background: #e7f7ee; }</style>
<table>
  <tr><th>Quarto</th><th>Pessoas</th><th>Diária</th><th>3 noites</th><th>7 noites</th></tr>
  <?php foreach ($quartos as $q): ?>
    <tr class="<?= $q['diaria'] === $menor ? 'destaque' : '' ?>">
      <td><?= htmlspecialchars($q['nome']) ?></td>
      <td><?= $q['capacidade'] ?></td>
      <td><?= reais($q['diaria']) ?></td>
      <td><?= reais(totalEstadia($q['diaria'], 3)) ?></td>
      <td><?= reais(totalEstadia($q['diaria'], 7)) ?></td>
    </tr>
  <?php endforeach; ?>
</table>

array_column tira uma coluna de um array de arrays. A sintaxe foreach (...): com endforeach; é a forma alternativa, mais legível no meio do HTML.
