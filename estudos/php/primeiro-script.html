PHP no servidor

Aula · 9 min

O PHP roda no servidor: quando alguém abre a página, o PHP executa, monta o HTML e só o resultado vai para o navegador. Ele move o WordPress (boa parte dos sites do mundo), lojas virtuais e muitos sistemas de pequenas empresas, e quase toda hospedagem barata já vem com ele.

Instalar e rodar

No Windows, baixe em windows.php.net (ou use winget install PHP.PHP.8.3); no Mac, brew install php. Depois: 

php -v                  # confere a versão
php ola.php             # roda um script no terminal
php -S localhost:8000   # servidor embutido: abra http://localhost:8000

A sintaxe

<!-- index.php -->
<?php
$nome = 'Ana';
$hora = (int) date('H');
$saudacao = $hora < 12 ? 'Bom dia' : ($hora < 18 ? 'Boa tarde' : 'Boa noite');
?>
<!doctype html>
<html lang="pt-BR">
  <body>
    <h1><?= $saudacao ?>, <?= htmlspecialchars($nome) ?>!</h1>
    <p>Hoje é <?= date('d/m/Y') ?>.</p>
  </body>
</html>
  • O código PHP fica entre <?php e ?>. Fora disso, é HTML normal.
  • <?= ... ?> é um atalho para imprimir um valor.
  • Variáveis começam com $ e não declaram tipo. Instruções terminam com ;.
  • Texto se junta com ponto: 'Olá, ' . $nome. Entre aspas duplas, a variável é trocada pelo valor: "Olá, $nome".
Dica

Sempre que imprimir algo que veio do usuário, passe por htmlspecialchars. Sem isso, alguém pode enviar um <script> que roda no navegador dos outros visitantes (o ataque XSS).

Teste o que aprendeu

  1. Onde o PHP é executado?

  2. Qual a diferença entre "Olá, $nome" e 'Olá, $nome'?

  3. Para que serve htmlspecialchars?
