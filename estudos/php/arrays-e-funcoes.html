Arrays, laços e funções

Aula · 12 min

Arrays

No PHP, o array serve tanto de lista quanto de dicionário (chave e valor):

<?php
$frutas = ['maçã', 'banana', 'uva'];
$frutas[] = 'manga';             // acrescenta no fim
echo count($frutas);              // 4

$quarto = [
    'nome' => 'Suíte Mar',
    'diaria' => 320.0,
    'hospedes' => 2,
];
echo $quarto['nome'];

$quartos = [
    ['nome' => 'Standard', 'diaria' => 180],
    ['nome' => 'Suíte Mar', 'diaria' => 320],
];
foreach ($quartos as $q) {
    echo $q['nome'] . ': R$ ' . number_format($q['diaria'], 2, ',', '.') . PHP_EOL;
}

Funções úteis de array

$precos = [180, 320, 250];
$comTaxa = array_map(fn($p) => $p * 1.05, $precos);
$caros = array_filter($precos, fn($p) => $p > 200);
$soma = array_sum($precos);
sort($precos);                        // ordena o próprio array
usort($quartos, fn($a, $b) => $a['diaria'] <=> $b['diaria']);
in_array(320, $precos);               // true

fn($p) => ... é uma arrow function. O <=> ("nave espacial") compara dois valores e devolve -1, 0 ou 1, exatamente o que o usort precisa.

Funções com tipos

<?php
declare(strict_types=1);

function totalEstadia(float $diaria, int $noites, float $desconto = 0): float
{
    return $diaria * $noites * (1 - $desconto);
}

echo totalEstadia(320, 3);              // 960
echo totalEstadia(320, 7, desconto: 0.1); // argumento nomeado

O PHP moderno (7 e 8) aceita tipos nos parâmetros e no retorno. Com strict_types=1 no topo do arquivo, passar um texto onde se espera int dá erro em vez de converter em silêncio.

  1. Como acrescentar um item no fim de $lista?

  2. O que o operador <=> devolve?

  3. O que muda com declare(strict_types=1)?
