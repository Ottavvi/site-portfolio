Classes, namespaces e PHP 8

Aula · 13 min

<?php
declare(strict_types=1);

namespace App\Reservas;

enum Status: string
{
    case Pendente = 'pendente';
    case Confirmada = 'confirmada';
    case Cancelada = 'cancelada';

    public function rotulo(): string
    {
        return match ($this) {
            self::Pendente => 'Aguardando pagamento',
            self::Confirmada => 'Confirmada',
            self::Cancelada => 'Cancelada',
        };
    }
}

final class Reserva
{
    public function __construct(
        public readonly string $hospede,
        public readonly \DateTimeImmutable $entrada,
        public readonly int $noites,
        private Status $status = Status::Pendente,
    ) {}

    public function confirmar(): void
    {
        if ($this->status === Status::Cancelada) {
            throw new \DomainException('Reserva cancelada não pode ser confirmada.');
        }
        $this->status = Status::Confirmada;
    }

    public function status(): Status { return $this->status; }
}
  • Promoção de construtor: declarar public readonly string $hospede no construtor cria e preenche a propriedade de uma vez.
  • readonly: só pode ser definida uma vez.
  • enum limita os valores possíveis. Nada de status 'confirmado' escrito errado num canto do código.
  • match é um switch que devolve valor, compara com === e dá erro se nenhum caso casar.

Autoload PSR-4

// composer.json
"autoload": { "psr-4": { "App\\": "src/" } }

Testes com PHPUnit

final class ReservaTest extends PHPUnit\Framework\TestCase
{
    public function test_nao_confirma_cancelada(): void
    {
        $this->expectException(DomainException::class);
        $r = new Reserva('Ana', new DateTimeImmutable(), 2, Status::Cancelada);
        $r->confirmar();
    }
}
// vendor/bin/phpunit tests
