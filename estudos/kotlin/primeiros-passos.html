val, var, tipos e nulos

Aula · 10 min

Kotlin é a linguagem recomendada pelo Google para apps Android. Roda na JVM (convive com código Java), tem uma sintaxe enxuta e impede, já na compilação, o erro mais comum do Java: o NullPointerException. Para começar sem instalar nada, use o Kotlin Playground em play.kotlinlang.org. 

fun main() {
    val nome = "Ana"        // val: não pode ser reatribuído (prefira sempre)
    var visitas = 1          // var: pode mudar
    visitas += 1
    val preco: Double = 19.9 // tipo explícito (opcional quando dá para deduzir)

    println("Olá, $nome! Visita número $visitas")
    println("Total: ${preco * 3}")   // expressões vão entre chaves
}

Sem ponto e vírgula, sem new. Os string templates ($nome, ${expressão}) montam textos.

Nulos sob controle

var apelido: String = "Aninha"
// apelido = null              // erro de compilação: String não aceita null

var telefone: String? = null    // o ? permite null
println(telefone?.length)       // ?. : se for null, o resultado é null (sem quebrar)
println(telefone?.length ?: 0)  // ?: (Elvis): valor padrão quando for null

if (telefone != null) {
    println(telefone.length)    // aqui dentro o compilador sabe que não é null
}
Dica

Existe o !!, que diz "confie em mim, não é null" e quebra se for. Evite: cada !! é um NullPointerException esperando para acontecer.

Teste o que aprendeu

  1. Qual a diferença entre val e var?

  2. O que String? significa?

  3. Quanto vale nome?.length ?: 0 quando nome é null?
