Prática: app de tarefas

Aula · 45 min

Tarefas

  1. Crie um projeto Empty Activity e adicione o Room (com o KSP) e o lifecycle-viewmodel-compose.
  2. Entidade Tarefa e DAO da aula anterior, mais um @Delete.
  3. TarefasViewModel que expõe a lista como StateFlow e tem adicionar, alternar e remover.
  4. Tela com um campo de texto e botão "Adicionar" (desabilitado com texto vazio) e a lista com uma caixa de seleção em cada tarefa.
  5. As tarefas feitas aparecem riscadas e no fim da lista. Fechar e abrir o app mantém tudo.

class TarefasViewModel(private val dao: TarefaDao) : ViewModel() {
    val tarefas: StateFlow<List<Tarefa>> = dao.todas()
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), emptyList())

    fun adicionar(titulo: String) = viewModelScope.launch { dao.inserir(Tarefa(titulo = titulo.trim())) }
    fun alternar(t: Tarefa) = viewModelScope.launch { dao.atualizar(t.copy(feita = !t.feita)) }
    fun remover(t: Tarefa) = viewModelScope.launch { dao.remover(t) }
}

@Composable
fun TelaTarefas(vm: TarefasViewModel) {
    val tarefas by vm.tarefas.collectAsStateWithLifecycle()
    var texto by rememberSaveable { mutableStateOf("") }

    Column(Modifier.fillMaxSize().padding(16.dp)) {
        Row(verticalAlignment = Alignment.CenterVertically) {
            OutlinedTextField(texto, { texto = it }, Modifier.weight(1f), label = { Text("Nova tarefa") })
            Spacer(Modifier.width(8.dp))
            Button(onClick = { vm.adicionar(texto); texto = "" }, enabled = texto.isNotBlank()) { Text("Adicionar") }
        }
        LazyColumn {
            items(tarefas, key = { it.id }) { t ->
                Row(verticalAlignment = Alignment.CenterVertically) {
                    Checkbox(checked = t.feita, onCheckedChange = { vm.alternar(t) })
                    Text(
                        t.titulo,
                        Modifier.weight(1f),
                        textDecoration = if (t.feita) TextDecoration.LineThrough else null
                    )
                    IconButton(onClick = { vm.remover(t) }) { Icon(Icons.Default.Delete, "Remover") }
                }
            }
        }
    }
}

O stateIn transforma o Flow do Room num StateFlow com valor inicial; o WhileSubscribed(5000) mantém a consulta viva por 5 s durante uma rotação, sem refazê-la. rememberSaveable preserva o texto digitado ao girar a tela. A ordem (feitas no fim) já vem do ORDER BY feita do DAO. Para criar o ViewModel com o DAO, use uma ViewModelProvider.Factory ou uma biblioteca de injeção como o Hilt.
