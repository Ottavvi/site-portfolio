Telas com Jetpack Compose

Aula · 14 min

Instale o Android Studio (developer.android.com/studio) e crie um projeto Empty Activity. Ele já vem com o Jetpack Compose, o jeito atual de fazer telas no Android: a interface é escrita em Kotlin, como funções. 

@Composable
fun Contador() {
    var cliques by remember { mutableIntStateOf(0) }
    Column(
        modifier = Modifier.padding(24.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text("Você clicou $cliques vezes", style = MaterialTheme.typography.titleLarge)
        Spacer(Modifier.height(16.dp))
        Button(onClick = { cliques++ }) { Text("Clique aqui") }
    }
}

@Preview(showBackground = true)
@Composable
fun ContadorPreview() { Contador() }
  • Uma função @Composable descreve a tela para um estado. Quando o estado muda, o Compose redesenha só o que depende dele (a recomposição).
  • remember guarda o valor entre recomposições; mutableIntStateOf avisa o Compose quando muda.
  • Column, Row e Box organizam; Modifier ajusta tamanho, espaço, clique e fundo.
  • @Preview mostra a tela no Android Studio sem rodar o app.

Listas

@Composable
fun ListaProdutos(produtos: List<Produto>, aoClicar: (Produto) -> Unit) {
    LazyColumn {
        items(produtos, key = { it.nome }) { p ->
            ListItem(
                headlineContent = { Text(p.nome) },
                supportingContent = { Text("R$ %.2f".format(p.preco)) },
                modifier = Modifier.clickable { aoClicar(p) }
            )
            HorizontalDivider()
        }
    }
}

LazyColumn só desenha os itens visíveis: aguenta listas enormes. O componente recebe os dados e uma função para os eventos, em vez de buscar ou alterar dados sozinho: isso o torna fácil de reaproveitar e de pré-visualizar.
