Prática: boletim da turma

Aula · 20 min

val notas = mapOf(
    "Ana" to listOf(8.0, 9.5, 7.0),
    "Bruno" to listOf(5.0, 4.5, 6.0),
    "Carla" to listOf(10.0, 9.0, 9.5),
    "Davi" to listOf(3.0, 6.0, 4.0)
)

Tarefas

  1. Escreva situacao(media): 7 ou mais "Aprovado", de 5 a 7 "Recuperação", abaixo de 5 "Reprovado".
  2. Imprima cada aluno com a média (uma casa decimal) e a situação.
  3. Mostre o nome do aluno com a maior média.
  4. Mostre quantos alunos há em cada situação.
  5. Imprima as iniciais de cada aluno junto do nome usando uma função de extensão.
Ver a resposta 
fun situacao(media: Double) = when {
    media >= 7 -> "Aprovado"
    media >= 5 -> "Recuperação"
    else -> "Reprovado"
}

fun String.inicial() = first().uppercaseChar()

fun main() {
    val medias = notas.mapValues { (_, n) -> n.average() }

    for ((aluno, media) in medias) {
        println("${aluno.inicial()} $aluno: ${"%.1f".format(media)} - ${situacao(media)}")
    }

    val melhor = medias.maxBy { it.value }
    println("Maior média: ${melhor.key}")

    val porSituacao = medias.values.groupingBy { situacao(it) }.eachCount()
    println(porSituacao)   // {Aprovado=2, Recuperação=1, Reprovado=1}
}

mapValues transforma só os valores do mapa. Na lambda, (_, n) desestrutura o par chave-valor e ignora a chave. groupingBy { }.eachCount() conta por grupo.
