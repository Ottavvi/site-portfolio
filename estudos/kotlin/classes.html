Classes, data e sealed classes

Aula · 13 min

class Conta(val titular: String, saldoInicial: Double = 0.0) {
    var saldo = saldoInicial
        private set                        // de fora, só leitura

    fun depositar(valor: Double) {
        require(valor > 0) { "Valor deve ser positivo" }
        saldo += valor
    }
}

val c = Conta("Ana")
c.depositar(100.0)

O construtor vem junto do nome da classe. val ou var nos parâmetros já cria as propriedades. require lança IllegalArgumentException se a condição falhar.

Estados com sealed class

Muito usado em apps: a tela está carregando, deu certo ou deu erro, e nunca outra coisa.

sealed interface Estado {
    data object Carregando : Estado
    data class Sucesso(val produtos: List<Produto>) : Estado
    data class Erro(val mensagem: String) : Estado
}

fun mostrar(estado: Estado) = when (estado) {
    Estado.Carregando -> "Carregando..."
    is Estado.Sucesso -> "${estado.produtos.size} produtos"
    is Estado.Erro -> "Ops: ${estado.mensagem}"
    // sem else: o compilador sabe que esses são todos os casos
}

Se alguém criar um quarto estado, todo when que não o trate vira erro de compilação. object cria um objeto único (singleton); enum class serve para listas fixas simples (enum class Nivel { BAIXO, MEDIO, ALTO }).
