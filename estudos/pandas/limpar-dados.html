Limpar dados

Aula · 13 min

Dados reais chegam sujos: decimais com vírgula, nomes com espaço sobrando, a mesma categoria escrita de três jeitos, linhas repetidas e campos em branco. Limpar costuma ser a maior parte do trabalho, e o pandas tem uma ferramenta para cada problema. 

import io
import pandas as pd

SUJO = """cliente;categoria;quantidade;preco
Ana; mercearia ;2;62,90
Bruno;Casa;;34,50
Ana; mercearia ;2;62,90
carla;UTENSÍLIOS;1;149,00
Diego;Casa;3;
"""
df = pd.read_csv(io.StringIO(SUJO), sep=";")
print(df)
print(df.dtypes)          # preco veio como texto (object) por causa da vírgula
print(df.isna().sum())    # quantos vazios em cada coluna

Uma ferramenta para cada problema

import io
import pandas as pd

SUJO = """cliente;categoria;quantidade;preco
Ana; mercearia ;2;62,90
Bruno;Casa;;34,50
Ana; mercearia ;2;62,90
carla;UTENSÍLIOS;1;149,00
Diego;Casa;3;
"""
df = pd.read_csv(io.StringIO(SUJO), sep=";")

# Texto: tirar espaços e padronizar maiúsculas
df["cliente"] = df["cliente"].str.strip().str.title()
df["categoria"] = df["categoria"].str.strip().str.capitalize()

# Número com vírgula: trocar por ponto e converter
df["preco"] = df["preco"].str.replace(",", ".").astype(float)

# Linhas repetidas
df = df.drop_duplicates()

# Valores faltando: preencher ou descartar, conforme o caso
df["quantidade"] = df["quantidade"].fillna(1).astype(int)   # assumir 1
df = df.dropna(subset=["preco"])                            # sem preço não dá para usar

print(df.reset_index(drop=True))
print(df.dtypes)
  • .str dá acesso aos métodos de texto em cada valor: strip, lower, title, replace, contains, split.
  • astype converte o tipo. pd.to_numeric(coluna, errors="coerce") converte e transforma o que não é número em vazio, em vez de dar erro.
  • fillna preenche os vazios; dropna descarta as linhas com vazio (o subset diz em quais colunas olhar).
  • Depois de remover linhas, reset_index(drop=True) renumera de 0 em diante.
