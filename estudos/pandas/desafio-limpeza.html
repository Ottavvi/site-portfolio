Desafio: limpar a exportação do sistema

Desafio · 18 min

O sistema da loja exporta as vendas com vários problemas. Escreva limpar(df), que recebe o DataFrame lido do CSV e devolve um novo, limpo:

  • cliente sem espaços nas pontas e com a primeira letra de cada palavra maiúscula ("ana souza" vira "Ana Souza").
  • preco como número decimal (vem com vírgula, como "62,90").
  • Linhas sem quantidade são descartadas, e quantidade vira número inteiro.
  • Linhas repetidas (iguais em tudo, depois de limpar) aparecem uma vez só.
  • Uma coluna nova, total, com quantidade × preço.
  • O índice volta a ser 0, 1, 2...

O que o código precisa ter

  • cliente sem espaços e com iniciais maiúsculas
  • preco é número decimal
  • Sem linhas sem quantidade, e quantidade inteira
  • Sem repetidas, com total e índice renumerado
  • Funciona com outros dados
Ver uma solução possível 
import io
import pandas as pd

TEXTO = """cliente;produto;quantidade;preco
ana souza;Café 1kg;2;62,90
 Bruno Lima ;Caneca;;34,50
ANA SOUZA;Café 1kg;2;62,90
carla dias;Moedor;1;149,00
"""
bruto = pd.read_csv(io.StringIO(TEXTO), sep=";")


def limpar(df):
    df = df.copy()
    df["cliente"] = df["cliente"].str.strip().str.title()
    df["preco"] = df["preco"].str.replace(",", ".").astype(float)
    df = df.dropna(subset=["quantidade"])
    df["quantidade"] = df["quantidade"].astype(int)
    df = df.drop_duplicates()
    df["total"] = df["quantidade"] * df["preco"]
    return df.reset_index(drop=True)


print(limpar(bruto))
