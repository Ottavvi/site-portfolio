Do pandas para o Excel, o banco e o Power BI

Aula · 11 min

A análise só vale quando chega em quem decide. Estes comandos rodam no seu computador (com pip install pandas openpyxl pyarrow matplotlib num ambiente virtual):

CSV que o Excel em português abre direito

resumo.to_csv("resumo.csv", sep=";", decimal=",", index=False, encoding="utf-8-sig")

Ponto e vírgula como separador, vírgula como decimal e o utf-8-sig para os acentos aparecerem certos ao dar dois cliques no arquivo.

Excel com várias abas

with pd.ExcelWriter("relatorio.xlsx") as arquivo:
    vendas.to_excel(arquivo, sheet_name="Vendas", index=False)
    resumo.to_excel(arquivo, sheet_name="Resumo")

Parquet: para dados grandes

O formato Parquet guarda os tipos das colunas, é comprimido (um CSV de 1 GB vira algumas dezenas de MB) e é lido muito mais rápido. O Power BI e o Power Query leem Parquet direto. 

vendas.to_parquet("vendas.parquet")
vendas = pd.read_parquet("vendas.parquet")

Bancos de dados

import sqlite3

with sqlite3.connect("loja.db") as conexao:
    vendas.to_sql("vendas", conexao, if_exists="replace", index=False)
    caros = pd.read_sql("SELECT * FROM vendas WHERE preco > ?", conexao, params=(100,))

Repare no ? com params: a mesma consulta parametrizada da trilha de segurança web.

Python dentro do Power BI e do Excel

  • No Power BI Desktop, Obter dados → Script Python roda um script e importa cada DataFrame como uma tabela.
  • No Excel do Microsoft 365, a função =PY() roda pandas direto na célula (o processamento é na nuvem da Microsoft).
  • Para relatórios que se atualizam todo dia, o mais simples costuma ser um script que gera o Parquet ou o CSV numa pasta, agendado no Agendador de Tarefas (veja a trilha de PowerShell), e o Power BI lendo essa pasta.
Dica

Jupyter Notebook (ou os notebooks do VS Code) é o jeito mais confortável de explorar dados: o código fica em células, e as tabelas e gráficos aparecem logo abaixo de cada uma.
