Avisos no celular e no app instalado

Aula · 10 min

No Android, new Notification() não funciona: lá, as notificações saem sempre pelo service worker, com registration.showNotification(). Usar sempre esse caminho funciona em todos os lugares: 

const registro = await navigator.serviceWorker.ready;
await registro.showNotification('Pedido saiu para entrega', {
  body: 'Chega em cerca de 40 minutos.',
  icon: '/icones/icone-192.png',
  badge: '/icones/badge-72.png',      // ícone pequeno, monocromático, da barra do Android
  tag: 'pedido-123',
  vibrate: [100, 50, 100],             // vibra, pausa, vibra (em ms), onde houver suporte
  data: { url: '/pedidos/123' },
  actions: [
    { action: 'rastrear', title: 'Rastrear' },
    { action: 'ajuda', title: 'Preciso de ajuda' }
  ]
});

Os botões de actions aparecem na notificação, e o service worker sabe qual foi clicado: 

// sw.js
self.addEventListener('notificationclick', evento => {
  evento.notification.close();
  const destino = evento.action === 'ajuda' ? '/ajuda' : evento.notification.data.url;
  evento.waitUntil(clients.openWindow(destino));
});

O selo no ícone

Num app instalado, a Badging API põe um número no ícone (como o contador de e-mails não lidos). É bem menos invasivo que uma notificação: 

if ('setAppBadge' in navigator) {
  navigator.setAppBadge(naoLidas);        // um número
  // navigator.clearAppBadge();           // limpa
}

iPhone e iPad

No iOS (a partir da versão 16.4), notificações web e selos só funcionam para sites adicionados à tela de início, e o pedido de permissão precisa vir de um toque da pessoa dentro do app instalado. Para quem usa muito iPhone, explique isso no convite, com o passo a passo do "Compartilhar, Adicionar à Tela de Início".

Dica

Teste as notificações num celular de verdade. O que aparece no computador (tamanho do texto, ícone, ações) muda bastante no Android e no iOS.

  1. Qual o jeito de mostrar notificação que funciona também no Android?

  2. Como saber qual botão de ação foi clicado?

  3. O que é preciso para notificações web no iPhone?
