Notificações push

Aula · 14 min

Tudo até aqui só funciona com a página aberta. Para avisar quando o site está fechado (uma mensagem nova, um pedido que saiu), é preciso push: o seu servidor manda uma mensagem para o serviço de push do navegador, que acorda o service worker do site, e ele mostra a notificação.

As peças

  1. Service worker: um script que o navegador mantém registrado mesmo com a aba fechada (a trilha de PWA explica em detalhes).
  2. Inscrição: com a permissão, a página pede ao PushManager uma inscrição. Ela traz um endereço (endpoint) e chaves, que você salva no seu servidor junto com a conta da pessoa.
  3. Chaves VAPID: um par de chaves do seu servidor. A pública vai na inscrição; a privada assina os envios, provando que é você.
  4. Envio: o servidor manda a mensagem para o endpoint, em geral com uma biblioteca como web-push (Node.js).

Na página: inscrever

const registro = await navigator.serviceWorker.register('/sw.js');
const permissao = await Notification.requestPermission();
if (permissao === 'granted') {
  const inscricao = await registro.pushManager.subscribe({
    userVisibleOnly: true,                 // todo push vira um aviso visível
    applicationServerKey: CHAVE_PUBLICA_VAPID
  });
  await fetch('/api/inscricoes', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(inscricao)
  });
}

No service worker: receber e mostrar

// sw.js
self.addEventListener('push', evento => {
  const dados = evento.data?.json() ?? { titulo: 'Novidade', texto: '' };
  evento.waitUntil(
    self.registration.showNotification(dados.titulo, {
      body: dados.texto,
      icon: '/icone-192.png',
      data: { url: dados.url ?? '/' },
      actions: [{ action: 'abrir', title: 'Abrir' }]
    })
  );
});

self.addEventListener('notificationclick', evento => {
  evento.notification.close();
  evento.waitUntil(clients.openWindow(evento.notification.data.url));
});

waitUntil mantém o service worker acordado até a notificação aparecer. Sem ele, o navegador pode desligá-lo no meio.

No servidor: enviar

// Node.js, com o pacote web-push
import webpush from 'web-push';

webpush.setVapidDetails('mailto:contato@meusite.com', CHAVE_PUBLICA, CHAVE_PRIVADA);

await webpush.sendNotification(inscricaoSalva, JSON.stringify({
  titulo: 'Pedido saiu para entrega',
  texto: 'Chega em cerca de 40 minutos.',
  url: '/pedidos/123'
}));
Dica

No iPhone e no iPad, o push na web só funciona depois que a pessoa adiciona o site à tela de início (como um app instalado). Se o seu público usa muito iOS, explique isso no convite.

Boas práticas

  • Quando o envio responde 404 ou 410, a inscrição morreu (a pessoa revogou ou trocou de navegador): apague-a do banco.
  • Deixe a pessoa escolher o que quer receber (pedidos sim, promoções não).
  • Promoção demais por push é o caminho mais curto para a permissão ser revogada.
