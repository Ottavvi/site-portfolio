Desafio: avisar do jeito certo

Desafio · 20 min

Escreva a função avisar(titulo, texto), que escolhe o melhor jeito de avisar:

  • Se a API existe, a permissão é 'granted' e a aba está escondida: cria uma new Notification(titulo, { body: texto }).
  • Em qualquer outro caso: acrescenta um toast em #avisos, um <div class="toast"> com o texto "titulo: texto".
  • O contêiner #avisos precisa ser anunciado por leitores de tela (role="status" ou aria-live="polite").

Os testes trocam Notification e o estado da aba por versões falsas.

O que o código precisa ter

  • #avisos tem role="status" ou aria-live="polite"
  • Permissão concedida e aba escondida: cria uma Notification
  • Aba visível: mostra um toast, mesmo com permissão
  • Sem permissão (ou sem a API): mostra um toast
Ver uma solução possível 
<style>
  #avisos { position: fixed; right: 12px; bottom: 12px; display: grid; gap: 8px; }
  .toast { background: #14303a; color: #fff; padding: 10px 14px; border-radius: 10px; }
</style>
<button id="testar">Avisar</button>
<div id="avisos" role="status"></div>

<script>
  function avisar(titulo, texto) {
    const podeNotificar =
      'Notification' in window &&
      Notification.permission === 'granted' &&
      document.visibilityState === 'hidden';

    if (podeNotificar) {
      new Notification(titulo, { body: texto });
      return;
    }

    const toast = document.createElement('div');
    toast.className = 'toast';
    toast.textContent = `${titulo}: ${texto}`;
    document.querySelector('#avisos').append(toast);
    setTimeout(() => toast.remove(), 4000);
  }

  document.querySelector('#testar').addEventListener('click', () => {
    avisar('Pedido', 'Seu café saiu para entrega.');
  });
</script>
