Avisos dentro da página

Aula · 11 min

Se a pessoa está olhando para a página, uma notificação do sistema é exagero: um aviso dentro da própria página (um toast) basta. A notificação faz sentido quando a aba está escondida.

A aba está visível?

document.visibilityState vale 'visible' ou 'hidden' (outra aba na frente, janela minimizada). O evento visibilitychange avisa quando isso muda: 

<ul id="log"></ul>
<script>
  document.addEventListener('visibilitychange', () => {
    const li = document.createElement('li');
    li.textContent = new Date().toLocaleTimeString('pt-BR') + ': ' + document.visibilityState;
    document.querySelector('#log').append(li);
  });
</script>
<p>Troque de aba e volte para ver o registro.</p>

Um toast acessível

Um aviso que só aparece na tela é invisível para quem usa leitor de tela. Uma região com role="status" (ou aria-live="polite") faz o leitor anunciar o texto novo sem interromper o que a pessoa está fazendo: 

<style>
  #avisos { position: fixed; right: 12px; bottom: 12px; display: grid; gap: 8px; }
  .toast { background: #14303a; color: #fff; padding: 10px 14px; border-radius: 10px;
           box-shadow: 0 6px 20px #0003; animation: entra .2s ease-out; }
  @keyframes entra { from { opacity: 0; transform: translateY(8px); } }
</style>
<button id="salvar">Salvar</button>
<div id="avisos" role="status"></div>

<script>
  function toast(texto, ms = 3000) {
    const item = document.createElement('div');
    item.className = 'toast';
    item.textContent = texto;
    document.querySelector('#avisos').append(item);
    setTimeout(() => item.remove(), ms);
  }
  document.querySelector('#salvar').addEventListener('click', () => toast('Alterações salvas.'));
</script>
Dica

Use role="alert" só para erros que exigem atenção imediata: ele interrompe o leitor de tela no meio de uma frase.

Contador no título

Para quem tem muitas abas abertas, o título é o que aparece. Um número entre parênteses chama atenção sem ser invasivo, e some quando a pessoa volta: 

let naoLidas = 0;
const tituloOriginal = document.title;

function novaMensagem() {
  if (document.visibilityState === 'hidden') {
    naoLidas++;
    document.title = `(${naoLidas}) ${tituloOriginal}`;
  }
}

document.addEventListener('visibilitychange', () => {
  if (document.visibilityState === 'visible') {
    naoLidas = 0;
    document.title = tituloOriginal;
  }
});
