Como as notificações funcionam

Aula · 9 min

Notificações são os avisos que aparecem fora da página, no canto da tela ou na central do sistema, mesmo com a aba em segundo plano. Um app de tarefas avisa de um lembrete, um chat avisa de uma mensagem nova. Como elas interrompem a pessoa, o navegador só deixa um site mostrá-las depois de uma permissão explícita.

Os três estados

Notification.permission diz em que pé está:

  • 'default': ainda não perguntou. Dá para pedir.
  • 'granted': a pessoa aceitou.
  • 'denied': a pessoa recusou. O site não pode perguntar de novo; só a própria pessoa muda isso nas configurações do navegador. 
<p id="estado"></p>
<script>
  const texto = 'Notification' in window
    ? 'Permissão atual: ' + Notification.permission
    : 'Este navegador não tem a API de notificações.';
  document.querySelector('#estado').textContent = texto;
</script>

Pedir e mostrar

Notification.requestPermission() abre a pergunta do navegador e devolve uma Promise com a resposta. Com a permissão, new Notification(título, opções) mostra o aviso: 

botao.addEventListener('click', async () => {
  const permissao = await Notification.requestPermission();
  if (permissao !== 'granted') return;

  const aviso = new Notification('Pedido enviado', {
    body: 'Seu café sai para entrega até as 15h.',
    icon: '/imagens/icone-192.png',
    tag: 'pedido-123'   // um aviso novo com a mesma tag substitui o anterior
  });

  aviso.addEventListener('click', () => {
    window.focus();      // traz a aba para frente
    aviso.close();
  });
});
Dica

O editor desta trilha roda dentro de um iframe, e muitos navegadores não deixam um iframe pedir essa permissão. Para ver uma notificação de verdade, teste o trecho numa página sua aberta em http://localhost ou em https: notificações só funcionam em páginas seguras.

Opções úteis

  • body: o texto. Curto e específico ("Ana respondeu: Pode ser às 15h?").
  • icon: a imagem ao lado, em geral o ícone do site.
  • tag: agrupa avisos. Dez mensagens no mesmo chat viram uma notificação atualizada, não dez.
  • requireInteraction: o aviso fica até a pessoa agir. Use só para o que é urgente de verdade.

Teste o que aprendeu

  1. A permissão está "denied". O que o site pode fazer?

  2. Para que serve a opção tag?

  3. Notificações funcionam numa página http:// comum (não localhost)?
