Pedir na hora certa

Aula · 8 min

Todo mundo já entrou num site e foi recebido com "Este site quer enviar notificações". A maioria clica em Bloquear por reflexo, e aí o site perdeu a chance para sempre. Navegadores como o Chrome e o Firefox até escondem pedidos feitos sem nenhum clique da pessoa.

A regra

Peça só quando a pessoa entender o benefício, e sempre a partir de um clique dela. O momento certo é logo depois de uma ação que tem relação com o aviso:

  • Ela criou um lembrete para amanhã: "Quer ser avisada na hora?"
  • Ela fez um pedido: "Avisar quando sair para entrega?"
  • Ela abriu as configurações e procurou "notificações".

Um convite na página antes do pedido

Mostre primeiro um convite seu, dentro da página, explicando o que será avisado. Só se a pessoa clicar em "Ativar" você chama o pedido do navegador. Se ela disser "Agora não", você não gastou a única chance: 

<style>
  .convite { border: 1px solid #c5ced6; border-radius: 10px; padding: 12px 14px; max-width: 360px; }
  .convite p { margin: 0 0 10px; }
</style>
<button id="lembrete">Criar lembrete para amanhã às 9h</button>
<div class="convite" id="convite" hidden>
  <p><strong>Quer um aviso às 9h?</strong> Mandamos uma notificação só na hora do lembrete.</p>
  <button id="ativar">Ativar avisos</button>
  <button id="depois">Agora não</button>
</div>
<p id="status" role="status"></p>

<script>
  const convite = document.querySelector('#convite');
  const status = document.querySelector('#status');

  document.querySelector('#lembrete').addEventListener('click', () => {
    status.textContent = 'Lembrete criado.';
    const podePerguntar = 'Notification' in window && Notification.permission === 'default';
    convite.hidden = !podePerguntar;
  });

  document.querySelector('#ativar').addEventListener('click', async () => {
    convite.hidden = true;
    const resposta = await Notification.requestPermission();
    status.textContent = resposta === 'granted' ? 'Avisos ativados.' : 'Tudo bem, sem avisos.';
  });

  document.querySelector('#depois').addEventListener('click', () => {
    convite.hidden = true;
    status.textContent = 'Você pode ativar os avisos depois, nas configurações.';
  });
</script>

Quando foi recusado

Se Notification.permission for 'denied', não esconda o recurso sem explicação: diga, numa frase, como reativar ("Clique no cadeado ao lado do endereço e permita notificações"). E respeite a escolha: não insista a cada visita.

Dica

Ofereça sempre um jeito de desligar os avisos dentro do próprio site. Quem não acha esse botão vai desligar pelo navegador, e aí desliga tudo.

Teste o que aprendeu

  1. Qual o melhor momento para pedir permissão?

  2. Para que serve o convite dentro da página antes do pedido do navegador?

  3. O que fazer se a permissão estiver negada?
