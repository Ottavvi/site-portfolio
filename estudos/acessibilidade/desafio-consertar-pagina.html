Desafio: conserte a página

Desafio · 18 min

A página abaixo tem vários dos erros mais comuns. Conserte sem mudar o conteúdo:

  • Declare o idioma da página como português do Brasil.
  • A foto do quarto precisa de um texto alternativo que a descreva; o ícone de onda é decorativo.
  • Só pode haver um h1, e os títulos não podem pular níveis.
  • O link "clique aqui" precisa dizer para onde leva (o texto precisa conter "preços").
  • O "botão" Reservar precisa ser um botão de verdade.
  • O campo de e-mail precisa de um rótulo ligado a ele.

O que o código precisa ter

  • A página declara o idioma pt-BR
  • A foto do quarto tem alt descritivo e o ícone decorativo tem alt vazio
  • Um só h1 e nenhum título pulando nível
  • O link diz para onde leva (contém "preços")
  • Reservar é um <button> que chama reservar()
  • O campo de e-mail tem um label ligado a ele
Ver uma solução possível 
<!doctype html>
<html lang="pt-BR">
  <body>
    <h1>Pousada Maré Mansa</h1>
    <img src="onda.svg" alt="">
    <h2>Nossos quartos</h2>
    <img src="quarto.jpg" alt="Quarto de casal com cama de madeira e janela para o mar">
    <h3>Quarto casal</h3>
    <p>Veja a <a href="precos.html">tabela de preços dos quartos</a>.</p>
    <button type="button" onclick="reservar()">Reservar</button>
    <label for="email">Seu e-mail</label>
    <input id="email" type="email" autocomplete="email">
    <script>
      function reservar() { console.log('Reservando...'); }
    </script>
  </body>
</html>
