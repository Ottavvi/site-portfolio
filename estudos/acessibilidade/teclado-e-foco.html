Teclado e foco

Aula · 12 min

A ordem do Tab é a ordem do HTML

O Tab segue a ordem dos elementos no código, não a posição na tela. Se o CSS muda a ordem visual (com order, flex-direction: row-reverse ou posicionamento), o foco "pula" de um lado para o outro e confunde. Organize o HTML na ordem de leitura.

Foco visível

Quem usa teclado precisa ver onde está. Nunca tire o contorno sem colocar outro no lugar. O :focus-visible mostra o anel só quando a pessoa está no teclado (o clique do mouse não mostra): 

<style>
  button { padding: 8px 14px; border: 0; border-radius: 6px; background: #0b7a6f; color: white; }
  button:focus-visible { outline: 3px solid #f59e0b; outline-offset: 3px; }
  .ruim:focus { outline: none; } /* nunca faça isso sem outra marca de foco */
</style>
<button>Com foco visível</button>
<button class="ruim">Sem foco visível</button>
<button>Outro botão</button>

tabindex

  • tabindex="0": põe na ordem do Tab algo que normalmente não estaria (use pouco: prefira um elemento nativo, como o button).
  • tabindex="-1": tira da ordem do Tab, mas ainda deixa focar pelo JavaScript com .focus(). Útil para levar o foco a um título ou a uma mensagem.
  • tabindex positivo (1, 2, 3): não use. Ele passa na frente de tudo e bagunça a ordem da página inteira.

Pular o menu

Quem navega por teclado teria de passar pelos 15 links do menu em cada página. Um link escondido, que aparece ao receber foco, leva direto ao conteúdo: 

<style>
  .pular { position: absolute; left: -9999px; }
  .pular:focus { left: 8px; top: 8px; background: #111; color: #fff; padding: 8px; }
</style>
<a class="pular" href="#conteudo">Pular para o conteúdo</a>
<nav><a href="#">Início</a> · <a href="#">Quartos</a> · <a href="#">Contato</a></nav>
<main id="conteudo" tabindex="-1"><h1>Conteúdo principal</h1></main>

Clique no resultado e aperte Tab: o link aparece.

Não prenda o foco

Componentes como mapas e editores às vezes "engolem" o Tab e a pessoa não consegue sair. Toda vez que o foco entra em algo, precisa haver um jeito de teclado de sair (Tab ou Esc). A exceção proposital é o modal aberto, assunto do nível avançado.
