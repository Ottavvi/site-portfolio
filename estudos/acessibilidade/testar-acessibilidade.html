Como testar acessibilidade

Aula · 11 min

Nenhuma ferramenta pega tudo. As automáticas encontram por volta de um terço dos problemas; o resto precisa de gente testando. Um bom roteiro combina as três camadas.

1. Automático

  • Lighthouse (F12 → Lighthouse → Acessibilidade): rápido, dá uma nota e lista os problemas.
  • axe DevTools (extensão gratuita): mais completo, com explicação e como corrigir cada item.
  • Nos testes automáticos do projeto, o @axe-core/playwright roda o axe em cada página e quebra o build se aparecer um problema novo. 
import { test, expect } from '@playwright/test';
import AxeBuilder from '@axe-core/playwright';

test('a página inicial não tem problemas de acessibilidade', async ({ page }) => {
  await page.goto('/');
  const resultado = await new AxeBuilder({ page }).withTags(['wcag2a', 'wcag2aa']).analyze();
  expect(resultado.violations).toEqual([]);
});

2. Teclado

Desligue o mouse e confira: dá para chegar em tudo com Tab? O foco está sempre visível? A ordem faz sentido? Dá para abrir e fechar menus e modais? Nada prende o foco?

3. Leitor de tela

O NVDA é gratuito no Windows; o VoiceOver vem no Mac (Cmd+F5) e no iPhone. Os atalhos do NVDA mais úteis para testar:

  • H: próximo título. Insert+F7: lista de títulos, links e marcos.
  • D: próximo marco (header, nav, main...). F: próximo campo de formulário.
  • Ctrl: para de falar.

Pergunte-se: cada botão diz o que faz? As imagens fazem sentido? Os erros do formulário são anunciados?

4. Outros ajustes

  • Zoom de 200%: nada pode sumir ou ficar cortado.
  • prefers-reduced-motion: quem pediu menos movimento no sistema não deve ver animações grandes.
  • Modo de alto contraste do Windows: os botões continuam visíveis?
Dica

O F12 do Chrome tem a aba Accessibility no painel de Elements: ela mostra o nome, o papel e o estado que o leitor de tela vai anunciar para o elemento selecionado.

Teste o que aprendeu

  1. Ferramentas automáticas encontram todos os problemas?

  2. No NVDA, qual tecla pula para o próximo título?

  3. Como rodar o axe a cada mudança no projeto?
