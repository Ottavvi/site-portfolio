Contraste, cor e formulários

Aula · 13 min

Contraste

A WCAG (nível AA) pede contraste de pelo menos 4,5:1 entre texto e fundo, ou 3:1 para textos grandes (24px, ou 18,66px em negrito) e para bordas de campos e ícones. A conta usa a luminância de cada cor: 

<script>
  function luminancia(hex) {
    const [r, g, b] = hex.match(/\w\w/g).map(c => {
      const v = parseInt(c, 16) / 255;
      return v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4;
    });
    return 0.2126 * r + 0.7152 * g + 0.0722 * b;
  }
  function contraste(a, b) {
    const [clara, escura] = [luminancia(a), luminancia(b)].sort((x, y) => y - x);
    return (clara + 0.05) / (escura + 0.05);
  }
  for (const [texto, fundo] of [['#777777', '#ffffff'], ['#595959', '#ffffff'], ['#ffffff', '#0b7a6f']]) {
    const c = contraste(texto, fundo);
    console.log(texto, 'sobre', fundo, '=', c.toFixed(2) + ':1', c >= 4.5 ? '✓ AA' : '✗ abaixo de 4,5');
  }
</script>

O cinza claro #777, tão comum em textos secundários, não passa. Na prática, use as ferramentas do navegador: no F12, ao inspecionar um texto, o seletor de cor mostra o contraste e sugere uma cor que passa.

Não dependa só da cor

Cerca de 8% dos homens têm alguma forma de daltonismo. "Os campos em vermelho estão errados" não serve para eles. Junte a cor com outra pista: um ícone, um texto, um sublinhado nos links dentro de parágrafos.

Formulários que explicam os erros

Quando um campo está errado, a pessoa precisa saber qual, por quê e como corrigir, e o leitor de tela precisa dizer isso ao chegar no campo: 

<form novalidate>
  <label for="cpf">CPF</label>
  <input id="cpf" aria-describedby="cpf-ajuda cpf-erro" aria-invalid="true" value="123">
  <p id="cpf-ajuda">Só os 11 números, sem pontos.</p>
  <p id="cpf-erro" style="color:#b42318">✗ O CPF precisa ter 11 números. Você digitou 3.</p>
</form>
  • aria-invalid="true" faz o leitor anunciar "inválido".
  • aria-describedby liga o campo aos textos de ajuda e de erro, que são lidos depois do rótulo.
  • Ao enviar com erro, leve o foco para o primeiro campo errado (campo.focus()).
  • Para avisos que aparecem sem a pessoa mudar de lugar (um "salvo!" no canto), use uma região aria-live="polite": o leitor fala quando o texto muda.
Dica

Agrupe opções relacionadas (como os botões de rádio de "forma de pagamento") com <fieldset> e <legend>. O leitor de tela diz a pergunta antes de cada opção.
