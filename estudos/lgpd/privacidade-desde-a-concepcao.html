Privacidade desde a concepção

Aula · 12 min

Privacidade desde a concepção (privacy by design) é pensar nos dados pessoais quando o sistema está sendo desenhado, e não depois do vazamento. No dia a dia, é uma lista de pequenas decisões:

Coletar menos

  • Para cada campo do formulário, pergunte: para que eu preciso disto? Data de nascimento para mandar parabéns? Talvez só o mês. CPF para newsletter? Não.
  • Prefira campos opcionais e explique por que algo é pedido ("Telefone, para o entregador avisar quando chegar").
  • Não guarde o que não precisa guardar: o número completo do cartão fica com o processador de pagamento, não no seu banco.

Cookies e rastreamento

Cookies essenciais (manter o login, o carrinho) não dependem de consentimento. Os de analytics e publicidade de terceiros, em geral, sim: carregue esses scripts só depois do aceite, e deixe recusar tão fácil quanto aceitar. A ANPD publicou um guia orientativo sobre cookies que vale a leitura. Uma alternativa é usar ferramentas de estatística sem cookies e sem dado pessoal (este site usa uma assim).

Logs e ferramentas

  • Não registre senhas, tokens, números de documento ou o corpo inteiro das requisições nos logs. Mascare: a***@gmail.com.
  • Defina por quanto tempo os logs ficam guardados.
  • Ambientes de teste com dados fictícios, nunca uma cópia do banco de produção.
  • Cada ferramenta de terceiro (e-mail, CRM, hospedagem, IA) é um operador: veja onde ela guarda os dados (transferência internacional também tem regras) e o que o contrato diz. 
function mascararEmail(email) {
  const [usuario, dominio] = email.split('@');
  return usuario[0] + '***@' + dominio;
}

logger.info('Login', { usuario: mascararEmail(email), ip: ipTruncado(req.ip) });   // sem senha, sem token

Aviso de privacidade

A política de privacidade explica, em linguagem simples: quais dados, para quê, com qual base legal, com quem são compartilhados, por quanto tempo ficam, como exercer os direitos e quem é o encarregado (com um contato). Ela precisa refletir o que o sistema realmente faz: copiar de outro site é pior que não ter.

Esta trilha explica a lei do ponto de vista de quem desenvolve e não substitui orientação jurídica. Confira sempre o texto da lei (planalto.gov.br) e as resoluções da ANPD (gov.br/anpd), que são atualizadas.
