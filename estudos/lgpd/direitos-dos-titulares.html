Direitos dos titulares

Aula · 11 min

O artigo 18 dá ao titular o direito de pedir ao controlador, a qualquer momento:

  • Confirmação de que há tratamento dos seus dados, e acesso a eles.
  • Correção de dados incompletos, inexatos ou desatualizados.
  • Anonimização, bloqueio ou eliminação de dados desnecessários, excessivos ou tratados em desacordo com a lei.
  • Portabilidade dos dados a outro fornecedor.
  • Eliminação dos dados tratados com base no consentimento (com exceções, como obrigações legais de guarda).
  • Informação sobre com quem os dados foram compartilhados e sobre a possibilidade de não consentir e suas consequências.
  • Revogação do consentimento.

O artigo 20 acrescenta o direito de pedir revisão de decisões tomadas só por meios automatizados que afetem os interesses da pessoa (uma análise de crédito feita por algoritmo, por exemplo). E o acesso deve ser atendido de forma simplificada imediatamente, ou com uma declaração completa em até 15 dias (artigo 19).

O que isso pede do sistema

  • Saber onde estão os dados de cada pessoa: banco, planilhas, logs, ferramentas de terceiros, backups. Sem um inventário, não dá para atender ninguém.
  • Uma tela "Meus dados" ou uma exportação (JSON, CSV) com tudo o que se refere à pessoa.
  • Uma exclusão de conta de verdade, que apague ou anonimize em todos os lugares, e não só marque ativo = 0.
  • Registro do que foi pedido, quando e como foi atendido.
// Exclusão de conta: apaga o que pode, anonimiza o que precisa ficar (notas fiscais, por obrigação legal)
async function excluirConta(usuarioId) {
  await db.transacao(async t => {
    await t.apagar('enderecos', { usuarioId });
    await t.apagar('preferencias', { usuarioId });
    await t.atualizar('pedidos', { usuarioId }, { nome: 'Titular removido', email: null, telefone: null });
    await t.apagar('usuarios', { id: usuarioId });
    await t.inserir('registro_lgpd', { tipo: 'exclusao', usuarioId, quando: new Date() });
  });
  await servicoDeEmail.removerContato(usuarioId);   // e nos operadores também
}
Dica

Pense em quanto tempo cada dado precisa existir e apague automaticamente quando o prazo acabar (logs de acesso, carrinhos abandonados, cadastros nunca confirmados). Dado que não existe não vaza.

Esta trilha explica a lei do ponto de vista de quem desenvolve e não substitui orientação jurídica. Confira sempre o texto da lei (planalto.gov.br) e as resoluções da ANPD (gov.br/anpd), que são atualizadas.
