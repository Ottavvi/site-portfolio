Navegar e mexer em arquivos

Aula · 9 min

O Bash é o terminal padrão do Linux, que roda a maioria dos servidores, os contêineres Docker e as máquinas do GitHub Actions. No Mac, o terminal (zsh) aceita quase tudo daqui. No Windows, use o WSL (wsl --install) ou o Git Bash, que vem com o Git.

Onde estou, o que tem aqui

pwd                    # pasta atual
ls                     # listar
ls -la                 # lista longa, incluindo ocultos (os que começam com .)
cd projetos            # entrar
cd ..                  # subir um nível
cd ~                   # pasta pessoal (ou só cd)
cd -                   # voltar para a anterior

Caminhos que começam com / são absolutos (/home/ana/projetos); os outros são relativos à pasta atual. . é a pasta atual, .. a de cima e ~ a sua pasta pessoal.

Criar, copiar, mover, apagar

mkdir -p testes/fotos      # -p cria as pastas do caminho que faltarem
touch testes/nota.txt      # arquivo vazio
cp testes/nota.txt testes/copia.txt
mv testes/copia.txt testes/backup.txt   # mover também é renomear
rm testes/backup.txt
rm -r testes/fotos         # apagar pasta com conteúdo
cat testes/nota.txt        # mostrar o conteúdo
less arquivo-grande.log    # ler com rolagem (q para sair)
Dica

O rm não manda para a lixeira: apaga de vez. Antes de um rm com curinga (rm *.log), rode ls *.log para ver o que seria apagado.

Ajuda

man ls abre o manual (q sai, / busca). ls --help mostra o resumo. A tecla Tab completa nomes; ↑ repete comandos; Ctrl+R busca no histórico; Ctrl+C interrompe.
