Prática: organizar fotos por data

Aula · 25 min

Prepare arquivos de teste:

mkdir -p ~/pratica-bash/fotos && cd ~/pratica-bash/fotos
touch -d "2025-12-24" natal.jpg
touch -d "2026-01-10" praia.jpg "praia 2.jpg"
touch -d "2026-03-05" aniversario.png
touch leia-me.txt

Tarefas

Escreva organizar.sh que:

  1. Recebe a pasta como argumento (padrão: a atual).
  2. Move cada .jpg e .png para AAAA/MM/ conforme a data de modificação.
  3. Aceita --simular como segundo argumento: mostra o que faria, sem mover.
  4. Funciona com nomes com espaço e não sobrescreve arquivos que já existam no destino.
  5. No fim, mostra quantos arquivos foram movidos.
Ver a resposta 
#!/usr/bin/env bash
set -euo pipefail
shopt -s nullglob nocaseglob     # curinga sem resultado vira lista vazia; .JPG também casa

pasta="${1:-.}"
simular=false
[[ "${2:-}" == "--simular" ]] && simular=true

movidos=0
for arq in "$pasta"/*.jpg "$pasta"/*.png; do
  data=$(date -r "$arq" +%Y/%m)          # no Mac: stat -f %Sm -t %Y/%m "$arq"
  destino="$pasta/$data"
  if $simular; then
    echo "[simulação] $arq -> $destino/"
  else
    mkdir -p "$destino"
    mv -n "$arq" "$destino/"             # -n: não sobrescreve
  fi
  movidos=$((movidos + 1))
done

echo "$movidos arquivo(s) $($simular && echo 'seriam movidos' || echo 'movidos')."
chmod +x organizar.sh
./organizar.sh ~/pratica-bash/fotos --simular
./organizar.sh ~/pratica-bash/fotos
find ~/pratica-bash/fotos

Sem nullglob, se não houver nenhum .png, o laço receberia o texto literal *.png. As aspas em "$arq" fazem o "praia 2.jpg" funcionar.
