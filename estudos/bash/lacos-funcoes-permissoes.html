Laços, funções e permissões

Aula · 13 min

Laços

for arq in *.jpg; do
  echo "Processando $arq"
done

for i in {1..5}; do echo "Rodada $i"; done

# Ler um arquivo linha por linha
while IFS=, read -r nome email; do
  echo "Enviar para $nome <$email>"
done < contatos.csv

O IFS=, diz que o separador é a vírgula, e o -r não trata barras invertidas como especiais.

Manipular nomes

arq="relatorio.final.pdf"
echo "${arq%.*}"     # relatorio.final  (tira a última extensão)
echo "${arq##*.}"    # pdf              (só a extensão)
echo "${arq/final/v2}" # relatorio.v2.pdf
echo "${#arq}"       # 19               (tamanho)

Funções e códigos de saída

registrar() {
  echo "[$(date +%H:%M:%S)] $*" >> script.log
}

site_no_ar() {
  curl -s -o /dev/null -w "%{http_code}" "$1" | grep -q "^200$"
}

if site_no_ar "https://exemplo.com"; then
  registrar "Site OK"
else
  registrar "Site FORA"
fi

Todo comando termina com um código de saída: 0 é sucesso; qualquer outro, falha. O if testa esse código. $? guarda o do último comando, e && e || encadeiam: make && echo ok || echo falhou.

Permissões

ls -l script.sh
# -rwxr-xr-- 1 ana equipe 512 ...
#  dono  grupo  outros

chmod +x script.sh      # todos podem executar
chmod 640 segredo.env   # dono lê e escreve; grupo lê; outros nada
sudo comando            # rodar como administrador (root)

Cada dígito do chmod numérico soma 4 (ler), 2 (escrever) e 1 (executar), para dono, grupo e outros.
