npm e pacotes

Aula · 10 min

O npm é o gerenciador de pacotes do Node: dá acesso a milhões de bibliotecas prontas. 

npm install express          # dependência do app (vai em "dependencies")
npm install -D prettier      # só para desenvolver (vai em "devDependencies")
npm install                  # instala tudo o que está no package.json
npm uninstall express
npx prettier --write .       # roda uma ferramenta sem instalar globalmente
  • node_modules/ é a pasta com os pacotes. Ela é enorme e recriada pelo npm install: vai no .gitignore, nunca no Git.
  • package-lock.json trava a versão exata de cada pacote (e dos pacotes dos pacotes). Vai no Git: garante que todo mundo, e o servidor, instale exatamente o mesmo.
  • npm ci instala exatamente o que está no lock, sem atualizar nada. É o comando para CI e deploy.

Versões

Pacotes seguem o versionamento semântico MAIOR.MENOR.CORREÇÃO: a correção não muda nada visível, a menor acrescenta recursos sem quebrar e a maior pode quebrar. No package.json:

  • "^4.21.2": aceita 4.x.x mais novas (o padrão do npm).
  • "~4.21.2": aceita só correções, 4.21.x.
  • "4.21.2": só exatamente essa.
<script>
  // Como o ^ decide se uma versão serve
  function aceitaCircunflexo(base, candidata) {
    const [b, c] = [base, candidata].map(v => v.split('.').map(Number));
    if (c[0] !== b[0]) return false;
    return c[1] > b[1] || (c[1] === b[1] && c[2] >= b[2]);
  }
  for (const v of ['4.21.2', '4.22.0', '4.21.1', '5.0.0']) {
    console.log('^4.21.2 aceita', v, '?', aceitaCircunflexo('4.21.2', v));
  }
</script>

Antes de instalar

Cada pacote é código de outra pessoa rodando na sua máquina e no seu servidor. Antes de adicionar um:

  • Veja se você realmente precisa: muita coisa já vem no Node ou no próprio JavaScript (fetch, crypto.randomUUID(), Intl, node:test).
  • Confira downloads semanais, data da última versão e se o repositório está vivo.
  • Rode npm audit de vez em quando: ele lista vulnerabilidades conhecidas nas dependências.
  • Cuidado com nomes parecidos com pacotes famosos (typosquatting): expresss não é o express.
