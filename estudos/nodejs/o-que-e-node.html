O que é o Node.js

Aula · 10 min

O Node.js pega o motor de JavaScript do Chrome e o coloca fora do navegador, com acesso a arquivos, rede e sistema operacional. Com ele, a mesma linguagem do front-end faz servidores, APIs, scripts de automação e ferramentas como o Vite e o Prettier.

Rodar um arquivo

Instale a versão LTS em nodejs.org e, no terminal:

// ola.js
const nome = process.argv[2] ?? 'mundo';
console.log(`Olá, ${nome}! Node ${process.version} em ${process.platform}`);
$ node ola.js Ana
Olá, Ana! Node v22.11.0 em win32

No Node não existe window nem document. No lugar, há objetos como process (argumentos, variáveis de ambiente, encerrar o programa) e os módulos do próprio Node: node:fs (arquivos), node:path (caminhos), node:http (servidores), node:crypto...

  • process.argv: os argumentos. Os dois primeiros são o caminho do node e do script; os seus começam no índice 2.
  • process.env: variáveis de ambiente, como process.env.PORT.
  • process.exit(1): encerra com código de erro (0 é sucesso). Scripts de CI usam isso para dizer que algo falhou.

package.json

Todo projeto Node tem um package.json, criado com npm init -y. Ele guarda nome, dependências e scripts: 

{
  "name": "minha-api",
  "type": "module",
  "scripts": {
    "dev": "node --watch servidor.js",
    "start": "node servidor.js",
    "test": "node --test"
  }
}

"type": "module" liga os Módulos ES (import/export), iguais aos do navegador. Sem ele, o Node usa o formato antigo, CommonJS (require e module.exports), que você ainda vai encontrar muito. npm run dev roda o script dev; --watch reinicia o programa a cada arquivo salvo.

A mesma linguagem

Tudo o que não depende do navegador funciona igual nos dois lados. Este código roda no Node e aqui:

<script>
  const vendas = [120, 80, 230, 95];
  const total = vendas.reduce((a, b) => a + b, 0);
  console.log('Total:', total, '| média:', total / vendas.length);
  console.log(new Intl.NumberFormat('pt-BR', { style: 'currency', currency: 'BRL' }).format(total));
</script>
Dica

Use sempre a versão LTS (Long Term Support) do Node em projetos: ela recebe correções por anos. As versões ímpares são experimentais.
