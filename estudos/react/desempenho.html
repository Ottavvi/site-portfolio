Desempenho: memo, useMemo e lazy

Aula · 13 min

Quando o estado de um componente muda, ele e todos os filhos são chamados de novo. Na maioria dos casos isso é rápido e não faz diferença. Otimize só quando medir um problema (a aba Profiler das React DevTools mostra quem desenhou e quanto levou).

memo: não desenhar o filho à toa

memo(Componente) faz o React pular o componente se as props não mudaram. Veja o contador de desenhos: 

import { useState, memo, useRef } from 'react';
import { createRoot } from 'react-dom/client';

function Lista({ itens }) {
  const vezes = useRef(0);
  vezes.current++;
  return <p>Lista com {itens.length} itens (desenhada {vezes.current}×)</p>;
}
const ListaMemo = memo(Lista);

const itens = Array.from({ length: 1000 }, (_, i) => 'Item ' + i);

function App() {
  const [texto, setTexto] = useState('');
  return (
    <>
      <input value={texto} onChange={e => setTexto(e.target.value)} placeholder="Digite aqui" />
      <Lista itens={itens} />
      <ListaMemo itens={itens} />
    </>
  );
}

createRoot(document.getElementById('root')).render(<App />);

A cada tecla, Lista desenha de novo; ListaMemo não, porque itens é o mesmo array.

useMemo e useCallback

O memo compara as props por identidade. Um array, objeto ou função criado dentro do componente é novo a cada desenho, e o memo nunca pula. Os dois hooks guardam o mesmo valor entre desenhos: 

// Recalcula só quando produtos ou busca mudarem (e o resultado mantém a identidade)
const filtrados = useMemo(
  () => produtos.filter(p => p.nome.toLowerCase().includes(busca.toLowerCase())),
  [produtos, busca]
);

// A mesma função entre desenhos, para um filho com memo não desenhar à toa
const remover = useCallback(id => despachar({ tipo: 'remover', id }), []);
Dica

Não espalhe useMemo e useCallback por tudo: eles também custam e deixam o código mais difícil de ler. Use quando um cálculo é caro de verdade ou quando um filho com memo recebe aquele valor.

Listas grandes e carregamento sob demanda

  • Listas com milhares de linhas: desenhe só o que está visível (virtualização, com bibliotecas como TanStack Virtual).
  • key estável em listas: com o índice como key, o React reaproveita os elementos errados ao reordenar.
  • Telas pesadas que nem todo mundo abre: lazy + Suspense carregam o código só quando a tela aparece (o import() dinâmico da trilha de Módulos ES). 
const Relatorios = lazy(() => import('./Relatorios.jsx'));

<Suspense fallback={<p>Carregando…</p>}>
  {mostrarRelatorios && <Relatorios />}
</Suspense>
