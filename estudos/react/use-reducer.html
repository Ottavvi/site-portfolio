useReducer

Aula · 12 min

Quando um componente tem vários useState que mudam juntos e muitas funções que mexem neles (adicionar, remover, aumentar, limpar...), a lógica fica espalhada. O useReducer junta todas as mudanças num lugar: uma função redutora que recebe o estado atual e uma ação, e devolve o estado novo. 

import { useReducer } from 'react';
import { createRoot } from 'react-dom/client';

function placar(estado, acao) {
  switch (acao.tipo) {
    case 'ponto':
      return { ...estado, [acao.time]: estado[acao.time] + acao.valor };
    case 'zerar':
      return { casa: 0, visitante: 0 };
    default:
      throw new Error('Ação desconhecida: ' + acao.tipo);
  }
}

function App() {
  const [estado, despachar] = useReducer(placar, { casa: 0, visitante: 0 });
  return (
    <>
      <h2>Casa {estado.casa} × {estado.visitante} Visitante</h2>
      <button onClick={() => despachar({ tipo: 'ponto', time: 'casa', valor: 1 })}>+1 Casa</button>{' '}
      <button onClick={() => despachar({ tipo: 'ponto', time: 'visitante', valor: 1 })}>+1 Visitante</button>{' '}
      <button onClick={() => despachar({ tipo: 'ponto', time: 'casa', valor: 3 })}>+3 Casa</button>{' '}
      <button onClick={() => despachar({ tipo: 'zerar' })}>Zerar</button>
    </>
  );
}

createRoot(document.getElementById('root')).render(<App />);
  • useReducer(redutor, estadoInicial) devolve o estado e a função despachar (em inglês, dispatch).
  • O componente só diz o que aconteceu ({ tipo: 'ponto', time: 'casa' }); o redutor decide como o estado muda.
  • O redutor é uma função pura: não mexe no estado antigo, não chama APIs, não usa Date.now(). Com a mesma entrada, devolve sempre a mesma saída. Por isso dá para testar sem React nenhum.
Dica

Regra prática: useState para valores independentes e simples (um campo, um booleano de "aberto"); useReducer quando várias ações mexem no mesmo estado ou quando o estado novo depende de regras.

Redutor + contexto

Juntando useReducer com contexto, qualquer componente da árvore pode despachar ações sem receber funções por props, um padrão comum para carrinho, sessão e preferências: 

const CarrinhoContext = createContext(null);

function ProvedorCarrinho({ children }) {
  const [estado, despachar] = useReducer(carrinho, { itens: [] });
  return <CarrinhoContext.Provider value={{ estado, despachar }}>{children}</CarrinhoContext.Provider>;
}

// Em qualquer lugar lá embaixo:
const { despachar } = useContext(CarrinhoContext);
despachar({ tipo: 'adicionar', produto });
