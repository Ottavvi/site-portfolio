Props, listas e condições

Aula · 12 min

Props

Props são os "atributos" de um componente: o jeito de passar dados de fora para dentro. Elas chegam como um objeto, que costuma ser desestruturado: 

import { createRoot } from 'react-dom/client';

function Produto({ nome, preco, emPromocao = false }) {
  return (
    <article style={{ border: '1px solid #ccc', padding: 10, marginBottom: 8, borderRadius: 8 }}>
      <h3>{nome}</h3>
      <p>R$ {preco.toFixed(2).replace('.', ',')}</p>
      {emPromocao && <strong>Promoção!</strong>}
    </article>
  );
}

function App() {
  return (
    <>
      <Produto nome="Café em grãos" preco={62.9} emPromocao />
      <Produto nome="Caneca" preco={34.5} />
    </>
  );
}

createRoot(document.getElementById('root')).render(<App />);

Texto vai entre aspas; números, booleanos, objetos e funções vão entre chaves. Uma prop sem valor (emPromocao) vale true. Props são só de leitura: o componente não muda o que recebeu.

Mostrar ou não

  • {condicao && <Algo />}: mostra só se a condição for verdadeira.
  • {condicao ? <A /> : <B />}: escolhe entre dois.
Dica

Cuidado com {lista.length && ...}: com a lista vazia, o React mostra um "0" na tela. Use {lista.length > 0 && ...}.

Listas com map

Para desenhar uma lista, transforme o array em elementos com map. Cada item precisa de uma key única e estável (em geral o id), que o React usa para saber qual item é qual quando a lista muda: 

import { createRoot } from 'react-dom/client';

const tarefas = [
  { id: 1, titulo: 'Estudar React', feita: true },
  { id: 2, titulo: 'Fazer o desafio', feita: false },
  { id: 3, titulo: 'Publicar no portfólio', feita: false }
];

function Lista({ itens }) {
  if (itens.length === 0) return <p>Nada por aqui.</p>;
  return (
    <ul>
      {itens.map(t => (
        <li key={t.id}>
          {t.feita ? '✔ ' : '○ '}{t.titulo}
        </li>
      ))}
    </ul>
  );
}

createRoot(document.getElementById('root')).render(<Lista itens={tarefas} />);

children

O que você coloca entre a abertura e o fechamento de um componente chega na prop especial children. Ótimo para "molduras" como cartões e modais: 

function Cartao({ titulo, children }) {
  return (
    <section className="cartao">
      <h2>{titulo}</h2>
      {children}
    </section>
  );
}

<Cartao titulo="Resumo">
  <p>Qualquer conteúdo aqui dentro.</p>
</Cartao>

Teste o que aprendeu

  1. Um componente pode alterar as props que recebeu?

  2. Para que serve a key nos itens de uma lista?

  3. O que {itens.length && <Lista />} mostra com a lista vazia?
