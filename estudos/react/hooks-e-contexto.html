Hooks próprios, contexto e projeto

Aula · 13 min

Hooks próprios

Quando a mesma combinação de estado e efeito aparece em vários componentes, ela vira um hook próprio: uma função que começa com use e usa outros hooks. Este guarda o estado no localStorage: 

import { useState, useEffect } from 'react';
import { createRoot } from 'react-dom/client';

function useLocalStorage(chave, inicial) {
  const [valor, setValor] = useState(() => {
    try {
      return JSON.parse(localStorage.getItem(chave)) ?? inicial;
    } catch {
      return inicial;
    }
  });
  useEffect(() => {
    localStorage.setItem(chave, JSON.stringify(valor));
  }, [chave, valor]);
  return [valor, setValor];
}

function App() {
  const [nome, setNome] = useLocalStorage('nome-react', '');
  return (
    <>
      <input value={nome} onChange={e => setNome(e.target.value)} placeholder="Seu nome" />
      <p>Olá, {nome || 'visitante'}! (mude o código: o nome continua aqui)</p>
    </>
  );
}

createRoot(document.getElementById('root')).render(<App />);

Repare no useState(() => ...): passando uma função, a leitura do localStorage acontece só no primeiro desenho, e não a cada atualização.

Contexto

Alguns dados interessam a muitos componentes em níveis diferentes: o tema, a pessoa logada, o idioma. Passar por props em cada nível ("prop drilling") cansa. O contexto deixa qualquer componente abaixo do provedor ler o valor direto: 

import { createContext, useContext, useState } from 'react';
import { createRoot } from 'react-dom/client';

const TemaContext = createContext('claro');

function Botao({ children }) {
  const tema = useContext(TemaContext);
  const estilo = tema === 'escuro' ? { background: '#222', color: '#eee' } : { background: '#eee', color: '#222' };
  return <button style={{ ...estilo, padding: '6px 12px' }}>{children}</button>;
}

function Barra() {
  return <nav><Botao>Início</Botao> <Botao>Perfil</Botao></nav>;
}

function App() {
  const [tema, setTema] = useState('claro');
  return (
    <TemaContext.Provider value={tema}>
      <Barra />
      <p><label><input type="checkbox" onChange={e => setTema(e.target.checked ? 'escuro' : 'claro')} /> Tema escuro</label></p>
    </TemaContext.Provider>
  );
}

createRoot(document.getElementById('root')).render(<App />);
Dica

Contexto não substitui props: use para dados realmente globais. Para o resto, props deixam claro de onde cada dado vem.

Um projeto de verdade

Fora deste editor, um app React começa assim:

npm create vite@latest meu-app -- --template react
cd meu-app
npm install
npm run dev          # servidor de desenvolvimento com recarga automática
npm run build        # gera a pasta dist/ para publicar

Cada componente costuma ir no seu arquivo (src/components/Cartao.jsx), exportado e importado com Módulos ES. Para várias páginas com URLs próprias, a biblioteca mais usada é o React Router: 

import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

<BrowserRouter>
  <nav><Link to="/">Início</Link> <Link to="/pedidos">Pedidos</Link></nav>
  <Routes>
    <Route path="/" element={<Inicio />} />
    <Route path="/pedidos" element={<Pedidos />} />
    <Route path="/pedidos/:id" element={<DetalhePedido />} />
  </Routes>
</BrowserRouter>
