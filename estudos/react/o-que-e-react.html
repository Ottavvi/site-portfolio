Componentes e JSX

Aula · 10 min

Em JavaScript puro, você muda a tela passo a passo: acha o elemento, troca o texto, cria um <li>, remove outro. Quando a interface cresce, fica difícil lembrar de atualizar todos os lugares. No React, você descreve como a tela deve ficar para cada situação, e ele descobre o que mudar.

Componentes

Um componente é uma função que devolve o que deve aparecer. O nome começa com maiúscula, e ele é usado como uma tag: 

import { createRoot } from 'react-dom/client';

function Saudacao() {
  return <h1>Olá, React!</h1>;
}

function App() {
  return (
    <main>
      <Saudacao />
      <p>Este parágrafo veio de um componente.</p>
    </main>
  );
}

createRoot(document.getElementById('root')).render(<App />);

A última linha é como todo app React começa: pega um elemento da página (aqui, o #root que o editor já tem) e desenha o componente principal dentro dele. Num projeto criado com Vite (npm create vite@latest), esse código fica no arquivo main.jsx.

JSX

Aquele HTML dentro do JavaScript se chama JSX. Ele vira chamadas de função antes de rodar. Parece HTML, mas tem regras próprias:

  • className em vez de class e htmlFor em vez de for.
  • Toda tag precisa fechar: <img />, <br />, <input />.
  • Um componente devolve um elemento. Para devolver vários sem criar uma div à toa, use o fragmento <>...</>.
  • Entre { } vai qualquer expressão JavaScript: variáveis, contas, chamadas de função.
  • style recebe um objeto: style={{ color: 'teal', fontSize: 20 }}.
import { createRoot } from 'react-dom/client';

function Perfil() {
  const nome = 'Ana';
  const anoAtual = 2026;
  return (
    <>
      <h2 className="titulo" style={{ color: 'teal' }}>{nome.toUpperCase()}</h2>
      <p>Programando desde {anoAtual - 3}, há {3} anos.</p>
      <img src="https://picsum.photos/seed/ana/120" alt="Foto de Ana" width="120" />
    </>
  );
}

createRoot(document.getElementById('root')).render(<Perfil />);
Dica

Se aparecer um erro no console, leia a mensagem: o Babel aponta a linha e a coluna do problema no JSX. O mais comum é esquecer de fechar uma tag.
