Estado com useState

Aula · 13 min

Estado é o dado que muda enquanto a pessoa usa a tela: o número do contador, os itens do carrinho, se o menu está aberto. Quando o estado muda, o React chama o componente de novo e atualiza só o que ficou diferente.

useState

import { useState } from 'react';
import { createRoot } from 'react-dom/client';

function Contador() {
  const [valor, setValor] = useState(0);

  return (
    <div>
      <p>Você clicou {valor} vez(es).</p>
      <button onClick={() => setValor(valor + 1)}>+1</button>
      <button onClick={() => setValor(0)} disabled={valor === 0}>Zerar</button>
    </div>
  );
}

createRoot(document.getElementById('root')).render(<Contador />);

useState(0) devolve um par: o valor atual e a função que troca o valor. Funções que começam com use são hooks, e só podem ser chamadas no topo do componente (nunca dentro de if ou laços).

Os eventos são props como onClick, onChange e onSubmit, e recebem uma função. Escreva onClick={() => setValor(0)}, não onClick={setValor(0)}, que executaria na hora de desenhar.

Não mude o estado direto

Para o React perceber a mudança, o estado é trocado por um valor novo. Com arrays e objetos, isso quer dizer criar cópias: 

import { useState } from 'react';
import { createRoot } from 'react-dom/client';

function Carrinho() {
  const [itens, setItens] = useState([{ id: 1, nome: 'Café', qtd: 1 }]);

  const adicionar = () =>
    setItens([...itens, { id: Date.now(), nome: 'Item ' + (itens.length + 1), qtd: 1 }]);

  const aumentar = id =>
    setItens(itens.map(i => (i.id === id ? { ...i, qtd: i.qtd + 1 } : i)));

  const remover = id => setItens(itens.filter(i => i.id !== id));

  return (
    <>
      <ul>
        {itens.map(i => (
          <li key={i.id}>
            {i.nome} × {i.qtd}{' '}
            <button onClick={() => aumentar(i.id)}>+</button>{' '}
            <button onClick={() => remover(i.id)}>remover</button>
          </li>
        ))}
      </ul>
      <button onClick={adicionar}>Adicionar item</button>
    </>
  );
}

createRoot(document.getElementById('root')).render(<Carrinho />);

itens.push(...) mudaria o array antigo e a tela não atualizaria. Os padrões são: [...lista, novo] para adicionar, map para alterar um, filter para remover e { ...objeto, campo: valor } para objetos.

Dica

Se o novo valor depende do anterior, use a forma com função: setValor(v => v + 1). Ela garante que você soma sobre o valor mais recente, mesmo com várias atualizações seguidas.
