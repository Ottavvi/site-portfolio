Formulários e estado compartilhado

Aula · 12 min

Campos controlados

Num campo controlado, o valor vem do estado (value) e cada tecla atualiza o estado (onChange). Assim o React sempre sabe o que está escrito, e dá para validar e formatar enquanto a pessoa digita: 

import { useState } from 'react';
import { createRoot } from 'react-dom/client';

function Cadastro() {
  const [nome, setNome] = useState('');
  const [email, setEmail] = useState('');
  const [enviado, setEnviado] = useState(null);
  const emailValido = email.includes('@');

  function enviar(evento) {
    evento.preventDefault();
    setEnviado({ nome, email });
    setNome('');
    setEmail('');
  }

  return (
    <form onSubmit={enviar}>
      <label htmlFor="nome">Nome</label>
      <input id="nome" value={nome} onChange={e => setNome(e.target.value)} />
      <label htmlFor="email">E-mail</label>
      <input id="email" value={email} onChange={e => setEmail(e.target.value)} />
      {email && !emailValido && <p style={{ color: 'crimson' }}>Falta o @.</p>}
      <button disabled={!nome || !emailValido}>Cadastrar</button>
      {enviado && <p>Cadastrado: {enviado.nome} ({enviado.email})</p>}
    </form>
  );
}

createRoot(document.getElementById('root')).render(<Cadastro />);

Levantar o estado

Quando dois componentes precisam do mesmo dado, ele sobe para o pai mais próximo dos dois. O pai guarda o estado e passa para baixo: o valor por props e as mudanças por funções: 

import { useState } from 'react';
import { createRoot } from 'react-dom/client';

function Busca({ texto, aoMudar }) {
  return <input placeholder="Buscar sabor" value={texto} onChange={e => aoMudar(e.target.value)} />;
}

function Resultados({ sabores, texto }) {
  const achados = sabores.filter(s => s.toLowerCase().includes(texto.toLowerCase()));
  return <p>{achados.length} encontrado(s): {achados.join(', ')}</p>;
}

function App() {
  const [texto, setTexto] = useState('');
  const sabores = ['Café', 'Caramelo', 'Chocolate', 'Baunilha', 'Canela'];
  return (
    <>
      <Busca texto={texto} aoMudar={setTexto} />
      <Resultados sabores={sabores} texto={texto} />
    </>
  );
}

createRoot(document.getElementById('root')).render(<App />);

Repare que a lista filtrada não é estado: ela é calculada a partir do texto e dos sabores a cada desenho. Guardar em estado algo que dá para calcular é a origem de muitos bugs (os dois ficam fora de sincronia).

Dica

Para formulários grandes, bibliotecas como React Hook Form evitam escrever um useState por campo. Mas o padrão de campo controlado continua sendo a base.
