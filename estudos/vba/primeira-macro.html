O editor e a primeira macro

Aula · 9 min

VBA (Visual Basic for Applications) é a linguagem de automação do Office. No Excel, ela faz em um clique o que você faria em vinte minutos: formatar um relatório, separar uma planilha em várias, juntar arquivos de uma pasta, mandar e-mails.

Preparar o Excel

  1. Mostre a guia Desenvolvedor: Arquivo, Opções, Personalizar Faixa de Opções, marque Desenvolvedor.
  2. Abra o editor com Alt+F11.
  3. No editor: Inserir, Módulo. É ali que o código fica.
  4. Salve a pasta como Pasta de Trabalho Habilitada para Macro (.xlsm). Um .xlsx descarta as macros ao salvar.

A primeira macro

Sub Ola()
    MsgBox "Olá! Hoje é " & Format(Date, "dd/mm/yyyy")
    Range("A1").Value = "Relatório gerado em " & Now
End Sub

Clique dentro do Sub e aperte F5. Uma macro é um Sub: começa com Sub Nome() e termina com End Sub. O & junta textos. Comentários começam com aspas simples (').

Gravar para aprender

Desenvolvedor, Gravar Macro, faça algo à mão (negrito, cor, largura de coluna), Parar Gravação. Depois veja o código no editor. O gravador escreve código cheio de Select e repetições, mas é ótimo para descobrir o nome de uma propriedade.

Dica

Macros não têm Ctrl+Z: o que elas fazem não se desfaz. Teste numa cópia da planilha até confiar no código.

Teste o que aprendeu

  1. Em que formato salvar uma pasta com macros?

  2. Qual atalho abre o editor do VBA?

  3. Dá para desfazer com Ctrl+Z o que uma macro fez?
