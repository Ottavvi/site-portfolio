Células, variáveis e laços

Aula · 12 min

Falar com as células

Range("A1").Value = "Produto"
Range("A1:D1").Font.Bold = True
Cells(2, 1).Value = "Café"          ' linha 2, coluna 1 (= A2)
Range("C2").Formula = "=A2*B2"      ' fórmula em inglês, com vírgula
Range("C2").FormulaLocal = "=A2*B2" ' fórmula em português, com ponto e vírgula
Worksheets("Vendas").Range("A1").Value = "Título"
Columns("A:D").AutoFit

Variáveis

Option Explicit   ' no topo do módulo: obriga declarar as variáveis

Sub Exemplo()
    Dim nome As String
    Dim quantidade As Long      ' use Long, não Integer (que vai só até 32.767)
    Dim preco As Double
    Dim hoje As Date
    Dim ws As Worksheet

    Set ws = ThisWorkbook.Worksheets("Vendas")   ' objetos usam Set
    nome = ws.Range("A2").Value
End Sub
Dica

Coloque Option Explicit no topo de todo módulo (ou marque em Ferramentas, Opções, "Requerer declaração de variável"). Sem ele, um erro de digitação no nome de uma variável cria uma variável nova vazia, e o bug fica invisível.

A última linha com dados

Dim ultima As Long
ultima = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row

É como ir na última linha da planilha e apertar Ctrl+↑. Assim a macro funciona com 10 ou 10 mil linhas.

Decisões e laços

Dim i As Long
For i = 2 To ultima
    If ws.Cells(i, "D").Value > 1000 Then
        ws.Cells(i, "D").Interior.Color = RGB(198, 239, 206)
    ElseIf ws.Cells(i, "D").Value = 0 Then
        ws.Cells(i, "D").Interior.Color = RGB(255, 199, 206)
    End If
Next i

Dim celula As Range
For Each celula In ws.Range("B2:B" & ultima)
    celula.Value = Trim(celula.Value)
Next celula
