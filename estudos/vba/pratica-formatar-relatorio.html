Prática: formatar um relatório

Aula · 20 min

Cole numa planilha chamada Vendas, a partir de A1:

Data Vendedor Produto Valor
01/10/2026 Ana Café 850
01/10/2026 Bruno Arroz 1200
02/10/2026 Carla Feijão 0
03/10/2026 Ana Açúcar 430
03/10/2026 Bruno Café 1560

Tarefas

Escreva uma macro FormatarRelatorio que:

  1. Deixe o cabeçalho em negrito, com fundo escuro e letra branca.
  2. Formate a coluna D como moeda (R$ #.##0,00).
  3. Pinte de verde os valores acima de 1.000 e de vermelho os zerados.
  4. Escreva "Total" e a soma na linha logo abaixo dos dados.
  5. Ajuste a largura das colunas. Funcione com qualquer número de linhas.
  6. Crie um botão (Desenvolvedor, Inserir, Botão) ligado à macro.
Ver a resposta 
Option Explicit

Sub FormatarRelatorio()
    Dim ws As Worksheet, ultima As Long, i As Long
    Set ws = ThisWorkbook.Worksheets("Vendas")
    ultima = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row

    With ws.Range("A1:D1")
        .Font.Bold = True
        .Font.Color = vbWhite
        .Interior.Color = RGB(31, 56, 100)
    End With

    ws.Range("D2:D" & ultima + 1).NumberFormat = "R$ #,##0.00"

    For i = 2 To ultima
        Select Case ws.Cells(i, "D").Value
            Case Is > 1000: ws.Cells(i, "D").Interior.Color = RGB(198, 239, 206)
            Case 0: ws.Cells(i, "D").Interior.Color = RGB(255, 199, 206)
            Case Else: ws.Cells(i, "D").Interior.ColorIndex = xlNone
        End Select
    Next i

    ws.Cells(ultima + 1, "C").Value = "Total"
    ws.Cells(ultima + 1, "D").Formula = "=SUM(D2:D" & ultima & ")"
    ws.Range("C" & ultima + 1 & ":D" & ultima + 1).Font.Bold = True

    ws.Columns("A:D").AutoFit
End Sub

O With evita repetir o mesmo objeto. No NumberFormat e no Formula, o VBA usa o padrão americano (vírgula de milhar, ponto decimal, SUM); o Excel mostra no formato brasileiro. Rodar a macro duas vezes escreve o total uma linha abaixo: um bom exercício extra é apagar o total antigo antes.
