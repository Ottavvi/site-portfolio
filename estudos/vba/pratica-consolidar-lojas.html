Prática: consolidar arquivos de lojas

Aula · 30 min

Crie uma pasta Lojas ao lado do seu .xlsm com três arquivos (Centro.xlsx, Praia.xlsx, Shopping.xlsx), cada um com cabeçalho Data, Produto, Valor e algumas linhas.

Tarefas

  1. Crie (ou limpe) a aba Consolidado com o cabeçalho Loja, Data, Produto, Valor.
  2. Para cada arquivo da pasta, copie as linhas de dados (sem o cabeçalho), com o nome da loja (nome do arquivo sem extensão) na primeira coluna.
  3. Feche cada arquivo sem salvar. Não use Copy/Paste.
  4. No fim, mostre quantas linhas e quantos arquivos foram juntados.
  5. Se a pasta não existir, avise e pare.

Option Explicit

Sub ConsolidarLojas()
    Dim pasta As String, arquivo As String
    Dim wb As Workbook, origem As Worksheet, destino As Worksheet
    Dim ultima As Long, linhas As Long, proxima As Long, arquivos As Long

    pasta = ThisWorkbook.Path & "\Lojas\"
    If Dir(pasta, vbDirectory) = "" Then
        MsgBox "Pasta não encontrada: " & pasta, vbExclamation
        Exit Sub
    End If

    On Error Resume Next
    Set destino = ThisWorkbook.Worksheets("Consolidado")
    On Error GoTo 0
    If destino Is Nothing Then
        Set destino = ThisWorkbook.Worksheets.Add
        destino.Name = "Consolidado"
    End If
    destino.Cells.Clear
    destino.Range("A1:D1").Value = Array("Loja", "Data", "Produto", "Valor")
    proxima = 2

    Application.ScreenUpdating = False
    arquivo = Dir(pasta & "*.xlsx")
    Do While arquivo <> ""
        Set wb = Workbooks.Open(pasta & arquivo, ReadOnly:=True)
        Set origem = wb.Worksheets(1)
        ultima = origem.Cells(origem.Rows.Count, "A").End(xlUp).Row
        If ultima >= 2 Then
            linhas = ultima - 1
            destino.Cells(proxima, "A").Resize(linhas, 1).Value = Left(arquivo, InStrRev(arquivo, ".") - 1)
            destino.Cells(proxima, "B").Resize(linhas, 3).Value = origem.Range("A2:C" & ultima).Value
            proxima = proxima + linhas
        End If
        wb.Close SaveChanges:=False
        arquivos = arquivos + 1
        arquivo = Dir()
    Loop
    Application.ScreenUpdating = True

    destino.Columns("A:D").AutoFit
    MsgBox proxima - 2 & " linhas de " & arquivos & " arquivos.", vbInformation
End Sub

Atribuir um único valor a um intervalo com Resize preenche todas as células (o nome da loja em todas as linhas). Array(...) escreve o cabeçalho de uma vez.
