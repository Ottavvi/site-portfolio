Funções próprias, arrays e erros

Aula · 13 min

Funções que viram fórmulas

Function DIAS_UTEIS_BR(inicio As Date, fim As Date) As Long
    DIAS_UTEIS_BR = Application.WorksheetFunction.NetworkDays(inicio, fim)
End Function

Function SEM_ACENTO(texto As String) As String
    Dim de As String, para As String, i As Long
    de = "áàâãéêíóôõúçÁÀÂÃÉÊÍÓÔÕÚÇ"
    para = "aaaaeeiooouc" & "AAAAEEIOOOUC"
    For i = 1 To Len(de)
        texto = Replace(texto, Mid(de, i, 1), Mid(para, i, 1))
    Next i
    SEM_ACENTO = texto
End Function

Uma Function num módulo aparece no Excel como fórmula: =SEM_ACENTO(A2). O valor de retorno é atribuído ao próprio nome da função.

Arrays: ler tudo de uma vez

Ler e escrever célula por célula é lento. O truque é trazer o intervalo inteiro para a memória, trabalhar no array e devolver de uma vez: 

Dim dados As Variant, i As Long
dados = ws.Range("A2:D" & ultima).Value     ' array 2D: dados(linha, coluna), começa em 1
For i = 1 To UBound(dados, 1)
    dados(i, 4) = dados(i, 4) * 1.1          ' reajuste de 10%
Next i
ws.Range("A2:D" & ultima).Value = dados

Em 50 mil linhas, isso leva menos de um segundo; o laço célula a célula pode levar minutos.

Tratar erros

Sub AbrirRelatorio()
    On Error GoTo Falhou
    Workbooks.Open ThisWorkbook.Path & "\relatorio.xlsx"
    Exit Sub
Falhou:
    MsgBox "Não consegui abrir: " & Err.Description, vbExclamation
End Sub

' Para um teste pontual
On Error Resume Next
Set ws = ThisWorkbook.Worksheets("Resumo")
On Error GoTo 0           ' volta ao normal logo depois
If ws Is Nothing Then Set ws = ThisWorkbook.Worksheets.Add
Dica

On Error Resume Next sozinho no topo da macro esconde todos os erros, e ela "funciona" fazendo coisa errada. Use só em volta da linha que pode falhar e desligue com On Error GoTo 0.
