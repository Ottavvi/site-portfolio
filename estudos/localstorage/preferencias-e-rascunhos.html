Preferências e rascunhos

Aula · 11 min

Lembrar uma preferência

O padrão é sempre o mesmo: ao abrir, ler e aplicar; ao mudar, salvar.

<style>
  body.escuro { background: #111; color: #eee; }
</style>
<label><input type="checkbox" id="escuro"> Tema escuro</label>

<script>
  const caixa = document.querySelector('#escuro');
  const aplicar = ligado => {
    document.body.classList.toggle('escuro', ligado);
    caixa.checked = ligado;
  };

  aplicar(localStorage.getItem('tema') === 'escuro');

  caixa.addEventListener('change', () => {
    localStorage.setItem('tema', caixa.checked ? 'escuro' : 'claro');
    aplicar(caixa.checked);
  });
</script>
Dica

Para o tema não "piscar" ao carregar, sites reais aplicam a preferência num script pequeno dentro do <head>, antes de o corpo ser desenhado. Este site faz exatamente isso.

Rascunho automático

Quem já perdeu uma mensagem longa ao fechar a aba sem querer sabe o valor disso. Salve a cada digitação e restaure ao abrir: 

<label for="msg">Mensagem</label>
<textarea id="msg" rows="4" cols="40"></textarea>
<p><small id="status"></small></p>

<script>
  const campo = document.querySelector('#msg');
  campo.value = localStorage.getItem('rascunho') ?? '';

  campo.addEventListener('input', () => {
    localStorage.setItem('rascunho', campo.value);
    document.querySelector('#status').textContent = 'Rascunho salvo';
  });
</script>

Escreva algo, depois mude o código (adicione um espaço): o texto volta. Num formulário de verdade, apague o rascunho com removeItem quando a mensagem for enviada.

sessionStorage

Tem os mesmos métodos, mas os dados duram só enquanto a aba estiver aberta, e cada aba tem o seu. Serve para coisas como o passo atual de um formulário longo.

Sincronizar abas

Quando uma aba muda o localStorage, as outras abas do mesmo site recebem o evento storage. Dá para manter o carrinho igual em todas: 

window.addEventListener('storage', evento => {
  if (evento.key === 'carrinho') {
    desenharCarrinho(JSON.parse(evento.newValue ?? '[]'));
  }
});
