Backup, cota e persistência

Aula · 11 min

Dados que vivem só no navegador podem sumir: a pessoa limpa os dados do site, troca de computador, ou o navegador apaga para liberar espaço. Um app que guarda coisas importantes no navegador deve oferecer backup.

Baixar um arquivo

<button id="baixar">Baixar backup</button>
<script>
  localStorage.setItem('app:tarefas', JSON.stringify(['Estudar', 'Treinar']));
  localStorage.setItem('app:tema', 'escuro');

  document.querySelector('#baixar').addEventListener('click', () => {
    const dados = {};
    for (let i = 0; i < localStorage.length; i++) {
      const chave = localStorage.key(i);
      if (chave.startsWith('app:')) dados[chave] = localStorage.getItem(chave);
    }
    const arquivo = new Blob([JSON.stringify({ versao: 1, dados }, null, 2)], { type: 'application/json' });
    const link = document.createElement('a');
    link.href = URL.createObjectURL(arquivo);
    link.download = 'backup-' + new Date().toISOString().slice(0, 10) + '.json';
    link.click();
    URL.revokeObjectURL(link.href);
  });
</script>

Restaurar

Um <input type="file"> entrega o arquivo escolhido, e await arquivo.text() lê o conteúdo. Valide antes de gravar: o arquivo pode ser de outro app, de outra versão, ou ter sido editado à mão. 

entrada.addEventListener('change', async () => {
  const arquivo = entrada.files[0];
  if (!arquivo) return;
  try {
    const backup = JSON.parse(await arquivo.text());
    if (backup.versao !== 1 || typeof backup.dados !== 'object') throw new Error('Formato desconhecido');
    for (const [chave, valor] of Object.entries(backup.dados)) {
      if (chave.startsWith('app:')) localStorage.setItem(chave, valor);
    }
    location.reload();
  } catch (erro) {
    alert('Este arquivo não é um backup válido: ' + erro.message);
  }
});

Quanto espaço há, e pedir para não apagar

<p id="saida">Calculando…</p>
<script>
  (async () => {
    if (!navigator.storage?.estimate) {
      document.querySelector('#saida').textContent = 'Este navegador não informa a cota.';
      return;
    }
    const { usage, quota } = await navigator.storage.estimate();
    const mb = n => (n / 1024 / 1024).toFixed(1) + ' MB';
    const persistente = await navigator.storage.persisted();
    document.querySelector('#saida').textContent =
      `Usado: ${mb(usage)} de ${mb(quota)}. Armazenamento persistente: ${persistente ? 'sim' : 'não'}.`;
  })();
</script>

Por padrão, o armazenamento é "melhor esforço": se o disco encher, o navegador pode apagar dados dos sites menos usados. navigator.storage.persist() pede para ele não fazer isso. Alguns navegadores concedem sozinhos para sites instalados ou muito usados; outros perguntam à pessoa.

Dica

O app de finanças e o de ordens de serviço deste portfólio guardam tudo no navegador e têm botões de exportar e restaurar backup, exatamente por esse motivo.
