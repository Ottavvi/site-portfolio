Guardar objetos e listas com JSON

Aula · 9 min

Para guardar um objeto ou uma lista, transforme em texto com JSON.stringify e, na leitura, de volta com JSON.parse: 

<script>
  const preferencias = { tema: 'escuro', fonte: 18, avisos: true };
  localStorage.setItem('preferencias', JSON.stringify(preferencias));

  const lidas = JSON.parse(localStorage.getItem('preferencias'));
  console.log(lidas.tema, lidas.fonte + 2, typeof lidas.avisos);
</script>

Um valor padrão para a primeira visita

Na primeira visita, a chave não existe e getItem devolve null. Combine com ?? para ter um padrão: 

<ul id="lista"></ul>

<script>
  const tarefas = JSON.parse(localStorage.getItem('tarefas-exemplo') ?? '[]');
  tarefas.push('Tarefa ' + (tarefas.length + 1));
  localStorage.setItem('tarefas-exemplo', JSON.stringify(tarefas));

  for (const t of tarefas) {
    const li = document.createElement('li');
    li.textContent = t;
    document.querySelector('#lista').append(li);
  }
</script>

Nunca confie no que está salvo

A pessoa pode editar o localStorage pelas ferramentas de desenvolvedor, uma versão antiga do seu site pode ter salvo outro formato, ou o navegador pode bloquear o acesso (algumas abas anônimas fazem isso). Ler com try/catch evita que um texto inválido quebre a página inteira: 

<script>
  function ler(chave, padrao) {
    try {
      const texto = localStorage.getItem(chave);
      return texto === null ? padrao : JSON.parse(texto);
    } catch {
      return padrao;
    }
  }

  localStorage.setItem('quebrado', '{isso não é json');
  console.log(ler('quebrado', { ok: false }));
  console.log(ler('nao-existe', []));
</script>
Dica

Date não sobrevive ao JSON: vira texto. Guarde a data como texto ISO (data.toISOString()) ou como número (Date.now()) e recrie com new Date(valor) na leitura.

  1. O que localStorage.setItem("x", { a: 1 }) guarda?

  2. Por que ler com try/catch?

  3. Qual o resultado de JSON.parse(null ?? "[]")?
