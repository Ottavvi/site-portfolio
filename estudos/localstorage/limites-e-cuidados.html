Limites, segurança e alternativas

Aula · 12 min

Limites

  • Espaço: em geral, cerca de 5 MB por site. Passar disso lança QuotaExceededError no setItem.
  • Síncrono: cada leitura e escrita trava a página até terminar. Para poucos dados, é imperceptível; para muitos, a página engasga.
  • Pode não existir: em alguns modos privados ou com cookies bloqueados, acessar o localStorage lança erro. Envolva em try/catch.

O que nunca guardar

Qualquer script que rode na página consegue ler o localStorage inteiro. Se o site tiver uma falha de XSS (um script malicioso injetado), tudo o que estiver lá pode ser roubado. Por isso:

  • Não guarde senhas, números de cartão ou documentos.
  • Tokens de sessão ficam mais protegidos em cookies HttpOnly, que o JavaScript não consegue ler.
  • Lembre que em computadores compartilhados o próximo usuário vê o que ficou salvo.

Versão dos dados

Seu app muda e o formato salvo muda junto. Guardar uma versão permite converter dados antigos em vez de quebrar: 

<script>
  // Simula um dado salvo por uma versão antiga do site: só uma lista de textos
  localStorage.setItem('app-dados', JSON.stringify(['Comprar pão']));

  function carregar() {
    const bruto = JSON.parse(localStorage.getItem('app-dados') ?? 'null');
    if (bruto === null) return { versao: 2, tarefas: [] };
    if (Array.isArray(bruto)) {
      // versão 1 → 2: cada tarefa vira um objeto
      return { versao: 2, tarefas: bruto.map(titulo => ({ titulo, feita: false })) };
    }
    return bruto;
  }

  const dados = carregar();
  localStorage.setItem('app-dados', JSON.stringify(dados));
  console.log(dados);
</script>

Quando usar outra coisa

  • IndexedDB: banco de dados do navegador, assíncrono, com espaço muito maior. Bom para apps offline com muitos registros ou arquivos. A API é verbosa; bibliotecas pequenas como idb-keyval deixam com cara de localStorage.
  • Cache Storage: para guardar respostas de rede (arquivos do site), usado pelos service workers. Aparece na trilha de PWA.
  • Um servidor: quando os dados precisam acompanhar a pessoa em outros aparelhos ou não podem se perder.
Dica

Uma ideia que aparece no próximo desafio: o localStorage não tem validade. Se o dado deve expirar (um cache de cotação, por exemplo), guarde junto o momento em que expira e confira na leitura.
