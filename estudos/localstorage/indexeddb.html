IndexedDB

Aula · 13 min

Quando o localStorage aperta (muitos registros, arquivos, buscas por campo), o próximo passo é o IndexedDB: um banco de dados dentro do navegador. Ele guarda objetos de verdade (não só texto), arquivos (Blob), tem índices para buscar e é assíncrono, então não trava a página.

As peças

  • Banco: aberto com indexedDB.open(nome, versao).
  • Object store: o equivalente a uma tabela. É criado no evento upgradeneeded, que roda quando a versão do banco muda.
  • Transação: toda leitura e escrita acontece dentro de uma, que é readonly ou readwrite.
  • Índice: permite buscar por outro campo além da chave.

A API original usa eventos (onsuccess, onerror) e é verbosa. Um pequeno embrulho em Promises deixa tudo com cara de await: 

<ul id="lista"></ul>
<script>
  const pedido = req => new Promise((ok, erro) => {
    req.onsuccess = () => ok(req.result);
    req.onerror = () => erro(req.error);
  });

  function abrir() {
    const req = indexedDB.open('exemplo-anotacoes', 1);
    req.onupgradeneeded = () => {
      const store = req.result.createObjectStore('notas', { keyPath: 'id', autoIncrement: true });
      store.createIndex('porTag', 'tag');
    };
    return pedido(req);
  }

  (async () => {
    const db = await abrir();

    const escrever = db.transaction('notas', 'readwrite').objectStore('notas');
    await pedido(escrever.add({ texto: 'Comprar café', tag: 'casa', criada: new Date() }));
    await pedido(escrever.add({ texto: 'Revisar o PR', tag: 'trabalho', criada: new Date() }));

    const ler = db.transaction('notas').objectStore('notas');
    const todas = await pedido(ler.getAll());
    const deCasa = await pedido(ler.index('porTag').getAll('casa'));
    console.log(todas.length, 'nota(s) no total;', deCasa.length, 'de casa');
    console.log('A data voltou como Date?', todas[0].criada instanceof Date);

    document.querySelector('#lista').innerHTML = todas.map(n => '<li>' + n.texto + ' (' + n.tag + ')</li>').join('');
    db.close();
  })().catch(e => console.error(e.message));
</script>

Repare que a data volta como Date: o IndexedDB guarda objetos sem passar por JSON. Cada vez que o código roda, duas notas novas são acrescentadas, porque o banco persiste.

Dica

Para uso simples, a biblioteca idb-keyval (menos de 1 KB) dá ao IndexedDB a cara do localStorage: await set("chave", valor) e await get("chave"). A biblioteca idb, do mesmo autor, embrulha a API completa em Promises.

Mudanças de versão

Para criar um store ou um índice novo, aumente a versão no open. O upgradeneeded recebe event.oldVersion, e você aplica só os passos que faltam (de 1 para 2, de 2 para 3...), como migrações de banco de dados.
