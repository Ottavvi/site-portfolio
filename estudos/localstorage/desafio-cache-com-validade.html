Desafio: cache com validade

Desafio · 20 min

Escreva duas funções para guardar dados com prazo de validade (como a cotação do dólar, que fica velha depois de alguns minutos):

  • salvarComValidade(chave, valor, minutos): guarda o valor (qualquer coisa que vire JSON) e o momento em que ele expira.
  • lerComValidade(chave): devolve o valor se ainda estiver válido. Se expirou, apaga a chave e devolve null. Se não existe ou o texto salvo for inválido, devolve null.

Use Date.now() para saber a hora: os testes "adiantam o relógio" trocando essa função.

O que o código precisa ter

  • Um valor recém-salvo é lido de volta (objetos inclusive)
  • Depois do prazo, devolve null e apaga a chave
  • Chave inexistente ou texto inválido devolvem null
Ver uma solução possível 
<script>
  function salvarComValidade(chave, valor, minutos) {
    const expira = Date.now() + minutos * 60 * 1000;
    localStorage.setItem(chave, JSON.stringify({ valor, expira }));
  }

  function lerComValidade(chave) {
    try {
      const salvo = JSON.parse(localStorage.getItem(chave));
      if (!salvo) return null;
      if (Date.now() > salvo.expira) {
        localStorage.removeItem(chave);
        return null;
      }
      return salvo.valor;
    } catch {
      return null;
    }
  }

  salvarComValidade('cotacao', { dolar: 5.42 }, 10);
  console.log(lerComValidade('cotacao'));
</script>
