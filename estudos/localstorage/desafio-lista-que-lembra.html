Desafio: lista de compras que lembra

Desafio · 20 min

A lista de compras funciona, mas esquece tudo ao recarregar. Faça ela lembrar:

  • ao adicionar um item, salve a lista inteira na chave compras, como um array JSON de textos;
  • ao abrir a página, mostre os itens salvos em compras (se não houver nada, a lista começa vazia);
  • o botão #limpar esvazia a lista na tela e apaga a chave.

Um dos testes abre uma cópia da página com itens já salvos, para conferir que eles aparecem.

O que o código precisa ter

  • Adicionar um item salva a lista em compras como JSON
  • Ao abrir, a página mostra os itens salvos
  • Limpar esvazia a tela e apaga a chave compras
Ver uma solução possível 
<form id="form">
  <label for="item">Item</label>
  <input id="item" required>
  <button>Adicionar</button>
</form>
<ul id="lista"></ul>
<button id="limpar" type="button">Limpar lista</button>

<script>
  const CHAVE = 'compras';
  const lista = document.querySelector('#lista');
  const campo = document.querySelector('#item');

  function carregar() {
    try {
      return JSON.parse(localStorage.getItem(CHAVE) ?? '[]');
    } catch {
      return [];
    }
  }

  let itens = carregar();

  function desenhar() {
    lista.replaceChildren(...itens.map(texto => {
      const li = document.createElement('li');
      li.textContent = texto;
      return li;
    }));
  }

  document.querySelector('#form').addEventListener('submit', evento => {
    evento.preventDefault();
    itens.push(campo.value.trim());
    localStorage.setItem(CHAVE, JSON.stringify(itens));
    campo.value = '';
    desenhar();
  });

  document.querySelector('#limpar').addEventListener('click', () => {
    itens = [];
    localStorage.removeItem(CHAVE);
    desenhar();
  });

  desenhar();
</script>
