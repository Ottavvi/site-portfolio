Guardar e ler

Aula · 8 min

O localStorage é um pequeno armário de chaves e valores que cada site tem no navegador. O que você guarda lá continua salvo depois de recarregar a página, fechar a aba ou desligar o computador. É perfeito para preferências (tema, idioma), rascunhos e listas simples.

Os quatro métodos

<p id="saida"></p>

<script>
  localStorage.setItem('nome', 'Ana');          // guarda
  const nome = localStorage.getItem('nome');      // lê
  localStorage.removeItem('apelido');             // apaga uma chave
  console.log(localStorage.getItem('apelido'));   // null: a chave não existe

  document.querySelector('#saida').textContent = 'Olá, ' + nome;
</script>

Para apagar tudo do site, existe localStorage.clear(). Use com cuidado: apaga também o que outras partes do site guardaram.

Ele lembra de verdade

O editor roda o código de novo a cada mudança. Este contador de visitas aumenta toda vez: edite qualquer coisa (um espaço basta) e veja. 

<p id="saida"></p>

<script>
  const visitas = Number(localStorage.getItem('visitas') || 0) + 1;
  localStorage.setItem('visitas', visitas);
  document.querySelector('#saida').textContent = `Você já rodou este código ${visitas} vez(es).`;
</script>

Só guarda texto

Tudo o que entra vira texto. O número 5 volta como '5', e por isso o exemplo acima usa Number(). Objetos viram o inútil '[object Object]'; a próxima aula mostra como resolver.

Dica

Para ver o que está salvo, abra as ferramentas de desenvolvedor (F12), aba Application (ou Armazenamento), item Local Storage. Dá para editar e apagar chaves por lá.

De quem é cada armário

Cada origem (protocolo + domínio + porta) tem o seu localStorage. O https://meusite.com não lê o que o https://outrosite.com guardou. Os dados ficam só naquele navegador, naquele aparelho: não vão para o servidor, nem para o celular da pessoa.

Teste o que aprendeu

  1. O que getItem devolve para uma chave que não existe?

  2. Você guarda setItem("total", 10). O que getItem("total") devolve?

  3. Os dados do localStorage aparecem em outro computador da mesma pessoa?

Seu progresso fica salvo neste navegador.
